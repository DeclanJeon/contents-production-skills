# Sources: scope read, claims adopted, verification limits

These citations back **external model descriptions and research findings** only. The skill's packet structure, execution order, mode rules, and bridge tables are this repo's own creative design — not a psychologically validated generation method.

## What was actually read

- Official MBTI description page (The Myers-Briggs Company) — read as the developer's own statement of intended use: four preference pairs covering attention/energy direction, trusted information, decision process, and orientation to the outer world; preference ≠ ability; same type can differ in motive, experience, values, skill, culture [1].
- Enneagram Institute: system overview (nine types, wings, stress/growth directions) [12] and the nine individual type pages [14–22] — read as that tradition's model description; the nine-lens table in `enneagram-lens.md` is our short paraphrase, not quoted text.
- ElevenLabs Voice Design docs — read as one vendor's control example (persona, emotion, timbre, pacing, delivery as distinct layers; prompt and preview lines should match; quality varies) [10]. Not evidence that all voice/video tools offer the same controls; vendor slot names never license inventing unsupplied character facts.
- Two papers via PubMed **abstracts only**: McCrae & Costa 1989 [11]; Hook et al. 2021 [3]. Summaries limited to what the abstracts state; no claim of having reviewed full text or per-sample analyses.

## Adopted vs. not adopted

Adopted: four MBTI axes as creative questions; nine Enneagram motive lenses (desire/avoidance/securing strategy) plus optional wing and direction theory as writing reference; the separation of voice identity, speech style, and per-line performance as handoff layers.

Not adopted as generation grounds: celebrity type classifications, pathology or addiction links on type pages, any type→appearance or type→timbre correspondence (current evidence does not support such mapping tables), test items or scoring — output is never an official MBTI result.

## Limits

The MBTI developer page is a primary source for intended use, not independent verification. The 1989 study used an older instrument and specific samples; it is not a blanket invalidation of every scale or use. The 2021 review reports mixed evidence — treated as a reason to keep typology a conditional creative lens, not a verdict on the tradition. No source here licenses diagnosing or typing real people.

## Update policy

Sources are version-pinned reference material: re-verify only when the external theory basis changes or a specific execution tool's capabilities need checking — not on every character generation. Web research never overrides a user's supplied character facts.
