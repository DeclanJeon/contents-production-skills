# EXEC01 v1.2 — 132 가을 프리미엄 광고 실행 계획·중단 기록

## 실제 권한과 범위
사용자의 원문: “이거 내가 승인 따로 안할거니까 니가 추천하는 방향으로 전부 진행하면 된다.” 요청 범위는 콘텐츠 제작 스킬의 설계·수정·커밋 후, codex-imagen 정지 에셋과 flow.google.com의 Omni 1.1 Flash로 성인 동양 여성 모델이 등장하는 가을 프리미엄 앰플 광고 25초를 실제 제작하고 QA하는 것이다. 창작·제작 판단은 위임되었으며 추가 구독·크레딧 구매·게시·다른 공급자로의 대체는 실행하지 않는다. 위임을 별도의 사용자 개별 이미지 검수나 관찰하지 않은 승인 클릭으로 표현하지 않는다.

## 현재 입력과 산출 범위
프로젝트: 132-AUTUMN-25S, v1.1. 정본 원장은 project.json이며 제작 문서와 실제 출력은 같은 폴더에 연결한다. 5샷, 10 clean 정지 패널, 최종 9:16 / 1080×1920 / 30fps / 25.000초. 720p 원본을 납품 규격으로 리사이즈하는 것이며 네이티브 1080p 생성이라고 표현하지 않는다.

제공한 병·스포이드·한 상자의 정면/측면 원본이 제품 정체성의 권위다. 제품 오프닝과 엔드카드는 생성 배경에 원본 RGBA를 합성한다. 피부 톤·모공·얼굴은 도포 전후 보존하고 의학적 효능이나 피부 변환을 연출하지 않는다. 방울의 분리→낙하→손바닥 접촉과 볼의 짧은 도포→해제가 실제로 보이는지 전체 동작 구간에서 검사한다.

## 실행자·사용량 경계
- 이미지: 지정된 codex-imagen hosted OAuth helper. 로컬의 유효한 구독 등급 claim은 self_serve_business_prolite이며 이는 로컬 토큰 메타데이터 확인이지 원격 인증·과금·이미지 생성 성공 증거가 아니다. 별도 API 키·추가 결제·신규 구독을 사용하지 않는다. 10개 패널에 해당하는 요청, 실패 원인이 확인된 경우에만 최대 2개 추가 수정 요청. 각 요청 timeout 300초, helper 자동 재시도 0. 부분 파일이 반환되면 먼저 검사하며 중복 제출하지 않는다.
- 영상: 전용 Flow 프로젝트 132 Autumn Evening Ritual · 25s, https://flow.google.com/u/1/project/b706c0a7-2fff-469a-9c72-463da944b618 . 기존 로그인된 로컬 headed Chrome/CDP를 재사용한다.
- 실시간 UI 확인: Omni 1.1 Flash / 동영상 / 프레임 / 720p / 9:16 / 6초 / x1, 생성 1회당 10크레딧. 계정 패널에 기보유 893크레딧 표시. 최초 5회는 50크레딧, 원인이 확인된 표적 재시도 최대 2회를 포함한 총 상한 70크레딧. 기존 허용량 안에서만 진행하고 추가 결제·자동 구매를 하지 않는다. 무료 무소모 작업이라고 표현하지 않는다.
- 프리뷰와 최종 편집은 동일 5개 원본 범위다. 새로운 대안 샷·추가 버전·고급 모델로 범위를 늘리지 않는다. 실제 제출마다 모델·설정·견적을 다시 읽고 기록한다. 미확정 비동기 작업은 중복 제출하지 않는다. 동시에 진행 중인 Flow 작업은 최대 2개로 제한한다.

## 실제 실행과 검사
P02v2 얼굴 앵커와 후속 패널을 실제 열람했다. SH01/SH05의 Flow 입력은 **빈 배경 플레이트**이며, 원본 제품 RGBA를 후반에 얹어 라벨 변형을 차단한다. 시작/종료 프레임 슬롯은 현재 Omni 1.1 Flash의 프레임 모드에서 실제 확인했다. SH04는 선택 이미지에 맞춰 오른손→오른쪽 뺨의 기존 가벼운 접촉→짧은 글라이드→분리로 실행한다. 시간코드 프롬프트는 의도이지 확정 결과가 아니다.

다운로드 후 ffprobe로 해상도·fps·원본 길이·오디오 스트림을 측정한다. 생성·합성·편집·자막·엔코딩을 구분해 기록한다. 영상의 전체 동작 재생과 샷 경계, 정체성, 제품 그래픽, 방울/도포 인과를 검사한다. 오디오 디코딩·신호 측정은 실제 청취를 대신하지 않는다. 실제 청취가 가능한지 별도로 확인하고 미청취는 미검증으로 남긴다. 생성되지 않은 출력, 공급자 차단, 실패한 시도는 성공으로 등록하지 않는다.

web-ai는 현행 지침의 지원 vendor가 ChatGPT/Gemini/Grok뿐이다. Flow 전용 어댑터가 없으므로 같은 로컬 Chrome/CDP의 browser DOM 제어로 지정된 Flow UI를 실행한다. 다른 영상 공급자나 모델로 바꾸지 않는다.

## 현재 중단 상태
위의 5샷/70크레딧 계획은 v1.1 실행 직전 범위다. 실제 다중행 입력 도구가 줄마다 제출하여 요청·동시성 경계가 깨졌다. 실패 카드 11개와 부분 프롬프트 원본 1개를 확인했으며, 잔액은 893→883이다. 사건은 `qa/flow-execution-incident.json`, 현재 판정은 `qa/report.md`를 따른다. 추가 생성 제출은 하지 않았다. 기존 승인을 새 실행 성공으로 재사용하지 않는다.

재개 입력은 줄바꿈을 공백으로 바꾼 단일 문자열로 넣고 전체 composer 내용을 대조한다. 실제 무제출 smoke에서 텍스트 일치 및 실패 카드/성공 썸네일 수 불변을 확인했다(`qa/safe-input-smoke.json`). 이것은 Flow의 unusual-activity 상태 해제나 생성 성공의 증거가 아니다. 정상 UI에서 서비스 상태를 해소하고 남은 요청·재시도 범위를 정합하기 전까지 실행 중단이다. 다른 프로필·모델·공급자로 우회하지 않는다.
