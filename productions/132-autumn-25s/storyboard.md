# BOARD01 v1.1 — 제작용 상세 스토리보드 (5샷·10패널·25s)

실제 선택한 clean 정지 패널 10장이 있으며 영상은 아직 생성 전이다. 수치 카메라·공간은 `camera_spec.json`(CAM01 v1.1)의 명목 설계값이며 생성 출력에서 물리적으로 실측한 값이 아니다.

## 1. 입력과 이야기 고정
- 입력: 위임된 제작 요청, SYN01 v1.1, VIS01 v1.1, CAM01 v1.1 및 실제 선택한 10개 정지 패널.
- 고정: 5비트/3씬/5샷/10패널, 25.000s 30fps 9:16 1080x1920 마스터, no_dialogue, 이미지=codex-imagen·영상=Flow Omni1.1Flash.
- 실시간 Flow UI: Omni 1.1 Flash, 720p/9:16/6초/x1, 10크레딧/회, 기보유 893크레딧, 시작/종료 프레임 슬롯 확인. 다운로드 원본 fps·해상도·오디오는 미측정. SH01/SH05는 빈 배경을 생성한 뒤 원본 제품 합성.
- 6s 소스 → 4/5/6/6/4s 편집 트림은 시간 선택이며 시간 압축이 아니다.

## 3. 전체 샷 명세표(필수 슬롯)

### SH01 — S01, beat B01, p1s1, 0–4s (120f@30), 소스 6s·트림, source_duration_status=estimated
- 추적/목적: 제품 공개 오프닝. 다음 SH02로 인물 등장 연결.
- 피사체: PR01 병 + PR03 측면 카톤, 정지. 손/인물 없음.
- 카메라: ECU 3/4, position [0.12,−0.20,0.90] → 동일(locked), target [0.0,0.42,0.84], 50mm, fov_x 39.6°, 정지. 무빙 동기=웜 실용광 빛띠 이동(조명).
- 공간: numeric(CAM01). 대상 거리 ~0.64m. VANITY_TOP은 하부 지지 bbox로 의도된 접촉(가림 증명 아님).
- VFX: enabled=true — 빈 Flow 배경에 제공 제품 RGBA와 접지 그림자를 결정론적으로 합성. 생성 모델은 제품을 그리지 않는다.
- 발화: 없음(no_dialogue), lip_sync N/A.
- 음향: 계획상 네이티브 앰비언스/미니멀 음악만; 미지원 시 무음. cue 레지스트리는 실행 단계.
- 패널: P01(hold) — 정확한 병+측면 카톤 정지 프레임.
- 상태 인계: N/A(정지 제품 홀드, 새 변화·후속 유지 없음).

### SH02 — S02, beat B02, p1s2, 4–9s (150f), 소스 6s·트림, estimated
- 추적/목적: 옆을 향한 CH01의 시선을 프레임 밖 화장대 제품 쪽으로 낮춰 리추얼을 시작한다.
- 피사체: CH01 상반신, 손은 자연스럽게 쉬고 PR01/카톤은 프레임 밖. 다른 화장품 소품은 만들지 않는다.
- 카메라: MCU, 35mm, [0.35,−0.90,1.30]→[0.33,−0.80,1.29] 완만한 푸시인(smoothstep), target [0.15,0.05,1.28]→[0.13,0.05,1.26].
- 공간: numeric(CAM01). axis CH01→PR01 allowed_side=negative.
- VFX: false.
- 발화: 없음.
- 음향: 계획 동일.
- 패널: P02(start, 얼굴 정체성 앵커), P03(end).
- 상태 인계: CH01 정체성·의상·조명 보존(후속 유지 의무의 원본).

### SH03 — S02, beat B03, p1s3, 9–15s (180f), 소스 6s(트림 없음), estimated
- 추적/목적: 대표 방울. 오른손 스포이드 끝(분리된 PR02)에서 투명 방울이 분리→중력 낙하→왼손바닥 접촉→젖은 자국.
- 피사체: HP01(왼손바닥 프록시), HP02(오른손+피펫 그립 프록시), PR02, CH01(인물 연결). 프록시는 계획 bbox이며 실제 손 측정/가림 증명이 아니다.
- 카메라: 매크로 인서트, 60mm, 잠금. position [0.16,0.10,0.97], target [0.11,0.33,0.95]. 끝-바닥 갭 ~2cm.
- 공간: numeric(CAM01). 축 N/A(단일 인서트).
- VFX: false — 물리 낙하는 생성 실사로 처리.
- 발화: 없음.
- 음향: 계획 동일.
- 패널: P04(start, 방울 맺힘), P05(action_peak, 손바닥 접촉), P06(end, 젖은 자국·피펫 끝 방울 없음).
- 상태 인계: 방울 점유 이행(피펫→자유낙하→왼손바닥), 젖은 흔적은 SH04까지 의무 유지. 중간 가림은 의무를 지우지 않는다.

### SH04 — S02, beat B04, p1s4, 15–21s (180f), 소스 6s, estimated
- 추적/목적: 기존 가벼운 접촉에서 오른손 검지·중지가 **오른쪽 뺨**을 한 번 짧게 글라이드한 뒤 손을 낮춘다.
- 피사체: CH01만(오른손+오른쪽 뺨, 관객 기준 화면 왼쪽).
- 카메라: 정적 포트레트, 50mm, [−0.05,−0.85,1.30], target [0.10,0.05,1.30].
- 공간: numeric(CAM01).
- VFX: false.
- 발화: 없음.
- 음향: 계획 동일.
- 패널: P07(start, 오른쪽 뺨에 이미 가벼운 접촉), P08(action_peak, 짧은 글라이드), P09(end, 손 낮춤·은은한 윤기).
- 상태 인계: 글라이드→국부 윤기→샷 끝까지 동일 윤기 유지. 피부색·모공·나머지 얼굴 보존. 가려진 손바닥은 미확인(마른 것으로 단정 금지).

### SH05 — S03, beat B05, p1s5, 21–25s (120f), 소스 6s·트림, estimated
- 추적/목적: 제품 기억/엔드카드. 앰플+정면 카톤이 ≥4s 가독.
- 피사체: PR01 + PR04 정면 카톤, 정지.
- 카메라: ECU 3/4 정지(SH01 미러), 50mm, [0.10,−0.22,0.90], target [0.0,0.40,0.84].
- 공간: numeric(CAM01).
- VFX: true — 빈 Flow 배경에 제공 제품 RGBA·접지 그림자·최종 카피를 결정론적으로 합성.
- 발화: 없음. 최종 카피 3줄은 후반 작업 오버레이(생성 패널 아님).
- 음향: 계획 동일.
- 패널: P10(hold).
- 상태 인계: N/A(정지 제품 홀드).

## 5. 수량·실제 파일 인계
- 패널 슬롯 10 · 실제 선택한 이미지 10 · 시트 0 · 제공 원본 4 · 예정 Flow 클립 5. 최초 출력/수정본과 실제 호출은 qa의 공급자 영수증으로 구분한다.
- Flow 프롬프트: `prompts/SH01-flow.txt`~`SH05-flow.txt`. 이미지 프롬프트는 실제 과거 요청 기록이며 초기 왼뺨/호버와 선택 출력의 차이를 숨기지 않는다.
- 카메라 정본: `camera_spec.json` CAM01 v1.1. 비교: `camera-comparison.csv`. 수치 프록시는 실제 생성 기하 정합의 증명이 아니다.

## 6. 이미지 단독 검수 — 현재 상태
- 실제 clean 이미지 10장 열람과 원본 제품 합성 확인을 수행했다. 독립 이미지 검수 및 차이 처리 근거는 `review.md`에 통합한다.
- 정지 패널은 각 순간의 구도만 증명한다. 방울의 분리/낙하와 도포/손 분리는 실제 생성 영상의 전체 동작 구간에서 별도 검사한다.
