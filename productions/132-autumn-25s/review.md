# REVIEW01 v1.3 — 실제 정지 패널 검수와 제한 복구 후 상태

## 사용자 권한과 현재 범위
사용자는 “이거 내가 승인 따로 안할거니까 니가 추천하는 방향으로 전부 진행하면 된다”라고 명시했고, codex-imagen 이미지·Flow Omni 1.1 Flash 영상의 25초 가을 프리미엄 광고 제작과 QA를 요청했다. 아래 정합은 그 창작·제작 판단 위임 안에서 수행한 총괄 결정이다. 사용자에게 개별 이미지를 승인받거나 새 승인 클릭을 관찰했다고 주장하지 않는다. 게시·신규 구독·크레딧 구매·공급자 변경은 제외한다.

현재 입력: BRIEF01/SYN01/VIS01/CAM01/BOARD01/HANDOFF01 v1.1. 실제 선택 이미지 10개; 파일·해시·디코딩·규격은 `qa/still-files.json`. 이미지 호출 원문과 응답은 `qa/parent-image-generation.json`, `qa/drop-panel-generation.json`, `qa/application-panel-generation.json`(JSON Lines). 마지막 파일의 P07 실행 설정 행과 결과 행은 같은 호출의 기록이며 두 번 제출했다는 증거가 아니다. 영상은 생성 전이며 전체 동작의 통과를 아직 선언하지 않는다.

## 독립 이미지 검수와 총괄 처리
독립 StillQuality 검수는 실제 10개 이미지와 제공 원본 4개를 열람했다. 다음은 관찰과 처리다.

| 패널 | 실제 관찰 | 판정·처리 |
|---|---|---|
| P01 | 원본 병·측면 상자 특징/라벨 보존, 병 받침과 상자 접지의 큰 오류 없음 | KEEP. 따뜻한 배경 대비 제품 조명이 다소 평평한 비차단 메모. 영상은 빈 배경+동일 원본 합성 |
| P02v2 | 성인 동아시아 여성, 로우번·아이보리 로브, 자연 피부; 별도 화장품 병 없음 | KEEP. 최초 출력의 불필요한 소품을 제거한 수정본 사용 |
| P03 | 같은 여성/의상/장소, 낮아진 시선, 제품은 화면 밖 | KEEP. 원래 병 전경 계획 대신 화면 밖 제품으로 정합 |
| P04 | 오른손 스포이드·왼손바닥, 끝에 붙은 방울; 큰 손가락 오류 없음 | KEEP 시작 상태. 후방 흐릿한 검정/금색 용기 형태는 정체 미확인 소품이며 132 제품으로 간주하지 않음 |
| P05 | 손바닥 젖은 반사 영역, 끝에 작은 방울; 자유낙하/충돌 순간은 분명하지 않음 | 결과 상태 표본으로만 사용. 충돌 순간의 관찰 증거라고 기록하지 않음 |
| P06 | 손바닥에 맑은 액체 비드, 큰 매달린 방울은 사라졌으나 작은 팁 반사/메니스커스 존재 | KEEP 종료 상태. 넓은 젖은 자국이나 완전히 마른 팁으로 과장하지 않음 |
| P07 | 오른손 두 손가락이 오른쪽 뺨(화면 왼쪽)에 이미 가볍게 접촉 | 초기 왼뺨/호버 요청과 불일치. 위임된 판단으로 현 포즈를 시작 상태로 채택; 관련 시놉·바이블·보드·Flow 프롬프트 정합 |
| P08 | 같은 오른뺨의 두 손가락 접촉, 억제된 윤기, 얼굴·피부 특징 유지 | KEEP. 정지 그림만으로 단일 글라이드의 전이를 증명하지 않음 |
| P09 | 오른손이 뺨에서 분리되어 어깨 부근으로 낮아짐, 피부색/모공 보존 | KEEP. 손이 완전히 화면 밖으로 내려갔다고 주장하지 않음; 특정 막의 지속은 영상 검수 대상 |
| P10 | 원본 병·정면 상자 특징/라벨/접합선 보존, 접지의 큰 오류 없음 | KEEP. 테이블 표면 차이는 비차단 세트드레싱 메모 |

후방 흐릿한 용기 형태는 브랜드나 효능 주장의 근거가 아니다. 정체를 발명하지 않고 근접 작업 컷의 배경 소품으로만 허용한다. 사용자 제공 병·상자 대신 사용할 제품으로 등록하지 않는다. 영웅 제품 샷의 로고·라벨은 제공 원본의 결정론적 합성으로 유지한다.

## 영상에서 반드시 별도 검수할 것
- SH03: 피펫 끝 방울 분리 → 실제 하강 → 왼손바닥 접촉 → 남은 액체. 정지 시작/끝과 P05는 이 인과를 대신하지 않는다.
- SH04: 이미 닿은 같은 오른뺨에서 한 번의 짧은 글라이드 → 손 분리. 얼굴·피부색·모공의 변환 금지; 국부 윤기는 실제 전체 동작 구간에서 검사.
- SH02: 작은 시선 하강, 동일 인물·로브·환경; 새 제품이 등장하지 않음.
- SH01/SH05: 빈 배경의 고정 기하, 실제 배경 동작, 원본 제품 합성과 엔드카드 가독성.

## 실행 결정
10개 선택 파일은 실제 존재·디코딩을 확인했다. 정지 프리프로덕션은 위임된 판단으로 채택한다. 현재 실행 계획은 정확한 5샷, Omni 1.1 Flash 720p/9:16/6초/x1, 10크레딧/회, 최초 50·표적 재시도 최대 20·합계 상한 70크레딧이며 기존 893크레딧 안에서만 수행한다. 시작/종료 프레임 슬롯은 실시간 UI에서 확인했다. 입력 프레임과 견적은 제출마다 다시 확인한다. 추가 구매·무제한 시도·다른 모델은 허용하지 않는다.

## 검사 범위와 한계
실제 PNG 10개 모두 디코딩: P01/P10 1080×1920, P02–P08 941×1672, P09 941×1671. 카메라 좌표/렌즈는 명목 설계이며 Blender 렌더나 생성 영상의 실측이 아니다. 영상 동작·오디오·최종 25초 인코딩은 아직 검수하지 않았다. 상태: 정지 자료 채택, 실제 영상 생성으로 인계.

## 실행 사고 후 상태
정지 자료 채택/실행 인계는 v1.1 시점의 판단이다. 초기 다중행 입력 사고 뒤 단일행 무제출 검증과 제한 복구를 수행했다. 정상 SH01은 확보했지만 SH02가 다시 unusual-activity 실패했으므로 자동 제출은 중단이다. 정지 이미지 해시·선택은 바뀌지 않았다. 현재 REVIEW01은 reviewed이며 새로운 실행 승인이나 완성 광고 검수를 뜻하지 않는다. 현재 EXEC01 v1.4와 `qa/report.md`를 따른다.
