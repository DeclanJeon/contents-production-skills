# SYN01 v1.2 — 위임된 창작 판단으로 정합한 시놉시스 (1문단 5문장)

"가을의 저녁, 빛을 담는 루틴." — 132 VITA-C25.5의 25초 버티컬 광고. 대사·나레이션 없는 무드 필름(no_dialogue)이며 네이티브 음악/환경음 지원 여부는 실행 결과에서 구분한다.

BRIEF01 v1.2의 실행 상태 주석과 버전을 정합했다. 아래 이야기·비트는 변경하지 않았으며 실제 생성 결과나 완료 주장이 아니다.

## 시놉시스 본문(문단 1, 문장 1–5 — 비트 로케이터)

**문단1 문장1 (p1s1)** — 창밖에 블루아워가 내려앉은 저녁 화장대 위에서 네이비/골드의 132 VITA-C25.5 앰플 병과 각진 네이비 카톤(측면)이 따뜻한 실용광의 움직이는 빛띠를 받으며 모습을 드러낸다.

**문단1 문장2 (p1s2)** — 아이보리 실크 로브의 한 여성(CH01)이 화장대 앞에 앉아 옆을 향한 시선을 조용히 낮추고, 프레임 밖 앰플을 향해 저녁 리추얼을 시작한다.

**문단1 문장3 (p1s3)** — 여성은 오른손에 들린 분리된 스포이드 끝에서 투명한 방울 하나가 분리되어 떨어지고, 그 방울이 왼손바닥에 닿아 맑은 젖은 자국을 남기는 대표적 순간을 맞이한다.

**문단1 문장4 (p1s4)** — 여성은 오른손 검지와 중지를 가볍게 댄 오른쪽 뺨에서 한 번의 작은 스트로크를 하고, 손을 떼어 낮추며 조용한 표정과 은은한 윤기를 남긴다.

**문단1 문장5 (p1s5)** — 다시 제품만 남은 화면에서 앰플 병과 카톤(정면)이 움직이는 빛과 단풍 그림자 속에 조용히 머물며 기억에 남는 마무리를 짓는다.
