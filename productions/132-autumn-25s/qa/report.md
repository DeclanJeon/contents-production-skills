## Flow 입력 사고
초기 `browser.fill`에 여러 줄을 전달했을 때 줄바꿈이 Enter 제출로 작동했다. 계획된 한 개의 입력이 여러 부분 프롬프트 요청으로 분리되어 제출·동시성 계획을 위반했다. 이를 정상적인 단일 생성이나 승인된 재시도로 재분류하지 않는다. 도구 결함을 신고하고 무제출 단일행 입력을 검증한 뒤 제한 복구를 실행했다.

초기 UI에는 **실패 카드 11개**와 미과금 문구가 표시됐다. 한 부분 요청을 다운로드한 당시 잔액은 **893→883크레딧**이었다. 이후 정상 SH01 1개 확보 후 잔액은 873이며, SH02 실패는 UI에서 미청구를 표시했다. 실패 문구와 잔액은 직접 증거이며 결제 거래 장부/환불 완료 검사는 아니다.

한 완료 요청의 실제 프롬프트는 빈 화장대 장면을 설명하는 첫 문단뿐이었다. 의도한 전체 광선 동작·잠금 카메라 프롬프트가 아니다. 파일: `../videos/SH01_actual_partial_prompt.mp4`. 전체 실행 증거는 `flow-execution-incident.json`, 화면은 `flow-blocked.webp`다.

## 미완료와 재개 조건
- 정상 SH01 배경 원본만 확보했다. SH02–SH05와 최종 마스터는 없다. 초기 부분 원본은 선택 SH01이나 다른 샷으로 대체하지 않는다.
- 방울 분리→낙하→접촉과 오른뺨 글라이드→손 분리의 실제 영상 검수 미실시.
- 25초/750프레임 최종 인코딩·오디오·컷 연결·최종 자막 QA 미실시.
- Flow의 `unusual activity` 상태를 사용자의 정상 UI에서 해소하고, 실제 요청 수·남은 사용량/재시도 한도를 새 실행 기록으로 정합한 뒤에만 재개한다. 다른 프로필·공급자·모델로 우회하지 않는다.
- 단일행 입력으로 정상 SH01 생성은 확인했지만 이후 SH02가 다시 차단됐다. 다음 실행은 전체 입력·프레임·설정·견적 확인과 동시 진행 1개 경계를 보존하며, 현재는 추가 제출하지 않는다.

## 스킬 검증과 영상 결과 분리
스킬 보강 QA의 실험·독립 리뷰·아키텍처 WATCH는 `../../../docs/STATE_CAUSALITY_QA.md`에 있다. 문서 인계 보강을 모델 품질 개선이나 이번 광고 완성의 증거로 삼지 않는다. 이번 사고는 실행 입력 도구/서비스 경계의 실패이며, 그 사실을 상태·출력·관찰 원장에 보존했다.
