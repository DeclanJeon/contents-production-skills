## Flow 입력 사고
`browser.fill`에 여러 줄을 전달했을 때 줄바꿈이 Enter 제출로 작동했다. 계획된 한 개의 프롬프트 입력이 여러 부분 프롬프트 요청으로 분리되어 제출·동시성 계획을 위반했다. 이를 정상적인 단일 생성이나 승인된 재시도로 재분류하지 않는다. 도구 결함을 신고했고 추가 생성 제출을 중단했다.

실제 UI에는 **실패 카드 11개**가 있으며 `unusual activity` 또는 일반 생성 실패와 **“이 생성에 대한 요금이 청구되지 않았습니다”**가 표시됐다. 한 요청은 완료되어 다운로드했다. 실제 계정 잔액은 **893→883크레딧**으로 관측되어 10크레딧 차이가 있다. 실패 카드의 미청구 문구와 잔액 관측은 직접 증거이며 별도의 결제 거래 장부/환불 완료를 검사한 것은 아니다.

한 완료 요청의 실제 프롬프트는 빈 화장대 장면을 설명하는 첫 문단뿐이었다. 의도한 전체 광선 동작·잠금 카메라 프롬프트가 아니다. 파일: `../videos/SH01_actual_partial_prompt.mp4`. 전체 실행 증거는 `flow-execution-incident.json`, 화면은 `flow-blocked.webp`다.

## 미완료와 재개 조건
- 필요한 SH01–SH05 선택 영상 없음. 실제 원본 한 개를 최종 광고나 성공한 SH01로 둔갑시키지 않음.
- 방울 분리→낙하→접촉과 오른뺨 글라이드→손 분리의 실제 영상 검수 미실시.
- 25초/750프레임 최종 인코딩·오디오·컷 연결·최종 자막 QA 미실시.
- Flow의 `unusual activity` 상태를 사용자의 정상 UI에서 해소하고, 실제 요청 수·남은 사용량/재시도 한도를 새 실행 기록으로 정합한 뒤에만 재개한다. 다른 프로필·공급자·모델로 우회하지 않는다.
- 재개 입력은 한 줄로 정규화하거나 실제 원자적 붙여넣기를 사용하고, composer 전체 문자열·두 프레임·설정·10크레딧 견적을 확인한 뒤 Generate를 한 번만 누른다. 서비스 복구와 생성 성공은 현재 미검증이다.

## 스킬 검증과 영상 결과 분리
스킬 보강 QA의 실험·독립 리뷰·아키텍처 WATCH는 `../../../docs/STATE_CAUSALITY_QA.md`에 있다. 문서 인계 보강을 모델 품질 개선이나 이번 광고 완성의 증거로 삼지 않는다. 이번 사고는 실행 입력 도구/서비스 경계의 실패이며, 그 사실을 상태·출력·관찰 원장에 보존했다.
