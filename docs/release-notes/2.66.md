## 요약
스킬팩을 특정 실행기에 의존하지 않는 독립 패키지로 정리했습니다. 기존 제작 지침과 검수 절차는 유지합니다.

## 개선
- 실행기 전용 스키마, 제출 스크립트, 단계 인계 명령을 제거했습니다. 스킬팩 탐색·장착·실행은 사용하는 도구가 맡습니다.
- 일반 스킬 설치와 배포 아카이브의 체크섬 검증은 그대로 지원합니다.

## 호환성
- 이전 버전의 전용 연동 규격을 요구하는 도구는 이 버전을 사용하려면 소비자 쪽 업데이트가 필요합니다. 이전에 고정한 스킬팩 버전은 그대로 사용할 수 있습니다.

## Summary
The skill pack is now standalone. The existing production craft and review procedures are preserved.

## Improved
- Removed consumer-specific schemas, submitters, and stage commands. Consumers own discovery, mounting, and execution.
- Generic installation and release archive checksums remain available.

## Compatibility
- Consumers that require the old integration contract need a consumer-side update before using this version. Previously pinned pack versions remain available.
