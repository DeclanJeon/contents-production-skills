## 요약
CineForge가 스킬팩을 버전별로 인식하는 계약(v1)과 검증된 파일 목록을 추가했습니다. 단계 담당 스킬·라우팅·크래프트 참고 문서를 CineForge 업데이트와 별개로 갱신할 수 있습니다.

## 새 기능
- CineForge v1 팩 어댑터: `cineforge skills`가 설치된 팩의 버전과 파일 해시를 확인합니다.
- 검증된 파일 목록(inventory)으로 프로젝트마다 사용한 팩 버전을 고정합니다.

## 호환성
- CineForge 0.1.4 이상이 필요합니다.
- 아카이브와 SHA-256 파일을 내려받아 검증한 뒤 버전별 폴더에 풀고 `CINEFORGE_SKILL_PACK`을 그 폴더로 지정하세요. 어댑터는 실행 권한을 부여하지 않습니다.

## Summary
Adds a CineForge v1 pack adapter and a verified file inventory. Stage owners, routes, and craft references can now be updated independently of CineForge.

## New
- CineForge v1 pack adapter: `cineforge skills` checks the installed pack version and file hashes.
- A verified inventory pins the pack version used by each project.

## Compatibility
- Requires CineForge 0.1.4 or later.
- Download the archive and its SHA-256 file, verify it, extract it to a versioned directory, and point `CINEFORGE_SKILL_PACK` at it. The adapter does not grant execution authority.
