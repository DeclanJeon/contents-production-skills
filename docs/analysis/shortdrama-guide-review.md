# 제작 가이드 통합 후속 점검 — 누락·실제 적용·개선 내역

## 결론

첫 통합이 **완전하게 끝났다고 볼 수는 없었다**. 23장/38항목의 핵심 공정은 대체로 연결됐지만, 세부 범용 공정 일부는 공통 설명 수준에 머물렀고 몇몇 단독 전문 요청의 진입 경로·작성 템플릿이 약했다. 이번에 이를 보완해 **44항목을 절차→기존 오너→작성 템플릿→검수 기준으로 대조**했다. 항목 수나 정적 검사 통과를 품질/완전성 백분율로 환산하지 않는다.

- 범위: 기존 PDF 101페이지 OCR·23장 추출 기록과 현재 스킬 소스/템플릿 재대조. 원문 pp6, 32, 43, 67, 77은 개별 렌더로 다시 읽어 최초 28페이지에 더해 **누적 33페이지**를 개별 대조했다.
- [44항목 기계 판독 연결표](../../video-production-assets/references/guide-01-coverage.json): 항목별 PDF 페이지·실무 절·오너·템플릿·수락 문구의 실제 위치.
- [23장/44항목 출처 대조](../../video-production-assets/references/guide-01-extraction.md), [스캔 범위/지문](../../video-production-assets/references/guide-01-scan.json), [통합 실무 절차](../../video-production-assets/references/29-reference-driven-production.md).
- 아래 ‘개선’은 **명세/지침/작성 가능성의 개선**이다. 실제 생성 실패율·시간·비용·미감 향상을 측정했다는 뜻이 아니다.

## 3. 이미 있어서 유지한 것과 제외한 것

- **기존 기능 유지:** 시놉→씬→샷→패널 ID 체인, SSOT/LOOK/마스터-파생 계보·버전 핀·stale, 상태·인과/접촉 QA, 단일 기록자, 과금/재시도 승인, 원본 보존·실제 파일/히스토리, 미검증/N/A 구분은 새 기능인 것처럼 재작성하지 않았다.
- **충돌 시 기존 계약 유지:** 전체 image_backed 인물당 Sheet A 7뷰, 조건부 3D/Blender 검증, 움직이는 프리비즈 별도 승인, 이미지 실행 경로는 책의 일반 권장보다 현재 패키지 계약을 우선한다.
- **의도적 제외:** 작품 인물/줄거리/얼굴/무기 디자인·능력/장소/전용 프롬프트·고유 타이밍/대사, 특정 모델/서비스 고정 추천, 행사·가격·검열·개인 속도/질감 순위, 90초/인물 수/장소 수/세 번 재시도 강제, 특정 언어·IPA/태그의 성공 보장.
- **실행 범위 보호:** 지침·템플릿 수정·읽기 전용 행동평가·임시 설치 후, 별도 사용자 승인에 따라 영상 1개와 음성 1개를 총 15.1크레딧 한도에서 생성했다. 이후 별도 배포 승인에 따라 전역 링크도 반영했다. 재시도·음성 복제·원본 외부 업로드·게시는 하지 않았다. 새 드라마 전용 스킬이나 경쟁 프로젝트 원장도 없다.

## 4. 실제 행동평가와 발견된 실패 보완

44항목 연결표의 정적 검사는 구조/소스 계약만 증명한다. 이번에는 별도로 **실제 모델 응답 18종을 실행·검토**했다.

- 실행기: Pi 1.3.0, `openai-codex / gpt-6.1-sol`, thinking low. 케이스마다 새 프로세스를 쓰고 현재 체크아웃의 지정 오너부터 읽도록 했다. `read,grep,find,ls`만 허용하고 확장·MCP·전역 스킬/컨텍스트 주입·쓰기/미디어 도구는 제외했다. OS 파일시스템 샌드박스는 아니며 실제 접근 추적을 검토했다.
- 케이스 원문을 그대로 전달했다. 기대값·QA·support·원문 추출 감사 파일은 실행 모델에 주입하지 않았고, 실제 호출도 관련 스킬 문서의 read/grep만 사용했다.
- 초기 18개 응답 검토에서 **미지정 화자를 수신자로 지정**, **원장 없이 SH01–03 생성**, **이미 통합된 경험서 재요청**, **원본 구간/시간 기준 및 비용 범위·통화·기간 누락**을 발견했다. 각 기존 오너를 수정한 후 18개를 다시 실행했다.
- 재실행은 **17 PASS / 1 PARTIAL**이었다. 군중 사례는 정확한 수·잔류·통로·신원 제외는 충족했지만 복제 검사를 별도 명시하지 않았다. `20-visual-mode-ssot.md`와 기존 군중 템플릿을 보완하고 해당 사례를 재실행했다. 같은 변경 파일을 읽었던 Sheet A 사례도 최종 임시 설치본에서 재실행했다.
- 최종 선정 응답은 **18 PASS / 필수 기준 76개 충족**이다. 변경 파일을 읽지 않은 round-2 응답 16개와 영향 사례 재실행 2개를 합산했다. 전체 18개를 최종 동일 스냅샷에서 다시 실행한 것처럼 보고하지 않는다. 이후 출처 감사 파일의 오래된 대기 문구만 상태 포인터로 고쳤으며, 어떤 케이스도 그 파일을 읽지 않았다. 선정 응답이 실제 읽은 모든 파일은 최종 소스/설치본과 개별 해시가 일치한다. 추적된 실행은 총 38회다.
- 응답 원문·JSONL·실제 읽기 추적·프롬프트/소스 지문은 [실행 기록](../../qa/guide-behavior-runs/)에, 기준별 실제 인용과 판정은 [행동평가 검토](../../qa/guide-behavior-review.json)에 보존했다. 실행 성공 기록은 `UNREVIEWED`로 유지하며, 별도 검토 결과만 판정을 부여한다.
- **검토 독립성 한계:** 케이스 실행자는 격리됐지만 채점자는 스킬 수정도 수행한 조정 에이전트다. 블라인드 외부 전문가 채점·다중 모델/다회 반복·미지정 오너 발견·전체 제작 행동 검증으로 일반화하지 않는다. 초기 응답의 모든 기준을 완전 채점한 전후 효과량 비교도 아니다.

## 5. 설치·공급자 확인 및 남은 승인

`--exclude-derived-support`를 설치기에 추가했다. 기본 동작은 기존처럼 소스 support 충돌을 **쓰기 전 차단**한다. 옵션을 명시한 경우에만 선택한 호스트 스킬의 예약 파생 항목 `support/{manifest.json,examples,qa,CHANGELOG.md}` 복사를 제외하고 현재 저장소의 지원 자료를 설치한다. 사용자 support 파일·원본·기존 목적지의 백업/링크 보호는 유지한다.

- `/tmp/shortdrama-guide-audit/installed-skills-final`에 **25개 스킬 설치 성공**.
- 정규화 manifest 포함 **334개 런타임 파일 레코드**의 원본/설치본 지문 일치. 파생 support·캐시·기존 `.from-backup`·저장소 QA/docs는 비교에서 제외했다.
- 설치본 Sheet A 행동 스모크 통과. 설치 시점 이후 작성한 최종 검토 보고서까지 support에 들어 있다고 주장하지 않는다.

### 미디어 시험 준비와 승인 후 실제 결과

먼저 Higgsfield의 현재 영상 후보·모델 제약, Seed Audio 제약·프리셋 보이스, 계정 준비 상태와 `get_cost:true` 견적을 확인했다. 아래 견적에 대해 사용자가 “응 진행해”라고 승인한 뒤 같은 설정의 견적을 다시 조회하고 실제 2건만 제출했다. 새 프로젝트 자동 생성 선호는 꺼져 있어 공급자 프로젝트를 만들지 않았다.

최초 [견적·정확한 요청문](../../qa/guide-media-preflight.json)은 역사적 스냅샷으로 보존한다. 승인 범위는 이 진단용 영상 1개·음성 1개·총 15.1크레딧·자동 재시도 0회에만 적용했다. 이미지 실행 경로는 건드리지 않았다.

**실제 결과:**
- **두 작업 생성 완료.** 거래 내역에서 해당 모델/제출 시각과 대응하는 15 + 0.1크레딧 차감을 확인했다. 거래 행에는 job ID가 없어 모델명·시각으로 대응한 증거임을 명시했다. 구매·추가 제출·재시도는 0회다.
- **영상:** 854×480, 24fps, 121프레임, 컨테이너 표시 5.04초, 오디오 스트림 없음. 전체 프레임을 디코딩하고 5개 contact sheet와 원본 크기 표본 5장을 직접 확인했다. 빨간 큐브의 접근→시각적 접촉→끝 상태 유지는 보이지만, 시작 약 0–0.75초에는 파란 큐브만 보이며 빨간 큐브는 화면 밖에서 진입한다. 따라서 처음부터 두 큐브의 분리 상태가 충분히 관측됐다고 **전체 통과시키지 않았다**. 실제 3D 충돌 물리·정속 재생은 미검증이다.
- **부분 사용:** 원본 PTS 2.0–5.041667초를 접근/접촉/정착의 잠정 후보로 기록했다. 실제 트리밍·편집·채택은 하지 않았고, 이 구간으로 원본 시작 상태의 누락을 상쇄하지 않는다. 다음 시도를 별도 승인한다면 초기 프레이밍만 바꾸는 안을 제안하되 이번에는 실행하지 않았다.
- **음성:** 3.2초, 24kHz, 16-bit stereo PCM WAV. 전체 디코딩·비무음·최대 샘플 클리핑 0개·피크 약 −8.01dBFS를 확인했다. 이 환경에는 청취 가능한 입력이나 로컬 ASR이 없어 실제 한국어 문구·발음·자연스러움은 **미검증**이다. 기술 검사만으로 청취 통과를 선언하지 않는다.

- [요청·작업 ID·결과 URL·기술 검사·판정](../../qa/guide-media-run-01/summary.json). 생성 바이너리/페이지별 프레임은 `/tmp/shortdrama-guide-audit/media-run-01/`에 두고 스킬 소스에는 재배포하지 않는다. 파일 해시를 증거에 남겼다.
