## 연습 1 — 투명 향수병과 쉼표 타이포그래피

### 브리프와 고정값

가상 브랜드 ‘간격’의 유리병 콘셉트 소개. 성인 대상이며 목표는 ‘병의 물성과 잠깐 멈추는 행동을 기억시키기’다. 카피는 ‘하루에 작은 쉼표’. 진정 효과·지속 시간·성분·건강 효과를 주장하지 않는다. 구매 URL이 없으므로 CTA는 ‘가상 제품 콘셉트’ 표기로 닫는다.

제품 SSOT 슬롯을 실제로 채운 선택: 실루엣은 둥근 모서리 직육면체, 제안 치수 70×30×90mm, 투명 무색 유리, 옅은 호박색 내용물, 무광 은색 닫힌 캡. 앞면 하단 중앙의 가상 벡터 라벨과 병 높이 60%의 수위를 유지한다. must-never-change는 캡 체결 상태·수위·로고 철자·모서리 비율이다. product_id·승인 참조 에셋 ID·법적 필수 표기는 미정이며 임의 인증 표시를 넣지 않는다. 자산은 앞/뒤/3⁄4 병 도면, 라벨 벡터, 손 외형 참조, 돌 받침, 얇은 천, 반사 카드 배치도, 텍스트 별도 레이어가 필요하다. 모두 planned/inferred이며 verified가 아니다.

### 소리·권리·출력 게이트

병 접촉음·천 마찰·간결한 음악은 **역할 제안**이다. 파일·권리·gain·mix anchor·sync_offset은 미정. 실제 파일 승인 후 접촉 이벤트와 소리 이벤트의 차이를 측정하고 컷별 허용 오차를 승인한다. 영상만·오디오만·전체 실시간 재생이 필요하다. 기존 원본 음악·인물·브랜드 로고를 쓰지 않는다. 출력 전에는 손 참조 동의, 라벨 아트워크 권리, ‘가상 콘셉트’ 고지, 실제 병 접촉과 최종 철자를 확인한다.

결정 가능한 것: 제품 불변값, 반사 보호 영역, 접촉 우선순위, 레이어 소유권. 입력 미정: 승인된 아트워크·실제 에셋/음원·출력 읽기 기준. 따라서 **계획 도출 성공 / 실행 승인 아님**이다. A10 제작 경로는 실물 또는 3D 병과 별도 타이포 합성 중 실제 자산·도구 계약을 받은 뒤 선택하며 소스의 제작자 주장을 우리 공정 증명으로 쓰지 않는다.

## 연습 2 — 가상 숙박 공간의 안내 동선과 POV

### 브리프·공간·인물

가상 공간 ‘여울집’에서 손님이 조용한 좌석을 요청하고 직원이 안내하는 콘셉트. 실제 호텔·예약 기능·치유 효과를 주장하지 않는다. 평면 관계를 새로 정한다: 남쪽 입구 → 루버 복도 → 동쪽 라운지 → 북쪽 테라스. 북쪽 원형 창을 반복 공간 기준점으로 쓴다. 카메라 제안은 눈높이 1.5m, 표준적인 원근감의 렌즈 후보이며 실제 센서/mm와 3D 카메라는 후속 공간 설계에서 정한다. 원본 한 프레임으로 이 배치를 복원했다고 주장하지 않는다.

직원의 동사는 ‘가리켜 안내한다’, 손님의 동사는 ‘받아 따라간다’. ‘만족한 표정’으로 대신하지 않는다. 손님은 닫힌 컵을 들고, 직원은 의자를 당긴다. 위치 도면·문 경첩/회전 범위·루버/창 방향·의자/컵 규격·인물/의상 참조·손 동작·외부 풍경·가상 고지 그래픽이 필요하다. 공간과 인물은 별도 SSOT이며 모든 자산 상태는 planned다.

| 창과 되돌아보기 / 공간 회수 | 손님 시선→북쪽 창→같은 좌석과 컵으로 돌아온다. 창 풍경보다 장소 관계를 우선한다. | 돌아온 컷에도 컵·의자·직원 위치가 유지된다. 필요하면 컵 질감 삽입을 쓰되 시간/공간을 별도 기록한다. | 사막·바다를 섞어 실제 한 호텔의 지리로 읽히게 하지 않는다. 풍경의 세계 관계가 미정이면 하나의 풍경만 선택한다. |
| 고지 홀드 / 기대 경계 | ‘가상 공간 제안’과 이름만 고정 화면에서 읽힌다. | 실제 예약 CTA·가격·주소는 넣지 않는다. | 존재하지 않는 시설을 예약 가능한 상품처럼 보이면 주장/고지 실패. |

A05 공간/서비스 경로, A07 상대 행동, A08 POV·가림·귀환, A04 접촉·상태 상속, A12 삽입 화면을 적용했다. 이동의 기능은 관객을 공간에 참여시키는 가설이지 몰입도·매출 상승의 검증이 아니다. 대안은 전체 고정 마스터로 동선을 먼저 명료하게 보여 주는 방식이다.

음성은 손님의 요청 한 문장과 직원의 답 한 문장을 새로 작성할 수 있으나 실제 대사/음원/권리는 승인 전 미정이다. 최종 패널의 audio/speech 구간과 샷 시간을 맞추고, 문 여닫기·의자 마찰·발소리를 실제 행동 기준으로 동기화한다. 자동 자막은 이 연습의 대사 시각이나 청취 결과가 아니다. 촬영/생성 경로와 출연 동의가 확인되어야 실행 가능하다.

독자 결과: A05–08의 관계와 생략 조건은 결정 가능했다. 정확한 공간 복원은 추가 도면/3D 작업의 입력 문제다. DESIGN가 공간 서비스 계열을 제안한다고 실제 숙박 시설의 권리·주소를 만들어 낼 수는 없다.

## 연습 3 — 가상 차량의 굴림·접촉·남은 자국

### 브리프·차량 SSOT·운동 조건

가상 전기 유틸리티 콘셉트 ‘모래길’. 카피는 ‘지나간 자리까지’. 사유의 통제된 평면 세트를 상정하며 주행 성능·주행거리·방수·견인 능력을 주장하지 않는다. 관객이 읽을 정보는 차량 형태 → 바퀴/지면 접촉 → 남은 두 자국 → 안정된 히어로다.

새 제안값: 휠 반경 0.35m, 휠베이스 2.7m, 윤거 1.6m, 낮은 일정 속도 3m/s. 이 연습은 무미끄럼 굴림을 요구하는 분기이므로 ω=v/r=8.57rad/s(약 1.36회전/s)를 목표 관계로 정한다. **원본 차량에서 측정한 값이 아니다.** 실제 회전·속도·접촉은 연속 프레임으로 검수한다. 스포크가 역회전해 보이는 aliasing과 실제 차체/휠 이동 실패는 구별한다. 드리프트를 원하면 별도 미끄럼 조건과 자국 방향을 정의해야 하며 두 분기를 섞지 않는다.

필요 자산은 차량 앞/뒤/측면 도면, 휠 축과 타이어 형상, 로고 벡터, 지면 높이/경사, 자국 레이어, 물/먼지 레이어, 깨끗함/젖음 상태 참조, 통제 구간의 사람 없는 배경이다. 앞/뒤 바퀴와 차체의 동일성이 유지되어야 한다. 휠·차체·물·먼지·로고의 합성 담당을 각각 지정해야 하며 현재 담당/실제 파일은 미정이다.

| 역할명 / 정보 기능 | 운동·카메라·이벤트 | 상태·편집 연결 | 대안 / 실패 QA |
|---|---|---|---|
| 정지 히어로 / 형태 기준 | 앞 3⁄4 고정 구도. 네 바퀴 구조와 차고를 읽힌 후 출발한다. | 깨끗한 차체 시작 상태를 등록. 앞면/측면 대응 특징을 기록한다. | 반사로 제품 윤곽을 감추면 형태 기준을 못 만든다. 로고는 별도 정확한 면 합성. |
| 굴림 / 원인 관계 | 출발 t=0, 가속 후 일정 구간을 보여 준다. 바퀴/지면 접촉점과 차체 상대 이동을 동시에 보게 한다. | 타이어 접촉·축 위치·차고를 보존. 회전 위상과 이동을 다음 컷에 넘긴다. | 측면 고정 카메라 대안이 추적보다 검수하기 쉽다. 뜨는 타이어·미끄러지는 차체는 실패. 바퀴가 가려진 구간은 미확인. |
| 얕은 물 / 충격과 후속 | 별도 제안 조건은 깊이 20mm의 제한된 물 구간. 첫 접촉 t=0 → 전방 밀림/튀김 → 휠 통과 → 뒤쪽 잔류 물결을 나눈다. | 앞휠 접촉이 먼저이고 후속 물은 그 뒤다. 젖은 하단과 자국은 이후 히어로까지 유지한다. | 큰 물폭발로 접촉을 감추지 않는다. 물이 닿기 전에 튀거나 뒤 컷에서 설명 없이 건조해지면 실패. 실제 촬영 안전은 별도 승인. |
| 두 자국 / 카피의 회수 | 차가 지나간 후 두 자국이 읽히는 고정 후방 또는 상부 구도. 카피는 자국을 가리지 않는 영역에 놓는다. | 바퀴 통과 위치와 자국 간격을 대응시킨다. 지나간 방향/윤거를 유지한다. | 차량과 무관한 중앙 먼지구름은 자국의 원인 증거가 아니다. 자국이 차량 앞에서 먼저 생기면 실패. |
| 최종 홀드 / 정확한 브랜드 | 정착한 3⁄4 차량과 ‘가상 차량 콘셉트’를 유지한다. 조명 띠는 차체 면을 따라가되 도색을 바꾸지 않는다. | 젖음 유지 또는 다른 테이크/세척 리셋을 명시. 문·휠·로고 형상 최종 검사. | 깨끗한 팩샷이 필요하면 리셋을 표시한다. 음악 상승으로 접촉 실패를 가리지 않는다. |

A06 차량 접촉, A04 누적 물성, A03 면/접촉점 대응, A11 반사 형태, A01 카피 회수, A12 매크로→전체→자국의 정보 배분을 사용했다. A10은 3D/실물/합성 경로 선택 및 레이어 소유권을 기록하는 분기다. V031의 ‘AI version’은 기존 영상 remaster 주장이라는 반례이며, 제목만으로 이 계획을 100% 생성이라고 분류하지 않는다. 원문 제작 도구 이름은 우리 도구의 현재 지원·비용·권리를 증명하지 않는다.

소리 역할은 타이어 접촉, 물 충격과 잔류, 저역 음악, 카피 선택적 VO다. 실제 소스를 받기 전에는 stem·음악 beat·sync_offset을 채우지 않는다. 음악과 실제 접촉 타이밍 충돌 시 접촉 가독성을 우선하고 음악을 재배치하는 대안을 검토한다. 실시간 영상/음성/무음 검수, 실제 물리 장면 안전, 음원/차량 디자인 권리, 허구 고지까지 통과해야 제작 승인이다.
