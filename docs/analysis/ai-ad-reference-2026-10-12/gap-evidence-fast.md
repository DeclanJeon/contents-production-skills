# 빠른 갭 증거 매트릭스 — 담당 30소스

## 판정과 사용 범위

70개의 소스별 메커니즘을 12개 통합 레시피 묶음으로 연결한다. 새 30개 미니 스킬 제안이 아니다. 각 행의 기능/이전은 **[INFERENCE / DESIGN_PROPOSAL]**이며 원 제작 의도나 성과 인증이 아니다. 표면 색·멋짐 대신 정보 공개, 물리적 상태, 행위 상대, 표현 층과 검수 실패를 뽑았다.

**ID 범위:** R01–R12는 이 `gap-evidence-fast.md` 안에서만 사용하는 로컬 레시피 가족 라벨이다. 최종 DESIGN의 전역 ID, 구현 계약의 enum, 프로젝트 shot/artifact ID가 아니다. 최종 설계가 채택할 때는 별도 ID 대응을 명시하며 이 번호를 전역 식별자로 재사용하지 않는다.

- **PRESENT·구체 예제 심화**: 기존 절차/필드로 바로 명세할 수 있음. 빈 도메인으로 주장하지 않는다.
- **PARTIAL·운영 레시피**: 관련 능력/슬롯은 이미 있지만 해당 재질·위상·등록·공간/카피 대응의 적용 순서와 반례를 보강할 여지가 있음. 키워드 부재만으로 판정하지 않는다.
- **EVIDENCE_INSUFFICIENT**: 도구·제작 방식은 uploader의 직접 주장까지 확보했지만 사용 로그/프로젝트/stem/실청취/저자·권리는 인증하지 못함. 레포 구현 부족으로 바꾸지 않는다.
- 이 추가 매트릭스에서 도메인 전체 또는 좁은 recipe조차 **NOT_FOUND로 단정할 행은 없다**. 초기 감사의 좁은 C14 분류도 이 표에서는 21의 접촉·26의 상태 슬롯을 대조하여 차량 적용 깊이의 PARTIAL로 취급한다. 본편 전체 카메라/조명/연기/사운드 누락 주장을 하지 않는다.

직접 확인한 30장은 FRAMES_REVIEWED. 후보 점수와 B block은 실제 컷 수가 아니다. V028의 S01.P01–P05/S02.P01–P02는 두 shot의 phase다. 아래 시간은 **각 장의 근사 경계**이며 native PTS 링크는 실제 추출 source frame이다. 영상은 .5s 또는 재사용 1s 표본이므로 접촉 순간/광학 원인/리듬·청취는 미검증일 수 있다. 원본 자동 자막은 시간 없는 텍스트, ASR는 기계 가설이다.
