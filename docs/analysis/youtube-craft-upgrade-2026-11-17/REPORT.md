# YouTube 제작 강의 12편 — contents-production-skills 업그레이드 분석

분석일: 2026-11-17 · 범위: 지정 12편 획득, 제공 자막·프레임 표본 분석, 현재 작업트리와 대조. **스킬 업그레이드 구현이나 배포는 하지 않았다.**

## 1. 결론

**배울 핵심은 ‘새로운 비밀 프롬프트’가 아니라, 승인한 입력을 만들고 작은 시험을 거쳐 원인층을 수정한 다음 좋은 구간을 편집하는 제작 루프다.** 이 루프는 현재 패키지의 `29-reference-driven-production.md`, 생성 QA, 편집·실행 절차에 상당 부분 들어 있다. 같은 규칙을 새 스킬로 다시 추가하면 중복과 권위 충돌이 생긴다.

가장 유용한 업그레이드는 다음 세 가지다.

1. **음성 중심의 짧은 이야기 제작을 실제 파일까지 잇는 작은 예제** — 정지 이미지 보이스 스토리와 생성 동영상 드라마를 명확히 구분한다.
2. **프로젝트의 어려운 샷으로 제한된 모델 비교를 수행하는 예제** — 모델 종합 순위를 고정하지 않고, 실제 채택 분량·필수 요구·지출로 고른다.
3. **설명 영상의 수치·글자·도식에 대한 의미 검증 예제** — 코드 렌더링도 내용과 시간 대응을 검사한다.

보조 개선은 참조 모순 진단과 클립 간 음향 접합을 기존 절차의 회귀 사례로 만드는 것이다. **기본 권한, 코디네이터, 라우팅, SSOT·필수 시트 계약, 실행 승인, 기존 상태 스키마를 바꿀 근거는 없다.**

읽기 전용 보조 연구도 다섯 후보를 기존 문서·eval과 대조했다. [COVERAGE_RESEARCH.md](COVERAGE_RESEARCH.md)에 정확한 절/줄과 조사 범위가 있다. 조정자는 10 근거 모듈·모델 라우팅 템플릿·기존 교육 예제를 추가로 열어 핵심 대조를 확인했다. 이는 독립적인 전체 영상 검수나 보고서 최종 승인과 다르다.

특히 `10-evidence.md`에는 이미 단위·분모·축·claim 대응 검수가 있고, `examples/15-second-education/plan-ko.md`에는 2+3=5 산술/집합 검증 **계획 예제**도 있다. 따라서 U3는 ‘수치 검증 기능 신설’이 아니라 **데이터→표시→도형→실제 렌더 결과의 연결 예제와 실패 반례 보강**이다. 실제 모델 비교 프로토콜과 이 렌더 연결이 조사 범위에서 가장 좁고 구체적인 보완 후보였다.

## 5. 권장 업그레이드: 기존 오너에 작은 예제와 검증을 붙인다

아래는 **제안이며 미구현**이다. 새 패키지/모델/외부 서비스 설치나 비용 발생을 승인받은 것이 아니다. 파일명은 기존 파일 외에는 후보명일 뿐 생성된 산출물이 아니다.

### U1 / P1 — 음성 중심 짧은 이야기의 실행 예제

- 근거: YT01의 사건별 해설, YT02의 음성-영상 정렬, YT11의 화자별 보이스와 청자 반응. **멀티화자 정지 보이스툰은 이 셋을 결합한 제안이지 영상에서 검증된 동일 공정이 아니다.**
- 기존 소유: `storytelling-with-still-images`의 음성·편집, `animatic-direction`의 타이밍, 대사/연기와 상태는 기존 22/26 모듈. 코디네이터와 단일 기록자 유지.
- 예제 내용: 승인된 짧은 원고 → 화자별 실제 음성/발화 원문 확인 → 실길이 측정 → 말하는 얼굴/청자 반응/중요 행동을 그림 구간에 배치 → 홀드·자막·음향 → 실제 MP4 → 정속 시청/실청취 결과. 사용자가 정한 길이를 따르고 90초/150초/50편으로 고정하지 않는다.
- 정지 전용 요청이면 생성 동영상을 쓰지 않는다. 생성 동영상 드라마 요청이면 실제 지원 경로와 별도 승인으로 분리한다. 설명용 팬/줌을 정확한 3D 이동이라고 부르지 않는다.
- 검증: 필수 대사가 잘리지 않음, 화자/보이스 뒤바뀜 없음, 반응/정보 공개 시점 대응, 정지 자료를 연속 모션 통과로 표기하지 않음, 실제 출력·시청·청취·수락 상태 분리.
- 변경 최소화: 기존 템플릿 필드와 파일 ID/버전을 재사용하는 worked example부터 만든다. 이미지 지원 전체 패키지의 필수 시트·신원·접촉 검수를 면제하지 않는다. 실제 제작에는 사용자가 승인한 범위의 에셋/보이스만 사용한다.

### U2 / P1 — 과제 기반 모델 비교 예제

- 근거: YT08. **순위가 아니라 시험 방법**을 배운다.
- 기존 소유: `assets/video-model-routing-template.md`, 24 실행, 21 QA, 29 R7 비용 회고.
- 패키지가 허용하는 영상 후보에 한해 같은 장면 목표·필수 사건·참조·편집 요구를 두고 실제 지원 설정을 확인한다. 이미지 실행자 정책이나 승인된 공급자를 임의로 바꾸지 않는다. 지원이 다른 해상도/FPS/길이/음성/참조 수는 차이를 숨기지 않는다. 동일 프롬프트 시험과 모델별 최적화 시험을 구분한다.

## 6. 사업성 관점: 무엇이 실제로 검증됐나

**이 12편만으로 돈 되는 포맷의 우승자를 고를 수 없다.** 대부분 도구 제작 강의이며, 선택된 성공 영상과 홍보·제휴/자체 플랫폼 설명을 포함한다. 동일 조건의 최근 채널 코호트·제작 원장·실제 광고수익·노동 공수는 없다.

- YT03은 자가보고 매출/도구비를 분리하고 실패·거절·수정 공수를 말한다는 점에서 유용하다. 그러나 제작대행과 자기 채널 운영은 다른 사업이다. $658 차액도 노동·세금 포함 순이익 인증이 아니다.
- YT11의 고객 제작·브랜드 통합·다음 회차 구독은 **수익 경로 가설**이다. 기대 조회수와 구독 전환율을 보장하지 않는다.
- YT12의 외부 월수입 추정·고정 RPM·가정 적격 조회수는 실제 정산 자료가 아니다. 검색 관심 감소→경쟁 감소→바이럴 쉬움이라는 인과도 이 자료로 입증되지 않는다.
- YT01/YT12의 타인 원본 재편집 형식은 권리와 플랫폼 수익 정책을 별도로 검토해야 한다. 다운로드·출처·해설·크롭·저작권 자동 검사 무경고가 재사용 권리와 수익 승인을 보장하지 않는다. 현행 정책의 정밀 조항은 이번 연구에서 추가 대조하지 않았다.

따라서 다음 제작을 승인한다면 **보이스 중심 정지 서사형 / 사실 기반 텍스트·도식 설명형**을 작은 자체 제작 파일럿 후보로 비교하는 것이 합리적이다. 이는 현재 목적과 도구 분업에 대한 제작 실험 제안이지, 수요·수익이 입증된 추천이 아니다. 생성 드라마는 별도로 연속성/연기 수정 원가를 측정해야 한다. 무단 클립 랭킹 재편집은 기본 실험안에서 제외한다.

측정할 것은 완성 편당 실제 노동, 실패 포함 생성/보이스 비용, 채택률, 품질 blocker, 실제 게시가 별도 승인된 뒤의 노출·유지·재방문이다. 매출이 없으면 회수 가능성을 꾸며 쓰지 않는다. 50편을 먼저 쓰거나 매일 게시를 강제할 근거도 없다.

## 7. 적용 순서와 완료 기준

1. **현재 진행 중인 라우팅 변경의 기준을 먼저 확정**하고 해당 버전에 이 대조를 다시 수행한다. 다른 작업의 파일을 덮어쓰지 않는다.
2. U1~U3 중 사용자 목적에 필요한 예제만 선택한다. 오너의 기존 참조/템플릿에 연결하며 새 스킬·거대 의무 체크리스트를 만들지 않는다.
3. 먼저 비용 없는 문서/입력 회귀 사례로 기대 행동과 실패 반례를 만든다. 실제 미디어 효과는 이것만으로 검증했다고 하지 않는다.
4. 실제 파일럿은 승인된 실행 경로·예산 안에서 수행하고, 파일·실제 요청문·실패·시간·비용·채택 구간을 보존한다.
5. 실제 출력의 정속 재생·청취와 별도의 검토를 거쳐 효과를 평가한다. 테스트 문자열 존재나 파일 수만으로 제작 품질 개선을 주장하지 않는다.

**현재 납품은 ‘자료 획득 + 제한된 근거 분석 + 개선 후보 보고’다. 구현·행동 평가·재현·커밋·배포는 다음 승인 범위다.**
