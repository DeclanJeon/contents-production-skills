## 실제 반영

- [의미 대역 인계 절차](../../blender-previsualization/references/semantic-proxy-handoff.md): BP01–BP11을 특정 인물/농구/선글라스에 종속되지 않는 실행 절차로 일반화.
- [기존 인계 템플릿](../../blender-previsualization/assets/previs-handoff-template.md): 대역 ID·면/방향·소품 상태/소유권·허용 수정·참조 슬롯 확인 추가.
- [네이티브 Blender 제작법](../../open-3d-production/references/native-blender-workflows.md): 추가 공식 근거로 제품 조명·인스턴싱·트래킹·합성 등을 보완. 주제 영상에서 보여주지 않은 기능은 이 영상의 성과로 귀속하지 않는다.
- 기존 `camera-spatial-1.0`과 proxy adapter는 그대로 둔다. 정밀 손 리그·접힘·물리·실제 트래킹은 별도 native 구현 범위로 표시한다.

## 재현 명령

아래 `PROJECT`는 외부 연구 폴더이며 `URL`은 문서 상단의 정규 URL이다. 명령은 이번 조사에서 사용한 형태이고, 자동 실행 정책이 아니다.

```bash
flucto download "$URL" --format mp4 --output-dir "$PROJECT/source" --json
flucto md "$URL" --language auto --output-dir "$PROJECT/source" --json
python3 "$PROJECT/inspect_source.py" "$VIDEO" "$PROJECT/inspection-overview" --step 10
python3 "$PROJECT/inspect_source.py" "$VIDEO" "$PROJECT/inspection-detail" --start 480 --end 576 --step 2
```

추출 폴더가 이미 있으면 검사 스크립트가 거부한다. 재실행은 새 폴더를 사용한다. 다운로드 CLI 자체의 덮어쓰기 동작을 피하려면 새 연구 프로젝트/출력 폴더를 선택한다.
