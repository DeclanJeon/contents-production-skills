## 재개 순서 — 1~3은 필수 마감 작업

5초 테스트 통과는 중간 검증이다. 1~3을 마치기 전에는 실제 제작 환경에서의 통합 검증 완료나 배포 준비 완료로 표시하지 않는다. 공급자 추가 테스트만 선택 사항이다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 작업 트리 검토·정리 | `git status --short`, `git diff --check`와 새 파일 목록을 확인한다. 기존 `.ultragoal/`, `.worktrees/`, `ai-delegation-loop/` 등 이번 범위 밖 파일을 섞지 않는다. 커밋이 요청되면 관련 변경만 포함한다. |
| 2 | 실제 한국어 숏폼으로 통합 검수 | 사용자 제공/승인 영상에서 발화와 표시 원고, 음성·컷 버전을 고정한다. 얼굴/모바일 UI 겹침, 줄바꿈, 컷·발화 싱크, BGM 아래 대사 가독성을 실제 재생으로 확인한다. 현재 테스트를 게시용 승인으로 쓰지 않는다. |
| 3 | 심화 자막과 엔진 검증 | 로컬 `subtitle-direction-skill/03_스킬/SKILL.md`와 실행 계약을 따르고, 전체 테스트는 충분한 제한 시간으로 실행한다. 모션/복합 레이아웃 샘플은 현재 계획 해시 승인 뒤에만 렌더한다. |
| 선택 | ElevenLabs SFX 자동 생성 | TTS와 별개로 공식 SFX 실행·인증을 확인한다. 예상 비용, 입력 전송, 공개 범위를 승인받은 뒤 1회 시험한다. 자동화가 불필요하면 권리 확인된 기존 음원을 쓴다. |
| 선택 | Typecast·ElevenLabs TTS 실생성 | 공급자별 짧은 한국어 문장을 별도 비용 승인 후 생성하고 발음·톤·정체성을 청취한다. 연결 확인을 실생성 통과로 표시하지 않는다. |

다음 세션은 1번의 변경 검토와 범위 분리부터 시작한다. 2번에는 작업 권한이 확인된 실제 한국어 숏폼이 필요하다. 3번의 로컬 엔진 테스트는 영상 확보를 기다리지 않고 진행할 수 있지만, 실제 영상의 심화 렌더는 계획 해시 승인 후 진행한다. 커밋·생성·공개·배포는 각각 권한 범위를 확인한다.
