# 모션 기법 양쪽 저장소 확장 · 설계 및 실행 큐

## 계약
`contents-production-skills`는 관객이 이해할 것과 선택 이유, 필요한 입력, 관찰 가능한 탈락 조건을 정의한다. CineForge는 지원하는 조합과 컷 스키마, 렌더러 및 기술 검증을 소유한다. 영상의 기본 레시피(타입·UI·단계도·모프)와 컷 보조 효과(와이프·입자·마스크)를 구분한다. 기술 구현 검증 전에는 카탈로그의 항목을 로컬 실행 가능이라고 표시하지 않는다. 같은 효과의 색·속도 차이는 개별 스킬을 만들지 않는다.

무음 세로부터 지원하며 기존 G2 검수 해시, 독립 공급자/비용 승인, 사용자 프리뷰 SHA 납품을 유지한다. 권리·자산·실제 데이터가 없으면 다른 표현을 선택하거나 차단한다. 웹/Blender/음향 실행은 기존 전문 레인을 재사용하며 임의 로컬 설치나 대체 실행은 하지 않는다.
