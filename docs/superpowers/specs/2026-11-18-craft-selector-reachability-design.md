# 크래프트 선택 문서 도달성 설계

상태: 구현 완료 2026-11-18 (package 2.57) · 선행: `2026-11-18-cinematic-directing-bible-import-design.md`

## 1. 문제

2.55–2.56에서 넣은 크래프트 문서 6묶음의 도달성을 라우팅→오너 SKILL.md→참조 순서로 실측한 결과:

| 묶음 | 실제 경로 | 도달성 |
|---|---|---|
| 스틸 모션 | 오너 SKILL.md 본문 | 항상 |
| 애니매틱 액션 비트 | `animatic-direction/SKILL.md` 4단계가 절 이름 지목 | 지목됨 |
| 08 모션 기법 | `video-production-assets/SKILL.md` 모듈 표 행 | 요청 분류에 의존 |
| 15 광과민 | 동일 모듈 표 행 | 요청 분류에 의존 |
| 속도·타격 + 효과음/음악/공간음향 표 | `SKILL.md:129` "외부 예시를 찾거나 표현을 비교할 때만" + `09-edit.md:209` "컷·전환·음향 예시를 비교할 때만" | **조건부(발화 불확실)** |
| 크로스워크 | 참조 색인 §선택→인계→검수 6단계 ← 다시 조건부 문장 | **2홉 + 조건부** |

원인은 두 가지다.

1. **조건부 게이트.** "…할 때만"으로 닫힌 문장은 그 문장이 상정한 프레이밍(예: 외부 예시 비교)이 아니면 발화하지 않는다. 이 패키지는 이미 같은 실패를 측정한 기록을 갖고 있다 — 2.53 `CHANGELOG`: "read the pair table only when two routes remain plausible"가 **11개 혼동 사례에서 11/11 미발화**해 REQUIRED로 바꿨다.
2. **용어 해석 진입점 부재.** 라우팅은 3슬롯(산출물·매체·권한)으로만 결정되고 27행 중 크래프트 문서를 `required_read`로 지목한 행은 0개다(설계상 의도: 미래 크래프트 preload 금지). 따라서 "ST-01", "impact frame", "leitmotif"처럼 **용어로 들어온 요청**은 어느 단계에서도 정본을 찾지 않는다.

## 2. 개념

- **크래프트 선택 지점(craft selection moment):** 요청이 기법·효과·소리·리듬 목표를 *이름으로* 지정해, 초안 전에 소유 표에서 골라야 하는 순간("타격 연출", "라이저", "스틸에 시차", "impact frame").
- **도달성 등급:**

| 등급 | 정의 | 비용 |
|---|---|---|
| L0 | 오너 SKILL.md 본문 안 (로드 시 항상 보임) | 오너 로드마다 지불 |
| L1 | 오너 SKILL.md의 단계 문장이 **파일+절 이름**을 지목 | 동일 |
| L2 | 오너 SKILL.md의 모듈/온디맨드 **표 행**이 요청 유형으로 매칭 | 동일 |
| L3 | 오너 참조 문서 안의 포인터 (한 홉 추가 + 조건부) | 낮음, 발화 불확실 |
| L4 | 도달 불가 | — |

**규칙 1.** 크래프트 *선택 표*는 L0–L2에 둔다. L3는 "필요할 때만" 게이트가 붙는 순간 L4와 구별되지 않는다.
**규칙 2.** 용어 해석기(크로스워크)는 특정 오너에 속하지 않으므로 **모든 경로에서 한 번 로드되는 지점**에 둔다. 오너별 5곳 중복은 비용과 드리프트를 동시에 늘린다.
**규칙 3.** 트리거 문구는 **긍정형 선택 행위**를 이름으로 쓴다. "예시를 비교할 때만"처럼 유일 조건으로 좁히지 않는다(§1 근거). 한 행에 한 분기.

변경하지 않는 것과 이유:

- **`routing.csv` `required_read` 추가 없음.** Step 1은 "미래 크래프트·공급자 카탈로그·전체 파이프라인 체크리스트를 preload하지 않는다"고 규정한다. 크래프트 선택은 라우트가 아니라 오너 단계의 일이다.
- **15-delivery 트리거 문구 변경 없음.** "자막·접근성·출력·납품" 행이 이미 광과민을 포함한다(무변경이 no-op 회피).
- **`video-production-assets/SKILL.md:129`의 외부 예시 문장 유지.** 그 문장은 외부 자료 비교 역할이지 크래프트 선택의 유일 통로가 아니게 만드는 것이 목표다.

## 4. 문구 규칙

1. 선택 행위를 이름으로 쓴다(고르다·바꾸다·지정하다).
2. 한 분기 = 한 행/한 문장. 동의어 나열은 분기를 늘리지 않는다.
3. 금지형보다 긍정형을 쓴다("예시를 비교하지 않으면 읽지 않는다" ✗).
4. 트리거 단어는 그 문서의 실제 표 이름과 일치시킨다(테스트가 이 일치를 검사한다).
