# Prompt Motion 기반 모션 제작 참조 보강

[인벤토리](../../research/prompt-motion-inventory.md)의 고정 출처 5개 및 공식 템플릿 2개에서 제작 원리만 새 문장과 중립 예시로 정리한다. 추천 프롬프트 24개는 분류와 링크를 보존하되 원문, 브랜드, 예시 영상, 폰트, 엔진, 실행 스크립트를 복제하지 않는다. 새 스킬·원장·공급자·모델 기본값은 추가하지 않는다.

- Cinetic/Showreel: 단일 콘셉트, 음악 박자 매핑, 전환 동기, 결정적 프레임·출력 검수.
- HTML Demo/Product Film/TasteSkill: 실제 UI와 승인된 데이터, 단일 결정적 시간축, UI 전이와 포인터, 타이포·여백, 라이브 데모와 납품 영상의 분기.
- Session Story: 사용자가 제공한 비식별 자료의 사건 인과만 연출. 로컬 로그를 스캔하는 동작은 포함하지 않는다.
- 3D 템플릿: 대표 구도, 프리셋이 아닌 컷별 의도, 실시간·스크롤과 선형 렌더의 구분. 공간 검증은 Blender 기존 경로를 보존한다.

프리: 컷 단위 의도와 검수 기준. 프로: 실제 에셋·선택한 렌더러·측정 증거. 포스트: 실제 출력 파일 검사. 기존 권한과 2회 검수 경계를 유지한다. 정량 설정은 타깃별 결정이고 샘플값을 고정 정책으로 올리지 않는다. 승인되지 않은 렌더·설치·외부 전송은 하지 않는다.
