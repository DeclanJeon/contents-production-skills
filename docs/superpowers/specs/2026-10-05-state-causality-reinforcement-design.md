2. 프로젝트 기존 검증과 pytest를 통합 완료 후 한 번 수행. 참조 링크와 설치 junction이 실제 저장소 변경을 노출하는지 검사한다.
3. 독립 품질 리뷰와 독립 아키텍처/반대 검토 및 제한된 anti-slop 정리. 절차 중복과 강제 적용이 없어야 한다.
4. 본 작업 파일과 추가분만 두 단계 이상 의미 단위로 커밋. 이전 변경의 내용은 포함하지 않는다.
5. 실제 생성 이미지·다운로드 영상으로 25초 광고를 조립하고 길이/화면비/제품·인물·접촉/경계/실제 움직임을 검사한다. 표본 관찰과 전체 동적 재생, 오디오 측정과 청취를 구분한다. 미검사 항목에 pass를 쓰지 않는다.

## 132 데모 적용

브랜드 홈페이지의 제품명·15ml·네이비/골드 제품 외형과 사용 맥락을 취한다. 효능 수치·2주 결과·세포 재생 등은 독립 증거가 없으므로 카피나 영상으로 주장하지 않는다. 성인 동아시아 여성 한 명, 가을 저녁 실내, 호박색 실용광·청색 황혼, 원본 병/스포이드/상자 전면·측면 참조를 사용한다. 상자 두 시점은 같은 물체의 다른 면이지 서로 다른 상자 제품이 아니다.

기본 제안: 세로 9:16, 25초, 5개 샷. 병 공개→여성의 저녁 루틴→방울 상호작용→여성의 자연스러운 반응→제품 엔드카드. 실제 생성 원본에서 맞는 구간을 선택하며 효능 전후 변신을 하지 않는다. 제품명/로고/웹 주소는 필요하면 원본 그래픽·결정적 후반 합성으로 정확도를 보장한다.

Flow 사전 확인: 새 전용 프로젝트 `b706c0a7-2fff-469a-9c72-463da944b618`; UI에 Omni 1.1 Flash, 720p, 9:16, 6초, x1, 10크레딧 표시. 첫 5개 원본과 원인이 특정된 최대 2개 재시도, 총 70크레딧 상한. 비용 또는 UI 조건이 바뀌면 상한 안에서 다시 산정하며 결제를 하지 않는다. 이미지 첫 5개와 필요한 최대 2개 표적 수정. 확인하지 않은 모델 선택·이미지 업로드·생성 성공을 기록하지 않는다.
