# 오디오 공급자 사전 점검과 자동 대체 설계

- 날짜: 2026-11-21
- 상태: 후속 라우팅 규칙을 저장소에 반영. 도구 설치·연결 및 유료 실행은 별도.
- 기준: [영상 오디오 라우팅 설계](2026-11-21-audio-production-routing-design.md). 승인 후 공급자 후보·설치 점검·대체 부분만 이 문서로 갱신한다. 단일 총괄, 내장 음향 기본값, 기존 큐 시트와 실측/청취 기준은 유지한다.

## 선택한 방식

항상 모든 MCP를 설치하는 방식은 준비 비용이 크고, 기본 공급자 실패 때마다 질문하는 방식은 이미 사용 가능한 대안을 낭비한다. **범위에 들어온 별도 큐만 사전 점검하고, 요구사항을 만족하는 준비된 후보가 있으면 자동으로 넘긴다.** `creative-production`이 결정하고 기존 큐 시트에 남긴다. 텍스트 작업자와 도구 어댑터는 공급자 선택을 반복하지 않는다. 설치, 사용자 계정 연결, 지출은 이 자동 선택에 포함하지 않는다.

## 사전 점검: 설치가 아니라 작업 가능 여부를 확인

실제 제작 목표에서 별도 큐의 요구사항이 파악되는 즉시, 유료 생성·해당 큐에 의존하는 편집 전에 공급자별로 한 번 점검한다. 설계·프롬프트 전용, 무음, 권리 승인된 음원 재사용, 지원 확인된 내장 음향은 설치 점검 대상이 아니다.

1. 큐별로 지원이 확인된 MCP, 공식 CLI/API의 기존 인증 경로를 읽기 전용으로 확인한다. 동일 공급자의 다른 연결 경로는 계정·기능·전송·비용 범위가 같을 때 공급자 변경으로 보지 않는다. 수동 웹 제작은 별도의 사용자 작업이다.
2. `READY`는 **연결+필요한 기능/모델+계정 접근**이 확인된 상태다. 이미 `READY`면 설치 안내를 건너뛴다. MCP가 없어도 적격 공식 CLI/API가 준비돼 있으면 중복 설치하지 않는다.
3. 설치 여부와 기능 가용성을 구분한다. `MISSING`은 실행 경로가 없고 공식 설치/연결 경로가 확인된 경우, `CONNECT_REQUIRED`는 설치됐지만 인증이 안 된 경우, `CAPABILITY_UNAVAILABLE`은 연결됐어도 필요한 도구/모델이나 플랜이 없는 경우, `UNVERIFIED`는 상태를 확인하지 못한 경우다. `UNVERIFIED`를 미설치라고 단정하지 않는다.
4. 쓸 수 있는 비고정 대체 후보가 있으면 해당 큐만 넘기고 원래 도구 설치를 요구하지 않는다. **필수 큐가 여전히 막혔거나 공급자가 고정된 경우**, 빠진 도구와 필요한 행동을 제작 초기에 한 번에 안내한다. 공식 설치 방법이 확인된 `MISSING`에만 설치를 안내하고, 인증 누락은 계정 연결, 기능 누락은 지원 경로/플랜 확인을 안내한다. 공식 경로가 미확인이면 설치 명령을 지어내지 않고 수동용 입력을 제공한다. 구현에는 패키지 자동 설치나 자동 로그인 없음.

## 큐별 후보와 대체 순서

| 별도 큐 | 선택 기준 및 다음 후보 |
|---|---|
| 내레이션·캐릭터 대사 | 승인된 녹음이나 고정된 화자 우선. **연기 중심:** Fish Audio `drama-3` → ElevenLabs TTS → Typecast. **Typecast 반복 포맷:** Typecast → Fish Audio `drama-3` → ElevenLabs TTS, 단 화자 교체를 허용한 경우만. **ElevenLabs 승인 보이스/워크플로우:** ElevenLabs TTS 먼저; 고정 정체성이 아니면 같은 큐 요구에 맞춰 Fish 또는 Typecast를 평가한다. 순서는 동률을 푸는 기준이다. 실제 언어·발음·감정 제어·허용 음색·화자 수·길이를 만족하지 않는 후보는 건너뛴다. 화면 속 대사는 화자 일관성과 립싱크를 별도로 검수한다. |
| 효과음·폴리·환경음 | **ElevenLabs SFX** → 권리 확인된 기존 효과음 → 직접 녹음 폴리 → 별도 트랙이 필수가 아닐 때 지원 확인된 영상 내장 SFX. TTS 연결만으로 ElevenLabs SFX 준비 완료를 표시하지 않는다. Fish와 Typecast는 효과음 후보로 사용하지 않는다. |
| BGM·OST·캐릭터 송·음악적 스팅 | **Suno** → 프로젝트에서 사용할 권리가 확인된 기존 곡/스톡 → 선택 큐일 때만 무음악안. 이 제작 정책에서는 ElevenLabs를 음악 후보로 쓰지 않는다. 업체의 전 제품군에 대한 기능 단정이 아니다. 필요한 음악을 일반 효과음으로 대체하지 않는다. |

ElevenLabs의 TTS와 SFX는 두 개의 독립 가용성 판정이다. 표의 공급자는 역할상 후보이며, 이 환경의 실제 연결 가능성이나 음질 순위를 보장하지 않는다. 기존 확인에서 Fish `drama-3`와 Typecast 합성 스키마는 노출됐지만, ElevenLabs SFX 실행 도구는 확인되지 않았다. ElevenLabs 음성·효과음 기능은 실행 전 각각 새로 확인한다.

## 자동으로 이어받는 조건

- **계획 전환은 자동:** 연결 불가, 기능 미지원, 또는 제출 전 확정된 비가용 후보는 건너뛰고 다음 적격 후보를 지정한다. 기존에 정한 제공자·보이스·모델·외부 전송 제한을 깨는 전환은 사용자의 결정이 필요하다. Fish의 `drama-3` 고정 요청을 Fish 기본 모델로 바꾸지 않는다.
- **생성 전환은 사전 승인 범위 안에서만 자동:** 큐별 허용 후보, 외부로 보내도 되는 입력, 화자 교체 허용 여부, 누적 비용/시도 한도가 기록돼 있고 다음 후보가 전부 충족하면 재질문 없이 이어서 생성한다. 원래 공급자만 승인됐거나 한도·권리·전송 범위를 벗어나면 대체 입력을 준비한 상태로 승인을 요청한다. 기본 순서에 있다고 승인된 것은 아니다.
- **애매한 결과에는 대체 생성 금지:** 타임아웃·연결 단절 뒤 접수 여부가 불명확하면 작업 ID/이력으로 먼저 대조한다. 불명확한 동안은 재시도도 다음 공급자 호출도 하지 않는다. 유료 결과가 났지만 품질이 불합격하면 검수 사유와 이미 든 비용을 기록한 뒤, 승인된 재작업·대체 한도 내에서만 다음 후보로 간다.
- **같은 큐를 인계:** 큐 ID, 원고 버전, 발음·연기, 의도한 컷/길이, 금지 조건, 이전 실패 및 집행 여부를 유지한다. 이전 공급자 전용 태그는 떼고 새 입력 규격으로 다시 옮긴다. 내레이션 테이크가 달라지면 그 음성에 의존하는 컷·자막 타이밍만 다시 맞춘다. 이미 채택된 다른 트랙은 그대로 둔다.

## 구현 인수 기준

- 이미 인증된 적격 도구에는 설치 안내 0건. MCP 없이 적격 공식 경로가 있으면 같은 공급자로 진행. 미설치/미인증/기능 누락/미확인 상태를 서로 잘못 보고하지 않는다.
- Fish가 없고 ElevenLabs TTS가 준비된 비고정 연기 큐는 ElevenLabs로 인계한다. TTS만 연결된 ElevenLabs는 SFX 큐를 받을 수 없다. 고정 보이스와 `drama-3` 요청은 변경하지 않는다.
- 다음 후보가 승인 목록과 비용·전송 한도 안이면 이어받고, 그 밖이면 준비까지만 한다. 타임아웃 후 미확정 작업은 두 번째 유료 호출 없이 정지한다.
- Suno 장애에서 ElevenLabs 음악 호출 금지. 필수 SFX나 음악이 미해결이면 그 큐만 보류하며, 독립 대본·보드·편집 준비는 계속한다.
