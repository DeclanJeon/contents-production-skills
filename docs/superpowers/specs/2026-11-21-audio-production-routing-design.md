# 영상 오디오 제작 및 대체 경로 설계

- 날짜: 2026-11-21
- 상태: 라우팅 문서 구현 승인 및 반영. 실제 오디오 생성·비용 집행은 미실시.
- 선행 설계: [Suno 음악 스킬](2026-11-21-suno-music-design.md)

## 목적과 소유권

`creative-production`이 콘셉트·장면·편집 의도에서 필요한 소리를 결정하고, **독립 오디오 에셋이 필요한 때만** 유형별 전문 경로에 배정한다. 요청에 공급자 이름이 없어도 별도 에셋이 범위에 들어오면 아래 기본 후보로 설계할 수 있다. 후보 선택은 생성·외부 전송·과금 승인이 아니다. 영상의 주 경로와 단일 프로젝트 작성자를 유지한다. `orchestrating-video-preproduction`은 텍스트 큐와 누락된 요구사항을 반환하고 공급자를 선택하거나 호출하지 않는다.

검토한 선택지: (1) 모든 소리를 영상과 함께 생성하면 작업은 짧지만 편집과 테이크 교체가 어렵다. (2) 항상 세 종류의 별도 트랙을 만들면 통제가 늘지만 불필요한 비용과 싱크 작업이 생긴다. **(3) 장면별로 재사용·영상 내장·별도 에셋을 섞는 방식을 권고한다.** 독립 음악·효과음 권한이 없는 일반 영상은 [영상 내장 음향 기본값](../../../creative-production/references/video-generation-planning.md#3b-voice-and-sound-design-are-in-request-by-default)을 유지한다.

## 결정 순서

1. **범위 잠금:** 무음·무음악·내레이션만·특정 공급자 고정·첨부 음원·권리 제한을 먼저 적용한다. 의도된 정적에는 어떤 생성도 배정하지 않는다.
2. **소리의 역할 결정:** 내레이션/대사, 효과음·폴리·환경음, BGM·OST·캐릭터 송, 또는 의도된 정적으로 큐를 분류한다. 분류는 길이보다 역할을 따른다. 문고리의 1초 충격음은 효과음, 테마의 1초 로고 사운드는 음악 큐다.
3. **에셋 방식 선택:** 지정된 기존 테이크를 먼저 사용한다. 재사용할 소리가 없으면, 독립 편집·교체·연속성·정확한 싱크가 필요한 큐나 별도 제작을 요청한 큐를 분리한다. 나머지는 지원이 확인된 영상 모델의 내장 음향으로 설계할 수 있다. 내장 음향을 지원하지 않는 모델에서는 지원 여부를 추정하지 않는다.
4. **별도 큐의 도구 후보 배정:** 아래 표를 따른다. 사용자 지정이나 이미 승인된 음색·테이크를 기본 후보보다 우선한다. 문제가 없으면 한 큐에 공급자 하나만 제안한다.

| 별도 큐 | 기본 후보와 입력 | 후보 선택 기준 |
|---|---|---|
| 내레이션·오프스크린 음성 | Fish Audio **Drama 3** 또는 **Typecast**. 발화 원고, 표시 자막 원고, 발음표, 호흡·강세·연기 지시, 화자 ID를 분리한다. | 기존 승인 보이스 우선. 새 연기·감정 변화 중심이면 Fish `drama-3`를 우선 제안한다. 검증된 Typecast 화자 또는 반복 포맷이 있거나 동일 화자·톤 유지가 우선이면 Typecast를 우선 제안한다. 한국어 발음과 톤의 적합성은 청취로 판단한다. 화면 속 대사는 립싱크 제약이 있는 별도 음성 의존 작업이다. |
| 효과음·폴리·환경음 | **ElevenLabs SFX**. 소리의 원인·재질·거리감, 시작/강조/잔향, 원샷/루프 의도, 컷 기준점을 적는다. | 독립적으로 움직이거나 레이어링할 효과음을 대상으로 한다. ElevenLabs TTS/보이스 도구는 SFX 실행 도구가 아니다. |
| BGM·OST·캐릭터 송 | **Suno.com**, 실행 시 공식 Suno MCP가 적격 경로. 기존 [`suno-music`](../../../suno-music/SKILL.md)에 역할·감정 변화·편곡·보컬 여부·고정 가사를 넘긴다. | 반복할 테마, 내레이션 밑에 깔 곡, 독립 보컬곡, 음악적 스팅·루프에 사용한다. 생활 효과음을 Suno에 자동 대체하지 않는다. 캐릭터 송의 보컬이 캐릭터 대사와 같다고 보장하지 않는다. |

## Fallback: 무엇을 바꿀 수 있는가

| 상황 | 허용되는 다음 단계 | 금지하거나 다시 승인받을 사항 |
|---|---|---|
| 이미 가진 음원이 있다 | 버전·지정 용도·권리·실제 품질을 확인해 재사용. 기존 소스를 자르거나 믹싱할 때도 편집 권한을 확인한다. | 출처·권리가 불명인 기존 파일이나 임시 음원을 최종 채택으로 표시하지 않는다. |
| TTS 후보가 불가하거나 발음/연기가 불합격 | 같은 승인 보이스에서 원고/발음/연기 중 문제만 수정하거나, 허용된 기존 녹음을 제안한다. 고정 화자가 아니라면 다른 TTS의 짧은 샘플을 **별도 승인 후보**로 제시한다. | Fish의 기본 모델로 조용히 강등하지 않는다. 공급자·모델·정체성 변경이나 유료 재생성은 기존 승인 범위 확인 후에만 한다. 승인이 없으면 타이밍은 추정으로 남긴다. |
| ElevenLabs SFX 실행 불가 | 권리 확인된 기존 SFX 라이브러리, 직접 녹음 폴리, 또는 독립 트랙이 필수가 아닐 때 지원이 확인된 영상 내장 SFX를 제안한다. | 지원 여부가 확인되지 않은 도구로 생성하지 않는다. 핵심 효과음의 누락을 무음으로 숨기지 않는다. |
| Suno 실행 불가 | 권리 확인된 기존 음악, 새로 권리 확보할 스톡 음악, 또는 콘셉트상 선택적인 음악에 한해 무음악 편집을 제안한다. | 음악이 필수면 미해결로 남긴다. 사용자 승인 없이 타 음악 생성 서비스나 영상 모델의 BGM으로 바꾸지 않는다. |
| 인증·예산·권리 또는 실행 승인 부족 | 입력, 컷 메모, 가능한 대안을 반환하고 독립 작업을 계속한다. | 로그인·계정 연결·설치·외부 전송·과금·게시를 묵시 승인으로 취급하지 않는다. |
| 생성 호출이 타임아웃/응답 불명 | 작업 ID·이력으로 유료 호출의 실제 상태를 먼저 조회한다. 확인 불가 시 미확정으로 남긴다. | 새 요청을 자동 제출하거나 다른 공급자를 즉시 호출하지 않는다. 재시도는 현재 권한과 공급자의 멱등성 규칙을 확인한다. |

## 제작 단계와 인수 기준

- **대본·보드:** 콘셉트와 컷마다 소리의 기능과 정적을 적는다. 필요한 큐만 기존 사운드 큐 시트에 기록한다. **내레이션 주도** 작업은 현재 내레이션 우선 워크플로우와 같이 가편집용 보드/샷 구상까지는 예상 길이로 진행하되, 최종 컷·자막 타이밍은 실제 승인 음성에서 다시 산출한다. 일반적인 영상의 보드 이전에 외부 합성을 강제하지 않는다.
- **S07 설계:** 기존 큐 시트에 큐 ID, 장면/컷/비트 ID와 소스 버전, 소리의 역할, 의도한 시작·끝/악센트, 대사 겹침, 필수/선택, 재사용·내장·별도, 공급자 후보, 권리·승인·검수 상태를 남긴다. 별도 원장을 만들지 않는다. 설계만 요청하면 여기서 반환한다.
- **S08 실행:** 라이브 스키마·가용 계정·권리·예상 비용·외부로 전송할 원고/참조·호출/결과 수를 확인한다. 승인 범위가 없는 큐만 보류한다. Fish `model`과 `voice_id`는 구분한다. 특정 보이스의 사용 권한과 생성 오디오의 상업 이용 권한을 별개로 확인한다.
- **편집·검수:** 생성 접수, 재생 가능, 실제 청취 검수, 최종 채택을 분리한다. 내레이션은 발음·누락·호흡·레벨을, 효과음은 프레임 싱크·잔향·루프 이음새를, 음악은 대사 마스킹·전개·컷 연결을 확인한다. 파일 버전/해시, 실측 길이 및 채택 구간을 기존 프로젝트 기록에 반영한다. 최종 믹스에서 내장 음향과 별도 트랙의 중복 재생을 확인한다. 미청취 또는 권리 미확인은 검수 완료가 아니다.

## 현재 확인 범위와 구현 인수 테스트

- 2026-11-21 읽기 전용 도구 스키마 확인: Fish MCP `text_to_speech`는 `drama-3` 명시 선택을 노출하며, Typecast MCP `generate_speech`는 화자 ID 기반 합성을 노출한다. Suno는 기존 설계의 확인 결과를 재사용한다. ElevenLabs SFX 실행 도구는 이번 MCP 탐색에서 발견하지 못했고 공식 페이지 조회도 완료하지 못했다. 따라서 **ElevenLabs는 설계상 기본 후보이고, 현재 세션의 실행 경로는 미확인**이다. 구현 전 지원 도구 및 인증된 실행 방식 확인이 필요하며 임의 API 키나 새 의존성을 도입하지 않는다.
- 구현 위치는 `creative-production` 조건부 공급자 경로와 텍스트 프리프로덕션 핸드오프, 기존 Suno 스킬 참조에 한정한다. 기존 Suno 문구의 ‘사용자가 직접 공급자 선택’과 새 ‘별도 음악 기본 후보’가 충돌하지 않게 두 규칙의 차이를 명시한다. 설계 후보만 자동 선정할 수 있다.
- 인수 시나리오: 일반 내장 음향 유지 / 무음 / 승인 음원 재사용 / 내레이션 우선 영상의 잠금 전후 타이밍 / 효과음과 음악적 스팅 구분 / 혼합 영상에서 세 큐의 올바른 전달 / ElevenLabs SFX 도구 없음 / 특정 모델·화자 고정 / 비용 승인 없음 / 타임아웃 중복 차감 방지. 문서·라우팅 시험과 실제 유료 생성·청취 검증을 분리한다.
