# 측정 기하 (Measured geometry)

`ref-*.png`에서 1080×1920로 스케일해 **픽셀로 측정**한 웹툰 페이지 문법. 레퍼런스 채널의 정체성·로고·작품·조회수·메타 문자열은 재현하지 않는다.

## 페이지 골격

| 요소 | 값 | 비고 |
|---|---|---|
| 캔버스 | 1080×1920, 30 fps | `W, H, FPS` |
| 헤더 바 | 높이 213 px, 배경 `#fdedb6` (253,237,182) | 최상단 전체 폭 |
| 햄버거 아이콘 | x 63–126, y 95–152, 3줄 | 막대 두께/피치 비율 0.30 |
| 제목 | 상단 286 px | 크기 66 |
| 메타 | 상단 380 px, x 128 | 크기 36 |
| 구분선 | y 449, 높이 5, `#5a5a5a` (90,90,90) | |
| 본문 | 상단 533 px, 줄 간격 64, 최대 폭 830 | 크기 46, 최대 3줄 |
| 패널 박스 | (85, 690) → (993, 1890), 908×1200 | 페이지 배경 `#ffffff` |
| 채널 라벨 | 크기 74, 최대 폭 830 | 스모크 시 `LOCAL TEMPLATE / NOT FOR UPLOAD` |

## 패널 채움과 크롭

- 패널 박스는 **가장자리까지** 아트워크가 채워진다(레터박스 금지). 소스 패널 941×1672 (+1장 940×1672).
- 인물을 측정할 수 없을 때의 세로 크롭 편향: `PANEL_CENTERING = (0.5, 0.50)`.
- 머리가 잘리지 않도록 크롭 상단 위로 `PANEL_HEAD_MARGIN = 0.10`을 남긴다.
- "잉크" 판정 임계값 `PANEL_INK_THRESHOLD = 110` (이 휘도 미만 = 캐릭터 선).
- **함정:** 패널 가장자리 픽셀의 옅은 배경(213–249)은 페이지 흰색(255)이 아니다. 이것을 근거로 렌더러를 "고치지" 말 것. 측정값이 정본이다.

## 템플릿 검증

- `channel_label`은 호출자 제공. 레퍼런스 채널명(`썰툰`)이면 **거부**한다.
- `meta_label`에 조회수/`views`/천단위 콤마 숫자가 있으면 **거부**한다 (`FORBIDDEN_META`).
- 라벨이 최대 폭을 넘으면 오버플로 대신 **축소**한다.
- **함정:** 라벨 쓰기는 바이트가 정본이다. 비전 모델이 `쓰멜씸`을 잘못 읽어도 그 판독으로 템플릿을 "고치지" 말 것.

## 샷 윈도우

샷 윈도우는 프레임 정렬되어 합이 정확히 1800 프레임(=60.000 s)이어야 한다. 초는 소수 6자리로 저장하고 `round(length*FPS)`가 `length*FPS`와 1e-3 이내로 일치하지 않으면 거부한다. 비정렬 창은 리핏 스크립트로 다시 맞춘다.

## 검증 순서

1. 페이지 프레임 픽셀 검사(바 배경, 좌우 여백 흰색, 구분선 어두움, 패널 가장자리 채움).
2. 패널 크롭에서 머리가 박스 안에 있는지.
3. 템플릿 거부 규칙.
4. 샷 창 합계 1800.
