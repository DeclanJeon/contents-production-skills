# 측정 기하 (Measured geometry)

아래는 기존 렌더러의 1080×1920 **템플릿 규격**이다. 과거 `ref-*.png` 측정에서 유래했다는 기록은 있으나 원본 파일·해시·측정 위치가 없는 현재 문서만으로 재측정 완료를 주장하지 않는다. 레퍼런스 채널의 정체성·로고·작품·조회수·메타 문자열은 재현하지 않는다. 새 입력의 실측은 파일 해시, 원본 크기, 스케일 변환, 픽셀/박스 좌표와 검사 산출물을 별도 기록한다.

## 패널 채움과 크롭

- 패널 박스는 가장자리까지 채운다(레터박스 금지). 원본 패널은 941×1672, 추가 1장은 940×1672다.
- 인물 위치를 측정할 수 없으면 `PANEL_CENTERING = (0.5, 0.50)`을 기본 세로 크롭 편향으로 사용한다.
- `panel_centering()`의 중앙 어두운 픽셀은 **후보 크롭 기준**일 뿐이다. `PANEL_HEAD_MARGIN = 0.10`은 목표 간격이지 머리 검출이나 보존 보장이 아니다. 이 휴리스틱은 중앙 인물 선화가 배경보다 어둡다고 가정한다. 인물이 중앙 밖에 있거나, 배경에 어두운 세부가 있거나, 임계 픽셀이 없거나, 소스 종횡비·편향 클램프가 영향을 주면 추정이나 목표 간격이 틀릴 수 있다.
- **함정:** 패널 가장자리의 옅은 배경은 페이지 흰색과 다를 수 있다. 213–249는 과거 기록이지 모든 입력의 보장 범위가 아니다. 실제 소스 픽셀과 렌더된 크롭을 확인한다. 이 차이만으로 레터박스나 렌더 오류라고 판정하지 않는다.

## 템플릿 검증

- `channel_label`은 호출자 제공. 레퍼런스 채널명(`썰툰`)이면 **거부**한다.
- `meta_label`에 조회수/`views`/천단위 콤마 숫자가 있으면 **거부**한다 (`FORBIDDEN_META`).
- 라벨이 최대 폭을 넘으면 오버플로 대신 **축소**한다.
- **함정:** 라벨 쓰기는 바이트가 정본이다. 비전 모델이 `쓰멜씸`을 잘못 읽어도 그 판독으로 템플릿을 "고치지" 말 것.

## 샷 윈도우

샷 윈도우는 프레임 정렬되어 합이 정확히 1800 프레임(=60.000 s)이어야 한다. 초는 소수 6자리로 저장하고 `round(length*FPS)`가 `length*FPS`와 1e-3 이내로 일치하지 않으면 거부한다. 비정렬 창은 리핏 스크립트로 다시 맞춘다.

1. 페이지 프레임 픽셀을 검사한다(바 배경, 좌우 여백, 구분선, 패널 가장자리 채움).
2. 실제 크롭에서 의도한 인물과 필요한 머리·얼굴 세부가 보이는지 확인한다. 어두운 픽셀 휴리스틱은 검수 근거가 아니다. 눈으로 확인하기 전에는 보존 여부를 미검증으로 기록한다.
3. 템플릿 거부 규칙을 확인한다.
4. 샷 창 합계가 1800 프레임인지 확인한다.
