# Suno Music

## 1. Read the cue

Reuse the supplied brief or coordinator packet. Identify the purpose, desired interval, dialogue overlap, vocal requirement, fixed lyrics and exclusions. Retain scene/shot/beat IDs and source versions when supplied. Ask only for an unknown that changes the route or blocks useful work; label reversible choices as proposals.

## 2. Choose inputs

Read [Suno fields and examples](references/suno-inputs.md) for the selected branch:

- **Narration BGM:** instrumental; keep space under speech. Describe the intended emotional change, tempo feel, core instruments, density and ending.
- **Vocal song:** open exploration uses Simple; approved lyrics use Custom with the supplied lyrics separate from vocal delivery and arrangement. Section names are hints.
- **Short sting or loop:** Sounds, not full-song generation. Describe onset, accent and tail for a sting; for a loop, describe the repeating bed and select loop mode.

Return the selected mode and paste-ready fields, an edit note for cut-sync/loop/trim where relevant, and a listening check. Treat exact timing as an edit target, not a prompt guarantee. On revision, preserve accepted choices and change one audible variable at a time.

## 3. Stop at the authority boundary

Prompt, planning and input-review requests stop at the proposed fields. A video handoff returns these fields against the cue IDs to the coordinator; it does not make a new project record or select another production owner.

For requested generation, discover the live Suno tools and current account capabilities read-only. Verify model/default, call count, expected outputs and credit cost, and any external input transfer. Obtain explicit approval of that scope before any credit-bearing call. If approval or the eligible tool is missing, return the prepared inputs and the blocker; do not silently switch providers, elevate settings, or submit a test job.

After approval, use only the selected call and approved inputs. Reconcile uncertain submission status before retrying and reuse the operation's idempotency key when supported. Do not publish. Distinguish submitted, playable, and actually listened-to; if playback cannot be inspected, say so. Report clip IDs and observed duration/status where available. The parent coordinator adopts the track and owns any video records and edit decisions.
