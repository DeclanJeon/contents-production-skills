# 영상에서 무빙을 읽는 절차

## 관찰과 역추정
- 팬/틸트 후보: 고정 배경의 화면 방향 변화. 회전 중심·센서·렌즈가 없으면 실제 각도는 불명확하다.
- 돌리/트럭/아크 후보: 서로 다른 깊이의 정적 특징에서 시차·가림·원근 변화. 움직이는 배경·합성 변형을 먼저 배제한다.
- 줌/디지털 크롭 후보: 크기 변화와 시차/원근 근거를 함께 확인한다. 피사체가 다가오는 경우도 고려한다. 줌과 돌리의 혼합도 가능하다.
- 추적 후보: 피사체는 화면에 머무르는데 배경이 이동. 실제 피사체 운동과 카메라 운동을 독립적으로 설명한다.
- 랙 포커스 후보: 대상 간 선명도 전환. 렌즈 호흡이 프레이밍에 영향을 줄 수 있어 이것만으로 위치 이동을 선언하지 않는다.
- 핸드헬드 후보: 불규칙 흔들림이 보여도 리그/후처리 원인은 추정이다. 의도적 흔들림·안정화 결함·생성 오류를 동일시하지 않는다.

## 시간과 수치
source_time_range, shot_local_time, PTS/time_base 또는 명시된 CFR fps, 실제 검사 구간을 적는다. move_start, acceleration_change, reveal/contact/emotion_peak, settling, cut 전후를 관찰한다. 빠른 움직임은 더 촘촘히 확인한다.
정규화 위치 변화와 픽셀 변위는 화면 측정이다. m/s·degrees/s로 바꾸려면 장면·카메라 캘리브레이션이 필요하다. 솔브 스케일은 알려진 거리로 설정하지 않으면 임의 단위다. 정확한 복원 없이도 근거 있는 정성 브리프를 납품할 수 있다.

## 재사용
원본 소재 복제보다 정보를 공개하는 기능을 새 소재에 적용한다. 길이·장소·피사체가 달라지면 경로·타이밍을 다시 설계한다. 원본 관찰 시각은 새 영상의 승인된 목표 시간이 아니다.
