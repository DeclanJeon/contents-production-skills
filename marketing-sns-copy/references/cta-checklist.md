# CTA 체크리스트

StoryBrand(직접/전환형 CTA), 1-Page Marketing Plan(하나의 제안, 리드 육성), Launch(실제 희소성), Content Inc.(소유 채널) 원칙을 재서술한 점검표.

## 1. CTA 유형 고르기

| 고객 단계 | CTA 유형 | 예 |
|---|---|---|
| 처음 봄 | 가벼운 참여 | 저장, 공유, 댓글로 의견, 팔로우 |
| 관심 | 전환형(관계 유지) | 무료 자료 받기, 뉴스레터 구독, 체험 신청 |
| 비교·결정 | 직접 | 구매, 예약, 상담 신청, 가격 보기 |
| 기존 고객 | 확장·추천 | 후기 남기기, 친구 초대, 재구매 |

## 2. CTA 품질 점검

- [ ] 게시물당 **주 CTA는 하나**인가? (보조 CTA는 최대 하나)
- [ ] 동사로 시작하고, 무엇을 하면 무엇을 얻는지 분명한가?
- [ ] 고객 단계에 맞는가? (처음 보는 사람에게 바로 구매만 요구하지 않는가)
- [ ] 클릭 이후 경험(랜딩·프로필 링크·DM 자동응답)이 CTA의 약속과 일치하는가?
- [ ] 플랫폼의 링크 위치에 맞게 안내하는가? (캡션 링크 불가 플랫폼은 "프로필 링크" 등 — 현재 정책 확인)
- [ ] 위험 감소 요소가 있는가? (가격 명시, 무료, 보증, 취소 쉬움 — 사실인 것만)
- [ ] 희소성·마감·한정은 **사실**인가? 가짜 긴급성은 금지.
- [ ] 광고·협찬 표기, 규제 문구가 필요한 업종이면 포함했는가?
- [ ] 일부 CTA는 구독·이메일 같은 **소유 채널**로 이어지는가?

## 3. CTA 테스트 설계

- CTA 문구만 바꾸고 나머지는 고정한다.
- 판정 지표: 목표 행동 전환(클릭, 신청, 구매)이 1차, 저장·공유는 보조.
