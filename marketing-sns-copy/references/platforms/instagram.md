# Instagram 카피 가이드 (피드 · Reels · 캐러셀 · 스토리)

> 참고값(미확인): 캡션 최대 약 2,200자, 캡션은 처음 1~2줄 이후 접힘, 해시태그 개수 상한 존재, 캡션 내 링크는 클릭 불가(프로필 링크·스토리 링크 스티커 사용). 작성 시점에 확인한다.

## 형식 단위

Reels(화면 텍스트 + 캡션), 캐러셀(장별 문구), 단일 이미지 피드, 스토리(스티커: 링크·투표·질문), 프로필 소개

## 원칙

- **캡션 첫 줄**이 "더 보기" 전 유일한 노출이다. 이득·공감·의외성으로 시작한다.
- **캐러셀 = 저장할 가치**(실용 가치). 1장: 약속(훅), 2~n장: 한 장 한 포인트, 마지막 장: 요약 + CTA(저장·공유·프로필 링크).
- **Reels**: TikTok과 같은 첫 3초 원칙. 단, 같은 영상이라도 화면 텍스트·캡션을 Instagram 말투로 다시 쓴다.
- **스토리**: 가볍고 즉각적인 CTA(투표, 질문, 링크 스티커). 판매 공지보다 대화.
- **시각 브랜드 일관성**(How Brands Grow의 독특한 자산): 캐러셀 템플릿, 색, 폰트, 고정 문구를 반복한다.
- 해시태그는 많이보다 관련성. 검색 키워드는 캡션 문장 속에도 자연스럽게 넣는다.

## 템플릿

```
[캐러셀]
1장: [약속/질문 훅]
2장: [포인트 1]
3장: [포인트 2]
4장: [포인트 3]
5장: [요약] + [저장/공유/프로필 링크 CTA]
캡션 첫 줄: [1장 훅을 다른 말로]
캡션 본문: [맥락 2~3줄] [CTA] [해시태그 소수]
```

## 점검

- [ ] 캡션 첫 줄만으로 가치가 보인다
- [ ] 캡션 내 링크를 클릭하라고 안내하지 않는다(정책 확인)
- [ ] 캐러셀 각 장이 한 포인트
