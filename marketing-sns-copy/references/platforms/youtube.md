# YouTube 카피 가이드 (롱폼 · Shorts)

> 사양 수치는 플랫폼이 수시로 바꾼다. 아래 "참고값"은 작성 시점에 공식 도움말로 다시 확인하고, 확인 못 하면 산출물에 "미확인"으로 표기한다.

## 형식 단위

- 롱폼: 제목, 썸네일 문구, 설명란(첫 2~3줄이 접히기 전 노출), 챕터, 고정 댓글, 커뮤니티 게시물
- Shorts: 화면 첫 텍스트, 제목, 짧은 설명
- 참고값(미확인): 제목 최대 약 100자, 설명 최대 약 5,000자, Shorts 최대 길이 약 3분

## 원칙

- **제목 = 헤드라인.** 이득 또는 뉴스(Ogilvy), 의외성 + 구체성(Made to Stick). 검색 의도가 있는 주제는 고객이 실제로 치는 말을 앞쪽에 둔다.
- **제목과 썸네일 문구는 역할을 나눈다.** 같은 말을 반복하지 말고, 하나는 주제/약속, 다른 하나는 감정/간극을 맡는다(`higgsfield-youtube-thumbnail`과 연결).
- **첫 30초(롱폼) / 첫 1~3초(Shorts)** 에 제목의 약속을 확인시켜 준다. 약속과 다른 도입은 이탈로 이어진다.
- **설명란 첫 줄**은 영상의 가치를 한 문장으로, 그다음 CTA(구독·링크)와 챕터.
- 롱폼은 시리즈·재생목록으로 다음 시청을 유도하는 CTA가 자연스럽다(소유 관계 강화: Content Inc.).

## 템플릿

```
제목: [고객이 원하는 결과/질문] + [구체 요소]
썸네일 문구(2~4단어): [감정/간극]
설명 1줄: 이 영상에서 [대상]은 [얻는 것]을 알게 됩니다.
CTA: [하나]
챕터: 00:00 …
```

## 점검

- [ ] 제목-썸네일-첫 장면이 같은 약속을 한다
- [ ] 제목에 과장·낚시 없음
- [ ] 설명 첫 줄만 봐도 가치가 보인다
