# X 카피 가이드

> 사양 수치는 작성 시점에 확인한다. 참고값(미확인): 일반 계정 게시물 280자 기준(유료 구독자는 더 긴 게시 가능), 이미지·영상·투표 첨부 가능.

## 형식 단위

단일 게시물, 스레드(연결 게시물), 인용, 답글, 이미지/영상 첨부

## 원칙

- **첫 문장이 전부다.** 피드에서 잘리기 전 첫 줄에 이득·뉴스·의외성 중 하나를 둔다.
- **한 게시물 = 한 주장.** 길어지면 스레드로 나누고, 첫 게시물만으로도 가치가 완결되게 쓴다.
- **스레드 구조**: 1) 약속(무엇을 얻나) 2~n) 한 칸에 한 포인트, 구체 사례·숫자 n+1) 요약 + CTA.
- 사회적 화폐·실용 가치(STEPPS)가 리포스트 이유가 된다: "아는 사람만 아는 것", "저장해둘 체크리스트".
- 대화형 플랫폼이므로 질문·의견 요청 CTA가 자연스럽다. 단, 분노 유발 논쟁 낚시는 금지.
- 링크는 맥락을 먼저 주고 뒤에 둔다(링크 노출 정책은 변하므로 확인).

## 템플릿

```
1/ [이득 또는 의외성 한 줄]. [무엇을 다룰지]
2/ [포인트 1 + 구체 예]
3/ [포인트 2 + 구체 예]
…
n/ 요약: [한 줄]. [CTA 하나]
```

## 점검

- [ ] 첫 줄만 보고 멈출 이유가 있다
- [ ] 각 게시물이 한 포인트
- [ ] 해시태그는 0~2개, 의미 있는 것만
