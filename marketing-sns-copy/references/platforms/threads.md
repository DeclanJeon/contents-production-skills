# Threads 카피 가이드

> 참고값(미확인): 게시물당 텍스트 약 500자, 이미지·영상·링크 첨부 가능. 작성 시점에 확인한다.

## 형식 단위

텍스트 게시물, 이어지는 연결 게시물, 이미지·캐러셀, 답글, 주제(토픽) 태그

## 원칙

- **대화 톤.** 광고 문구보다 사람의 말투가 맞는다. 브랜드도 1인칭·구어체를 기본으로 하되 보이스 가이드를 지킨다.
- **과정·생각 공유**(Show Your Work!)가 잘 어울린다: 만들면서 배운 것, 시행착오, 뒷이야기.
- 첫 줄에 공감 또는 의외성. X보다 길게 써도 되지만 첫 2줄 안에 핵심을 둔다.
- **질문으로 끝내기**가 자연스럽다. 답글을 유도하되, 답글에 실제로 반응할 계획이 있을 때만.
- Instagram과 연결된 청중이 많으므로 Instagram 카피를 그대로 붙이지 말고 텍스트 중심으로 다시 쓴다.

## 템플릿

```
[공감되는 순간 또는 의외의 관찰 1~2줄]
[내 경험/과정에서 얻은 구체적 포인트 2~3개]
[한 줄 정리]
[질문 또는 가벼운 CTA]
```

## 점검

- [ ] 광고문처럼 읽히지 않는다
- [ ] 첫 2줄에 핵심
- [ ] 판매 게시물 비중이 과하지 않다
