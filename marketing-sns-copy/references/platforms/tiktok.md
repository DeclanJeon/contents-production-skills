# TikTok 카피 가이드

> 참고값(미확인): 캡션 최대 약 4,000자, 영상 길이 선택 폭이 넓다(수 초~수 분). 작성 시점에 확인한다.

## 형식 단위

영상 첫 화면 텍스트(온스크린 훅), 말로 하는 첫 문장, 캡션, 해시태그, 고정 댓글, 댓글 답장 영상

## 원칙

- **관심사 기반 배포**(Day Trading Attention): 팔로워보다 콘텐츠 자체가 변수다. 처음 보는 사람 기준으로 쓴다.
- **첫 1~3초**: 화면 텍스트 + 첫 대사 + 첫 컷이 같은 약속을 한다. 화면 텍스트는 "이게 무슨 영상인지"를 바로 알려준다.
- **네이티브 말투**: 플랫폼 문화·유행 포맷을 이해하고 쓰되, 유행 음원·포맷의 권리와 브랜드 적합성을 확인한다.
- **소리 없이도 이해**되게 자막/화면 텍스트를 쓴다.
- 캡션은 보조: 맥락 한 줄 + 검색될 만한 키워드 + CTA. 길게 설명해야 하는 내용은 영상 안에서 해결한다.
- **댓글을 다음 콘텐츠로**: 질문 댓글에 답하는 후속 영상이 자연스러운 시리즈가 된다.
- UGC·리뷰 스타일 대본은 실제 사용 경험에 근거하고, 협찬이면 표기한다. 생성 영상이 필요하면 `higgsfield-generate` Marketing Studio(UGC 모드)로 넘긴다.

## 템플릿

```
온스크린 훅(첫 화면): [5~10자 내외 약속/질문]
첫 대사: [훅을 말로]
본문 비트: 1) … 2) … 3) …
마무리 대사 + CTA: [하나]
캡션: [맥락 한 줄] [키워드] [CTA]
```

## 점검

- [ ] 소리 꺼도 이해된다
- [ ] 첫 화면 텍스트가 안전 영역 안에 있다
- [ ] 광고처럼 보이는 첫 컷이 아니다(필요하면 결과·문제 장면부터)
