# 검증·성과 지표

카피는 가설이고, 게시 후 데이터가 판정한다. Ogilvy on Advertising(시험하라), How Brands Grow(도달과 정신적 가용성), Day Trading Attention(빠른 반복), 기존 `creative-production` 캠페인 검토 규칙을 바탕으로 정리했다.

## 1. 게시 전 자체 검수

- [ ] 포지셔닝 문장·차지할 단어와 카피가 일치한다.
- [ ] 훅의 약속을 본문이 지킨다.
- [ ] 모든 사실·수치·후기·비교에 출처가 있다(없으면 삭제하거나 "가정"으로 표시).
- [ ] 주 CTA 하나, 고객 단계에 맞다.
- [ ] 플랫폼 형식(길이, 링크, 해시태그, 화면 텍스트 안전 영역)을 작성 시점 기준으로 확인했다. 미확인 항목은 표기했다.
- [ ] 브랜드 보이스·금지 표현·규제 문구·광고 표기를 지켰다.
- [ ] 처음 보는 사람도 이해한다(내부 용어 없음).

## 2. 목표별 1차 지표

| 목표 | 1차 지표 | 보조 지표 |
|---|---|---|
| 인지·도달 | 비팔로워 도달, 노출 | 프로필 방문, 브랜드 검색 증가 |
| 참여·관계 | 저장, 공유 | 댓글 질, 팔로우 전환 |
| 영상 시청 | 초반 유지율(첫 3초), 평균 시청 비율 | 완주율, 재시청 |
| 트래픽 | 링크 클릭률 | 랜딩 체류, 이탈 |
| 리드 | 신청·구독 수, 리드당 비용 | 이메일 오픈 |
| 매출 | 구매 전환, CPA/ROAS | 객단가, 재구매 |

지표 이름·정의는 플랫폼마다 다르다. 실제 대시보드의 정의를 그대로 기록한다.

## 3. 측정 계획 형식

```
- 가설: [변수]를 [A→B]로 바꾸면 [지표]가 [방향]
- 고정 변수: …
- 기간/표본: [기간], 최소 노출 [N] (확보 못 하면 결론 보류)
- 판정 규칙: 예) 동일 기간 비교에서 1차 지표가 기준 이상 + 보조 지표 악화 없음 → 채택
- 다음 테스트: …
```

## 4. 규칙

- 실제 데이터(기간, 노출, 지출, 지표) 없이 "잘 될 것이다"를 결론으로 쓰지 않는다. 예측은 예측이라고 쓴다.
- 한 번에 한 변수만 바꾼다. 여러 개를 바꿨으면 "탐색"으로 표시한다.
- 참여율만 보지 않는다. 새로운 사람에게 닿았는지(도달)와 브랜드를 알아봤는지를 따로 본다.
- 분석 도구(예: Higgsfield Virality Predictor)의 점수는 게시 전 참고 신호다. 실제 성과로 보고하지 않는다.
- 광고 확대·중단 제안은 실제 캠페인 데이터가 있을 때만 하고, 지표·기간·판정 규칙을 함께 적는다.
