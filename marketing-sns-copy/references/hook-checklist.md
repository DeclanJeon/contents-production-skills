# 훅 체크리스트

훅 = 스크롤을 멈추게 하는 첫 1~3초(영상) 또는 첫 줄(텍스트)·제목. 아래 원칙은 Contagious, Made to Stick, Ogilvy on Advertising, Day Trading Attention 등에서 증류한 설계 가설이다.

## 1. 훅 각도 목록 (서로 다른 각도로 최소 5개)

| 각도 | 설명 | 예시 틀(직접 채울 것) |
|---|---|---|
| 이득 약속 | 결과를 먼저 약속 | "[기간] 만에 [결과]를 얻는 법" |
| 뉴스 | 새 기능·변화·발표 | "이제 [제품]에서 [새 기능]이 됩니다" |
| 의외성 | 통념 뒤집기 | "[통념]은 사실 반대입니다" |
| 질문/간극 | 답이 궁금한 질문 | "왜 [대상]은 [현상]일까?" |
| 대비/비교 | 대안과 나란히 | "[기존 방식] vs [새 방식]" |
| 공감/문제 | 고객의 순간 묘사 | "[구체적 불편한 순간], 겪어보셨죠?" |
| 실용 | 저장할 만한 팁 | "[주제] 체크리스트 3가지" |
| 사회적 화폐 | 아는 사람만 아는 것 | "대부분 모르는 [기능/사실]" |
| 이야기 | 사건으로 시작 | "[인물]이 [상황]에서 [선택]했다" |
| 증거/결과 먼저 | 결과물 화면을 먼저 | 완성 결과 → "이렇게 만들었습니다" |

## 2. 훅 품질 점검

- [ ] **본문이 지킬 수 있는 약속인가?** (낚시성 과장 = 실패)
- [ ] 대상 고객이 **자기 얘기**로 느끼는가? (코호트 명시)
- [ ] 이 콘텐츠가 **무엇에 관한 것인지** 첫 화면·첫 줄에서 바로 알 수 있는가?
- [ ] 구체적인가? (형용사 대신 숫자·장면·이름 — 숫자는 검증된 것만)
- [ ] 전문 용어·내부 약어가 없는가? (지식의 저주)
- [ ] 핵심 메시지/포지셔닝 단어와 연결되는가? (의외성만 있고 브랜드와 끊긴 훅 금지)
- [ ] 브랜드를 알아볼 신호(말투, 시그니처 포맷, 색)가 초반에 있는가?
- [ ] 영상이면: 화면 텍스트·첫 컷·첫 대사가 같은 약속을 하는가? 소리 없이도 이해되는가?
- [ ] 플랫폼 형식에 맞는가? (제목 길이, 캡션 접힘 위치, 화면 안전 영역)
- [ ] 분노·공포·혐오를 자극하는 방식에 기대고 있지 않은가?

## 3. 훅 테스트 설계

- 훅만 바꾸고 본문·CTA·비주얼은 고정한 세트를 만든다(무엇을 고정했는지 목록으로 남긴다).
- 판정 지표: 영상은 초반 유지율·3초 시청 비율, 텍스트는 노출 대비 클릭/펼치기·참여.
- Higgsfield Virality Predictor 같은 분석 결과는 게시 전 정성 신호일 뿐, 측정 성과가 아니다.
