# 마케팅·SNS 카피

독립 카피 산출물을 위한 비영상 스킬이다. 영상 코디네이터(`creative-production`)를 활성화하지 않는다. 원칙은 참고 도서에서 증류한 **설계 가설**이며, 도달·전환·바이럴을 보장하지 않는다. 성과 주장은 실제 데이터가 있을 때만 한다.

## 언제 쓰는가

- 제품·서비스·콘텐츠를 알리는 SNS 게시물, 광고 문구, 캡션, 제목, 스레드, CTA를 써달라는 요청
- 기존 카피를 플랫폼별로 변형하거나 A/B 세트를 만들라는 요청
- 카피가 왜 약한지 진단·수정하라는 요청

다음은 다른 오너로 넘긴다(연결 지점은 아래 "기존 스킬과의 연결" 참조).

- 영상 자체의 기획·콘티·생성·편집 → `creative-production`
- 어떤 주제가 수요가 있는지 고르는 일 → `topic-demand-selection` (+ 공개 게시물 근거 수집은 `searching-social-media`)
- 광고/UGC 영상 생성, 완성 영상의 훅·주의 분석 → `higgsfield-generate` (Marketing Studio, Virality Predictor)
- YouTube 썸네일 이미지 → `higgsfield-youtube-thumbnail`

## 입력 확인 (먼저, 짧게)

빠진 항목은 질문하되, 요청자가 "알아서"라고 하면 가정을 명시하고 진행한다.

1. 무엇을 파는가/알리는가 (제품·서비스·콘텐츠, 가격·제안이 있으면 그대로)
2. 누구에게 (적합 고객, 지금 쓰는 대안)
3. 목표 행동 하나 (팔로우, 클릭, 신청, 구매, 저장, 댓글 등)
4. 플랫폼과 형식 (YouTube 롱폼/Shorts, X, Threads, TikTok, Instagram 피드/Reels/스토리/캐러셀)
5. 브랜드 보이스, 금지 표현, 법적·규제 문구. **한서윤 계정·페르소나 카피면** [한서윤 가이드](references/han-seoyun-influencer-copy.md)를 보이스·금지의 정본으로 쓴다(출처: `/workspace/team/HAN_SEOYUN_BRIEF.md`).
6. 근거 자료 (리뷰, 수치, 사례). **없으면 지어내지 않는다.** 써보지 않은 제품 후기·효능 주장은 금지(한서윤 규칙과 동일).

## 워크플로

각 단계는 짧은 산출물을 남긴다. 단계를 건너뛰어도 되지만 건너뛴 이유를 한 줄로 적는다.

### 1. 포지셔닝 — "무엇과 비교되어, 누구에게, 왜 낫나"

[Obviously Awesome 요약](references/books/obviously-awesome-positioning.md), [Positioning 요약](references/books/positioning-ries-trout.md)

- 고객이 실제로 고려하는 대안(경쟁사, 수작업, 아무것도 안 함)을 적는다.
- 그 대안에 없는 고유 속성 → 고객에게 주는 가치 → 그 가치를 가장 크게 느끼는 고객 → 이해를 돕는 시장 범주 순으로 잇는다.
- 산출물: 포지셔닝 한 문장 + 고객 마음속에서 차지할 단어/개념 1개.

### 2. 메시지 — 고객이 주인공인 한 줄

[StoryBrand 요약](references/books/storybrand-sb7.md), [Made to Stick 요약](references/books/made-to-stick-success.md)

- 고객(주인공)의 원하는 것 → 외적·내적 문제 → 브랜드(가이드)의 공감과 권위 → 간단한 계획 → 행동 요청 → 피한 실패 / 얻은 성공으로 메시지 뼈대를 만든다.
- 핵심 메시지는 하나. 나머지는 버리거나 다음 게시물로 미룬다(지식의 저주 경계).
- 산출물: 원라이너(문제-해결-결과) 1개, 증거 포인트 2~3개(출처 표기).

### 3. 훅 — 첫 1~3초 / 첫 줄

[훅 체크리스트](references/hook-checklist.md), [Contagious 요약](references/books/contagious-stepps.md), [Ogilvy 요약](references/books/ogilvy-on-advertising.md). 각도·첫 줄이 막히면 [marketingskills 브리지](references/marketingskills-bridge.md)의 social·ad-creative 경로.

- 훅 후보를 서로 다른 *각도*로 5개 이상 만든다(이득, 뉴스, 의외성, 질문, 대비, 공감, 실용 팁 등).
- 훅은 본문이 지킬 수 있는 약속만 한다. 낚시성 과장 금지.
- 산출물: 훅 후보 목록 + 각도 라벨 + 추천 1~2개와 이유.

### 4. 본문 — 약속을 지키는 최소 분량

- 구체적 사례·장면·숫자(검증된 것만)로 추상을 대신한다.
- 한 게시물 = 한 아이디어. 스캔 가능한 줄바꿈, 짧은 문장.
- 이야기 형식이면 제품/핵심 아이디어를 지웠을 때 이야기가 그대로인지 시험한다(연결이 약하면 수정).
- 산출물: 플랫폼 미지정 기본 본문(마스터 카피).

### 5. CTA — 하나의 다음 행동

[CTA 체크리스트](references/cta-checklist.md), [1-Page Marketing Plan 요약](references/books/one-page-marketing-plan.md), [Launch 요약](references/books/launch.md). CTA 슬롭·각도 변형은 [marketingskills 브리지](references/marketingskills-bridge.md).

- 목표 행동 하나를 동사로 시작해 명확히. 직접 CTA(구매·신청)와 전환형 CTA(저장·팔로우·무료 자료)를 구분해 고객 단계에 맞춘다.
- 희소성·마감은 **사실일 때만** 쓴다.
- 산출물: 직접 CTA 1개 + 전환형 CTA 1개.

### 6. 플랫폼별 변형

[Day Trading Attention 요약](references/books/day-trading-attention.md), 플랫폼 가이드: [YouTube](references/platforms/youtube.md) · [X](references/platforms/x.md) · [Threads](references/platforms/threads.md) · [TikTok](references/platforms/tiktok.md) · [Instagram](references/platforms/instagram.md)

- 같은 핵심 메시지를 플랫폼의 형식 단위(제목/스레드/캡션/화면 문구/캐러셀)와 문화(말투·관용 표현)에 맞게 다시 쓴다. 복사-붙여넣기 금지.
- **한서윤 카피**: Threads만 반말, 그 외(IG·X·YouTube·TikTok·DM)는 존댓말. 채널 말투 체크는 [한서윤 가이드](references/han-seoyun-influencer-copy.md).
- 글자 수·해시태그·링크 정책은 바뀌므로 작성 시점에 확인하고, 확인 못 하면 "미확인"으로 표기한다.
- 산출물: 플랫폼별 카피 블록(아래 출력 형식).

### 7. 성과 지표 / 검증

[검증·지표 가이드](references/validation-metrics.md), [How Brands Grow 요약](references/books/how-brands-grow.md)

- 게시 전: 체크리스트 자체 검수(포지셔닝 일치, 훅-본문 약속 일치, 근거 출처, CTA 하나, 플랫폼 형식, 규제 문구). 한서윤이면 AI 표시·후기/효능 금지·말투까지 포함.
- 초안 다듬기 참고: [marketingskills 브리지](references/marketingskills-bridge.md)의 copy-editing Seven Sweeps(명확성→보이스→So What→입증→구체성…).
- 게시 후: 목표 행동에 맞는 1차 지표 하나 + 보조 지표 1~2개를 정하고, 단일 변수 A/B(훅만, CTA만)로 학습한다.
- 산출물: 측정 계획(지표·기간·판정 기준). 예측 수치를 측정치처럼 쓰지 않는다.

## 출력 형식 (기본)

```
## 포지셔닝
- 대안 / 고유 속성 / 가치 / 적합 고객 / 범주 / 차지할 단어
## 핵심 메시지
- 원라이너, 증거 포인트(출처)
## 훅 후보
1. [각도] 문구  … (추천 표시)
## 마스터 카피
## CTA (직접 / 전환형)
## 플랫폼별 변형
### YouTube / X / Threads / TikTok / Instagram (요청된 것만)
## 측정 계획
- 1차 지표, 보조 지표, 기간, 판정 규칙, 다음 테스트 변수
## 가정·미확인
## 한서윤인 경우
- 채널 말투 / AI 표시 / 후기·효능 금지 체크
```

요청자가 "카피만" 원하면 포지셔닝·측정 계획은 생략하고 카피 블록만 낸다(생략 사실은 한 줄로).

## 지켜야 할 경계

- **사실 근거**: 가격·성능·수치·후기·경쟁사 비교는 제공 자료나 확인한 출처에서만. 후기·평점·사용자 수를 꾸며내지 않는다. **써보지 않은 제품 후기·효능 주장·가짜 방문 인증 금지**(한서윤 운영 시 필수, 일반 카피에도 동일 원칙).
- **한서윤 운영 카피**: [한서윤 가이드](references/han-seoyun-influencer-copy.md) — 채널별 말투(Threads만 반말), AI 생성 표시 필수, 주제·톤 경계. 브리프 본문은 복제하지 않는다.
- **AI 티(tells)**: 상투 대비 구문·부정 나열·훅/CTA 슬롭을 피한다. 상세는 [marketingskills 브리지](references/marketingskills-bridge.md).
- **과장 금지**: 플랫폼 정책·광고 규제(건강·금융·의료·어린이 등)와 표시광고법 등 관할 법규를 우선. 협찬·광고 표기가 필요하면 넣는다.
- **게시·집행 분리**: 카피 작성 ≠ 게시·예약·광고 집행. 게시나 지출은 별도 명시 승인 없이는 하지 않는다.
- **저작권**: 참고 도서의 문장을 복제하거나 길게 인용하지 않는다. 원칙만 자기 말로 적용한다. 레퍼런스 게시물은 구조(훅 유형→문제→증거→제안→CTA)만 참고하고 문구·이미지·음원은 베끼지 않는다.

## 기존 스킬과의 연결

- `creative-production` — 영상 전용 코디네이터. 요청이 영상 광고·숏폼 제작이면 그쪽이 오너다. 이 스킬의 포지셔닝·메시지·훅 산출물은 영상 브리프의 *입력*으로 넘길 수 있다. 영상 광고 변형 규칙(단일 변수 세트, 각도 라벨, VOC 근거, 캠페인 데이터 기반 판단)은 [marketing-source-adaptation](../creative-production/references/marketing-source-adaptation.md#6-structured-ad-variation-and-campaign-review)과 같은 기준을 텍스트 카피에 적용한 것이다.
- `video-production-assets` — [30-marketing-story-craft](../video-production-assets/references/30-marketing-story-craft.md)의 "실제 대안→차별 속성→가치", "VOC를 만들지 않는다", "제품 삭제 시험"과 같은 원칙을 공유한다. 영상 쪽 서술을 바꾸지 않고 카피 쪽으로 확장했다.
- `higgsfield-generate` — Marketing Studio의 **hook**은 영상 앞에 붙는 재사용 오프닝 각도다. 이 스킬의 훅 후보(각도 라벨 포함)를 Marketing Studio `--prompt`나 훅 선택의 기획 근거로 쓸 수 있지만, 생성·지출은 그 스킬의 패키지 게이트와 승인 절차를 따른다. UGC 모드(`ugc`, `ugc_how_to`, `product_review` 등)용 대본 카피도 이 스킬에서 쓰고 생성은 넘긴다. **Virality Predictor**는 완성 영상의 훅·주의·유지 분석이다. 결과는 분석이지 성과 측정이 아니므로 [검증·지표](references/validation-metrics.md)에서 "게시 전 정성 신호"로만 취급한다.
- `higgsfield-youtube-thumbnail` — 썸네일 문구와 YouTube 제목은 서로 반복하지 말고 보완하게 쓴다([YouTube 가이드](references/platforms/youtube.md)).
- `topic-demand-selection` / `searching-social-media` — 주제 선정·수요 근거는 그쪽 소관. 이 스킬은 정해진 주제의 카피만 쓴다.
