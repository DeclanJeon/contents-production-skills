# 카메라 구도·움직임·전환 카탈로그

첨부 가이드 「카메라 연출 비율 & 컷 연결 가이드」, 「카메라 구도 24 × 연출 의도 & 사용 상황」, 「카메라 움직임 & 전환 24」의 촬영 어휘와 사용 기준을 카메라 설계·AI 인계·Blender 프리비즈에서 공통으로 참조한다. 이는 선택 가능한 연출 어휘집이다. 각 프로젝트에서 장면 목적에 맞는 항목을 고르고, 목록의 모든 항목을 한 장면에 강제 적용하지 않는다.

## 공통 설계 원칙

- 기본 구도는 읽기 쉽게 안정적으로 잡고, 강한 앵글·특수 효과는 이야기의 강조점에 배정한다.
- 컷 순서는 기본적으로 **정보 → 행동 → 감정 → 결과**를 고려한다. 장면의 실제 목적에 맞게 순서를 조정한다.
- 같은 구도·샷 크기·기법을 반복할 수 있지만, 다음 컷에서 새 정보·행동·반응·감정·시선 중 무엇이 바뀌는지 기록한다. 변화가 없으면 반복의 이유를 다시 검토한다.
- 샷 크기, 앵글, 카메라 이동, 초점, 재생 속도, 편집 전환은 서로 다른 선택이다. 한 단어로 뭉뚱그리지 말고 해당 채널과 담당 단계를 분리한다.
- 시선 방향, 화면 방향, 180도 축, 피사체 순서와 이동 방향을 인접 컷과 함께 확인한다. 의도적으로 축을 바꿀 때는 관객이 공간을 다시 파악할 단서를 둔다.
- 이미지의 비율은 교육용 예시다. 사용자가 비율 준수를 요청하면 해당 선택을 기록하고, 그렇지 않으면 장면의 목적에 따라 샷을 구성한다. 비율을 품질 점수나 보편 규칙으로 취급하지 않는다.

| 06 | 클로즈업 (CU) | 얼굴 위주로 충격·결심·놀람·분노 등 감정을 강조하고 시선을 집중시킨다. | 결정적 감정이나 중요한 반응 |

| 12 | 하이 앵글 (High-Angle) | 위에서 내려다봐 인물을 작고 약하게 보이게 한다. 취약함·고립·압박을 표현한다. | 패배, 위협, 압박, 고립 |

## B. 카메라 이동·촬영 방식·전환 24종

### 01–08. 카메라가 이동하는 방식

| ID | 기법 | 사용 상황·느낌 | 설계 시 분리해 적을 것 |
|---|---|---|---|
| 01 | 팬 (Pan) | 넓은 공간을 보여주거나 시선을 따라간다. 공간 연결·탐색·정보 전달. | 고정 회전축, 좌우 방향, 시작·끝 시선, 속도·정착 |
| 02 | 틸트 (Tilt) | 높낮이·규모를 보여준다. 위압감·탐색. | 고정 위치, 상하 방향, 보여줄 대상·끝 프레이밍 |
| 03 | 돌리 인 (Dolly In) | 카메라가 대상에 가까워져 집중·긴장·몰입과 감정 고조를 만든다. | 실제 카메라 위치 이동, 대상 거리, 접근 시점·감속·끝 프레이밍 |
| 04 | 줌 인 (Zoom In) | 렌즈 화각으로 빠르게 대상을 확대한다. 갑작스러운 집중·충격. | 위치 고정 여부, 렌즈 변화, 광학/디지털 구분, 속도 |
| 05 | 트래킹 (Tracking) | 인물과 함께 이동해 몰입감·현장감·동행감을 만든다. | 피사체 동선과 카메라 경로를 같은 시간 기준에 놓고 상대 프레이밍을 명시 |
| 06 | 오비트 (Orbit) | 인물을 중심으로 회전해 다각적 관찰·드라마틱함을 만든다. | 회전 중심, 궤도 반경·방향, 대상 가시성·가림 |
| 07 | 크레인 업/다운 (Crane) | 카메라 높이를 크게 바꾸어 규모감·극적인 공간 공개를 만든다. | 높이 경로, 상승/하강 시점, 대상과 공간의 공개 순서 |
| 08 | 드리 줌 / 돌리 줌 (Dolly Zoom) | 카메라 이동과 렌즈 변화를 결합해 인물 크기를 유지하면서 배경 원근을 바꾼다. 불안·충격·어지러움. | 위치 경로와 초점거리 곡선을 별도 채널로 설계하고 결합 결과를 프레임으로 확인 |

| 14 | 스피드 램프 (Speed Ramp) | 장면 안에서 속도를 바꿔 리듬·집중·역동성을 만든다. | 속도 곡선, 적용 구간, 카메라 동작과 피사체 동작의 시간 기준 |

### 17–24. 편집 전환

| ID | 전환 | 사용 상황·느낌 | 편집 인계에 기록할 것 |
|---|---|---|---|

| 21 | 와이프 (Wipe) | 화면의 한 부분이 다른 화면을 밀어내며 바뀐다. 명확한 전환·공간 이동. | 밀리는 방향·경계·진입/퇴장과 새 장면 공개 |
| 22 | 스매시 컷 (Smash Cut) | 강한 대비의 장면으로 갑자기 전환한다. 놀람·충격·강한 임팩트. | 대비할 이전/다음 상태와 정확한 컷 시점 |
| 23 | J컷 (J-Cut) | 다음 장면의 소리가 먼저 들리고 화면은 이전 장면에 남는다. 자연스러운 연결·기대감. | 다음 장면 오디오 선행 시작과 화면 전환 시점 |
| 24 | L컷 (L-Cut) | 화면이 바뀐 뒤에도 이전 장면의 소리가 잠시 이어진다. 부드러운 연결·여운·감정 지속. | 화면 전환과 이전 장면 오디오 종료 시점 |

## C. 교육용 비율 참고값

다음 숫자는 이미지에 제시된 예시를 보존한 참고값이다. 별도 요청이나 프로젝트 맞춤 근거가 없으면 shot plan의 필수 배분으로 사용하지 않는다.

### 20컷 샷 크기 예시

| 샷 크기 | 예시 배분 |
|---|---:|
| 익스트림 와이드 | 5%(1컷) |
| 와이드 | 15%(3컷) |
| 풀 샷 | 10%(2컷) |
| 미디엄 | 25%(5컷) |
| 미디엄 클로즈업 | 25%(5컷) |
| 클로즈업 | 15%(3컷) |
| 익스트림 클로즈업 | 5%(1컷) |
| 인서트 | 별도 2–3컷 권장(디테일·오브젝트·손·소품) |

기본 흐름 예: **장소 설명 → 행동 관찰 → 감정 집중**(와이드 → 미디엄 → 클로즈업). 인서트 권장 컷을 20컷 배분에 더할지 대체할지는 장면 설계에서 결정한다.

### 앵글 예시

| 앵글 | 예시 배분 | 안내문에 적힌 의도 |
|---|---:|---|
| 아이레벨 | 70%(14컷) | 기본 시점, 자연스러움 |
| 로우 앵글 | 5%(1컷) | 권력/위압, 강하게 보임 |
| 극단적 로우 앵글 | 0–5% | 극한의 위압, 특별한 순간 |
| 하이 앵글 | 10%(2컷) | 취약/고립, 작아 보임 |
| 탑 샷 | 5%(1컷) | 구조 설명, 전체 파악 |
| 버드아이뷰 | 5%(1컷) | 구조 설명, 넓은 시야 |
| 더치 앵글 | 0–5% | 불안, 긴장감 |
| 지면 높이 샷 | 5%(1컷) | 현장감, 몰입감 |

### 카메라 이동 예시

| 기법 | 예시 배분 | 의도 |
|---|---:|---|
| 고정 카메라 | 60% | 안정감, 기본 |
| 팬(좌/우) | 10% | 공간 탐색, 좌우 이동 |
| 틸트(상/하) | 5% | 상하 정보, 위아래 탐색 |
| 돌리 인/아웃 | 10% | 몰입/접근, 거리 변화 |
| 트래킹 | 10% | 따라감, 이동 묘사 |
| 크레인 | 5% | 높이/스케일, 웅장함 |

줌·오비트·돌리줌은 이미지에서 “필요할 때만 사용”으로 안내한다. 특수 앵글·움직임은 많이 넣는다고 강조가 커지지 않으며, 움직임이 많으면 강조가 약해질 수 있으므로 필요한 순간에만 쓴다.

## C2. 예시 리듬·감정 프로필 (선택)

아래 값은 **사용자 제공 제작 가이드북**(GUIDE-01)의 3장(pp9–12: 사건과 다음 이야기), 11장(pp48–50: 화면 따라가기·컷 전환 리듬), 13장(pp56–60: 감정과 키 비주얼)에서 읽은 **예시 프로필**이다. 출처 등록과 통합 기록은 [GUIDE-01 추출·통합 기록](../../video-production-assets/references/guide-01-extraction.md), 일반화된 실무 절차는 [R3·R7·R8](../../video-production-assets/references/29-reference-driven-production.md)에 있다. 다른 장르·길이·플랫폼의 규칙이 아니며, 요청하거나 프로젝트 합의가 있을 때만 적용하고 적용 시 분모·근거를 함께 적는다.

**고정 90초·구간 배분·인물/장소 수를 강제 규격으로 채택하지 않는다.** 범용화되는 것은 아래의 *방법*이고, 숫자는 한 작품에서 읽은 예시일 뿐이다. 옮길 때는 그 프로젝트의 길이·플랫폼·장르·관객을 먼저 다시 정한다.

### 예시: 90초 단편의 3구간

| 구간 | 예시 시간 | 역할 | 넘어가는 조건 |
|---|---|---|---|
| 소개 | 0–30초 | 장소·인물·관계·현재 문제 제시 | 관객이 상황과 목적을 알 때 |
| 시도 | 30–65초 | 주인공이 정보에 반응해 행동 | 관계·권력·위험의 변화가 보일 때 |
| 변화 | 65–90초 | 결과와 남은 질문 | 마무리 또는 다음 화로 이어질 때 |

### 예시: 컷 전환 리듬

- 한 컷이 4초 전후로 넘어가면 “4초에 한 번 컷”으로 읽힌다는 관찰이다. 이 값을 강제하지 말고, 전환마다 새 정보·행동·반응·감정·시선 중 하나가 실제로 바뀌는지 확인한다. 이 확인 기준은 [R3](../../video-production-assets/references/29-reference-driven-production.md#space-performance)의 컷 정보 변화 원칙과 같으며, 초 단위 수치 없이도 적용된다.
- 컷 속도를 높이려고 정보 없는 컷을 늘리지 않는다. 정보가 없는 구간은 길게 잡거나 하나로 합친다.
- 인서트 2–3컷 + 컨티 1–2컷은 예시 조합이다. 20컷 배분에 더할지 대체할지는 장면 설계가 정한다.

### 예시: 감정 지속과 키 비주얼

- 감정 전환 뒤 12–18초를 유지한다는 관찰이 있다. 그 구간 안에 카메라가 계속 보낼 정보나 행동이 있어야 하며, 정지 화면만 유지하지 않는다. 유지 길이 자체는 규칙이 아니라, **그 안에 카메라가 보낼 정보/행동이 남아 있는가**를 확인하는 기준이다.
- 감정은 **원인과 행동 사이의 고리**로 설계한다: 감정 → 몸짓/행동 → 결정적 한 프레임(키 비주얼). 표정 하나만으로 감정을 설명하지 말고 손·어깨·거리·시선 같은 몸짓을 먼저 정한다. 이 연쇄는 [R3](../../video-production-assets/references/29-reference-driven-production.md#space-performance)의 감정·키 비주얼 절차와 같은 것이며 여러 장르에 그대로 적용된다.
- 감정 구간에서 카메라는 세 가지 중 하나를 선택한다: 움직이지 않기(끝까지 밀어붙이기), 근거를 따라가기(감정의 원인을 따라감), 다르게 만들기(관점을 틀어 감정을 흔들기). 특별한 이유 없이 카메라를 계속 흔들어 감정을 흐리지 않는다.

## D. 반복 컷·연결 레시피·실전 체크

### 연속 사용 판단

- **하이앵글 → 하이앵글:** 거리나 정보가 달라지면 사용 가능. 좋은 예: 와이드에서 클로즈로 좁히며 공간에서 감정으로 이동. 같은 거리·정보의 거의 동일한 구도 반복은 피한다.
- **클로즈업 → 클로즈업:** 감정 단계가 달라지면 사용 가능. 좋은 예: 놀람에서 눈물로 반응 강화. 같은 크기·정보를 반복해 공간 정보가 부족하거나 변화가 없어 답답하게 느껴지는 전환은 피한다.
- **움직임 → 고정:** 탐색 뒤 발견, 충격, 결론에 사용 가능. 의미 없는 움직임에서 단순히 고정으로 전환하면 어색할 수 있다.
- **고정 → 움직임:** 중요한 행동이나 대상에 시선이 갑자기 집중되는 순간에 사용 가능. 의미 없이 움직임만 추가해 집중을 흐리는 전환은 피한다.

### 장면별 컷 연결 예시

1. **상황 소개:** 장소·상황을 보여줄 때 — 와이드 → 미디엄 → 클로즈업.
2. **발견의 순간:** 중요한 것을 발견할 때 — 미디엄 → 인서트 → 클로즈업 → 하이앵글.
3. **권력 대비:** 인물의 힘 관계 — 하이앵글(약자) → 로우앵글(강자).
4. **대화 장면:** 자연스러운 대화 — 투샷 → OTS → 반응 클로즈업.
5. **긴장 상승:** 몰입감과 긴장 상승 — 고정 → 트래킹 → 인서트 → 정지.

### 실전 체크리스트

1. 한 장면에 목적이 분명한 2–3개 요소를 조합했는가?
2. 기본 구도 비중을 높게 유지했는가?
3. 특수 앵글은 전환점에 사용했는가?
4. 정보 변화 없는 반복을 피했는가?
5. 시선 방향과 동선 연결을 확인했는가?
6. 중요한 순간에만 강한 연출을 집중했는가?

## 스킬 간 적용

- 카메라 설계 요청은 이 카탈로그에서 의도에 맞는 어휘를 선택하고 `camera-intent`와 `camera_spec`을 연결한다.
- 리듬·감정 예시 프로필(C2)을 적용할 때는 적용 구간·분모·근거를 함께 적고, 적용하지 않으면 근거 없는 숫자를 채우지 않는다.
- AI 영상 변환은 선택된 기법의 연출 의도를 보존하고, 실제 provider schema에서 확인된 입력만 `HARD_CONTROL`로 낸다. 텍스트 지시와 시작/끝 이미지만으로 경로 제어를 보장하지 않는다.
- Blender 구현 요청은 [Blender 기법 구현표](../../blender-previsualization/references/camera-technique-implementation.md)를 사용해 구현/대역/외부 편집/미지원 상태와 필요한 검수를 정한다.
- 편집 기법은 샷의 카메라 동작과 섞지 않고 컷·오디오 타이밍으로 편집 모듈에 인계한다.
- 기법 선택은 설계의 완전성을 위한 목록 조회이지, 장면마다 48개를 모두 적용하라는 뜻이 아니다.

## E. 원본 카드별 전체 설명 및 예시 전사

앞의 A·B 절은 설계에 쓰기 쉽게 요약한 카탈로그다. 아래에는 이미지 2와 이미지 3에서 읽히는 카드별 설명, 사용 상황, 연출 의도와 실무 예시를 빠뜨리지 않도록 상세 전사로 보존한다. 이 전사 문구는 선택 가능한 참고 어휘이며 장면에 전부 강제 적용하지 않는다. 판독 메모가 붙은 항목은 원본 이미지의 해상도 한계가 있다.

### 캡처 UI 메모

세 이미지에 공통으로 보이는 게시물 지표는 하트 652, 댓글 66, 재게시 236, 보내기 410이다. 상단 닫기·더보기 버튼, 하단 Android 내비게이션 아이콘, 검은 여백은 카메라 가이드의 지침이 아니라 캡처 UI다. 삽화의 시각적 예시는 카드별 문구와 목적·사용 상황으로 기록했으며, 장식 배경이나 아이콘 픽셀을 텍스트처럼 전사하지 않는다.

### 이미지 2 — 구도 24종 상세 전사

### 01–06. 샷 크기

#### 01. 익스트림 와이드 샷 (EWS)

- 광대한 공간, 장소 소개
- 인물의 작고 왜소함
- 시대적 배경, 세계관 전달
- **사용 상황:** 새로운 장소, 사건의 규모
- **연출 의도:** 광활함, 고립, 경외감

#### 02. 와이드 샷 (WS)

- 인물과 주변 환경의 관계
- 전체 상황과 동선 파악
- 여러 인물이 있는 장면
- **사용 상황:** 장소 소개, 행동 시작
- **연출 의도:** 상황 설명, 관계, 안정감

#### 03. 풀 샷 (FS)

- 인물의 전신과 동작
- 자세, 신체 언어 표현
- 걷기, 달리기, 전투 등 행동
- **사용 상황:** 행동 표현, 움직임 강조
- **연출 의도:** 활동성, 역동감, 성격 표현

#### 04. 미디엄 샷 (MS)

- 허리 위, 표정과 행동의 균형
- 대화, 일상적인 행동
- 주변 소품과 상호작용
- **사용 상황:** 일반적인 대화, 설명 장면
- **연출 의도:** 자연스러움, 정보 전달

#### 05. 미디엄 클로즈업 (MCU)

- 가슴 위, 감정 변화 강조
- 중요한 대화와 반응
- 미묘한 표정과 눈빛
- **사용 상황:** 감정이 변화하는 대화
- **연출 의도:** 친밀함, 감정 집중

#### 06. 클로즈업 (CU)

- 얼굴 위주, 강한 감정
- 충격, 결심, 놀람, 분노 등
- 관객의 시선을 완전히 집중
- **사용 상황:** 결정적 감정, 중요한 반응
- **연출 의도:** 강한 몰입, 심리 강조

### 07–12. 세부 샷 & 카메라 각도

#### 07. 익스트림 클로즈업 (ECU)

- 눈, 손, 사물의 극단적 확대
- 결정적 단서와 미세한 변화
- 긴장감과 디테일 강조
- **사용 상황:** 중요한 세부, 반응의 순간
- **연출 의도:** 강한 긴장감, 결정적 포인트

#### 08. 인서트 샷 (Insert)

- 핵심 물체나 정보 강조
- 문서, 사진, 도구, 버튼 등
- 이야기의 단서 전달
- **사용 상황:** 중요한 물건, 정보 소개
- **연출 의도:** 정보 전달, 기억 강조

#### 09. 아이레벨 (Eye-Level)

- 카메라와 눈높이 동일
- 자연스럽고 현실적인 느낌
- 관객과 인물의 동등한 시선
- **사용 상황:** 일반 대화, 인물 소개
- **연출 의도:** 중립, 공감, 현실감

#### 10. 로우 앵글 (Low-Angle)

- 아래에서 위로 올려다봄
- 인물을 강하고 위대하게 보임
- 권력, 자신감, 위협감 표현
- **사용 상황:** 권력자, 영웅, 강한 존재
- **연출 의도:** 권위, 힘, 위압감

#### 11. 극단적 로우 앵글 (Extreme Low)

- 매우 낮은 위치에서 촬영
- 대상의 크기와 위압감 극대화
- 공포, 거대함, 압도적 존재감
- **사용 상황:** 거대한 대상, 절대적 권력
- **연출 의도:** 공포, 압도감, 무력함

#### 12. 하이 앵글 (High-Angle)

- 위에서 아래로 내려다봄
- 인물을 작고 약하게 보임
- 취약함, 고립, 통제당하는 느낌
- **사용 상황:** 패배, 위협, 압박, 고립
- **연출 의도:** 무력함, 외로움, 통제

### 13–18. 특수 각도 & 화면 배치

#### 13. 탑 샷 / 오버헤드 (Top Shot)

- 바로 위에서 수직으로 촬영
- 배치, 구조, 패턴을 보여줌
- 인물을 하나의 요소로 표현
- **사용 상황:** 공간 구조, 인물 배치 설명
- **연출 의도:** 질서, 통제, 관객의 조망

#### 14. 버드아이 뷰 (Bird’s-Eye)

- 높은 곳에서 넓은 공간을 조망
- 규모, 지형, 전체 동선 파악
- 군중, 전쟁, 재난 등 광범위한 장면
- **사용 상황:** 도시, 전장, 대규모 사건
- **연출 의도:** 규모감, 전체 파악, 서사성

#### 15. 더치 앵글 (Dutch Angle)

- 수평을 기울여 촬영
- 불안, 혼란, 비정상적 상황
- 심리적 균형이 무너진 느낌
- **사용 상황:** 위기, 혼란, 정신적 충격
- **연출 의도:** 불안, 긴장, 심리적 불안정

#### 16. 지면 높이 샷 (Ground-Level)

- 지면 가까이에 카메라 배치
- 관절음, 바퀴, 먼지/면적(판독 불확실), 질감 강조
- 현장감과 물리적 위협 표현
- **사용 상황:** 추격, 접근, 전투, 긴장감
- **연출 의도:** 현장감, 몰입성, 긴박감

#### 17. 정면 구도 (Frontal)

- 인물을 정면으로 촬영
- 직접적인 감정 전달
- 결의, 선언, 대면의 느낌
- **사용 상황:** 고백, 결심, 경고, 대면 장면
- **연출 의도:** 직접성, 정직함, 압박감

#### 18. 측면 / 3/4 구도 (Profile / 3/4)

- 측면 또는 3/4 각도에서 촬영
- 행동 방향과 입체감 표현
- 자연스러운 관찰 시점
- **사용 상황:** 걷기, 작업, 생각, 대화
- **연출 의도:** 자연스러움, 거리감, 입체감

### 19–24. 시점 & 인물 배치

#### 19. 뒷모습 (Rear View)

- 인물의 뒷모습을 보여줌
- 목적지, 결심, 미지의 대상
- 감정의 유보, 관객의 상상 유도
- **사용 상황:** 출발, 발견, 새로운 장소
- **연출 의도:** 미지, 여정, 감정의 여백

#### 20. 어깨너머 샷 (OTS)

- 한 사람의 어깨 너머로 촬영
- 대화의 현장감, 시선 교환
- 심리적 거리와 관계 표현
- **사용 상황:** 대화, 심문, 협상, 갈등
- **연출 의도:** 관계성, 몰입감, 긴장감

#### 21. 인물 시점 / POV

- 특정 인물이 보는 장면을 그대로
- 직접 체험하는 느낌
- 발견, 공포, 몰입감 극대화
- **사용 상황:** 발견, 위협, 낯선 장소
- **연출 의도:** 몰입, 주관적 경험, 긴장감

#### 22. 투 샷 (Two Shot)

- 두 인물을 한 화면에 배치
- 관계, 거리, 권력 차이 표현
- 협력, 대립, 친밀감 강조
- **사용 상황:** 대화, 협상, 대립, 화해
- **연출 의도:** 관계, 균형, 대비

#### 23. 중앙 / 대칭 배치 (Centered)

- 인물을 화면 중앙에 배치
- 좌우 대칭으로 질서와 통제감
- 권위, 엄격함, 의식적인 분위기
- **사용 상황:** 공권, 행정, 의식, 군대 등
- **연출 의도:** 질서, 권위, 통제, 긴장

#### 24. 여백 / 고립 배치 (Negative Space)

- 인물 주변에 넓은 여백 배치
- 외로움, 부재, 기다림, 불안
- 보이지 않는 위협 암시
- **사용 상황:** 고독, 기다림, 단절
- **연출 의도:** 외로움, 여운, 미지의 위협

### 이미지 3 — 움직임·전환 24종 상세 전사

### 제목과 공통 안내

- **카메라 움직임 & 전환 24**
- 언제 쓰는지, 어떤 느낌을 주는지, 실무 예시까지 한눈에 보는 가이드
- 영상의 흐름을 만들고, 감정을 조절하고, 장면을 자연스럽게 연결하는 24가지 기본 동작
- **01–08 카메라의 움직임**(카메라가 실제로 움직이는 방식): 공간을 탐색하고, 인물과 대상에 다가가거나 멀어지며, 관객의 시선을 유도하는 움직임이다.
- **09–16 카메라의 촬영 방식**(어떻게 움직이거나 흔들면서 찍을 것인가): 카메라를 들고 촬영하는 방식, 속도를 조절하는 방식, 특수한 시점으로 촬영하는 방법이다.
- **17–24 편집의 전환 효과**(장면에서 다음 장면으로 넘어가는 방법): 두 개의 영상을 자연스럽게나 강렬하게 이어주는 편집 기법이다.

### 01–08. 카메라의 움직임

#### 01. 팬 (Pan)

- **어떤 상황에?** 넓은 공간을 보여줄 때, 시선을 따라갈 때
- **느낌:** 공간의 연결감, 탐색, 정보 전달
- **예시:** 도시 전경을 좌→우로 훑어보며 소개

#### 02. 틸트 (Tilt)

- **어떤 상황에?** 높낮이를 보여줄 때
- **느낌:** 규모감, 위압감, 탐색
- **예시:** 건물의 아래에서 위까지 올려다봄

#### 03. 돌리 인 (Dolly In)

- **어떤 상황에?** 인물 또는 대상에 가까워질 때
- **느낌:** 집중, 긴장, 몰입
- **예시:** 주인공에게 서서히 다가가며 감정 고조

#### 04. 줌 인 (Zoom In)

- **어떤 상황에?** 빠르게 가까워질 때
- **느낌:** 갑작스러운 집중, 충격
- **예시:** 놀란 표정을 빠르게 확대

#### 05. 트래킹 (Tracking)

- **어떤 상황에?** 인물을 따라 이동할 때
- **느낌:** 몰입감, 현장감, 동행
- **예시:** 주인공이 시장을 걷는 뒤를 따라감

#### 06. 오비트 (Orbit)

- **어떤 상황에?** 인물을 중심으로 회전할 때
- **느낌:** 다각적 관찰, 드라마틱함
- **예시:** 인물 주변을 한 바퀴 돌며 소개

#### 07. 크레인 업/다운 (Crane)

- **어떤 상황에?** 높은 곳으로 올라가거나 내려올 때
- **느낌:** 규모감, 극적인 연출
- **예시:** 마을 전체를 위로 올라가며 보여줌

#### 08. 드리 줌 (Dolly Zoom)

- **어떤 상황에?** 인물을 유지하면서 배경을 왜곡할 때
- **느낌:** 불안, 충격, 어지러움, 심리적 긴장
- **예시:** 놀람이나 깨달음 순간의 대표 연출

### 09–16. 카메라의 촬영 방식

#### 09. 랙 포커스 (Rack Focus)

- **어떤 상황에?** 초점을 앞뒤로 바꿀 때
- **느낌:** 시선 이동, 중요 인물 강조
- **예시:** 앞의 물체에서 뒤의 인물로 초점 이동

#### 10. 핸드헬드 (Handheld)

- **어떤 상황에?** 현실감과 긴박함이 필요할 때
- **느낌:** 현장감, 불안정, 생동감
- **예시:** 전투, 추격, 다급한 상황

#### 11. FPV (드론/1인칭)

- **어떤 상황에?** 빠르게 날아가는 시점이 필요할 때
- **느낌:** 속도감, 몰입, 스릴
- **예시:** 드론으로 숲 사이를 빠르게 비행

#### 12. 더치 앵글 (Dutch Angle)

- **어떤 상황에?** 불안정하고 이상한 상황일 때
- **느낌:** 혼란, 긴장, 심리적 불안
- **예시:** 위기 상황, 정신적 충격

#### 13. 슬로우 모션 (Slow Motion)

- **어떤 상황에?** 중요한 순간을 강조할 때
- **느낌:** 감정의 여운, 드라마틱함
- **예시:** 검을 휘두르는 순간을 느리게

#### 14. 스피드 램프 (Speed Ramp)

- **어떤 상황에?** 속도를 점진적으로 바꿀 때
- **느낌:** 리듬감, 집중, 역동성
- **예시:** 정상 속도 → 느려짐 → 다시 빨라짐

#### 15. 타임랩스 (Time-Lapse)

- **어떤 상황에?** 긴 시간의 흐름을 짧게 표현할 때
- **느낌:** 시간의 흐름, 변화, 성장
- **예시:** 해가 떨어지고 도시가 밤으로 변화

#### 16. 프리즈 프레임 (Freeze Frame)

- **어떤 상황에?** 특정 순간을 정지할 때
- **느낌:** 강한 인상, 의미 부여, 내레이션 연결
- **예시:** 결정적인 장면에서 화면을 멈춤

### 17–24. 편집의 전환 효과

#### 17. 점프 컷 (Jump Cut)

- **어떤 상황에?** 같은 장면의 시간을 짧게 제거할 때
- **느낌:** 빠른 템포, 현실감, 거침없는 느낌
- **예시:** 대화 중 불필요한 시간을 잘라냄

#### 18. 매치 컷 (Match Cut)

- **어떤 상황에?** 비슷한 형태/움직임으로 이어질 때
- **느낌:** 자연스러운 연결, 상징적 의미
- **예시:** 눈동자 → 달, 손의 움직임 → 다음 장면

#### 19. 휩 팬 (Whip Pan)

- **어떤 상황에?** 빠르게 다음 장면으로 넘어갈 때
- **느낌:** 속도감, 충격, 에너지
- **예시:** 카메라를 빠르게 돌려 다른 장소로 전환

#### 20. 크로스 디졸브 (Cross Dissolve)

- **어떤 상황에?** 부드럽게 시간을 넘길 때
- **느낌:** 자연스러운 시간 흐름, 감성적 연결
- **예시:** 낮의 풍경이 서서히 밤으로 바뀜

#### 21. 와이프 (Wipe)

- **어떤 상황에?** 화면이 밀리면서 바뀔 때
- **느낌:** 명확한 전환, 공간 이동
- **예시:** 문이 열리면서 다음 장소로 전환

#### 22. 스매시 컷 (Smash Cut)

- **어떤 상황에?** 강한 대비와 충격을 줄 때
- **느낌:** 놀람, 충격, 강한 임팩트
- **예시:** 평화로운 장면 → 갑자기 위험한 장면

#### 23. J 컷 (J-Cut)

- **어떤 상황에?** 다음 장면의 소리가 먼저 들릴 때
- **느낌:** 자연스러운 연결, 기대감
- **예시:** 다음 장면의 대사가 먼저 들리고 화면은 전 장면

#### 24. L 컷 (L-Cut)

- **어떤 상황에?** 이전 장면의 소리가 이어질 때
- **느낌:** 부드러운 연결, 여운, 감정 지속
- **예시:** 화면은 바뀌었지만 이전 대사가 잠시 이어짐
