# 레퍼런스 영상 분석 리포트

읽기 전용 분석 산출물이다. 이 리포트를 채우는 것은 생성·제작·업로드·유료 분석 승인이 아니다. 해당하는 섹션만 채우고, 확인할 수 없는 항목은 `미확인`으로 남긴다.

## 소스
| 항목 | 값 |
|---|---|
| 식별자/출처 | 제목·채널·링크 또는 파일명(확인 가능한 만큼) |
| 검사한 버전/구간 | 직접 검사 또는 사용자 기록의 버전·범위(미검사 구간 명시) |
| 형식·길이·화면비·장르·관객·목적 | 관찰 또는 메타데이터로 구분 |
| 분석 범위 | 측정 / 근사 / 표본 프레임만 |

## 축별 분석 (해당하는 축만)
각 축에서 **관찰**(직접 프레임·재생·청취 또는 사용자 기록; 출처 명시) / **해석·추정**(유도한 의도) / **미확인**(권리·성과·범위 밖)을 분리한다. 사용자 기록은 직접 검사 결과가 아니며 점수·합격 판정은 없다.

| 축 | 관찰 | 해석·추정 | 미확인 |
|---|---|---|---|
| 편집/리듬/공개 순서 | | | |
| 샷/구도/카메라 | | | |
| 비주얼 스타일 | | | |
| 사운드 | | | |
| 서사/감정 효과 | | | |

## 시점 대응 (다중 시점이 있을 때만)
시점 사이에서 같은 특징만 짝짓는다. 각 쌍에 관찰/가림/미확인을 표시하고, 가려진 특징을 없다고 단정하거나 다른 시점 관찰 없이 만든 형상 변화로 쓰지 않는다. 해당 없으면 `N/A`.

| 대상/특징 | 시점 A 관찰 | 시점 B 관찰 | 대응 상태: 관찰/가림/미확인 |
|---|---|---|---|
| | | | |

## 광학 역추정 (정확한 재현 요구 시만)
한 프레임과 물체 크기 미상 조건에서 카메라 해는 단일이 아니다. 관측과 양립하는 후보 범위와 근거를 적고 물리 렌즈·센서·거리의 확정값을 만들지 않는다. 새 제작의 목표는 확정 카메라 값이 아니라 관찰된 화면 특성(원근 압축·심도·왜곡·피사체 화면 대비)이다. 수치 카메라·공간 명세는 `$camera-spatial-design`이 소유한다. 해당 없으면 `N/A`.

| 항목 | 관찰(프레임에서 직접 읽음) | 추정(유도) | 미확인 |
|---|---|---|---|
| 화면 정규화 기준점(소실점·지평선·피사체 화면 대비·보이는 면·왜곡) | | | |
| 알려진 크롭·출력 화면비(제약) | | | |
| 원근 압축·심도 특성 | | | |

| 가능한 카메라 후보 범위 | 후보와 양립하는 관측 근거 | 후보를 가르는 관측(민감도) | 반증·확정에 필요한 추가 증거 |
|---|---|---|---|
| | | | |


## 이전 체인 (제안 → 새 브리프)
메커니즘만 이전한다. 캐릭터·브랜드·특정 디자인·대사·음악 등 보호 표현은 새 브리프 요소로 바꾼다. 제안 시간은 원본 측정 시간과 별도 열로 둔다. 산출물·샷·패널 ID는 이후 담당 단계가 부여 — 여기서 확정 ID를 만들지 않는다.

| 레퍼런스 증거(관찰+위치) | 메커니즘 | 의도 효과(해석) | 새 브리프 제작 요구 | 제안 시간(신규) | 정성 검증 기준 |
|---|---|---|---|---|---|
| | | | | | |
