# 대사 연기 큐

## 국소 발음 교정 기록 (실제 오류의 교정 요청만)

- 원본 음성/영상 ID·버전 · 원본/타임라인 시간 basis:
- 정확한 원문 / 실제 들린 오류 / 근거(직접 청취·사용자 보고·미검증):
- 교체 in/out · 단어/어절/구절 선택 이유(연음·받침·호흡):
- 보존할 음색·억양·숨·감정 / 보이는 입:
- 승인된 보이스 핀 · 교정 문구/지원 큐 · 현재 도구 근거:
- 요청된 복제에만: 권리/동의 근거 · 실제 샘플/현재 길이·형식 요건 (반복/스테레오 복제 금지):
- 기존 시도 ID / 단일 주요 변경 / 승인 상한:
- 채택 교정 오디오 ID·버전 (미생성이면 없음):
- 별도 트랙 편집 위치 / 자음·받침·들숨 경계 / 음량·밝기·잔향·룸톤 / 크로스페이드:
- 재검수: 교체 구절 → 앞뒤 문장 → 전체 장면 믹스 → 영상/입/감정 (실제 범위 또는 unverified):
- 재검토할 종속 자막·립싱크·타이밍 ID / 미해결:

이 기록은 기존 연기/편집 artifact의 일부이며 새 원장이나 실행 승인이 아니다. [국소 교정 절차](../references/29-reference-driven-production.md#dialogue-repair)를 따른다.

## 광고·내레이션 보이스 브리프 (해당할 때만)

필요한 값만 짧게 채운다. 승인 카피는 03, 연기 의도는 04, 믹스/`audio_cues`는 09의 정본을 참조한다.

- 청중·전달 기능: `{누구에게 / 이 발화가 해야 할 일}`
- 승인된 발화문·버전: `{정확한 한국어 원문 또는 03의 ID·버전}`
- 언어·억양/방언 근거 및 승인 보이스: `{요청·샘플 청취 근거 / voice ID·profile 또는 미선정}`
- 고정 정체성·품질 기준: `{보이스 앵커 / 자연스러움·명료도 등 이 작업에서 확인할 기준}`
- 연기 아크·타이밍: `{시작→변화→끝; 구간별 의도·속도·숨/쉼·강조; 목표 길이·구간 시간}` — 생성 전 시간은 `estimated`
- 발음 위험: `{정확한 이름·외래어·숫자 → 승인 발음 → 확인된 지원 제어 또는 03 교정}`
- 실행 전 확인: `{공급자·모델·실제 지원 제어·비용·승인 횟수/상한}`
- 믹스 인계: `{보이스 우선순위 / BGM·SFX와의 관계; 큐는 09에 연결}`

생성 후 각 버전을 **실제 음성 전체 단독 청취 후, 최종 믹스/맥락에서 재청취**하고 기존 음성 선택·청취 기록을 갱신한다. 문제는 아래 한 줄만 해당 artifact에 기록하고 재검수한다; 이를 별도 시도 원장으로 확장하지 않는다.

`{timecode/단어} | {직접 청취·사용자 보고·도구 출력·추론} | {관객 영향} | {최소 수정 및 소유자 03/현재 보이스 제어/09} | {같은 기준의 재검수 또는 unverified}`


캐릭터: {공급/기존 character_id} | character_sheet: {배정된 artifact ID·version 또는 미배정} | voice_profile: {배정된 ID·version 또는 미배정 — character_sheet에서 파생} | persona 요약: {role/personality/observable_behavior/speech — SSOT 정본에서 파생, 별도 편집 장소 아님}

보이스: {실제 선택 기록의 voice ID·타입·모델/버전·설정 또는 미선정} | 음성 asset_id: {실제 ID 또는 미생성} | 권리/동의: {공급 근거 또는 미확인} | 청취 검수: {실제 결과/범위 또는 미검증}

voice_identity_direction: {모든 발화에 재사용하는 고정 음성 정체성 — 청각 앵커·발음·문장 끝 습관·기본 리듬·허용 변화 범위}

미지원 제어 간극: {요청했으나 현재 도구가 지원하지 않는 제어와 그 처리 — 적용했다고 주장하지 않음}

| 시간/대사 | 화자 | 의도/서브텍스트 | 숨/멈춤 | 강조 | 속도/압력 | 입 우선순위 | 청자 반응 | 신체 행동 |
|---|---|---|---|---|---|---|---|---|

규칙: 각 행은 그 대사의 `performance_cue`다 — 정확한 대사·의도/서브텍스트·숨·멈춤·강조·속도/압력을 생략하지 않는다(특별한 변화가 없으면 자연/기본/없음을 명시, 장면 근거 없으면 미정). 고정 정체성은 위 `voice_identity_direction`에만 둔다. 상태 변주는 음색·발음 앵커를 유지한다. 무언 역할의 음성 큐는 이유를 적은 N/A이며 시각 연기는 별도 표현 연결로 넘긴다. `proposed`/`unresolved`는 선택됨이 아니며 미지원 지시를 TTS 대사 본문에 넣지 않는다.
