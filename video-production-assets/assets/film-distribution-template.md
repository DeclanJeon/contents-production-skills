# 영화 배급·패키지 기록 (라이프사이클)

project_id: {프로젝트}
artifact_id: {이 기록의 artifact ID}
version: {버전}
status: draft
lifecycle_stage: 06 Distribution
최종본 입력: {최종 마스터/승인 컷 artifact ID·버전}
dependencies: {입력 artifact ID와 버전}

이 문서는 버전이 붙은 인계 artifact이며 `project.json`의 artifact/dependency/version/approval, `delivery_spec`, `delivery_checks`, `asset_registry`를 대체하는 정본이 아니다. **계획 작업 ≠ 실제 에셋 ≠ 실제 제출/공개 ≠ 관객 반응** — 한 행의 계획을 실제 산출물·제출·개시·피드백으로 읽지 않는다. 없는 데이터는 발명하지 않는다. 납품만 요청된 작업에는 이 양식 전체가 N/A다.

| 항목 (키아트/포스터·티저/트레일러·EPK·스틸 등) | 계획 작업 artifact ID·버전 | 실제 에셋 asset_registry ID·버전 | registry 상태 (planned/available/verified) | 원본 마스터 버전 | 권리/출처 상태 | 비고 |
|---|---|---|---|---|---|---|
| | | | | | | |

- 실제 파일이 존재할 때만 asset_registry ID와 버전·해시를 기록한다. 계획된 에셋은 planned(`path=null`)로 두고 완성 매체로 취급하지 않는다.

## 목적지 전략 — 목적지별 delivery_spec 연결

| 목적지 ID | 유형 (극장/OTT/온라인/기타) | 목표 창구·시기 | delivery_spec 참조 | 규격 근거 (공식/사용자 제공) | 규격 확인 일자 | 권리 범위 연결 | 상태 (계획/확인됨/unverified) |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

- 규격(해상도·컨테이너·코덱·오디오·자막·패키징)은 사용 시점에 공식 문서·사용자 제공 원본에서 확인한다. 기억·다른 프로젝트 값을 재사용하지 않고 미확인이면 unverified로 둔다.
- DCP·ProRes 마스터 등 목적지 전용 산출물은 실제 요청·확인된 목적지에만 계획한다 — 모든 영화에 강제하지 않는다.

## 영화제·제출 기록 — 계획/접수/결과 분리

| 영화제/기관 | 부문·카테고리 | 자격 근거 (공식 규정 locator) | 자격 확인 상태 | 마감일 | 마감 근거·확인 일자 | 필요 규격/패키지 | 계획 작업 ID | 실제 접수 기록 (일자·방법·확인) | 결과 (선정/탈락/대기) |
|---|---|---|---|---|---|---|---|---|---|
| | | | unverified | | | | | | |

- 자격·마감·규정은 실제 공식/사용자 제공 근거에서만 적는다 — 규칙을 기억으로 만들지 않는다.
- 계획된 출품과 접수 완료, 결과를 같은 상태로 취급하지 않는다. 스킬이 자동으로 출품·업로드·게시하지 않는다.
