- take_id는 `project.json`의 샷·에셋에 대응하는 artifact/asset locator로 연결한다.
- 실제 촬영 순번은 셋업·테이크 양쪽에 기록하고 이야기 순서(패널 배열·최종 타임라인)와 혼합하지 않는다.

|---|---|---|---|---|---|---|---|
| | | | | | | | |

- 관측된 연속성 상태의 정본은 `continuity-ledger.csv`다 — 이 표는 실제 상태 값을 다시 기록하지 않고, 해당 날짜의 검토 결과와 판정만 연결한다.
