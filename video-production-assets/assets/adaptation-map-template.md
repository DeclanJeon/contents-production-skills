treatment, article, brief). One row per meaningful source beat. Do not copy
source prose verbatim into narration; prefer visual storytelling when the
screen can carry the same information.

## Content treatment notes
For sensitive beats record: source function / what must remain / what must not
be shown directly / safe visual or audio substitute / aftermath or reaction
option. Preserve narrative meaning without requiring explicit depiction.
