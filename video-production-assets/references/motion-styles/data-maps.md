# 모션 스타일 — 데이터·지도

수치 데이터를 움직이는 차트·결산 영상으로, 지리 정보를 지도 영상으로, 구조를 아이소메트릭 장면으로 만드는 스타일을 고를 때만 연다. [33 모션 스타일 사전](../33-motion-style-library.md) 색인에서 이 계열을 고른 뒤에 열며, [08 애니메이션](../08-animation.md)·[05 비주얼](../05-visual.md)의 심화다. 승인된 브랜드 키트·브랜드 색·글꼴이 아래 어떤 값보다 우선하고, 조정 가능한 값 묶음은 절마다 ‘시작값’으로 따로 표시한다. 화면의 값·순위·날짜·장소 사실은 공급된 데이터에서만 가져오고, 측정값에는 기준 기간·날짜와 보고 주체를 붙인다. 예시 숫자와 좌표는 자리표시일 뿐 쓰지 않는다([10 근거](../10-evidence.md)). 지도 윤곽·타일·사진은 열린 데이터나 사용 권한이 있는 것만 쓰고 출처와 라이선스를 기록한다. 개인 데이터는 사용 권한이 확인된 행만 쓰고, 생성한 인물·이미지는 생성물임을 표기하며 유료 생성은 사용자 동의 뒤에만 한다. CTA는 브리프가 행동과 목적지를 둘 다 줄 때만 넣는다. 실행은 [policy.md](../../../creative-production/references/policy.md) 게이트와 [24 제작 실행](../24-production-execution.md)을 따르고, 도구는 패키지의 기존 레인(Remotion·FFmpeg·Blender·선택된 생성기)을 쓴다. 각색 절의 출처와 라이선스는 [open-design 이전 기록](../upstream/open-design-provenance.md)에 있다.

## open-design 각색 절

### 페이퍼 맵 저니 {#od-openmotion-paper-map-journey}
- 쓰는 곳: 여행 설명·일정·목적지 소개·확장 이야기.
- 구성·시작값: 입력은 순서 있는 장소 목록, 정류장마다 사실 하나, 화면비. 지도 윤곽은 라이선스를 기록한 열린 데이터에서, 저작권 지도는 따라 그리지 않는다. 시작값 — 크림 종이 `#F3EEDF` 바탕, 민트 지형 `#BFE3D0`, 옅은 파랑 물. 빨간 경로 `#D7263D`는 이동 중 점선·완료 뒤 실선. 정류장마다 종이 랜드마크나 사진 컷아웃, 작은 라벨, 큰 순서 숫자.
- 움직임·타이밍: 시작값 — 전체 지역에서 첫 정류장으로 1–1.5초 줌. SVG 경로로 정류장 사이를 그리고 카메라가 선두를 따른다. 정류장에서 랜드마크가 300ms에 팝업북처럼 솟아 사실 하나와 2–4초 머문다. 끝은 전체 경로로 물러난다.
- 피할 것: 틀린 지리나 지어낸 국경, 30초에 정류장 다섯 초과, 경로와 겹치는 라벨.
- 검수: 순서·위치가 지리적으로 맞는가, 라벨이 읽히는가, 경로가 튀지 않는가, 지도 데이터 출처·라이선스가 기록됐는가.

### 차트 애니메이션 {#od-chart-animation}
- 쓰는 곳: 막대 레이스·순위 변화·꺾은선·카운터, 한 디자인을 여러 데이터셋에.
- 구성·시작값: 값은 현재 프레임의 순수 함수로 계산한다(라이브러리 타이머·CSS 전환 금지). 표시값은 반올림 뒤 서식을 적용하고 `tabular-nums`로 폭을 고정한다. 데이터는 입력, 색·글꼴·레이아웃은 테마 한 곳에. 축 단위는 한 번, 값 라벨은 값과 함께 움직이고 연도·날짜 표시를 둔다. 출처·기준 기간 표기.
- 움직임·타이밍: 시작값 — 첫 프레임 1–1.5초 정지. 읽는 값은 ease-out(선형은 시계·연도 같은 등속 축만), 순위 변화는 스프링. 레이스는 행 사이와 순위를 보간해 추월이 미끄러지게. 행당 0.3–0.6초, 강조 순간 +0.5–1초, 마지막 2–3초 정지. 시리즈는 하나씩, 콜아웃은 교차·정점에만.
- 피할 것: 소수점 긴 값 노출, 자릿수에 흔들리는 레이아웃, 모든 데이터 동시 노출.
- 검수: 시작·중간·끝 정지 프레임에서 축·값·순위·단위가 정확하고 안전 영역 안인가, 실제 데이터로 확인했는가, 한 데이터셋 검증 뒤 일괄 렌더하는가.
출처: iart-ai/data-animation-skills@8ce2709c3992 chart-animation

### 아이소메트릭 애니메이션 {#od-isometric-animation}
- 쓰는 곳: 설명·제품 UI·인포그래픽의 2.5D 층 쌓기·분해도·압출 블록.
- 구성·시작값: 투영을 하나 정해 섞지 않는다 — 진짜 아이소(지면 축 수평 ±30°, `rotateX(60deg) rotateZ(45deg)`)나 2:1 디메트릭(약 26.57°). 원근은 끄고 높이는 Z로 올린다. 블록 음영은 고정 광원에서 윗면 가장 밝게·왼쪽 중간·오른쪽 가장 어둡게. 작은 블록·격자는 SVG, 소수 층은 CSS 3D, 가림·그림자는 직교 카메라 3D.
- 움직임·타이밍: 시작값 — 층 등장은 0.12초, 쌓기는 0.15초 간격. 분해·조립은 공유 간격 값 하나를 0.7–1초에. 카메라 드리프트는 몇 도·몇 px의 6–12초 사인 왕복. 빌드는 DOM 순서가 아닌 물리적 위치(아래층 먼저)로.
- 피할 것: 스케일로 높이 만들기, 큰 카메라 이동, 장면 중 광원 변경, 두 투영 혼용.
- 검수: 축 각도·Z 순서·음영이 맞고 z-fighting이 없는가, 끝 프레임에 모든 층이 정확히 안착하는가. 웹 산출물은 움직임 줄이기에서 완성된 장면만.
출처: iart-ai/explainer-video-skills@3e2d411b725d isometric-animation

### 지도 애니메이션 {#od-map-animation}
- 쓰는 곳: 장소 설정, 지리 위 이동(경로·항로), 국가·지역 강조, 좌표 목록 지도.
- 구성·시작값: 길을 고른다 — 실사 지형·시네마틱 카메라는 Google Earth Studio를 AE에서 합성(3D 카메라 내보내기, 오버레이는 트랙에 부모), 깔끔한 벡터는 GeoJSON/SVG를 Remotion·D3로(투영 하나로 좌표 공유). 보통 둘을 섞는다. 순서 있는 비트 배열 하나가 카메라·핀·경로·라벨의 유일한 원천.
- 움직임·타이밍: 시작값 — 24fps 편집에서 그래픽 레이어만 12fps(2프레임 유지, 30fps는 2–3프레임), 베이스는 매끄럽게. 카메라는 느리게, 핀은 스프링으로 떨어지고 경로는 `stroke-dashoffset`으로 읽는 순서대로, 곡선은 `geoInterpolate`. 강조는 대상만 밝히고 나머지 약 35%. 라벨은 착지 뒤 수평.
- 피할 것: 전체를 12fps로 끊기, 카메라 급이동, 중간에 색 의미 바꾸기, 도는 라벨.
- 검수: 알려진 도시로 핀·경로·강조 지역이 맞는가, 라벨 철자가 맞는가, 인접 두 프레임에서 오버레이만 같고 베이스는 진행하는가, 안티메리디안 잘림이 없는가.
출처: iart-ai/map-animation-skills@390ca98bbcf2 map-animation

### 랩드 비디오 {#od-wrapped-video}
- 쓰는 곳: 데이터 행 하나를 사람·계정·팀의 공유용 세로 결산 영상으로. 행별 데이터가 없으면 쓰지 않는다.
- 구성·시작값: 모든 문구·숫자·이름·색은 입력 행에서 오고 못 채우는 장면은 뺀다. 행은 스키마로 검증. 시작값 — 장면 5–7개, 각 약 2.5–4초(인트로·큰 숫자·톱X·최상급·비교·시간·공유 카드). 1080×1920, 핵심은 중앙 80%(위 12%·아래 18% 밖). 프레임당 아이디어 하나.
- 움직임·타이밍: 시작값 — 작은 맥락에서 가장 크고 개인적인 수치로 오름차순, 영웅 수치는 가장 크고 오래. 숫자는 프레임 기준으로 세고 `tabular-nums`. 장면은 2초 안에 읽힌다. 2인칭. 공유 카드(최상급·이름·핸들·로고·조건을 채운 CTA)는 2초 이상 완전히 멈춘다.
- 피할 것: 두 사람에게 같게 읽히는 프레임, 첫 장면의 영웅 수치, 데이터에 없는 순위.
- 검수: 큰 숫자가 행의 값에 정확히 안착하는가, 톱X 순위·라벨이 행과 맞는가, 대표 한 행을 정지 프레임으로 본 뒤 일괄 렌더하는가.
출처: iart-ai/explainer-video-skills@3e2d411b725d wrapped-video
