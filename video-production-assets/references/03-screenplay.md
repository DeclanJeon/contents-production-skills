# 영상 각본·대사·내레이션

## 입력과 산출물
입력: 확정 비트와 인물, 언어, 길이 예산

산출물: 장면 각본, 내레이션, 화면·소리 대조표 (선택: 씬 아웃라인, 비트→씬→시퀀스·막 매핑, 서브텍스트 메모, 리라이트 기록)

## 실행 절차
1. 장면에 장소·시간·인물·목적을 붙이고 촬영하거나 애니메이션으로 표현할 수 있는 행동으로 쓴다.
2. 해설을 이미지로 바꿀 수 있는지 확인한다. 화면이 이미 말하는 내용을 내레이션이 반복하면 새로운 맥락만 남긴다.
3. 대사는 인물의 목적과 관계를 바꾸게 한다. 드라마에서 설명만 하는 대사는 행동·반응·서브텍스트로 재구성한다. 교육·튜토리얼은 정확하고 직접적인 설명이 필요하면 유지한다.
4. 시간을 화면 행동, 발화, 반응, 전환으로 나눠 계산한다. 원고 분량이나 페이지 수만으로 실제 러닝타임을 확정하지 않는다.
5. 광고·교육·인터뷰에서 사실 주장에 claim_id를 연결한다. 창작 인용문·가상 고객·재연은 그 상태를 표시한다.
6. 말로 읽어보고 수정한다. 실제 음성이 없으면 예상 발화 시간을 표시하고 측정 필요 상태로 인계한다.

## 서사 단위와 제작 단위 — 영화·서사 요청 시

비트→씬→시퀀스→막은 **서사 단위**이고 샷은 **촬영·편집 단위**다. 샷을 서사 구성 단위로 섞지 않으며, 샷 설계는 [블로킹·촬영·스토리보드](06-shots.md)가 소유한다.

- **비트**: 행동·감정·상황의 의미 있는 변화 하나. 비트시트는 주요 비트의 순서와 인과를 기록한 목록이다.
- **씬**: 한 장소·시간·행동 블록. 장면별 장소·시간 지시, 화면 행동, 대사로 구성한다. 산문 요약(트리트먼트)이나 씬 목록(씬 아웃라인)은 각본이 아니다.
- **시퀀스·막**: 하위 씬을 묶는 선택 구조다. 3막·5막은 도움이 될 때만 적용하고, 비선형·실험 작업에는 강제하지 않는다.
- **씬 아웃라인**: 씬별 장소·시간·인물·목적 목록. 각본 작성 전 순서 점검용이며 촬영 각본이 아니다.
- **씬 검토 질문(선택)**: 해당 씬에 답이 필요할 때만 묻는다 — 이 씬의 목표는? 갈등/저항은? 전환점은? 감정 변화는? 새로 드러나는 정보는? 다섯 질문을 모든 씬의 필수 필드로 만들지 않는다.
- **서브텍스트**: 대사가 직접 말하지 않는 의도·관계 압력. 각본에는 필요한 메모로만 두고, 대사별 연기 지시는 [대사·립싱크](22-dialogue-lipsync.md)·[연기 디렉팅](04-performance.md)에 인계한다.
- **리라이트 기록**: 새 버전 artifact에 변경 요약과 이전 버전 ID를 기록한다. 별도 승인 원장을 만들지 않고, 상위 버전 변경 시 실제 dependency가 있는 하위 산출물만 stale 처리한다.

## 완료 조건
장면 기능·대사 목적이 명확한가? 화면과 소리가 서로 보완하는가? 원고와 목표 길이가 맞는가? 서사 단위(비트·씬·시퀀스·막)와 샷을 혼합하지 않았는가?
