# 장르 긴장·코미디 설계 (온디맨드 심화)

모듈 02(서사·감정 구조)와 03(각본)의 심화. 장르 영상·하이브리드 장르·코미디/병맛·재미있는 광고·진지한 소재의 절제된 유머에 연다. 장르 틀은 필수 비트 수가 아니며 인과와 인물 선택을 우선한다.

## 1. 장르 긴장

장르는 기대 계약이다. 핵심 쾌락을 충족하면서 경로를 변주한다.

1. 1차 장르와 선택적 2차 장르를 고른다.
2. 장르 약속을 관객 언어로 적는다: 두려움·풀이·그리움·웃음·경외·응원·발견·목격.
3. 아래 장르 패턴은 선택적 비교안이다. 브리프에 맞는 긴장 엔진을 고르고 화살표의 순서·개수 자체를 합격 기준으로 쓰지 않는다.
4. 잃을 수 있는 것·오해될 것·드러날 것·변형될 것을 세운다.
5. 지식·위험·친밀감·대가·시간 압박을 바꿔 에스컬레이션한다.
6. 반전이 장르 약속과 브리프에 유익하면 비교안으로 제시한다. 반전 없는 형식에 최소 개수를 강제하지 않는다.
7. 약속된 쾌락을 결말 전 또는 결말에서 전달한다. 일반적 교훈으로 대체하지 않는다.
8. 하이브리드는 한 장르가 구조를, 다른 장르가 톤이나 선택된 비트를 맡게 한다.

### 장르 패턴

- 호러 비교안: 일상 → 이상 → 의심 → 증거 → 취약 → 접근/회피 선택 → 조우 → 결과. 예상된 위해와 불확실성을 긴장 가설로 검토하되 공포의 일반 원인식으로 단정하지 않는다.
- 스릴러: 목표 → 위협 → 좁아지는 선택지 → 시간/대가 → 반전 → 필사적 계획 → 대치.
- 미스터리: 질문 → 단서 → 가설 → 모순 → 새 프레임 → 공개 → 함축. 공정성이 중요하며 해석 가능한 증거를 심는다.
- 로맨스: 끌림 → 마찰 → 재인식 → 취약 → 위협/이별 → 선택 → 변한 관계.
- 드라마: 가치 갈등 → 압력 → 어려운 선택 → 결과 → 변한 자아/관계.
- 액션: 목표 → 장애 → 전술적 선택 → 물리적 결과 → 새 제약 → 더 큰 세트피스 → 결정적 행동.
- 감동/성장: 한계 → 구체적 노력 → 좌절 → 적응 → 정당한 진전 → 의미. 가짜 역경은 피한다.
- 다큐/설명: 질문 → 관찰된 현실 → 복잡화 → 증거 → 해석 → 미해결 뉘앙스 또는 결론.
- 경이: 일상적 규모 → 숨은 규모/체계 공개 → 감각적 몰입 → 관점 전환.

## 2. 코미디 설계

코미디는 규칙·인물·상황·기대에서 나온다. 무작위함만으로는 농담이 되지 않는다.

1. 코미디 원천을 찾는다: 인물 결함·지위 격차·불가능한 규칙·사회적 긴장·문자 해석·숨은 지식·물리적 장애·장르 충돌.
2. 관객이 일어날 일을 예측할 수 있게 정상 규칙을 분명히 세운다.
3. 기대를 한 번 위반한다. 행동이나 반응으로 관객이 알아차리게 한다.
4. 관련 없는 기묘함이 아니라 같은 코미디 논리로 에스컬레이션한다.
5. 반복 시 규모·결과·참가자·타이밍·해석을 변주한다.
6. 반응은 선택 가능한 연기 장치다: 부인·늦은 깨달음·과신·태연한 수용·지위 상실. 늦은 깨달음은 아래 Culhane의 double take처럼 자극→아직 반응 없음→인지/반응으로 설계할 수 있다. 반응 추가가 웃음을 배가한다는 효과·고정 지연 시간을 주장하지 않는다.
7. 콜백을 쓸 때는 앞 디테일과 뒤 의미의 연결을 적고 즉시 회수/간격을 둔 회수를 비교할 수 있다. “관객이 거의 잊은 때”는 관측하지 않은 기억 상태이므로 필수 회수 시점이나 QA 기준으로 쓰지 않는다. 콜백 없는 안도 유효하다.
8. 가장 강한 깨끗한 보상으로 끝낸다. 농담을 뒤에서 설명하지 않는다.
9. 표적과 존엄을 점검한다. 약자 공격·굴욕·고정관념은 구성의 대체재가 아니다.

### 코미디 기제

- 미스디렉션: 합리적 예측을 유도한 뒤 다르지만 일관된 의미를 드러낸다.
- 지위: 인물이 지위를 얻고·지키고·숨기고·회복하려 싸운다.
- 드라마틱 아이러니: 관객이 인물이 모르는 것을 안다.
- 삼단 규칙: 패턴을 두 번 세우고 세 번째 비트가 방향이나 크기를 바꾼다.
- 반복+변주: 재인식이 기대를 만들고 변주가 놀라움을 만든다.
- 문자화: 은유·완곡어법·사회적 관례를 물리적 진실로 취급한다.
- 과소/과잉 반응: 사건과 반응의 불일치.
- 압축: 설명 단어를 빼고 셋업-펀치 거리를 줄인다.
- 콜백: 뒤 비트가 앞 디테일의 기억을 바꾸거나 보상한다.
- 시각적 모순: 화면이 대사나 자기 이미지와 다른 말을 한다.

### 에스컬레이션 사다리

선택적 비교안: 불편 → 당혹/지위 위험 → 실질적 결과 → 관계적 결과 → 공적 결과 → 전제와 일관된 부조리/극단. 한두 축만 바꾸는 안과 여러 축을 바꾸는 안을 필요할 때 비교한다. 새 행동·브리프의 보상이 읽히는지 검토하며, 이 사다리·축 수·같은 개그의 반복 여부 자체로 실패시키지 않는다.
