# Minimum take repair

Use for an identified defect in an actual take. Keep the source immutable and use the existing [execution and cost gate](24-production-execution.md) and [sequence contract](sequence-execution.md); this reference neither chooses a provider for the user nor authorizes an external operation.

| Observed defect | Smallest eligible intervention |
|---|---|
| Noise, sibilance or uneven level; performance valid | Compare matched-level original and locally treated dialogue. Installed FFmpeg filters to consider: afftdn, deesser, acompressor and loudnorm. Treat only demonstrated problems; preserve breath, intentional texture and room tone. DeepFilterNet is a conditional 48 kHz WAV restoration candidate, not an automatic dependency. |
| Voice color only | Compare an approved usable existing take first. ElevenLabs voice-changer or Higgsfield Voice Change are optional speech-to-speech candidates; not pronunciation or delivery repair. |
| Incorrect wording, pronunciation, delivery, tone or emotion | Apply [R6 phrase repair](29-reference-driven-production.md#dialogue-repair). Prefer approved alternate/ADR; Fish Audio Drama 3 or Typecast are optional synthesis paths only if the active transport can select the approved voice/model/controls. Synthesizing is not existing-waveform editing. Dubbing applies only to a requested language version. Higgsfield TTS exclusion stays intact. |
| Missing Foley, ambience or SFX | Prefer rights-cleared material and align to the actual cue. If authorized, ElevenLabs sound-effects or Higgsfield Seed Audio/Mirelo are separate SFX candidates. Do not confuse synthesis with cleaning a mixed recording. |
| Face, gaze or body performance | Try a valid alternative take or coverage. Runway character_performance and Higgsfield Genjutsu/Kling motion transfer are candidates for bounded rework, not verified in-place facial fixes. |
| Visible mouth disagrees with locked audio | Use [dialogue/lip-sync QA](22-dialogue-lipsync.md). Try appropriate coverage first. LatentSync is a conditional local GPU/model candidate; Higgsfield Lipsync Studio is UI-only evidence until an eligible transport is verified. |

**Local audio:** Probe the input and use a separate PCM/WAV dialogue stem. For steady noise, start with a conservative `afftdn` pass and inspect that result before adding any other filter. Example on a new authorized output: `ffmpeg -nostdin -n -i source.wav -af afftdn=nr=6 -c:a pcm_s24le repaired.wav`. Use readings and actual listening to choose de-essing, compression or normalization; this example is not a preset for all mixes. Keep sample rate, channel layout and time mapping unless the required delivery contract changes them. For phrase replacement choose boundaries from the actual waveform and listening, preserve adjacent audio, and check conformed duration against the timeline before adoption.

**Provider gate:** resolve the exact runtime, model/control and input rights (voice, image, uploads and applicable consent), license, quote, retry ceiling and current authorization before submitting. Hosted availability and public code are not evidence of execution; unknown cost or unsupported control blocks the affected operation. ElevenLabs adapters, DeepFilterNet, Runway and LatentSync require their own runtime/smoke verification before activation. Do not automatically install, clone voices, replace a provider, or retry an unresolved submission.

Record original/derived versions, scene/cut and source/timeline interval, observed defect, required invariant and test. Compare repaired phrase, adjacent speech, scene mix and the affected mouth/cut edges. Update only real dependents (e.g. captions, sync, timing, mix); the coordinator alone adopts the version. If the result fails under the same conditions, stop that repair path and report the blocker rather than retrying blindly. Continue independent work and return the full edit for user review only after whole-film QA.
