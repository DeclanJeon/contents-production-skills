# 서사·감정 구조

## 입력과 산출물
입력: 브리프, 핵심 소재, 장르, 러닝타임

산출물: 로그라인, 인물 설계, 인과 비트, 감정 곡선 (선택: story/plot 분리 기록, 제작용 시놉시스, 트리트먼트, 관계·갈등 지도, 세계관 규칙)

## 실행 절차
1. 주인공의 외적 목표·내적 필요·장애·실패 비용을 분리한다. 대립자는 단순 악역이 아니라 목표를 저지하는 힘으로 설계한다.
2. 3막·5막·비트시트·영웅 여정을 비교해 하나를 작업 틀로 선택한다. Campbell의 비교신화 모델을 모든 문화와 형식의 보편 법칙으로 취급하지 않는다.
3. 각 비트를 원인→선택→결과→다음 압력으로 연결한다. 시간 순서만 있는 사건 배열은 인과 서사로 고친다.
4. 각 장면에서 가치·관계·정보가 어떻게 바뀌는지 적는다. 설정·호흡 장면을 포함할 때도 필요한 기능을 명시한다.
5. 감정은 감정 단어 대신 관객이 볼 행동과 잃을 것으로 설계한다. 반복 모티프와 복선은 결말에서 의미를 바꾸거나 회수한다.
6. 교육·설명 영상에는 질문→관찰/증거→해석→적용을 사용할 수 있으며 인물 갈등을 의무화하지 않는다. 비선형·실험 영상에는 변화 규칙과 관객의 탐색 경로를 제시한다. 억지 갈등 대신 대비·발견·패턴의 변형도 허용한다.

## 개발 문서 구분 — 요청된 것만 작성

영화/단편 요청에서 요청·승인 범위에 맞는 문서만 채운다. 서사 구조 요청을 전체 개발 패키지로 확장하지 않는다. 사용자가 제공하지 않은 방향은 `제안`으로 표시한다.

- **Story**: 이야기 세계에서 일어난 사건의 전체 내용과 시간 순서. 사건 목록만 있으면 이 문서다.
- **Plot**: 관객에게 사건을 배열·공개하는 구조 — 공개 순서, 시점, 복선·회수, 비선형 배열을 기록한다. story의 동의어로 쓰지 않는다.
- **시놉시스**: 시작부터 결말까지의 압축 요약. 제작용은 반전과 결말을 포함하며, 홍보용 블러브(결말을 숨기는 판매 문구)와 목적 필드로 구분한다. 요청 없이 제작용 내용을 홍보 문구로 돌리지 않는다.
- **트리트먼트**: 각본보다 앞선 산문형 전개 문서 — 사건·주요 장면·인물 행동과 감정 변화 수준. 대사를 확정하는 각본과 섞지 않는다.
- **캐릭터**: 욕망(외적 목표)/필요(내적 결핍)/결함(방해 성향)/아크(결말의 상태 변화)를 분리한다. 인물 없는 비서사 작업은 이 블록을 N/A와 사유로 표시한다. 등장인물이 있고 캐릭터 시트(외형·음성·연기 정체성의 정본)가 요청되거나 필요하면 `assets/character-ssot-template.md`를 별도 산출물로 작성하고 이 문서에서 ID로 연결한다 — 시트가 없으면 위 네 항목의 인라인 요약으로 충분하며, 로그라인·스토리 단독 요청에 강제하지 않는다.
- **관계·갈등 지도**: 인물 쌍의 관계와 목표 충돌을 기록한다. 단순 등장인물 나열과 구분한다.
- **세계관 규칙**: 이야기 내부 법칙 — 무엇이 가능/불가능한가, 규칙 위반의 대가. 시각 룩·팔레트는 [시각 구조·아트 디렉션](05-visual.md)과 `assets/style-world-bible-template.md` 소유이며 여기 복제하지 않는다.
