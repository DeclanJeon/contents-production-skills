# 컷·전환·음향 표현 선택표

편집·소리 선택이 필요한 요청에만 읽는다. [09 편집·사운드](09-edit.md)의 시간·소스·오디오 모드·권리·청취 절차가 정본이다. 카메라 카탈로그의 B17–24 ID/정의는 유지하며 이 문서는 실제 편집 인계 조건을 보완한다. X의 작성자 설명과 Eyecandy 분류는 탐색 자료이고 클립 전체 분석/효과 검증이 아니다. [참조 색인](production-reference-index.md)의 검사 범위와 권리 기록을 적용한다.

| 표현 | 선택 조건 / 필요한 자료 | 실패 조건·실제 검수 | 기존 09 인계 칸 |
|---|---|---|---|
| Match cut | 두 화면의 형태·방향·위치 또는 행동 단계 대응 | 컷아웃/컷인 대응이 읽히지 않음; 실제 전환 양쪽 프레임과 재생 확인 | 행동·카메라 변화 / 컷아웃→컷인 phase·state + cue time, transition/duration_s |
| Jump cut | 의도된 시간 생략·불연속을 드러냄 | 원치 않는 순간이동·소품 상태 리셋; 생략 전후와 후속 유지 확인 | 컷 이유, 시간 압축·생략 표 |
| Cross-cutting / parallel editing | 다른 공간/행동의 관계를 교대로 공개 | 동시성이 미확정인데 동시 사건으로 단정하거나 기능 없는 교대 | 컷 이유, final_start_s/final_end_s |
| Montage | 선택 단계·대비·시간 압축으로 관계를 전달 | 생략 단계·실제 경과시간을 발명, 필수 원인 제거 | 시간 압축·생략, source_in_s/source_out_s |
| Smash cut | 앞뒤 화면·소리 대비가 선택된 강조 | 대비 의도 없이 단순 hard cut을 효과로 과장 | 컷 이유, transition/duration_s, sound_id·sync anchor |
| Shot / reverse shot | 발화·듣기·관계·시선을 필요한 시점에서 읽힘 | 기계적 1대사=2컷; 축·시선·반응 계기 불일치 | 컷 이유, reaction/settle hold, 06의 시선/축 |
| J-cut / L-cut | 다음 소리의 선행 / 이전 소리의 잔류 | 시각 컷과 음향 경계 혼동·잘린 말·공간 점프 | sound_id·sync anchor, final time, sound-cues start/end |
| Dissolve / wipe / whip-pan transition | 시간/공간 연결 방식이 브리프에 필요 | 전환 중첩으로 총길이·읽기 시간 소실; whip은 촬영 무빙과 편집을 구분 | transition/duration_s, source handles, final time |
| Foley / material detail | 보이는 접촉·재질·힘을 소리로 구체화 | 다른 재질·주체·시점·접촉보다 빠른/늦은 사건 | layer, function, sync_anchor/sync_offset_s |
| Ambience / room tone | 공간과 컷 간 이어지는 청취 관점 | 역방향마다 채널 뒤집기·잔향/배경음 단절 | mix_note의 관점·위치·거리/잔향, fade |
| Music / silence | 선택된 감정·리듬·공개 기준 | 무음 요청에 음악 삽입, 단순 음악 존재로 기능 주장 | audio_mode·레이어, function, gain_db, mix_note |

## 예시를 실행 명세로 옮기기

기존 09 표의 `소싱 후보`, `출처/파일 ID·버전`, `기능·감정·길이·동기 기준점`, `권리 근거/확인 시점·제한`, `청취 결과`, `선택`을 채운다. 실제 없는 파일/ID/in-out은 미선택·미확인이다. 공급자 혼합 오디오에 없는 stem을 발명하지 않는다.

J컷을 제안하는 경우 시각 컷 시각과 다음 소리 시작을 별도로 적는다. 제안 오프셋은 측정값이 아니며 허용 오차는 브리프/합의 기준을 따른다. source time, final time, shot-local/generation-local time은 기존 시간 계약대로 변환한다. 보이스·사운드의 기본 경로는 참조·지정 실행자·첨부 오디오가 없을 때 같은 지원 요청의 AUDIO 구획에 보이스·사운드 설계를 넣어 함께 생성하는 것이며([영상 계획 §3b](../../creative-production/references/video-generation-planning.md#3b-voice-and-sound-design-are-in-request-by-default)), 별도 파라미터가 없다는 이유로 외부 TTS를 자동 추가하지 않는다.

실제 전체 시퀀스를 소리와 함께 재생하고 필요한 무음/오디오 단독/경계 프레임 검사를 추가한다. 표본 프레임·오디오 스트림 메타데이터·자동 전사만으로 리듬·발음·공간음·믹스 통과를 주장하지 않는다. 권리 미확인은 해당 사용/업로드/게시 행위를 막고 자료 없는 설계는 진행한다. 소리의 서사 효과는 창작 의도이며 관객 반응 측정이 아니다.

## 속도·타격 표현 선택표

위 표의 컷·전환은 **장면 사이**를 잇고, 아래 표현은 **화면 안의 속도 자체**를 만든다. 시간 조작(램프·리매핑)은 편집·후반 소유이며 선택한 생성 모델이 프레임 단위 속도 곡선을 지원한다고 가정하지 않는다. 요청문에 표현 이름을 썼거나 배속 필드를 채웠다는 이유로 실제 램프·정지·흔들림이 생겼다고 판정하지 않는다. 같은 이름의 정의·ID는 [카메라 카탈로그](../../camera-spatial-design/references/camera-language-catalog.md) B10·B13–B16(핸드헬드·슬로모션·스피드 램프·타임랩스·프리즈 프레임)과 B17–24(컷·전환), 이 문서의 위 표가 유지한다. 아래 표는 그 정의를 다시 쓰지 않고 실제 편집 인계 조건만 더한다.

| 표현 | 선택 조건 / 필요한 자료 | 실패 조건·실제 검수 | 기존 09 인계 칸 |
|---|---|---|---|
| Speed ramping | 한 동작 안에서 느림→급가속(또는 가속→정지)의 대비가 사건 강조에 필요하고 원본에 핸들 프레임이 있음 | 상수 배속 하나를 램프로 표기; 한 shot/행에 곡선을 넣어 검증기가 거부; 램프 구간 프레임 부족; 구간별 실제 rate와 재생 확인 | 구간별 cut 행(같은 shot_id) 또는 인접 shot 분해, 구간별 `source_in_s`/`source_out_s`와 상수 `playback_rate`, `final_*_s`, 컷 이유 |
| Time remapping | 구간별로 시간 흐름을 늘리거나 줄여야 물리·감정이 읽힘(정점 유지, 관성 늘리기) | 전 구간 동일 속도로 대체; 늘린 구간의 프레임 반복이 정지처럼 보임; 실제 프레임 대조 | `playback_rate` 구간 분할(샷당 스칼라), `final_*_s`, 구간 경계에서의 상태 유지 |
| Rhythmic editing | 음악 박·내레이션 강세·반복 동작이 컷 위치의 근거를 제공하고 그 비트 시각이 실제 확인됨 | 비트 미확인 상태의 추정 배치, 박자와 무관한 컷을 리듬으로 표기; 오디오를 포함한 실제 재생 확인 | 컷 이유, `sound_id`·sync anchor, `final_*_s` |
| Kinetic editing | 앞 컷의 이동 방향·속도가 다음 컷의 이동과 이어져 컷 자체를 감춤 | 방향·속도가 반대인데 연결됐다고 표기; 양쪽 프레임과 재생 대조 | 컷아웃→컷인 phase·state + cue time, 컷 이유 |
| Impact frames | 타격·충돌 순간에 1~3프레임 삽입이 사건 인지를 돕고 삽입 소재가 승인됨 | 삽입 프레임이 접촉·소유 상태를 바꾸거나 없는 소재를 발명; 실제 프레임 인덱스 확인 | `source_in_s`/`source_out_s`, `final_*_s`, 접촉 phase, 유지 상태 |
| Staccato editing | 매우 짧은 컷 연속이 압박·조급함을 만들고 각 컷이 서로 다른 정보/상태를 줌 | 같은 상태를 쪼개 읽기 시간만 지움; 필수 공개·반응 소실; 정상속도 재생 확인 | 컷 이유, `final_*_s`, reaction/settle hold |
| Motion blur | 빠른 이동의 방향·속도가 읽혀야 하고 획득 방식(촬영·렌더·후반)이 구분됨 | 정지 프레임의 블러를 실제 이동 증거로 사용; 방향이 이동과 반대; 실제 재생 확인 | 05 시각/소품 메모, 06 카메라 동작, 09 컷 이유(획득 방식) |
| Speed lines | 그림체·그래픽 요소로 가속을 과장하는 양식이 승인됨 | 실사 소스에 없는 만화 효과 삽입, 이동 방향과 불일치; 실제 프레임 확인 | 05 시각/양식 슬롯, 09 컷 이유 |
| Camera shake | 충돌·폭발·주관 충격을 카메라 흔들림으로 전달하는 것이 승인된 양식 | 전 구간 상시 흔들림으로 피로 유발, 접촉·정보 가림; 실제 재생 확인 | 06 카메라 동작·샷 크기, 09 컷 이유 |

배속·리매핑의 실제 초·rate·프레임 수는 [09 배속과 원본](09-edit.md#배속과-원본)과 시간 압축 절이 정본이다. 여기서는 표현 선택과 인계 칸만 정한다. 램프가 필요한데 실행자가 구간별 rate를 지원하지 않으면 컷 분할 또는 상수 배속 + 컷을 대체안으로 제시하고, 지원하지 않는 제어를 요청문에 적은 것을 완료로 세지 않는다. 공간·해부·접촉 결함은 속도 램프·모션 블러·충격 프레임·카메라 흔들림으로 가리지 않는다 — 가려야 할 결함이면 소스를 수리하거나 컷을 바꾼다.

## 효과음 설계 선택표

아래 세 표는 **선택 조건과 인계 칸**만 정한다. 믹스 절차·계층 우선순위·권리·청취 기준의 정본은 [09 오디오 의도](09-edit.md#오디오-의도와-실행-경로)·[음악·효과음 소싱과 권리](09-edit.md#음악효과음-소싱과-권리)이며, 표의 항목을 모두 쓰는 것이 합격 조건이 아니다.

| 표현 | 선택 조건 / 필요한 자료 | 실패 조건·실제 검수 | 기존 `sound-cues`/09 인계 칸 |
|---|---|---|---|
| Layered impact(중첩 타격) | 충격의 재질·규모·접촉 지점이 정해져 있고, 저음·접촉·파편/잔향을 실제로 다른 소스나 레이어로 구분할 수 있음 | 세 층이 같은 순간·같은 재질로 뭉쳐 한 덩어리로 들림; 층별 어택이 어긋나 접촉이 안 읽힘; 레이어를 나눴어도 분리 청취가 안 되면 미검증 | `layer`, `function`, `sync_anchor`/`sync_offset_s`, `gain_db`, `rights_status` |
| Whoosh(이동음) | 화면의 이동 방향·근접도가 확정되어 있고 접촉음과 구분할 여유가 있음 | 모든 손동작에 삽입, 이동 방향과 반대 재생, 접촉음과 겹쳐 접촉이 둔해짐 | `sync_anchor`, `sync_offset_s`, `fade_in_s`/`fade_out_s`, `mix_note`(방향·근접) |
| Riser(상승음) | 위험 공개·정점 직전 구간이 타임라인에 있고 정점 기준점이 정해져 있음 | 동일 상승음 반복으로 예측 가능, 정점 이후에도 지속돼 강조가 무더짐 | `start_s`/`end_s`, `sync_anchor`(정점), `gain_db` |
| Pre-impact silence(타격 전 무음) | 정점 직전에 앰비언스까지 줄일지, 유지할 층을 구분해 정했음 | 실내 환경음까지 무의도로 끊어 공간 상실, `no_audio` 요청과 혼동 | `audio_mode` 유지, `gain_db` 자동화 구간, `mix_note`(유지하는 층) |
| Sound bridge(소리 이어붙이기) | 다음 장면의 소리가 다음 컷 전에 시작되는 것이 사건 관계상 읽힘 | J컷/L컷 인계와 중복 표기, 사건 시간 관계 혼동 | `sync_offset_s`(선행이면 음수), `start_s`, J컷 인계와 구분 메모 |
| Transient design(어택 설계) | 총성·발소리·문 닫힘처럼 첫 순간이 사건인 소리 | 과도한 어택으로 피로·왜곡·클리핑, 다른 층을 압도 | `gain_db`, `mix_note`, 실제 청취 결과 |

## 음악 설계 선택표

음악의 기준점·오프셋·허용 오차와 권리는 [09 실행 가능한 편집·사운드 큐](09-edit.md#실행-가능한-편집사운드-큐)가 정본이다. 아래는 어떤 음악적 선택이 그 기준점에 붙는지다.

| 표현 | 선택 조건 / 필요한 자료 | 실패 조건·실제 검수 | 기존 인계 칸 |
|---|---|---|---|
| Leitmotif(반복 주제) | 같은 대상·위협·기억이 작품 안에서 두 번 이상 실제로 등장함 | 첫 등장 없이 회상에서만 시작, 같은 멜로디 기계적 재생 | `sound_id`, `layer`, `function`(연결 대상), `mix_note` |
| Ostinato(반복 패턴) | 추격·불안이 단계적으로 상승하고 길이를 감당할 구간이 있음 | 밀도 과다로 피로, 컷마다 패턴이 끊켜 상승이 안 읽힘 | `start_s`/`end_s`, `gain_db`, `mix_note` |
| Musical hit point | 음악 강조를 붙일 사건 기준점(`action_peak`·`reveal`·`cut`)이 이름붙어 있음 | 임의 오프셋으로 사건과 어긋남, 같은 강조 반복으로 예측 가능 | `sync_anchor`/`sync_offset_s`, 허용 오차는 브리프/승인 기준 |
| Musical counterpoint(대조 음악) | 장면 감정과 음악의 불일치가 의도된 해석을 만든다는 결정이 있음 | 의도 없는 톤 충돌, 관객이 장르 실수로 읽음 | `function`(대조 대상·의도), `mix_note` |
| Musical silence | 음악이 빠지는 구간이 사건·호흡과 연결됨 | `no_audio`·`no_dialogue` 요청과 혼동, 앰비언스까지 소실 | `start_s`/`end_s` 빈 구간, `audio_mode`, `layer` |

## 공간 음향 선택표

청취 관점·좌우 유지·역방향 컷 처리의 정본은 [09의 스테레오·공간음 규칙](09-edit.md#실행-가능한-편집사운드-큐)이다. 아래 값은 실제 채널을 들어 확인하기 전까지 미검증이다.

| 표현 | 선택 조건 / 필요한 자료 | 실패 조건·실제 검수 | 기존 인계 칸 |
|---|---|---|---|
| Distance attenuation(거리 감쇠) | 접근·이탈이 사건이고 인물·카메라 거리가 샷별로 확정됨 | 음량만 줄이고 고역·반사를 유지해 가까워져도 멀게 들림 | `gain_db` 자동화, `mix_note`(거리·고역), 실제 좌우/다운믹스 청취 |
| Early reflection(초기 반사) | 공간 크기·재질(복도·방·계단)이 장소 정본에 있음 | 공간과 맞지 않는 리버브, 컷마다 잔향이 단절 | `mix_note`(관점·잔향), `fade_in_s`/`fade_out_s` |
| Occlusion(차폐) | 문·벽·계단 너머라는 공간 관계가 화면과 일치함 | 차폐 이유 없이 먹먹함, 벽을 무시한 직접음 유지 | `layer`, `gain_db`, `mix_note`(차폐 근거) |
| Pan automation(좌우 이동) | 화면 밖 위협·이동의 방향이 블로킹과 맞음 | 화면 방향과 반대, 역방향 컷마다 자동 반전 | `mix_note`(좌우·이동 구간), 실제 채널 청취 |
| Subjective muffle(주관 먹먹함) | 충격·폭발 직후 인물의 청각 상태가 서사에 필요함 | 지속이 길어 정보·편안함을 해침, 전 구간 상시 적용 | `layer`(주관 구간), `start_s`/`end_s`, `mix_note` |

## 물리 재질 기반 SFX 프롬프트 변환 규칙

Foley 및 접촉 SFX를 `sound-cues.csv`나 오디오 생성기로 넘길 때는 **`[물체 A 재질/무게] + [물체 B 표면 재질] + [운동 형태(slide/scrape/thud/click/snap)] + [공간 잔향 및 제외할 과장음]`** 순서로 구체화한다. 화면의 물리적 규모(예: 소형 로봇, 실내 소품)를 초과하는 시네마틱 폭발음·트레일러 브람(Braam) 키워드를 습관적으로 넣지 않는다.
