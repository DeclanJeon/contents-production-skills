# 조명 표현 선택표

조명 표현을 비교할 때만 읽는다. 기존 [07 조명](07-lighting.md)의 설계·광원/노출·역방향 매칭 절차가 정본이다. 아래는 자체 작성한 선택 후보와 관찰 기준이며 외부 영상의 전수 분석이나 관객 효과 검증이 아니다. 근거 진입점과 검사 한계는 [참조 색인](production-reference-index.md), 기존 ARRI 발췌의 정확한 범위는 07의 근거 절을 따른다.

| 표현 | 선택할 조건·관찰할 화면 | 정할 것 / 흔한 실패 | 07의 기존 칸 |
|---|---|---|---|
| High-key / 밝은 낮은 대비 | 얼굴·정보를 밝고 넓게 읽히게 하는 목표 | 배경/피부/의상의 밝기 관계. 단순 과노출과 구분 | 키/필 관계, 배경 분리, 노출 상태 |
| Low-key / 어두운 높은 대비 | 일부 정보나 공간을 그림자에 유보 | 반드시 읽혀야 할 눈·손·소품. 모든 암부가 뭉개지면 실패 | 광원 동기, 그림자 규칙, 노출 상태 |
| Soft side light / 부드러운 측광 | 형태를 보이며 그림자 경계를 완만하게 | 유효 발광면·상대 크기·거리/방향. 밝기만 낮춘 하드광과 구분 | 방향/높이, 경도/확산, 키/필 관계 |
| Hard light / 선명한 그림자 | 의도된 그림자 형태가 정보일 때 | 그림자 경계·패턴·주요 얼굴/텍스트 가림 | 경도/확산, 그림자 규칙 |
| Rim / edge light | 배경과 외곽의 분리가 필요할 때 | 가장자리 위치·폭·색과 필요한 얼굴광. 발광 테두리를 신원으로 굽지 않음 | 방향/높이, 배경 분리 |
| Backlit silhouette | 외곽만 읽히고 신원/표정 유보가 목적 | 식별해야 할 행동·소품 외곽. 표정 필수 장면과 충돌하면 다른 안 | 배경 분리, 그림자 규칙, 매칭 주의 |
| Golden-hour motivated | 낮은 따뜻한 주광원을 장면 시간과 연결 | 공간상의 광원 방향·피부/의상색·장면 변화. 오렌지 필터만으로 시간 증명하지 않음 | 광원 동기, 방향/높이, 색 의도 |
| Moonlight motivated | 밤의 방향·분리·가독성이 필요 | 달/창/주변광의 설정과 얼굴 가독성. 파랑=실제 색온도 확정 금지 | 광원 동기, 색 의도, 노출 상태 |
| Candle / fire motivated | 화면 속 불빛과 얼굴 반응 연결 | 광원 위치·색·시간 변화·다른 광원. 불꽃/밝기 변동은 실제 재생 검사 | 광원 동기, 색 의도, 매칭 주의 |
| Dappled / blinds pattern | 잎/블라인드의 가림 패턴이 공간 단서 | 패턴을 만드는 구조·투사 방향·동작 시 유지. 얼굴/중요 문자 가림 | 그림자 규칙, 방향/높이, 매칭 주의 |

## 프롬프트와 검수

예시 의도: `soft side light from the established window; a gradual shadow edge across the face; the eyes remain readable`. 이는 결과 목표이며 실제 기구·조도·노출 제어가 아니다. 실제 f-number/T-stop·Kelvin·광량 필드는 현재 실행자가 노출한 경우만 입력하고 제안과 실측을 구분한다. 색온도만으로 피부/배경색 일치를 보장하지 않는다.

선택은 07의 해당 행, 11의 `조명·룩`/`유지 규칙`/`도구 지원 확인`에 연결한다. 시트의 중립 identity 조명과 이번 샷의 극적 조명을 구별한다. 인접/역방향의 광원은 공간에 고정하고 화면 좌우와 분리한다. 동작/조명 리빌이 있으면 시작→변화→정착→유지를 해당 샷 시간 기준으로 적는다. 실제 승인 프레임·연속 재생을 확인한 만큼만 12/21 QA에 남긴다. 정지 한 장으로 플리커·움직이는 반사·역방향 연속성 전체를 통과시키지 않는다.
