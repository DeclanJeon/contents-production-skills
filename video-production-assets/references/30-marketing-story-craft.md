# 마케팅·스토리 서적에서 보완한 제작 판단

기존 브리프·비트표·대사 연기 지시에 필요한 항목만 더한다. 별도 필수 원장이나 모든 콘텐츠에 적용하는 성공 공식을 만들지 않는다. 승인된 사건·결말·고객 사실은 아래 기법보다 우선한다.

## 영상 광고의 메시지와 공유 이유

광고/브랜드 영상의 기획·변주에만 적용한다. 일반 영화·교육 영상에 구매 CTA를 붙이는 근거가 아니다.

- **실제 대안 → 차별 속성 → 고객 가치 → 적합 고객 → 이해할 범주**를 기존 브리프에서 연결한다 [M2]. 대안은 동종 업체뿐 아니라 수작업·현재 방식·아무것도 하지 않기일 수 있다. 고객이 실제 검토한 대안과 제작자의 추측을 구분한다. 속성만 나열하지 말고 그 차이가 어떤 상황의 고객에게 왜 중요한지, 영상에서 무엇으로 보여줄지 정한다. 확인 안 된 상대 우열은 사실로 쓰지 않는다.
- **VOC를 만들지 않는다** [M3]. 인터뷰/리뷰를 해석할 때 과거의 구체적 사건, 현재 해결법, 실제 지출·시간·행동을 칭찬·가정적 구매 의향과 분리한다. “이런 영상 좋아하실까요?”보다 “최근 이 문제를 겪었을 때 무엇을 했나요?” 같은 질문을 제안할 수 있지만, 조사 실행이나 답변을 꾸미지 않는다. 인터뷰의 구매 관심은 조회 수·시장 전체 수요의 증명이 아니다.
- **누가 누구에게 왜 전달할까?** [M1]. STEPPS의 사회적 가치·일상 계기·감정·관찰 가능성·실용성·이야기 중 브리프에 맞는 관점을 골라, 실제 비트와 연결한다. 여섯 가지를 전부 넣거나 과장·분노를 유발하라는 체크리스트가 아니다. 생활 속 회상 계기와 영상 초반의 주목 훅은 서로 다른 결정이다.
- **제품/핵심 아이디어 삭제 시험** [M1]. 브랜드명을 말미에 붙이는 것만으로 이야기와 효익이 연결되지는 않는다. 제품이나 전달할 아이디어를 지워도 사건·해결·교훈이 그대로라면 연결이 약한 후보로 표시한다. 데모·선택·결과에 승인된 효익을 자연스럽게 연결하는 수정안을 제시하되, 픽션 장면을 효능 증거로 쓰지 않는다. 의도적으로 분위기·인지도를 다루는 영상은 그 목적을 적고 이 시험을 강제 탈락 조건으로 삼지 않는다.

위 항목은 메시지 설계 가설이다. 공유율·인지·전환 개선을 보장하지 않으며, 기존 캠페인 검토의 실제 데이터·기간·판정 기준을 대체하지 않는다.

## 캐릭터 아크와 선택

인물 중심 서사의 개발·수정에서만 적용한다 [S1]. 기존 욕망/필요/결함/아크 항목에 다음을 짧게 연결한다:

`시작의 믿음/가치 → 이를 시험하는 압력 → 인물의 선택 → 결말의 믿음/행동 증거`

- 긍정 변화, 신념을 지키며 주변을 바꾸는 flat arc, 부정 변화 모두 가능하다. 모든 인물을 성장·치유시키거나 결말에 교훈을 추가하지 않는다.
- 외적 목표 달성과 내적 변화는 별개다. 이겼지만 악화되거나, 졌지만 관점이 바뀔 수도 있다. 승인된 결말에서 실제로 무엇이 변했는지 구분한다.
- 믿음/오해/필요는 창작상 해석으로 표시한다. 제공되지 않은 트라우마·과거사·정신적 진단을 원인으로 만들지 않는다. 짧은 장면이나 비인물 콘텐츠에는 아크를 강제하지 않는다.
- 보드에는 추상적 성격 설명보다 선택 직전/직후의 행동·관계·소품 상태로 연결한다. 이미 승인된 시놉에는 변경 제안만 내며 임의로 사건을 추가하지 않는다.

## 대사를 행동으로 쓰기

대사 중심 드라마에서 기존 speech ID와 연기 지시를 사용한다 [S2]. 중요한 교환에 `누구에게 무엇을 얻으려는가 → 말로 쓰는 전술(달래기/떠보기/회피 등) → 상대의 실제 반응 → 다음 전술`을 연결한다. 감정 이름이나 말투 형용사만으로 대사의 기능을 대신하지 않는다.

상대가 반응했다고 매번 새 샷/패널을 만들지 않는다. 반응이 정보·관계·행동을 바꾸는 순간에 기존 발화/청자 커버리지와 연결한다. 설명·독백·내레이션도 목적이 있을 수 있으므로 직접 설명을 무조건 지우지 않는다. 원문 대사나 잠긴 타이밍 변경은 승인 범위를 따른다.

## 컷 또는 유지의 선택

컷을 더 많이 만드는 대신 해당 순간의 감정·이야기·리듬·시선 이동·화면축·공간 연속성 사이의 우선순위를 비교한다 [S3]. 기존 cut/hold 이유에 이익과 손실을 기록하며, 의도된 불연속도 관객이 무엇을 놓칠 수 있는지 검토한다. Murch의 비율을 점수표·합격 가중치·관객 반응 통계로 쓰지 않는다. 보드의 컷 의도 검토와 실제 편집본의 재생·청취 검토는 별개다.
