# GUIDE-01 제작 경험서 추출·통합 기록

## 요청과 범위

사용자 제공 `AI 숏드라마 '야장시단' 제작 가이드북_20261020.pdf`의 재사용 가능한 노하우/공정을 기존 스킬에 통합했다. 드라마 전용 스킬·캐릭터·세계관·복제 프롬프트는 만들지 않았다. 출처의 저작 설명과 이번 패키지의 운영 선택을 분리하며, ‘전 페이지 처리’는 ‘모든 글리프와 모든 외부 영상 검증’을 뜻하지 않는다.

- 출처 ID: **GUIDE-01** (기존 숫자 서적 ID와 별도).
- PDF: **101페이지**, **43,462,504 bytes**, SHA-256 **9dbc047ccbb9ef9e40f27cce0954e800838e35ccae32ce95b31ae6d2f5fb4a7d**.
- 파일명 날짜는 20261020, 표지에는 2026.09가 보인다. 날짜 차이를 임의 교정하거나 판본 발행 사실로 확대하지 않는다.
- 결과: [범용 실무 인계 R1–R8](29-reference-driven-production.md), 기존 모듈/템플릿의 보강. 원본 PDF·페이지 이미지·전체 OCR은 패키지에 포함하지 않는다.
- 프로젝트 schema·manifest 설치 스킬 수·이미지 실행자·Sheet A·승인/예산·단일 원장은 그대로다. 변경은 Unreleased 기록이며 전역 설치/동기화/미디어 생성은 하지 않았다.

## PDF 스캔 방법과 한계

1. `pdfinfo`로 이미지형 문서의 101페이지·비암호화·2000×2800pt 페이지 크기를 확인했다.
2. `pdftotext -layout`은 페이지 구분만 출력했다(유효 본문 0자). 이를 빈 문서로 오인하지 않고 이미지 경로로 전환했다.
3. `pdftoppm`으로 pp1–4는 긴 변 1400px PNG, pp5–101은 1600px JPEG(quality 85)로 모두 렌더했다.
4. 한국어/영어 Tesseract **5.5.0**, `kor+eng`, 기본 PSM으로 **101/101페이지 OCR**을 수행하고 페이지별 순서로 전체 결과를 읽었다. OCR 실행 파일·공개 언어팩은 `/tmp/shortdrama-guide-audit/ocr`에 로컬 추출했으며 시스템 설치/관리자 변경은 하지 않았다. 첫 ESM 패키지 다운로드는 인증 거부되어 공개 Ubuntu 패키지 버전으로 전환했다. PDF를 외부 OCR 서비스에 업로드하지 않았다.
5. **101/101페이지 contact sheet**를 개관해 도해·사진·시트·입력 화면·캡션의 관계를 확인했다. 작은 contact sheet는 세부 전사 근거가 아니다.
6. **첫 통합 때 28페이지**를 개별 렌더로 추가 대조했다: **1–4, 7, 22, 35–36, 38–39, 52, 65, 69–70, 75–76, 80–83, 93–99, 101**. 주요 역할표·얼굴 삭제/잘림·T/f 구분·번역·실제 확장·클론 화면/접합·완료 상태·출력 검수의 해석을 확인했다.
   후속 누락 점검에서는 pp6, 32, 43, 67, 77을 개별 렌더로 추가 대조했다(누적 33페이지). 최초 스캔의 범위는 보존하고 scan JSON의 followup_reviews로 추가 기록한다.
7. OCR은 워터마크, 다단 편집, 작은 UI, 중국어, 파일명/숫자에서 오인식·열 순서 손상이 있다. 중국어 OCR을 정확한 원문 프롬프트로 재사용하지 않았다. 전체 글리프 정확도·전문 교정·모든 스크린샷 세부 전사 검증은 **미수행**이다.
8. `pdfdetach -list` 결과 **embedded file 0개**. 책에서 연결한다고 설명하는 원본 영상·음성·전체 프롬프트·.blend는 확보/실행/재생/청취하지 않았다. PDF의 링크·공급자 공식 문서도 이번 작업에서 외부 확인하지 않았다. 정지 사진은 동작 성공/발음/공급자 현재 기능의 증거가 아니다.

페이지별 렌더/OCR 지문·읽기 방식은 [scan JSON](guide-01-scan.json)에 있다. 렌더/OCR 원본은 임시 경로이므로 영구 재검토는 사용자 보유 원문 PDF에서 재생성해야 한다.

## 23장 전체 대조

페이지는 **1기준 PDF 페이지**다. 한 페이지에서 장이 바뀌므로 경계 페이지는 두 범위에 포함된다. `보강`은 기존 절차의 공백을 메운 것, `유지`는 이미 있던 규칙을 중복 구현하지 않은 것, `제외`는 작품/경험/미검증 조건이라 규칙으로 승격하지 않은 것이다.

## 충돌 해결·의도적 제외

- **시트 뷰 수:** 책은 필요한 방향부터 권장하지만 이 패키지의 전체 image_backed Sheet A 7뷰는 유지한다. 추가 상태/표정/입력 선택만 필요 기반이다.
- **프리비즈:** 책의 선택적 도구 관점으로 기존 장면별 3D 검증 게이트를 면제하지 않는다. 정적 공간 검증과 별도 승인된 동적 출력·실사 결과를 구분한다.
- **이미지 도구:** 책 속 서비스/모델 기본값을 가져오지 않는다. 현재 패키지의 codex-imagen 경로·폴백 금지·해당 승인 규칙을 유지한다.
- **언어:** 중국어 사용은 선택이다. 해당 사례 문자 수는 책의 보고이며 원본 언어 파일로 독립 재계산하지 않았다. 토큰/비용/품질 우위를 도출하지 않는다.
- **음성:** 공급자·태그·현재 최소 길이/요금·속도 우열을 고정하지 않는다. 복제는 요청과 권리 근거가 있는 별도 실행이고, PDF 화면을 클론/교정 성공으로 보지 않는다.
- **회차/재시도:** 90초·인원·장소·구간 배분·세 번 재시도는 예시다. 사용자 요청과 실제 승인 상한을 우선한다.
- **작품:** 인물 이름·얼굴·의상 디자인·무기/특수 능력·지형·고유 타이밍·대사·전용 프롬프트는 범용 실행 지침에 옮기지 않는다. 개인 이력/연락처/계정/워터마크도 전사하지 않는다.
- **입증:** 책의 특정 생성 결과와 프롬프트 사이의 계보, 사용자 발음 보고의 독립 청취, 서비스의 ‘현재’ 기능/검열/성능, 모든 세부 글리프는 확인하지 않았다. 과거 서적 근거를 새 경험서 전체의 근거로 교차 인용하지 않는다.
