## 로컬 각색과 비채택

정본은 [원고 크래프트](../writing-craft.md)이며 기존 오너가 해당 조건에서만 읽는다. 원본 스킬을 실행하거나 별도 설치할 필요가 없다.

- 이해 전제 점검을 영상 설명 원고에 제한하고 기존 선행지식·추상 형식·의도된 비밀 공개를 보존한다. 기존 beat/artifact ID와 기능 보존, 증거 상태, 배정 버전과 단일 기록자는 이 패키지의 로컬 계약이지 Matt의 데이터 스키마가 아니다.
- 조언이 아니라 사용할 문장을 반환하는 완료 형태를 기존 변경 제안/검사/미해결 입력에 적용한다. 새 템플릿 필드·산출물·원장은 추가하지 않는다.
- 제공된 작업용 의미·ID/역할 묶음·고정 문장의 대조와, 사용 가능한 사실이 없을 때의 보류는 로컬 보존 계약이다. 미제공 제품 기능을 추측해 채우는 재창작과 제공 원문 수리를 구별한다. 조건별 읽기 주소는 패키지 루트와 문서 상대 링크를 명시적으로 구별한다.
- 미정인 핵심 사용자 결정과 양립 불가 조건의 확인은 각각 기존 방향 계약·각본 시작 분기가 직접 소유한다. 공용 참조는 그 정본을 가리킨다. 조건 완화 허락의 확인은 로컬 권한 경계 보완이며 원본의 인용문이 아니다.
- 원본의 무제한 인터뷰, 전체 design tree, 기본 후보 2–3개, 단락/비트마다 승인·즉시 파일 저장, 별도 article/fragment 파일은 이식하지 않는다. One pass와 명시적 비트별 협업은 기존 요청에 따른다.
- 원본의 비판·수리 원리는 craft 제안일 뿐 사실 출처, 과금·게시 승인, 실제 매체 검사나 미디어 권리 허락을 대신하지 않는다. MIT는 이 지침의 각색/배포 고지이며 사용자 제공 자산의 권리 판정이 아니다.

공식 제휴나 원본 워크플로의 재현을 주장하지 않는다. 향후 갱신은 원본 차이 검토와 승인된 변경·행동 재평가를 거치며 전역 설치본을 자동 동기화하지 않는다.
