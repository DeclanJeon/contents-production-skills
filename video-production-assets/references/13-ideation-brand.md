# 아이디어 발상·브랜드 영상

## 실행 절차
1. 소재가 없거나 광고/브랜드 영상이면 제품·관객의 구체적 자료와 다른 분야의 관찰 자료를 구분해 모은다. 사실과 가상을 표시한다. 관객 세분화가 필요하면 필요·행동·추구 편익·지역/사용 맥락을 함께 살피고, 인구통계 라벨만으로 동일한 요구를 가정하지 않는다. 자료로 확인되지 않은 세그먼트는 추론으로 표시한다.
2. 영상 주제·시놉시스 탐색을 요청받았을 때는 [정본 수요·선정 정책](../../topic-demand-selection/SKILL.md#decision-procedure)을 읽어 사용자 명시 우선순위, 기본 수요 우선 비교, 독립 사실 적격성 게이트와 unknown 처리를 적용한다. [탐색 계약](../../orchestrating-video-preproduction/references/video-direction.md#discovery-topic-and-synopsis)은 개수·선택·확정 입력 생략에 사용하며 별도 적합성 우선 순위를 만들지 않는다. 트렌드는 확인 가능한 출처/시점이 있는 근거이며 일반 콘셉트 요청에 탐색 단계를 강제하지 않는다.
3. 관객 문제×제품 증거×뜻밖의 상황을 조합해 서로 다른 콘셉트 후보를 만든다. 각 후보에 한 문장 약속·대표 장면·제작 제약·다른 후보와 구별되는 판단 포인트를 붙인다. 탐색 계약이 적용되지 않으면 명시된 후보/앵글 수를 지키고, 미지정이면 요청 범위에 필요한 탐색 폭으로 수를 정한다. 텍스트 후보 수를 실제 이미지/영상 출력 수로 승계하지 않는다; 생성 수·설정·비용은 별도 실행 승인 범위다.
4. 발상 과정을 사람에 대한 설명으로 다섯 단계로 분리한다: 재료 수집 → 재료 관계 검토와 부분 아이디어 기록 → 문제에서 물러나 숙성 → 떠오른 통찰 기록 → 현실 제약에 맞춰 수정하고 타인의 비평으로 검토한다. 숙성은 선택적 인간 발상 과정이지 에이전트가 무의식적으로 일하거나 실제로 기다린 뒤 자동 통찰을 얻었다는 뜻이 아니다.
5. 브랜드가 지향하는 가치와 실제 제공 가능한 경험을 분리한다. 로고·색만 맞추는 것으로 브랜드 일치 판정을 끝내지 않는다.
6. 품질을 판단할 수 있는 제품 사용·비교·조건·한계를 화면에 넣는다. 광고 분위기로 실제 품질 정보를 대체하거나 가짜 후기를 만들지 않는다.
7. 구매 전·사용 중·구매 후 가운데 영상이 다루는 고객 순간을 정한다. CTA가 향하는 다음 경험과 영상의 약속이 맞는지 확인한다.
8. 관객 관련성·증거·기억할 장면·브랜드 일치·실행 가능성으로 후보를 비교한다. 선택 이유를 설명하되 성과가 검증됐다고 주장하지 않는다.
