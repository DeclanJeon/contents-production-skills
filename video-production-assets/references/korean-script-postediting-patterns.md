# 발화용 선택 패턴 KP01–KP08

[실행 절차](korean-script-postediting.md#workflow)의 국소 후편집에만 사용한다. 원본 ID는 출처 대응용이며 전수 규칙/코퍼스 성능을 이식했다는 뜻이 아니다. [고정 출처](upstream/im-not-ai-provenance.md)를 따른다.
빈도는 같은 화자·문맥에서 검토한다. 단일 출현·카운트 0·같은 어미 자체가 수정/무수정 근거는 아니다. 예시는 정답 치환 사전이 아니다.

| 패턴 | 원본 대응 | 발동·교정 | 대사 / 내레이션 예외 | 보존 반례와 예시 |
|---|---|---|---|---|
| KP01 번역투·피동 | A-3/A-7/A-8/A-9/A-19 | 불필요한 문어 번역투만 조사/단일 피동으로 | 관료적 말투 / 주체 미상 피동 보존 | “문이 열렸다” 주체 발명 금지. “해결되어졌다”→“해결됐다” |
| KP02 명사화·형식명사 | F-4/F-5/I-2/I-3 | 추상명사 연쇄가 이해를 막을 때 동사/형용사로 | 전문 인물 어휘 / 학술 정의·표준 용어 보존 | “정체성”을 단순화하지 않음. “확인이 필요한 상황입니다”→“확인이 필요합니다” |
| KP03 추상 주어·연결 | A-15/D-8/D-9 | 주체·관계가 입력에 분명할 때 표현 직결 | 책임 회피 전술 / 시적 화자의 관점 보존 | “시대가 묻는다”가 시적 의도면 유지. “필요한 것은 확인입니다”→“확인이 필요합니다” |
| KP04 상투 도입·결론 | D-1/D-2/D-3/D-6 | 실제 내용 없이 반복한 문패만 축약 | 상투 말버릇 / 교육 요약 기능 보존 | “시사하는 바가 크다”에 없는 결론 발명 금지. 불필요한 재요약이면 “정리하자면, 문을 닫았습니다”→“문을 닫았습니다” |
| KP05 접속·열거 | C-7/C-8/C-9/H-4 | 필요 없는 연결 반복만 최소 수정 | 공방/펀치라인 / 절차 순서·열거 보존 | 안전 절차 첫째/둘째 유지. “즉, 다시 말해, 문이 닫혔습니다”→“다시 말해, 문이 닫혔습니다” |
| KP06 어미·리듬 | E-2/E-7 | 같은 화자·관계의 무의미한 기계 반복일 때만 | 화자별 존대 / 공적 격식·리듬 유지 | “싫어. 싫어. 싫다고.” 보존. “기다리고 있습니다”→“기다리는 중입니다”도 시점·말투 대조 후만 |
| KP07 유보 중첩 | A-10/G-1/G-2/I-4 | 같은 가능성 중복인지 확인; 강도 보존, 불확실하면 유지 | 협상/회피 / 의학·법률·정책 유보 보존 | “보인다”→“이다” 금지. 같은 유보인 경우만 “그럴 가능성이 있을 수도 있어요”→“그럴 수도 있어요” 제안 |
| KP08 수식·호흡 | A-18/E-1/C-11 | 이해를 막는 긴 수식은 같은 단위 안에서 호흡 분리 | 끼어듦·쉼표 / 시적 장문·계획된 호흡 보존 | “너는, 정말…” 쉼표 자동 삭제 금지. “그는 문을 열고, 안으로 들어갔어요”→“그는 문을 열었어요. 그리고 안으로 들어갔어요”도 강세/호흡 대조 후만 |

100자 장문 삽입, 어미 의무 변주, 비유·대구·쉼표 일괄 제거는 강제하지 않는다. 구조를 다시 써야 하는 문제는 기존 오너로 반환한다. 교정 예시는 사실·시제·관계·서브텍스트를 직접 대조한 뒤 채택한다.
