# 씬 연출 도구함 — 공통 정본으로 연결

표정·몸짓·관계·샷·앵글·구도·빛·재질·환경·액션·편집의 조건부 레시피는 [공통 시각 연출·장면 전달](../../video-production-assets/references/visual-scene-communication.md)이 소유한다. 이 경로는 기존 참조 호환용이며 내용을 복제하지 않는다.

대사 유무와 무관한 표현 도구를 해당 씬의 목적에 맞게 필요한 절만 읽는다. 무성 작업의 발화/오디오/자막 제약은 `silent-visual-storytelling` 진입점에서 따로 보존한다. 공통 참조 사용이 새 원본 조사나 생성/렌더/게시를 승인하지 않는다.
