# FrameAtlas · Scene Frameworks

Original public-use field guide · CC0-1.0

## Start with a premise

Begin with a person, a place and a pressure. A flooded town where everyone repairs rather than replaces things is more useful than a list of visual adjectives.

Exercise: Write a sentence: In this place, people must ___ because ___.

## Set the rules

Choose constraints on technology, materials, weather and behavior. A rule is useful when it rules something out. Decide what cannot exist here, then test every new object against that boundary.

Exercise: List three things this world allows and three it rejects.

## Build a visual vocabulary

Collect your own material observations. Choose warm oxidized metal, pale cloth and cool daylight, for example. Define the light direction and a recurring shape before making many variations.

Exercise: Describe one room in materials, light and scale.

## Give people a purpose

Define what each figure does in the world. An exhausted courier carries different objects and moves differently from a patient archivist. Show those differences in action and wear.

Exercise: Give each recurring figure a task and a visible habit.

## Define rejection criteria

Write a short list of details that would weaken the project. This makes selection faster and helps a sequence stay coherent even when individual images are attractive.

Exercise: Reject an image if it breaks a rule or adds a competing visual idea.

## Make motion reveal something

Use movement when it changes what the audience knows. A slow retreat can reveal an empty room; a sideways move can uncover a hidden doorway. Motion needs a destination and a reason.

Exercise: For each move, name the information that becomes visible.

## Sequence the work

Build a few connected shots before expanding. Start with a wide geography, choose an action, show one meaningful detail and finish with a reaction. Reuse the same light and material rules.

Exercise: Make a four-shot scene before designing a whole film.
