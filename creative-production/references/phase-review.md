# 단계별 논스톱 검수

- **3단계 경계:** PRE(S00–G2)는 검수된 제작 지시, PROD(S08)는 검수한 실물 소스·채택 구간, POST(S09–S11)는 실제 출력본을 넘긴다. S12는 운영 피드백이다. 프리비즈와 제작용 참조를 혼동하지 않는다.
- **두 번의 검수 예산:** G2에서 대본↔콘티↔보드 세 쌍, 페르소나·표정·반응·속도·액션·대사·톤·소품·사운드를 각 컷의 must-show/must-hide와 대조한다. S08 제출 직전에는 실제 요청·참조만 보고 예상 시작/행동/끝을 기술한 뒤 보드와 대조한다. 입력 미준비는 회차가 아니다. 각각 첫 회에 전수 검사, 문제 없으면 즉시 통과. 관점별 결과는 단일 담당자가 사용자 제약 > 이야기 기능 > 취향 순으로 통합하고 수정한다. 2회차는 영향받은 부분만 확인한다. 마지막 검토본의 잔여 위험을 기록하고 3차 검수나 미검증 창작 수정 없이 진행한다. 권리/계약/권한 위반은 예외가 아니다. 테이크 채택은 재생성 승인이 아니다.
- **호스트 재개:** CineForge의 `review_pre_*` / `review_prompt_*` 요청은 사람이 아닌 제작 호스트가 처리한다. 요청에 연결된 실자료를 확인하고 evidence와 컷별 findings를 지정된 응답 경로에 기록한다. 동일 명령을 재개하고, 첫 회 수정 지시가 있으면 수정 후 재개한다. 테스트 mock은 의미 검수 증거가 아니다.
