# CineForge 단계 인계 가이드

이 문서는 팩 매니페스트의 해당 단계에 연결된다. 인계 패킷의 오너 진입점·참조 파일과 이 문서의 현재 단계만 읽는다. 작업 권한, 출력 형식, 완료 조건은 CineForge 패킷과 승인 기록을 따른다. 이 문서와 참조 연결은 렌더러 선택이나 실행·과금 승인이 아니다.

| 단계 | 작업 지침 | 컷 수정 조건이 있을 때 |
|---|---|---|
| S04_story | 비트·복선을 보강하고 대본과 `ssot/story.json`을 맞춘다. | 수정 대상 밖의 이야기 조건을 유지한다. |
| S05_character_world | 캐릭터 바이블, 연기·의상, 공간과 소품의 일관성을 보강한다. | 지정된 캐릭터·공간 앵커를 유지한다. |
| S06_storyboard | 패널·렌즈·동선과 컷 상태, 길이, 전환을 검증한다. | 수정 범위·보존 조건을 해당 컷과 인접 편집 경계에 연결한다. |
| S07_assets | 필요한 에셋·참조·프롬프트를 보강한다. 모델별 프롬프트 방언은 실행 직전에 적용한다. | 수정 대상과 보존할 참조 에셋을 구분한다. |
| S08_generation | 승인된 실행 경로에서만 컷 상태·타이밍과 실제 출력을 확인한다. | 기존 테이크를 먼저 비교하고 생성 결함 수정은 승인 범위에서만 검토한다. |
| S09_edit | 합성·믹싱·편집 상태와 전환을 확인한다. | 해당 구간만 최소 수정하고 보존할 요소를 기록한다. |
| S10_qa | 실제 출력으로 컷과 전편을 구분해 검사한다. | 수정 전후 버전·시간 기준, 재검수 및 미확인 결과를 기록한다. 부분 검사는 전편 검수가 아니다. |

조건별 전문 참조는 인계 패킷의 `craft_refs`를 따른다. 호스트가 작업을 더 구체화할 때는 [craft bridge](craft-bridge.csv)에서 현재 단계 및 해당 소재의 행만 골라 읽는다.
