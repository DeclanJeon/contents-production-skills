# Non-video execution and handoff contract

공통 오너는 이 파일이며 브랜드·카드·사진·웹·상품 페이지의 실제 실행/인계 때만 읽는다. 독립 작업은 `creative-production`을 호출하지 않는다. 현재 사용자의 요청 범위·기존 프로젝트·승인을 우선하고, 혼합 영상 프로젝트에서 명시적으로 위임받은 경우에만 해당 총괄의 ID/버전/수락 조건을 소비한다.

## Scope, storage and return

요청한 산출물만 만든다. 기존 선택 폴더를 재사용하고 없으면 사용자에게 이미 지정되거나 도구로 확인된 작업 위치를 사용한다. 제작 산출물을 스킬 소스에 저장하지 않는다. 실제 파일·프롬프트·입력/출력·해시·완료/실패/중단을 기존 프로젝트 기록에 남긴다. 기존 `project.json`/`.history`를 받은 경우 소유자에게 변경 제안만 반환하고 새 프로젝트 원장이나 승인 DB를 만들지 않는다. 단독 작업은 제공된 프로젝트가 없다는 이유로 영상 폴더/원장을 만들지 않는다. 브랜드 도메인의 `brandkit/state.json`은 기존 승인·변경 그래프를 유지한다.

인계는 요청된 산출물/버전, 사용한 입력과 버전, 실제 경로·검사 범위, 공급자 job/URL과 실제 파일의 대응, 변경 영향과 미해결 항목을 포함한다. 공급자 UUID/URL은 실제 에셋 ID가 아니다. 파일·링크가 생겼다는 사실과 품질·사용자 수락·상업 권리를 분리한다.

## Execution, rights and eligibility

텍스트/로컬 설계에 계정 확인·설치·업로드·과금을 추가하지 않는다. 실제 요청한 단계 직전에만 해당 도구·인증·현재 입력/출력 스키마를 확인한다. 누락 도구는 자동 설치하지 않는다. 기존 승인된 범위는 재사용하되 새로운 업로드·학습·생성·지출·배포/게시는 각각 필요한 권한이 있어야 한다. 범위/수량/재시도/현재 견적·비용 상한을 보존한다. 알 수 없는 제출 결과는 같은 job의 상태를 확인한 뒤 처리하며 재제출로 확인하지 않는다.

원본에서 유지한 제한: **Higgsfield 이미지 생성/편집 및 private image enhancer 실행은 이 팩에서도 제외**한다. 현재 설치된 `codex-imagen`이 기본 정지 이미지 실행자이며 지원·참조·출력 경로를 실제 계약에서 확인한다. 호스트의 명시적인 이미지 실행 어댑터가 있으면 그 호스트 규칙을 따른다. 다른 실행기를 원 backend와 같다고 표현하지 않는다. 모델명·프리셋·URL·구독은 현재 지원·권리·실행 허가가 아니다. 생성기 업로드·작품 내 사용·원본 재배포·AI 학습 권리는 각각 근거를 확인한다.

웹 작업은 현재 웹 전문 스킬의 편집·배포 경계를 유지한다. 파일 소유권·비밀정보·원본 보존과 실제 반환 형식도 유지한다. 배포·구독·결제·계정 변경은 이동/검증만으로 허가되지 않는다. 보지 않은 이미지·듣지 않은 음원·미실행 결과는 미검증이다.

Codex Imagen 정지 이미지에는 원본의 현재 정책대로 가격·사용량·쿼터/비용 승인 확인을 새 필수 조건으로 만들지 않는다. 실행자·인증·지원 입력/출력·자료 권리·요청 범위를 확인하고 별도 공급자의 실제 비용/실행 계약과 구별한다.
