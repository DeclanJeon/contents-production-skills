# 러프 화면 설계

status: draft
assumptions: 아래는 2D 설명 그림 제안이다. 용도·제품 사양·가격·성능·우열은 미확인. 기존 오너 역할은 유지하며 각본의 고정 발화를 변경하지 않는다.

기본 룩: 같은 크기의 가상 포장 A/B를 같은 높이·명암으로 병렬 배치. 색·광택·크기로 승자를 암시하지 않는다.
주요 대비 축: 첫인상 → 관찰 항목 → 방향을 바꾼 확인 → 판단 유보.

## 4비트 제안

| 비트 | 화면·인물 블로킹 | 언어·공개 정보 | 종료 프레임 |
|---|---|---|---|
| 1 | 설명자와 청자, 두 포장을 하나의 테두리 있는 그림 안에 둔다. | 고정 발화 그대로: **“비싸다고 늘 알맞은 건 아닙니다.”** 테두리에 ‘가정/예시·실제 구매/실험 아님’을 지속 표시. | A/B를 동등하게 제시. 어느 쪽이 비싼지는 지정하지 않음. |
| 2 | 포장의 개봉 위치·여닫는 구조·취급/보관 표시를 차례로 가리킨다. 시험·파손·내용물 보존 결과는 그리지 않는다. | 화면 문자는 관찰 질문만: ‘어디로 여나?’, ‘어떻게 여닫나?’, ‘사용하려는 조건과 표시가 맞나?’ 용도와 표시 내용은 미정. 추가 대사 없음. | 항목만 남고 적합 판정은 비워 둠. |
| 3 | 청자가 거꾸로 놓인 A의 가상 기호를 보고 생각풍선 ‘9?’에 손가락을 댄다. 같은 A를 직접 돌려 밑줄이 있는 ‘6’을 확인한다. B와 A의 식별점은 유지. | ‘방향 읽기용 예시 기호·가격/규격 아님’. 오독은 청자의 잠정 해석, 회전 후 확인은 그림 속 문자 판독에만 한정. | 청자가 ‘9?’를 지우고 올바른 방향의 표시를 다시 짚음. |
| 4 | 동일한 설명 틀의 A/B 병렬 화면으로 복귀. 회전한 A의 방향은 유지하고 승자 체크·구매 행동은 넣지 않는다. | ‘용도·표시 확인 후 판단 / 실제 적합성 미확인’. | 관찰 항목과 미확인 칸을 남김. |

## 검사 포인트

- **관찰:** 같은 물체를 돌리는 손·기호·방향 변화가 이어지는가? 표정만으로 깨달았다고 처리하지 않는다.
- **예시:** 비교 그림의 테두리·지위 표지가 삽입과 복귀에 유지되는가? 예시가 본편의 실제 구매·실험 이력으로 남지 않는가?
- **추정:** ‘9?’가 객관적 사양처럼 보이지 않는가? 문자 판독을 효능·적합성 확인으로 확대하지 않는가?
- **화면/언어 분담:** 화면은 관찰 행동, 발화는 가격과 적합성의 비동일성, 문자는 예시 지위·질문·한계를 담당한다. 발화의 일반 명제를 이 그림이 입증한다고 쓰지 않는다.

미확인 사항: 실제 용도·표시 내용·성능 근거, 작은 화면의 판독성·회전 동작의 실제 재생. 현재는 텍스트 제안만이며 시각 검증 미실시.
다음 단계 인계: 용도·표시 자료가 제공될 때 관찰 질문을 구체화하되 결론은 근거 범위 안에서만 작성.
