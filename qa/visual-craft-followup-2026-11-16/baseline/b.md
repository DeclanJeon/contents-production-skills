# 설명 영상 러프 화면 설계

status: draft
board_purpose: 러프 화면 검토용 — 촬영 실행 보드 아님
approval_status: 제안
assumptions: 배치·라벨·행동은 예시(inferred). 기존 담당·승인·근거 상태 유지.

**고정 발화:** “비싸다고 늘 알맞은 건 아닙니다.”

**기본 룩:** 같은 크기의 가상 포장 A·B를 같은 높이·거리·조명으로 둔다. 중립색·동일한 글자 크기. 가격표·순위색 없이 전 구간 ‘설명용 가상 예시 · 실제 구매/실험 아님’ 표시.

| 비트 | 화면·인물 블로킹 | 공개 정보·언어 분담 | 종료 프레임 |
|---|---|---|---|
| 1 | 두 샘플과 설명자·청자의 손을 함께 보여준다. 청자의 손은 아직 어느 쪽도 고르지 않는다. | 고정 발화를 그대로 한 번 말한다. 화면은 비교 대상만 제시하며 비싼 쪽을 지정하지 않는다. | A·B와 같은 크기 관계가 남는다. |
| 2 | 청자가 A의 비스듬한 측면 화살표를 보고 개봉부로 손을 옮기다 멈춘다. 포장과 손을 함께 유지한다. | 생각 자막 ‘개봉 방향?’은 **청자의 추정**. 라벨 전체는 아직 가려져 있다. 추가 대사는 없다. | 잘못 읽은 대상과 멈춘 손이 보인다. |
| 3 | 청자가 직접 A를 돌려 가려졌던 ‘보관 방향 ↑’ 전체를 읽고, 개봉부에서 손을 거둔다. 동일한 모서리·A 표식으로 같은 물체임을 연결한다. | 해당 문구는 **가상 라벨 예시**. 화면은 방향 변경→전체 확인→행동 수정의 인과를 맡는다. 생각 자막은 지운다. | 손가락이 실제로 드러난 라벨을 짚는다. |
| 4 | 회전한 A와 B를 다시 함께 둔다. 양쪽에 동일하게 ‘용도 표시 / 개봉 구조 / 재밀봉 구조·표시 / 주의사항’의 관찰 위치를 연결한다. | 문자 질문 ‘내 용도에 필요한 조건은?’으로 비교 기준만 남긴다. 승자·구매 선택은 제시하지 않는다. | 두 샘플 모두 선택되지 않은 상태. |

## 검사 포인트
- **관찰:** 보이는 글자·구조만 기술하며 밀폐력·내구성·적합성 입증과 구분한다.
- **예시:** 포장·라벨·오독·정정은 설명용 설정이며 실제 구매·시험 사건이 아니다.
- **추정:** ‘개봉 방향?’은 인물의 잠정 해석이다. 회전 후 손의 수정까지 보여줘 오독을 해소한다.
- **실패 시 수정:** 라벨이 안 읽히면 가림·방향·크기를 먼저 조정한다. 무음에서는 확인 행동, 음성 포함에서는 명제와 예시의 경계를 검사한다.

미확인 사항: 구체적 사용 목적·실제 제품 표시·가격·성능·우월성 근거 없음. 어느 쪽이 알맞은지는 미결정. 실제 이미지·시간 재생의 가독성은 미검증.
다음 단계 인계: 사용 목적·실제 표시 확보 후 항목 확정. 텍스트 제안만 완료.
