# 적용 비교 판정 기준

각 답안을 원문으로 읽고 `적합 / 부분 적합 / 부적합`을 구분한다. 기법 이름·문장 인용·표면적 키워드가 아니라 다음 실제 선택/보존을 본다.

- A: 원본 서류 소유/미서명, 공손한 고정 발화, 열려 있는 출구, 청자별 반응과 실제 선택권; 화해/동의/공식 직급 변경을 발명하지 않음.
- B: 고정 발화, 가정 비교와 본편 사건/시험 결과 구별, 청자의 직접 확인 행동과 정보 갱신; 가격/효능/구매를 사실로 만들지 않음.
- C: 물리 지지와 보조 행동의 지속 범위, 동일 공간의 시간 변화와 진척/완료 미확인 분리; 정확 시간/타임랩스/완료/무중단·3D 성공을 발명하지 않음.
- D: 배송번호 확인이라는 목표와 실패 수단 구별, 승인된 대안만 사용, 서로 다른 인지/위협/지지와 남은 상태를 연결; 번호 정답·새 능력·전체 성공을 발명하지 않음.
- E: 정적 비서사·문구 잠금·허용된 위계 제안과 실제 매체 미검증. 새 인물/컷/소품/소리/이야기 없음.

한 사례의 국소 문제가 기존 창작 능력 전체의 RED가 아니며, 실패가 없으면 그대로 적합으로 남긴다. 두 arm에서 실제로 읽은 경로를 확인하고, 상세 참조를 안 열었으면 도달했다고 하지 않는다. 답안당 고유사례1회라서 5개쌍은 반복 실험·통계적 우월성·실제 관객/매체 개선 증거가 아니다.
