# 시각 구조·아트 디렉션

status: draft — 화면 배치 제안
assumptions: 실제 도표 이미지·출력 규격·녹음은 제공되지 않았다. 두 도표와 수치는 사용자 승인본을 그대로 사용한다.

## 기본 룩
12초 내내 하나의 정적 화면을 유지한다. 왼쪽에 현재 사용량 도표, 오른쪽에 남은 용량 도표를 놓고 중간 여백으로 두 정보 묶음을 분리한다. 두 영역의 상단과 라벨 기준선을 맞춘다. 도표의 축·범례·비율·수치·색상은 바꾸지 않으며, 배치 때문에 한쪽 도표만 확대하거나 잘라내지 않는다.

각 도표 바로 위에 **‘현재 사용량’ / ‘남은 용량’**을 같은 크기와 굵기로 배치한다. 기존에 같은 제목이 있으면 중복 추가하지 않는다. 읽는 순서는 **항목명 → 해당 수치·단위 → 도표의 세부 정보**로 설계한다. 승인된 수치를 복제해 별도 대형 숫자로 만들지 않는다. 강조는 제목의 굵기와 주변 여백으로 해결한다. 배경은 차분한 단색으로 두고, 장식·입체 그림자·점멸·순차 등장·줌은 넣지 않는다.

## 주요 대비 축
두 항목은 우열이 아니라 역할 차이다. 동일한 시각적 무게를 주되, 위치와 명시적 라벨로 구별한다. 한쪽에만 경고색이나 굵은 테두리를 추가해 ‘문제’ 또는 ‘권장’이라는 의미를 만들지 않는다.

| 구분 | 맡길 정보 |
|---|---|
| 화면만으로 구별 | 왼쪽이 현재 사용량이고 오른쪽이 남은 용량이라는 대응, 각 도표의 승인된 수치·단위·범례. 색을 구별하지 못해도 라벨과 위치로 대응할 수 있게 한다. |
| 내레이션에 맡김 | 두 항목을 왼쪽부터 소개하는 설명 순서와 연결 문장. 「왼쪽은 현재 사용량, 오른쪽은 남은 용량입니다.」를 그대로 유지한다. 전체 문장을 화면에 다시 크게 쓰지는 않는다. |

## 미확인 사항
**지금 검토할 수 있는 것:** 배치 지시의 좌우 일치, 정보 위계의 명확성, 승인본 변경 금지 조건, 0–12초 단일 정적 화면이라는 계획, 인물·갈등·줄거리·추가 컷의 부재.

**실제 이미지·재생 없이는 확인할 수 없는 것:** 수치가 승인본과 실제로 일치하는지, 글자 크기·대비·잘림·도표의 판독성, 작은 화면에서의 식별, 실제 12초 길이, 발화 속도와 종료 시점. 현재 이를 통과했다고 판정하지 않는다.

## 다음 단계 인계
승인 도표 원본과 출력 크기를 확보한 뒤 실제 화면에서 무음으로 좌우 대응·가독성을 확인하고, 재생본으로 길이와 내레이션 종료 여유를 확인한다.
