# 공통 시각 연출 통합 — 범위와 검증

## 사용자 의도와 범위
사용자는 두 무성 관련 스킬에 한정하지 말고 스틸·샷·앵글·구도·인물 묘사·표정·액션 등 모든 전이 가능한 연출을 일반 작품에서도 배우도록 요청했다. 대사를 없애라는 명령이 아니라 대사가 있어도 각 씬의 시각층이 맡는 의도·감정·관계·정보를 전달하게 하라는 요청으로 적용한다. 이전 전체 전수 연구를 재시작하거나 추가 스킬/제작 스키마를 만드는 것은 범위 밖이다.

## 실제 근거
- 부모가 원본12개 JPG(6회차의 선택 연속 컷)를 직접 재확인: `visual-recheck.md`의 정확 경로/영역/관찰·해석·한계.
- 독립 문서 감사: `owner-gap-review.md`.13개 후보에서 기존 오너의 실제 절차/템플릿/QA와 대비. 감사자는 원본 픽셀을 직접 보지 않았으며 저장 기록 상속임을 명시했다.
- 핵심 공백은 craft 기초의 전면 부재가 아니라 무성 전용 참조에 있던 구체적인 조건부 표현 도구를 일반 오너에서 발견/선택할 수 없었던 연결이다.

## 선택한 구현
공통 정본 `video-production-assets/references/visual-scene-communication.md`에 기존 도구함을 옮기고 대사/소리의 독립 역할, 공개/감정/유보 의도, 스틸 순간 선택, 앵글/거리의 득실, 같은 구도의 액션 비교, 여러 몸/손/소품 소속, 물증으로 생략 전달, 서로 다른 반응의 병치를 보강했다. 기존02/03/04/05/06/07/08/09/12 및 두 조정자/콘티 오너가 해당 절만 조건부 사용한다. 무성 오너는 발화/오디오/자막 계약만 유지하며 옛 참조 경로는 호환 포인터다. 같은 거리 액션은 긴장감이 죽는다는 단정/2단계 스케일 점프 강제를 제거했다. 러프 패널의 동시 원인 노출·인체 표정·포어쇼트닝도 목적별 선택으로 정리했다.

역할별 실제 기존 필드를 재사용한다.12축 연구표·새 원장·고정 컷 수/초수·인체 큐 수·특정 감정의 보편 색/앵글을 강제하지 않는다. 일반 대사 작업을 무성 스킬로 보내거나 원본 캐릭터·샷 배열·절대 타이밍을 재현하지 않는다. 교재 인용/성과/관객 효과는 기존 한계를 유지한다.
