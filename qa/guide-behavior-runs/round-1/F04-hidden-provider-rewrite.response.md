**실제 제출문과 공급자 내부 변환문을 분리해서 기록하세요. `NOT_EXPOSED`는 숨겨진 변환문에만 적용합니다.**

기존 프롬프트 이력에 다음처럼 남기면 됩니다.

| 항목 | 기록할 내용 |
|---|---|
| 실제 요청문 스냅샷 | API에 보낸 **전체 본문 그대로** 보존. 변경분이나 요약만 남기지 않기 |
| 실행 설정 | 공급자·모델/버전, 실제 API 옵션, **자동 보정 ON**. 모르는 값은 `UNKNOWN` |
| 참조 연결 | 참조 ID·버전·해시 → 실제 업로드 슬롯/태그 → 가져올/제외할 속성·충돌 시 우선 기준 |
| 공급자 변환 후 본문 | `NOT_EXPOSED — 자동 보정 활성, 공급자 내부 변환문 비공개` |
| 버전 연결 | 요청문 스냅샷과 참조 역할표를 같은 실행 이력에 연결. 번역했다면 대응 검수문도 같은 버전으로 연결 |

**해시는 파일 식별 근거이지, 참조 내용의 검수 통과나 공급자가 지시를 준수했다는 증거는 아닙니다.** 실제 제출문·참조 연결 증거는 보존하되, 내부 변환 내용을 추정해 복원하거나 “최종 변환문 확인 완료”라고 기록하지 마세요. 새 원장이나 JSON 필드를 만들 필요도 없습니다.
