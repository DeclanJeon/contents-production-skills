## 세로 영상 검수 계획

**기준은 타임라인이 아니라 내보낸 파일이다.** 보고된 무음·손 잘림·결론 선공개를 납품 차단 항목으로 두고 검수한다. 실제 파일이 제공되지 않았으므로 현재 검사 상태는 모두 `unverified`다.

### 1. 검사 대상 고정
- 문제가 난 출력본과 수정본의 파일 ID·버전, 연결된 프로젝트·원본·자막·오디오를 기록한다.
- 목적지의 세로 규격, 오디오 의도, 자막 방식과 UI 가림 영역을 확인한다. 미확인 규격은 추정하지 않는다.

### 2. 증상별 검수

| 항목 | 검사 방법·원인 분리 | 수정 및 통과 기준 |
|---|---|---|
| **무음** | 출력 파일의 오디오 스트림 유무를 확인하고 직접 청취한다. 타임라인 트랙 mute·출력 버스 → 내보내기 오디오 포함 설정 → 재생기 음소거·출력 장치를 각각 구분한다. 다른 재생기로 교차 확인한다. | 확인된 원인만 수정한다. 수정 출력본 전체에서 의도한 대사·음악·효과가 들리고 누락·끊김이 없어야 통과한다. |
| **손 잘림** | 세로 출력에서 손이 등장하고 움직이며 대상과 접촉하는 구간을 재생하고 프레임 단위로 확인한다. 크롭·위치 이동·자막·목적지 UI의 가림을 구분한다. | 구간별 리프레이밍·축소 배치 등을 비교한다. 필요한 손동작과 접촉 관계가 유지되고 자막도 읽혀야 통과한다. 가로본이 있다면 별도로 검사한다. |
| **자막의 결론 선공개** | 원문·최종 실제 발화·자막을 나란히 놓고 **반응 시점, 결론 발화 시점, 자막 노출 시점**을 기록한다. 한 자막에 뒤의 결론까지 묶였는지도 확인한다. | 자막을 의미 단위로 나누고 최종 음성에 맞춰 재타이밍한다. 반응을 보기 전에 결론이 드러나지 않으면서 발화 동기·읽기 시간을 충족해야 통과한다. 내용 변경이 필요하면 승인받는다. |

근거: `video-production-assets/references/29-reference-driven-production.md` §R8, `video-production-assets/references/15-delivery.md` 「자막·출력 파일 재검수」.

### 3. 수정본 회귀 검수
- **새로 내보낸 파일 전체를 처음부터 끝까지** 시청·청취한다.
- 첫/끝, 중간 끊김, 오디오, 손·접촉, 자막 타이밍을 다시 확인한다.
- 실제 작은 화면과 목적지 UI 미리보기에서 자막·손 가림을 확인한다. 대표 프레임만으로 동기화 통과를 선언하지 않는다.
- 편집·인코딩 문제는 해당 설정과 구간부터 수정하며, 전체 미디어 재생성을 기본 해결책으로 삼지 않는다.

### 4. 기록·납품 판정
각 항목에 **파일/버전·타임코드·검사 방법·관측 결과·수정 내용·재검수 결과**를 남긴다. 상태는 `pass / fail / unverified / N/A`로 구분한다. 세 차단 항목이 해결되고 실제 출력 재검수가 끝나기 전에는 납품 완료로 처리하지 않는다.
