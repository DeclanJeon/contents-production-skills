## 한 단어 발음 교정 계획

**현재 상태:** “연기는 좋고 한 단어만 오발음”은 사용자 보고다. 직접 청취 전이므로 발음·연기·싱크는 `unverified`로 둔다. 깨끗한 승인 TTS 보이스를 우선 사용하며, 전체 영상 재생성이나 보이스 복제는 계획하지 않는다.

1. **교정 지점 확인**
   - 문제 단어·승인된 정확한 발음·원본 타임코드를 기록한다.
   - 실제 청취 시 앞뒤 숨·억양·감정과 보이는 입을 확인하고, 유지할 특성을 표시한다.

2. **최소 교체 범위 선택**
   - 자연스럽게 분리되면 단어만, 받침·연음·호흡이 이어지면 주변 어절이나 짧은 구절까지 교체한다.
   - 음절 하나를 무조건 잘라 붙이거나 문장 전체를 다시 만들지 않는다.

3. **승인 보이스로 교정 후보 준비**
   - 기존 문구와 보이스 정체성을 유지하고, 확인된 발음 제어만 사용한다.
   - 새 생성이 필요하면 기존 비용·시도 승인 범위 안에서만 진행한다. 보이스 보유를 생성 승인으로 간주하지 않는다.

4. **원본을 보존한 국소 접합**
   - 별도 트랙에서 자음·받침·들숨이 잘리지 않는 경계를 청취로 고른다.
   - 음량·밝기·잔향·룸톤을 맞춘다. 크로스페이드 길이는 실제 소리로 결정한다.
   - 길이가 맞지 않으면 무조건 압축하지 않고 짧은 구절 교체와 비교한다.

5. **같은 기준으로 재검수**
   - **교체 구절 → 앞뒤 문장 → 장면 전체 믹스 → 영상의 입·감정** 순서로 확인한다.
   - 성공 기준은 정확한 발음뿐 아니라 원래 인물이 같은 숨과 감정으로 이어 말하는지다.
   - 변경 음성에 종속된 자막·립싱크·타이밍만 재검토하고, 영향 없는 승인은 유지한다. 미청취 항목은 통과 처리하지 않는다.
