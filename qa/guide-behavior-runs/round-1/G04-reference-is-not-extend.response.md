아니요. **마지막 프레임 첨부 + “이어서”라는 요청은 실제 Extend 사용이 아닙니다.** 사이트가 일반 생성만 제공한다면 다음처럼 기록하세요.

- **생성 방식:** 새 생성 — 직전 영상 마지막 프레임 참조
- **요청문:** 실제 제출한 “이어서” 문구 그대로 보존
- **Extend 사용:** 아니요
- **후속 작업:** 원본과 편집 연결 예정(아직 연결하지 않았다면)
- **연속성 검수:** 미검수라면 `unverified`
