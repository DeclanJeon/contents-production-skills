## 텍스트 인계 — 참조 역할과 충돌 해결

실물은 제공되지 않았으므로 아래는 **사용자가 설명한 역할에 따른 인계**이며, 파일·버전·실제 내용은 미검증이다.

| 자료 | 가져올 속성 | 제외할 속성 | 충돌 시 기준 |
|---|---|---|---|
| **A 승인 얼굴** | 인물의 얼굴 정체성 | 별도 승인되지 않은 의상·배경·카메라 | **얼굴은 A**. B·D·E의 다른 얼굴로 대체하지 않는다. |
| **B 다른 얼굴의 의상** | 의상 디자인·색·재질·여밈·겹침 등 | B의 얼굴·신원·체격 | **의상 디자인은 B**. A의 인물에게 적용하며 B의 인물을 복제하지 않는다. |
| **C 옛 지도** | 기존 공간 관계·위치·경로 중 현재 승인된 항목 | 지도 문자·화살표·도형 색의 화면 전사, 폐기된 배치 | 오래됐다는 이유만으로 버리지도, 기존 지도라는 이유만으로 정본 취급하지도 않는다. **공간·소품 위치는 현재 승인 배치**로 확정한다. |
| **D 새 카메라 프리비즈** | 지정 카메라 위치·방향·경로·컷·타이밍 | 대역 얼굴·체형·임시 색·질감·음향 | **카메라는 승인된 D 명세**. ‘최신’만으로 승인 간주하지 않는다. 블로킹은 승인된 범위만 가져온다. |
| **E 직전 채택 클립** | 실제 채택 종료 시점의 자세·시선·소유·소품 손·의상 상태·진행 방향 | 완료 동작 재연, 불필요한 원본 소리, 우연한 생성 오류 | **다음 샷 시작 상태는 E의 채택 종료 상태**를 잇되, 승인 기준 위반은 먼저 해결한다. |

### 충돌 해결 지시
- **A ↔ B/D/E:** 얼굴은 A로 고정한다. E에 얼굴 오류가 있어도 정본으로 승격하지 않는다.
- **B ↔ E:** B는 의상 **디자인**, E는 직전의 **착용·젖음·손상 등 연속 상태**를 담당한다. E가 승인 디자인을 위반했다면 오류 수용 또는 수정 승인을 먼저 받는다.
- **C ↔ D:** 공간 배치와 카메라를 분리한다. 승인 배치를 유지하면서 D의 카메라를 적용한다. 카메라 때문에 소품 위치를 몰래 바꾸지 않는다.
- **D ↔ E:** 시작 자세·소유·진행 방향은 E, 이후 카메라는 승인된 D를 따른다. 연결이 불가능하면 조정안을 승인받기 전 **실행 보류**한다.
- 속성마다 우선 기준은 하나만 둔다. 미해결 충돌은 실행 blocker다. 실제 인계 시 파일·버전·슬롯을 연결하며, 현재 A–E는 자료 식별자이지 업로드 태그가 아니다.
