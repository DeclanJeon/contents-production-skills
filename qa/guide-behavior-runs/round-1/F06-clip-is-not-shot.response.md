아니요. **파일 수·샷 수·생성 시도(테이크)는 별개**로 기록하세요.

사용자 설명대로 세 컷이 있다면:

| 샷 ID | 내용 | 첫 번째 생성 결과 | 두 번째 생성 결과 |
|---|---|---|---|
| SH01 | 와이드 | 해당 파일의 원본 in/out | 해당 파일의 원본 in/out |
| SH02 | 손 인서트 | 해당 파일의 원본 in/out | 해당 파일의 원본 in/out |
| SH03 | 반응 클로즈업 | 해당 파일의 원본 in/out | 해당 파일의 원본 in/out |

- **샷은 3개**입니다. 파일 하나 안에 있다고 한 샷으로 합치지 않습니다.
- **별도 생성 두 번이면 생성 시도 2개**로 구분하고, 각각 같은 세 샷 ID에 연결합니다. 동일 결과를 두 번 다운로드한 것이라면 새 시도로 세지 않습니다.
- 테이크 표기를 쓰더라도 각 샷의 후보가 어느 생성 결과에서 왔는지 추적되게 하세요. 같은 입력이라고 같은 동작·타이밍으로 간주하지 않습니다.
- 실제 파일이 제공되지 않았으므로 정확한 컷 경계·채택 구간은 **미확인**입니다.
