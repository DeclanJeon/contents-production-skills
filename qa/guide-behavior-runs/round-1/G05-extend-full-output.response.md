### 편집에 넣는 방법
- 제공 설명상 **원본 8초+추가 6초가 포함된 14초 파일**이다. 기존 8초 뒤에 이 파일 전체를 붙여 **22초로 중복 연결하지 않는다.**
- 기존 8초를 확장 파일 전체로 교체하거나, 기존 8초를 유지하고 확장 파일의 **추가 부분인 소스 8–14초만** 이어 붙인다. 정확한 경계는 실제 프레임·타임스탬프로 확인한다.
- 원본은 보존하고 확장 결과는 새 테이크로 관리한다. 실제 파일 ID·버전, `source_in_s/source_out_s`, 시간 기준과 최종 타임라인 위치를 기록한다.  
근거: `video-production-assets/references/29-reference-driven-production.md` §R5·R7.

### 검사할 것
- **8초 접합부:** 정속 재생·프레임 단위·청취로 자세 초기화, 끝난 행동이나 대사 반복, 시선·진행 방향 역전 여부를 확인한다.
- **화면 연속성:** 인물 외형·크기·의상·소품을 든 손·위치·카메라·광원·배경이 갑자기 바뀌지 않는지 본다.
- **음향 연속성:** 대사 중복·절단, 환경음·음악·잔향·음량의 점프와 영상 싱크를 듣는다.
- **추가 6초와 편집 결과:** 필요한 후속 행동이 실제로 완결되는지, 다음 컷과 리듬이 맞는지 전체를 소리와 함께 재생한다. 원본 8초의 통과를 추가 구간의 자동 통과로 취급하지 않는다.  
근거: 같은 파일 §R5·R7; `video-production-assets/references/09-edit.md` §실행 가능한 편집·사운드 큐.

실제 파일은 제공되지 않았으므로 위 내용은 **편집·검수 계획**이다. 전체 클립·채택 구간·편집 후 판정은 각각 미검증으로 두며, 승인 사실과 실제 검사 완료를 구분한다.
