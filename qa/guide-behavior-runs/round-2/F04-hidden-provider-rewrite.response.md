**실제 보낸 요청문과 공급자 내부 변환문을 분리해 기록하세요.** 비공개인 내부 변환문만 `NOT_EXPOSED`로 남깁니다.

기존 프롬프트 이력에 다음처럼 보존하면 됩니다.

| 항목 | 기록 내용 |
|---|---|
| 실제 제출 요청문 | API에 보낸 **최종 전체 원문 스냅샷**. 변경분이나 요약만 남기지 않음 |
| 제출 옵션 | 자동 보정 `ON` 및 실제 전달한 설정값 |
| 참조 연결 | 보유 해시와 에셋 ID·버전, 실제 첨부 슬롯/태그의 대응 |
| 참조 역할 | 가져올 속성·제외할 속성·충돌 시 우선 기준 |
| 공급자 변환 후 본문 | `NOT_EXPOSED — 자동 보정 활성화, 공급자가 내부 변환문을 공개하지 않음` |

해시는 파일 식별 근거이지 **내용 검수나 SSOT 준수의 증거는 아닙니다.** 실제 요청문과 참조 연결을 보존하되, 숨겨진 변환문이나 모델의 실제 준수까지 확인했다고 기록하지 마세요.
