## 편집에 넣는 방법
제공 조건상 결과는 **원본 8초를 포함한 총 14초**다. 다음 중 하나로 넣는다.

- **전체 교체:** 기존 8초 클립 자리를 확장 결과의 0–14초로 교체한다.
- **추가분만 연결:** 기존 8초를 유지하고 확장 결과의 **8–14초만** 뒤에 붙인다. 실제 프레임 경계를 확인해 중복·누락 없이 연결한다.

**기존 8초 뒤에 결과 14초 전체를 붙이면 원본이 반복되므로 안 된다.** 원본은 보존하고 확장 결과는 별도 테이크·버전으로 관리한다.  
근거: `video-production-assets/references/29-reference-driven-production.md` §R5.

## 검사할 것
1. **8초 접합부:** 정속 재생·프레임 단위·청취로 자세 초기화, 완료 행동이나 대사 반복, 동작 끊김·진행 역전을 확인한다.
2. **시각 연속성:** 얼굴·크기·위치·시선·의상·소품을 든 손·카메라·광원·배경이 갑자기 바뀌지 않는지 본다.
3. **음향 연속성:** 대사 중복·잘림, 음량·환경음·음악·잔향의 점프와 화면 싱크를 듣는다.
4. **추가 6초와 편집 전체:** 필수 행동과 끝 상태가 완결되는지, 앞뒤 컷에 붙였을 때 리듬과 연속성이 유지되는지 전체를 소리와 함께 재생한다. 원본의 통과를 추가분의 자동 통과로 취급하지 않는다.

원본 파일·버전, `source_in_s/source_out_s`, FPS/PTS 등 시간 기준을 남기고 **전체 클립·채택 구간·편집 후 판정은 따로 기록**한다. 실제 파일을 보지 않은 현재 검수 결과는 `unverified`다.
