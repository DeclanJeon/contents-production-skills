## 텍스트 전용 인계 체크

미디어 생성·실행은 하지 않습니다. 아래는 **설계안**이며 실제 동작 검수는 모두 `unverified`입니다.

### 1. 기계 생물 → 수레 접근
- **구조:** 몸통과 관절의 연결, 지면 지지점, 유지할 부품·실루엣을 명시.
- **동선:** 수레·인물 대비 상대 크기, 접근 방향·경로·정지 지점, 관절 동작 범위와 인물 진입선을 분리.
- **접촉:** 접근만으로 충돌·밀기·공격을 추가하지 않음. 접촉이 필요하면 대상과 양쪽 응답을 별도 명시.
- **검사 예정:** 발 미끄러짐, 관통, 부품 분리, 불가능한 균형. 미제공 질량·관절 각도는 미정.

### 2. 인물 → 수레 탑승·이탈
- **비트:** 탑승 준비 → 지지점 확보 → 체중 이동 → 탑승 안정 → 수레 이동 → 인물과 함께 퇴장.
- **지지:** 탑승 위치, 발판·좌석 등 실제 하중 지지점, 필요한 손 접촉을 지정.
- **이동:** 출발 방향과 퇴장 경로를 고정하고, 이동 중 인물의 탑승 위치·수레 구조를 유지.
- **검사 예정:** 탑승 순간 관통·순간이동, 인물만 뒤처짐, 출발 전 지지 상실.
- 수레의 구동 주체는 확인 필요. 생물이 끈다고 임의 설정하지 않음. 정확한 무미끄럼 검사는 승인된 물리적 굴림 요구가 있을 때만 적용.

### 3. 광효과 → 등장·소멸
- **상태:** 발동 전 꺼짐 → 시작 → 지속 → 소멸 → 소멸 후 상태.
- **확인 필요:** 발동 원인·위치, 접근/탑승/출발 중 어느 시점에 켜지고 꺼지는지.
- **소멸 후:** 잔광·입자·표면 변화가 남는지, 원래 상태로 복귀하는지 명시. 빛이 사라져도 인물·수레가 사라지는 것은 아님.
- **레이어 메모:** 가림 순서, 필요한 조명·반사 변화, 소멸 시 함께 종료할 영향 기록.
