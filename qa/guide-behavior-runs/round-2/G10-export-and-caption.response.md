## 세로 영상 출력 검수 계획

**판정 대상은 타임라인이 아니라 내보낸 파일 자체다.** 제보된 무음·손 잘림·결론 선공개를 납품 차단 항목으로 등록한다. 현재 실제 파일은 제공되지 않았으므로 검사 상태는 모두 `unverified`다.

### 1. 검수 준비
- 문제 출력본과 수정본의 버전, 편집 프로젝트·원본·최종 음성·자막을 연결한다.
- 납품 목적지의 화면비·해상도·오디오 조건과 자막 모드를 확인한다. 미확인 규격은 임의로 정하지 않는다.

### 2. 증상별 진단 및 통과 기준

| 항목 | 검사·수정 순서 | 통과 기준 |
|---|---|---|
| **소리 없음** | 출력 파일의 오디오 스트림 유무 확인 → 타임라인 트랙·마스터 mute 확인 → 내보내기 오디오 포함·트랙 설정 확인 → 다른 재생기에서도 청취해 재생 환경 문제 분리 | 의도한 대사·음악·효과가 실제 출력에서 들리고, 전체 재생 중 누락·끊김이 없음 |
| **손 잘림** | 세로 출력 전체에서 손동작·물체 접촉 구간을 표시하고 동작 전후까지 확인. 원본과 비교해 크롭·위치 이동 원인을 구분. 리프레이밍이나 축소 배치로 수정하고, 필요하면 여백/배경 처리 검토 | 중요한 손동작과 접촉 관계가 보존되고 자막·목적지 UI에도 가리지 않음 |
| **결론 선공개 자막** | 원문·최종 발화·자막을 나란히 대조. 결론 자막 시작, 실제 발화, 인물 반응 시점을 기록. 긴 자막을 의미 단위로 나누고 해당 정보가 공개되는 시점에 맞춰 재배치 | 자막이 반응이나 의도된 정보 공개를 앞질러 결론을 누설하지 않으며, 발화 동기와 읽기 시간도 충족 |

원본 하드 자막이 있다면 실제 문구·타이밍·가독성부터 확인한다. 검사 없이 삭제·가림·대체를 확정하거나 새 자막을 겹치지 않는다.

### 3. 수정 출력 재검수
1. 먼저 문제 구간을 시험 출력해 세 증상을 재확인한다.
2. 최종 출력본은 **처음부터 끝까지 영상·소리를 함께 재생**한다. 첫/끝, 중간 끊김, 자막 동기, 작은 화면과 목적지 UI 가림을 확인한다.
3. 가로본도 납품한다면 별도 파일로 검사한다. 세로본 통과를 가로본에 대신 적용하지 않는다.
4. 편집·인코딩 문제는 해당 설정과 구간을 수정한다. 이를 이유로 전체 미디어를 재생성하지 않는다.

### 4. 기록과 완료 조건
`파일 버전 | 타임코드 | 증상 | 확인된 원인/가설 | 수정 내용 | 재검수 근거 | pass/fail/unverified`로 기록한다.

**세 차단 항목이 해소되고 최종 파일 전체 재생이 통과해야 납품 가능으로 판정한다.** 파일·도구가 없어 확인하지 못한 항목은 통과가 아니라 `unverified`로 남긴다. 사용자 수락·게시 승인은 별도다.
