아니요. **마지막 프레임 첨부와 ‘이어서’라는 요청만으로 Extend로 기록하면 안 됩니다.** 실제 사이트가 일반 생성만 제공한다면 다음처럼 기록하세요.

- **생성 방식:** 새 생성
- **참조:** 이전 영상 마지막 프레임
- **의도:** 직전 끝 상태를 이어가는 후속 클립
- **Extend:** 미사용 — 해당 기능 미지원
- **연결 방식:** 생성 후 편집 연결 예정(완료와 구분)

접합부의 자세·소품 손·진행 방향·광원·음향 연속성은 별도 검수하며, 확인 전에는 통과로 기록하지 않습니다.
