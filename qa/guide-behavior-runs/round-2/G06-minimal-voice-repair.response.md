## 한 단어 발음 교정 계획

**현재 상태:** “영상 연기는 좋고 한 단어만 오발음”은 **사용자 보고**로 기록한다. 승인된 깨끗한 TTS 보이스는 유지하되, 직접 청취 전이므로 발음·연기 연속성·싱크는 `unverified`다. 생성·편집은 실행하지 않는다.

1. **교정 지점 확정**  
   원문, 틀린 단어, 승인된 정확한 발음, 원본 타임코드를 확인한다. 직접 청취할 때 보존할 숨·억양·감정과 입이 보이는 구간도 표시한다. 정확한 발음이 미정이면 추측하지 않는다.

2. **최소 교체 범위 선택**  
   독립적으로 접합 가능하면 단어만, 받침·연음·호흡이 이어지면 주변 어절이나 짧은 구절까지 교체한다. 영상 전체나 문장 전체 재생성을 기본값으로 삼지 않는다.

3. **승인 보이스로 교정 후보 준비**  
   기존 보이스 정체성과 성공한 연기를 유지하고 발음 교정에 필요한 변수만 바꾼다. 실제 도구가 지원하는 발음 제어를 확인하며, 추가 생성은 별도 승인된 비용·시도 범위 안에서만 한다. 복제나 Voice Changer를 기본 해결책으로 쓰지 않는다.

4. **원본 보존·별도 트랙 접합**  
   자음 시작·받침 끝·들숨을 자르지 않는 경계를 청취로 찾는다. 음량·밝기·잔향·룸톤을 맞추고 크로스페이드는 실제 소리로 결정한다. 길이가 다르면 강제 압축보다 짧은 구절 재생성을 비교한다.

5. **같은 인물이 이어 말하는지 재검수**  
   **교체 구절 → 앞뒤 문장 → 장면 전체 믹스 → 영상의 입·감정** 순서로 확인한다. 혼합 원본이면 음악·노이즈 점프도 검사한다. 입 불일치가 남을 때만 해당 짧은 구간의 영상 수정 대안을 검토한다.

6. **영향 범위만 갱신**  
   기존 기록에 교정 텍스트·오디오 버전·교체 위치·실제 청취 범위를 연결한다. 변경 음성에 종속된 자막·립싱크·타이밍만 재검토하고, 무관한 영상 승인은 유지한다. 미청취 상태에서는 완료 판정을 하지 않는다.
