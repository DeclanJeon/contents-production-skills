## 텍스트 인계 — 참조 역할과 충돌 해결

실물 파일은 제공되지 않았으므로 아래는 **역할 지정안**이다. 파일·버전·실제 내용은 미검증이며, 업로드 슬롯/태그는 미배정이다.

| 자료 | 가져올 속성 | 제외할 속성 | 충돌 시 기준 |
|---|---|---|---|
| **A 승인 얼굴** | 승인 인물의 얼굴·정체성 | 지정되지 않은 의상·포즈·배경 | 얼굴은 **A 우선**. B·D·E의 다른 얼굴을 섞지 않는다. |
| **B 다른 얼굴의 의상** | 의상 구조·색·재질·여밈·겹침·신발 등 확인 가능한 의상 속성 | B의 얼굴·신원·체형·포즈·배경 | 의상은 **B 기준으로 지정**하되, A 인물에게 적용한다. B의 의상 승인 여부는 별도 확인한다. |
| **C 옛 지도** | 위치·경로·공간 관계의 기존 계획 | 화살표·문자·도형 색상, 오래됐다는 이유만으로 유지할 수 없는 배치 | **현재 승인 배치**가 우선. C가 현재 승인 배치인지 확인 전에는 잠정 참조다. |
| **D 새 카메라 프리비즈** | 제안된 카메라 위치·방향·경로·컷·타이밍 | 대역 얼굴·체형·임시 색상·질감·음향 | 카메라는 **승인된 카메라 명세** 우선. D는 새 자료라는 이유만으로 승인 기준이 되지 않는다. |
| **E 채택 직전 클립** | 채택된 실제 마지막 구간의 종료 자세·시선·위치·소품 소유/손·진행 방향·의상 상태 | 완료 동작 재연, 불필요한 원본 소리, 우연한 생성 오류 | 다음 샷 시작 상태의 기준. 단, A/B·승인 배치와 어긋난 오류는 자동 정본으로 승격하지 않는다. |

### 충돌 처리 지시
- **얼굴 A / 의상 B / 공간은 현재 승인 배치 / 카메라는 승인 명세 / 시작 상태는 E의 채택 끝**으로 속성별 기준을 하나씩 둔다.
- **C와 D 충돌:** 카메라 이동과 인물·소품 이동을 분리한다. 새 카메라 때문에 공간 배치를 임의로 바꾸지 않는다.
- **E와 승인 기준 충돌:** 오류를 수용할지 수정할지 먼저 승인받는다. 잘못된 끝을 그대로 이어 고착시키지 않는다.
- B의 의상 승인, C의 현행성, D의 카메라 승인 등 **미해결 충돌은 실행 blocker**로 남긴다.
- E 참조는 실제 Extend 사용을 뜻하지 않는다. 이번 인계는 텍스트만이며 생성·수정·확장을 실행하지 않는다.
