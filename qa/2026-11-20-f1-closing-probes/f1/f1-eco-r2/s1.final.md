# 4. 시놉시스

**로그라인** — 마감 직전의 동네 카페, 마지막 손님에게 온기를 건넨 바리스타가, 텅 빈 카운터로 돌아와 처음으로 자기 몫의 잔을 데운다.

**시놉시스** — 늦은 오후, 창가 테이블을 닦던 바리스타가 문 열리는 소리에 고개를 든다. 화면 밖 손이 카운터에 동전을 놓고, 바리스타의 시선이 붉고 굳은 손끝에 반 박자 머문다. 그는 말 대신 잔을 예열하고, 물줄기와 증기와 우유가 짧게 교차한다. 컵을 두 손으로 감싸 건네는 순간 손끝에서 온기가 옮겨가고, 손님이 나간 자리에는 컵 받침과 증기 자국만 남는다. 바리스타는 자기 잔을 꺼내 같은 방식으로 데우고, 창가에 앉아 두 손으로 감싼다. 어깨가 처음으로 내려가고, 증기 위로 해가 더 낮게 기운다.
