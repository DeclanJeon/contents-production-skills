## 0. 적용 전제 (모두 `inferred` — 아니면 알려줘)
- 1920×1080 / 30fps 가로 인터뷰, 원문=한국어 발화 / 아래 줄=영어 번역 (화자가 영어면 두 줄을 그대로 바꿔 적용)
- 납품은 하드 자막(burned-in) 기준, 별도 SRT를 낼 경우 내용·타이밍 정본은 15 납품 규칙을 따름
- 브랜드 폰트·컬러 미지정 → 아래 시작값 사용. 브랜드 값이 오면 그쪽이 항상 우선
- 읽기 속도·줄 수 상한은 목적지(플랫폼) 확정 전까지 `unverified` — 숫자를 상수로 굳히지 않음

## 1. 한영 이중 자막 — 룩 사양
**구조**: 한 쌍 = 원문 1줄 + 번역 1줄. 한 언어당 한 줄, 총 2줄 고정. 3줄·줄바꿈 중첩 금지.

**배치**
- 하단 15% 안전 영역 중앙 정렬, 좌우 5% 인셋 유지
- 어두운 패널 `rgba(14,18,16,.66)`, 반경 16px, 패널 안쪽 여백 12–16px
- 얼굴·입·턱·플랫폼 UI(구독 버튼, 진행 바)와 최소 5% 이격. 입 위 자막 금지 — 하단 3분의 1의 가슴 높이 아래로만

**타이포**
- 원문(한국어): 굵은 산세리프, 40px, `#FFFFFF`, 줄간 1.35, 자간 0. 활성 발화어만 `#FFD45C`
- 번역(영어): 같은 폭·같은 글꼴 계열, 원문의 약 70%(≈28px), 가는 이탤릭 세리프 또는 같은 산세리프, `#D9E6DC`, 줄간 1.3
- 글꼴은 한글·라틴 두 문자체계를 모두 덮는 1종(예: Pretendard / Noto Sans 계열). 혼용 시 대체 글꼴로 떨어지는지 반드시 실제 렌더로 확인
- 행당 약 42자 상한(한글은 42자, 영문은 같은 박스 폭 기준). 넘치면 문구를 줄이지 말고 절 경계에서 끊되 2줄 초과 금지

**움직임·타이밍 (시작값)**
- 쌍은 구절의 첫 단어에 **컷**으로 등장, 페이드는 150ms 초과 금지
- 원문 강조는 측정된 단어 타이밍을 따름(균등 분배 금지), 오차 ±3프레임
- 번역 줄은 원문보다 120–250ms 늦게 올라와 위 줄이 먼저 읽히게 함
- 쌍 교체는 구절 경계에서만, 2–3프레임 간격. 1초 넘는 침묵에서는 자막을 비움
- 영상 내내 같은 스타일 하나 — 스타일 2종 혼용 금지

**영어 줄 번역 규칙**
- 말한 것보다 더하지 않음. 용어집이 그대로 두기로 한 이름·제품명·직함은 번역하지 않음
- 문장부호는 번역 언어 관례대로, 고유명사 표기는 승인된 표기 고정
- 강조색은 1개만(`#FFD45C`). 색만으로 정보를 구분하지 않음(15 접근성)
- 대비는 실제 프레임 위에서 확인: 일반 텍스트 4.5:1, 큰 텍스트 3:1 기준 적용 여부를 명시

## 2. 로어서드 (이름·직함) — 디자인 규칙
**구조**: 2줄 고정 — 1줄 이름, 2줄 직함/소속. 이름·직함·성은 사용자가 준 철자·구두점 그대로. 지어내지 않고, 둘째 줄이 없으면 빼거나 사용자 문구를 씀. 카드(패널)는 텍스트와 별도 레이어.

**배치·크기 (1920×1080 시작값)**
- 좌하단, 모든 픽셀은 가장자리에서 5%(≈96px) 이상 안쪽
- 이름 50–80px, 직함은 그 절반(25–40px)
- 띠/패널 폭은 프레임 폭의 약 38% 이내, 중앙은 화자를 위해 비움
- 글자 뒤 패널·띠 또는 진한 그림자로 밝은/어두운 배경 모두에서 읽히게. 얇고 연한 글자를 사진에 직접 얹지 않음

**타이밍 (시작값)**
- 총 약 8초: 진입 300–400ms(1초 미만), 정지 유지 5–6초, 퇴장 0.5초
- 움직임은 진입·퇴장에만, 유지 구간은 정지(느린 광택 1개까지)
- 첫·마지막 프레임은 비워 편집에서 튀거나 잘리지 않게
- 무음 그래픽(오디오 없음)

**이중 언어 로어서드**
- 1줄: 한국어 이름(표기 고정), 2줄: 영어 표기 이름 + 직함/소속을 대상 언어로. 2줄 초과 금지
- 직함 번역이 불확실하면 원문 직함 유지 + `[직함 확인 필요]` 플레이스홀더. 추정 번역 금지

**자막과의 충돌 규칙**
- 로어서드가 떠 있는 동안 이중 자막 쌍은 로어서드 위로 이동(간격 최소 24px), 애니메이션은 동일하게
- 두 요소 동시 점유 높이가 프레임의 35%를 넘으면 자막을 비우거나 로어서드를 침묵 구간으로 이동
- 로어서드·자막 모두 얼굴·입·손·제품을 가리지 않음

## 3. 납품 형태
- 영상 내 자막: `caption_mode = burned_in`으로 명시하고 외부 자막 파일과 구분
- 로어서드를 알파 오버레이로 넘길 경우: OBS/스트림 WebM, 편집 툴(Pr·Resolve·FCP) ProRes 4444 `.mov`, 웹은 WebM + Safari용 HEVC 사본. 알파 없는 H.264 MP4는 바탕색 없이 내지 않음
- 목적지 미정이면 코덱·읽기 속도 규격은 `unverified`로 남김

## 4. 검수 체크 (렌더·스틸에서 확인)
- [ ] 1배속에서 모든 자막 쌍을 두 번 읽을 수 있는가
- [ ] 번역이 원문보다 더하지 않았는가 / 빠진 글리프(한글·라틴·구두점) 없는가
- [ ] 강조가 실제 발화 단어에 ±3프레임으로 맞는가
- [ ] 로어서드 가장 긴 이름·직함 카드의 정지 프레임이 밝은/어두운 배경에서 모두 읽히고 잘리지 않는가
- [ ] 사용한 글꼴이 실제로 로드됐는가(폴백 렌더 흔적 없음)
- [ ] 진입·퇴장 프레임별 시트에서 글자가 패널 밖으로 나오거나 먼저 나타나지 않는가
- [ ] 로어서드·자막·얼굴·UI 겹침이 없는가
- [ ] 알파 오버레이는 유지 구간 프레임을 디코딩해 알파가 실제로 있는가
- [ ] 자동 점검 결과만으로 통과 판정하지 않았는가(사람 눈 확인 별도)
