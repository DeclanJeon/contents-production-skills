## 1. 선택: **푸시인 타이포 (Push-In Type)** — 키네틱 타이포 계열

**왜 이 스타일인가**

| 판단 기준 | 이 스타일 |
|---|---|
| 용도 표기 | 원문 사용처가 "앱·SaaS 런칭 티저, 로고 오프너" — 요청과 정확히 일치 |
| 제품 증거 | 카메라가 z축으로만 전진 → **실제 앱 화면을 같은 축의 레이어로 통과**시킬 수 있음(키네틱 타이포 중 유일하게 제품 화면과 서사가 같은 운동을 씀) |
| 30초 지속 | 단발 푸시는 6–15초용 → **6블록 재진입 구조**로 쪼개 30초를 버팀(아래 비트맵) |
| 엔드카드 | 원문 종료 규격이 "로고·제품명·한 줄 약속" = 앱 런칭 종료 요건 그대로 |
| 브랜드 안전성 | 카메라 회전·틸트·바운스 금지 → 로고·UI 왜곡 위험이 구조적으로 낮음 |

**탈락시킨 대안 (주 스타일 교체는 1개만 가능)**

- **플랫 비트**: 컷당 1.5초 이하 → 30초에 20컷 이상, 피로 + 앱 화면 증거를 읽게 두기 어려움
- **매니페스토 팝**: 선언형(문제→제품)이라 기능 3개 시연과 충돌. **브랜드 성격이 선언적·캠페인형이면 이것으로 교체**
- **에코 스택 타이포**: 4–6단어 티저 전용, 30초에 부적합
- **셔터 밴드**: 카메라 축이 없어 앱 화면 증거가 약함 → 주 스타일 불가
- **스플릿 슬롯 / 셔터 밴드**: **부품으로만** 사용(각 1회 이내)

**부품 허용 한도**: 기능명이 병렬 구조일 때 슬롯 교체 1회(B4), 장면 전환은 셔터 밴드 없이 z 통과로만. 부품이 2개를 넘으면 "바쁘다" 결함으로 판정.

## 2. 모션 상수 (작품 전체 1개씩 고정)

| 항목 | 값 | 근거 |
|---|---|---|
| 모션 성격 | 키네틱 × **날카로움** (오버슈트 0%) | 앱 런칭은 정밀 기구 → 튕김 금지 |
| 등장 이징 | `cubic-bezier(0.16,1,0.3,1)` | 작품의 80% |
| 퇴장 이징 | `cubic-bezier(0.55,0,0.85,0.35)` (가속) | 등장보다 30–50% 짧게 |
| 카메라 예외 곡선 | 위 가속 곡선 재사용 (별도 3번째 곡선 만들지 않음) | 연속 카메라는 등장/퇴장과 축이 다름 — 예외 사유 명시 |
| 기본 시간 단위 | **0.4s = 12f** (큰 이동 24f, 미세 6f) | 모든 길이는 12f의 배수 |
| 스태거 | 글자 2f(67ms) / 레이어 3f(100ms) | 30fps 양자화 |
| 전환 계열 | **z 통과 + 겹침 진입만** (매치컷·와이프·페이드 금지) | 한 계열 |
| 이동량 | 스케일 60%→100%, 오버슈트 0%, 회전·틸트 0° | |
| 홀드 규율 | 히어로 정지 가독 ≥15f(0.5s) / 주장 줄 ≥36f(1.2s) / 엔드카드 ≥66f(2.2s) | |
| 빈 프레임 | 겹침 6f 고정, 전환부 빈 프레임 0 | |

## 3. 화면 구성 (16:9)

- **규격**: 1920×1080, 30fps, 900f. 안전 여백 상하 96px / 좌우 120px, 하단 120px는 자막·플랫폼 UI 회피
- **축**: 모든 타이포 레이어는 **화면 중앙 동일 축**. 보조 라벨은 레이어 내부 하단 1/4, 같은 x축
- **타입 스케일 3단**: 히어로 응축 굵은 대문자 180–240px(2–3단어) / 서포트 그로테스크 60–72px / 라벨 28–32px. 행간 0.92, 자간 −1~−2%
- **팔레트 (시작값, 브랜드킷 우선)**: 종이 `#F2EEE6` / 잉크 `#16161A` / 포인트 `#F0532B`(화면당 1개) / 통과 슬래시 `#F7C534`. 그레인 3–5%, 단색 배경
- **브랜드 색이 있을 때**: 포인트색만 1:1 교체, 바탕·잉크 비율 유지
- **앱 화면 규격**: 실제 캡처만 사용, 종횡비 유지·정면·기울임 0°, 표시 폭 ≥520px, **텍스트는 굽지 않고 라이브 텍스트로**
- **증거 카드 규칙**: 제품 화면 카드는 **블러 통과 금지** — z 유지 후 축소(0.5s)로 뒤로 물러남(읽는 중 블러 금지)
- **위계**: 히어로 → 서포트 → 텍스처. 위에서부터 움직이고 먼저 멈춤

**표준 90f 사이클 (B3–B5)**

```
 0–12f  진입 60%→100% (C1)           | 12–48f 정지 가독 36f
48–66f  보조 요소 3f 스태거            | 66–78f 카메라 통과 100%→800%, blur 6→12px
78–84f  다음 레이어 겹침 진입(6f)      | 84–90f 다음 레이어 정지 상태
```

**금지 (원문 규격)**: 레이어당 3단어 초과 · 카메라 회전/틸트 · 푸시 대신 컷 · 푸시 안의 작은 본문 · 읽는 중인 단어의 잔여 블러 · 화면당 포인트색 2개 · 장면마다 인용·통계 지어내기

**오디오**: 보이스오버 없음 기본. 음악·BPM 미공급 시 무음 유지(임의 펄스를 비트라고 부르지 않음). 음악이 오면 컷·통과 타이밍을 비트 ±2f로 재배치하고 로고 착지를 사운드 피크에 맞춤.

**결함 → 결정 (수정 지시문 형태로 기록)**
슬라이드쇼 같음 → 한 객체를 의미 있는 변형으로 운반 / 모두 경쟁 → 주 동작 정하고 보조 삭제·지연 / 무게 없음 → 이동 시간·가속 조정 / 텍스트 안 읽힘 → 홀드·대비 증가 / 밋밋함 → 타입 스케일·모티프 강화 / 바쁘지만 말 없음 → 장식 제거하고 인과 동작만

**한계 고지**: 이 문서는 계획 명세다. 렌더·재생 검수는 하지 않았고, 위 12개 항목은 실제 출력이 생겼을 때 판정한다.
