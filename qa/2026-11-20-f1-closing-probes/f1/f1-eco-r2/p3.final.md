## 0. 지금 막혀 있는 지점 (전사 없이는 후보표를 못 만든다)

레시피의 첫 규칙이 "프레임으로 말을 짐작하지 말고 단어 시간이 있는 전사를 쓰라"입니다. 그래서 후보 선정은 아래가 있어야 실행됩니다. 계획 자체는 지금 완성 가능하므로 대기 항목으로만 둡니다.

| 필요 입력 | 이유 | 없을 때 |
|---|---|---|
| 단어 타임스탬프 전사본 (호스트/편집기 기능) | 훅 줄 인용, 컷 in/out, 캡션 싱크 | 후보 시각 전부 `UNKNOWN` |
| 캠 A·캠 B 파일 + 별도 오디오 파일 | 동기 오프셋, 앵글 확인 | 멀티캠 컷 초안 불가 |
| fps·해상도·화자 이름·마이크 소유자 | 프레임 단위 컷·±1프레임 립싱크 검수 | 초 단위 제안만 가능 |
| 목표 편수·플랫폼(쇼츠/릴스)·금지 소재 | 안전 여백·길이 상한 | 시작값으로 `inferred` 처리 |

## 1. 인벤토리·동기 (편집 전, 30분 내)

1. 캠 A/B + 오디오 3개 파일의 길이·fps·해상도·시작 오프셋을 기록. **오프셋을 짐작하지 않는다.**
2. 전사 겹침으로 구조를 먼저 판별: 같은 말이 같은 시각에 있으면 별개 앵글 / 공유 발화 없이 시간만 이어지면 한 대가 재시작된 것.
3. **동기화된 마스터**와 **컷 초안**을 분리된 타임라인에 둔다. 중첩 멀티캠 객체를 만들지 않는다.
4. 각 앵글의 시작·중간·끝에서 립싱크 ±1프레임 확인. 오프셋이 흘러가면 조용한 타임스트레치로 덮지 말고 클럭 드리프트/프레임 드롭으로 보고.
5. 신뢰도 낮은 매칭은 숨기지 않고 목록으로 남긴다.

## 2. 후보표 (자르기 전에 표부터)

1시간 원본 → **후보 6~12개** (원본 5~10분당 1개 시작값). 강한 순간이 적으면 채우지 말고 적게 낸다. 할당량 아님.

**표 스키마**

| # | start–end | 앵글 | 훅 줄(전사 원문 인용) | 단독으로 서는 이유 | 점수(0–100) | 위험 |
|---|---|---|---|---|---|---|
| C01 | `[HH:MM:SS–HH:MM:SS]` | A/B/와이드 | "…" | … | 0 | 앞 맥락 필요 / 사적 인물 지칭 / 오디오 불명 |

**점수 시작값(합 100)**

| 항목 | 배점 | 판정 기준 |
|---|---|---|
| 훅 강도 | 30 | 첫 1~3초에 잡아끄는 문장인가 |
| 단독 이해도 | 25 | 원본 없이 이해되는가 |
| 결말 분명성 | 15 | 끊긴 엔딩이 아닌가 |
| 감정·대비 | 15 | 주장↔반론, 구체적 사례·숫자 |
| 편집 난이도 | 15 | 컷 수, 재프레이밍 리스크, 오디오 상태 |

**위험 신호는 점수와 별도 표기** — 앞 맥락 필요 / 목차식 요약 / 끊긴 엔딩 / 사적 인물 실명 / 오디오 불명. 위험은 감점이 아니라 사용자 판단 재료다.

## 3. 선택 게이트 (사용자 결정)

후보표를 보고 **직접 고른다.** 편집은 승인 후에만 시작하고, 첫 1편은 파일럿으로 먼저 끝낸다.

## 4. 숏츠 1편 편집 계획

**길이 시작값**: 20~75초. 요청 없이 90초 초과 금지. 총 숏츠 합계는 원본의 절반 이하.

**구성**
1. 훅 문장에서 시작 — 인용 그대로, 새 문장 창작 금지
2. 군말·긴 공백은 걷되 자연스러운 숨은 남긴다. 단어 중간 컷 금지
3. 끝은 분명한 문장에서 끊는다 (다음 화제로 넘어가기 전)

**멀티캠 컷 규칙(시작값)**

| 항목 | 값 |
|---|---|
| 화자 교체 컷 | 새 화자 발화 시작 후 4~8프레임 또는 숨에서 |
| 최소 샷 길이 | 1.5초 (반응 샷 예외) |
| 두 목소리 겹침 | 0.8초 초과 → 와이드 |
| 반응 샷 | 분당 2개 이하, 눈에 보이는 반응일 때만, 0.5~1초 |
| 긴 발언 끊기 | 20~40초마다 와이드 1회 |
| 금지 | 단어마다 컷, 펀치라인 가로채는 반응 샷 |

**9:16 재프레이밍** — 얼굴이 실제로 어디 있는지 확인한 뒤 결정. 시작값: 2인 → 위아래 스택 레이아웃. 대안(활성 화자 단일 크롭)을 쓰면 이동 거리·얼굴 크기를 근거로 적고 편차 이유를 남긴다. 중앙 크롭·말하는 사람 잘림·찌그러뜨림·레터박스 기본값 금지.

**캡션** — 전사 단어 시간에 맞춰 하단 3분의 1, 플랫폼 UI와 겹치지 않게. 자동 ASR 결과를 발화 시각 근거로 쓰지 않는다.

**사운드** — 팟캐스트 원본 오디오가 기준. 음악은 공급된 경우에만, 그리고 BPM이 주어졌을 때만 비트 그리드(박→프레임 환산) 적용. 없으면 비트 싱크 강제하지 않음. 음악이 대사를 덮지 않게 확인.

**컷 계획 표(편 당)**

| shot | source_in_s | source_out_s | playback_rate | 앵글 | 컷 이유 | 최종 start–end |
|---|---|---|---|---|---|---|

배속은 **샷당 상수 1개**. 한 샷 안에서 속도를 바꾸려면 같은 동작을 연속 행으로 분해하고 "곡선 적용"이라고 쓰지 않는다.

## 5. 배치

파일럿 1편 승인 → 같은 스타일(레이아웃·캡션 위치·컷 리듬)로 나머지를 같은 규칙으로 제작. 편당 검수 후 다음 편. 승인 전 일괄 제작 금지.

## 6. 검수 체크리스트 (실제 재생 전 판정 금지)

- [ ] 원본 없이 이해되는가 / 첫 줄이 훅인가
- [ ] 캡션이 발화와 일치하는가
- [ ] 크롭이 말하는 사람을 자르지 않는가
- [ ] 화자 교체 컷이 실제 활성 음성을 따르는가, 반응 샷에 근거가 있는가
- [ ] 와이드 사용 목적(겹침·웃음·오프닝·긴 발언)이 기록됐는가
- [ ] 립싱크 ±1프레임 (각 앵글 시작·중간·끝)
- [ ] 무음 재생 / 소리만 듣기 / 실시간 전체 재생 3종 확인
- [ ] 플랫폼 안전 여백·해상도·음량을 최종 파일에서 측정
- [ ] 제외한 후보마다 사유가 있는가

## 7. 이 계획에서 하지 않는 것

전사 없이 후보 시각 추정, 후보표 없이 편집 착수, 승인 전 일괄 제작, 오프셋 짐작·조용한 타임스트레치, 위치 확인 없는 중앙 크롭, 발화에 없는 문장·자막 창작, 근거 없는 가격·주장 삽입, 파일 생성, 게시.
