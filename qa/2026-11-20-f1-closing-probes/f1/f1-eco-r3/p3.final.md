## 적용 라우팅 (먼저 밝힘)

- **deliverable_kind**: 편집 계획 1건(선정 절차 + 후보표 + 컷 계획 양식) — 숏폼/롱폼 추출 = `09a 숏폼 편집 레시피`(계획 09-edit)
- **media_axis**: `text_only` — 파일 생성·렌더 금지(사용자 지시)
- **authority_axis**: 비어 있음 — 편집 실행/과금 승인 없음, 계획까지만
- **route**: `R13 one_production_asset` (owner: video-production-assets). R31(로컬 시퀀스 편집/익스포트)은 실제 편집 권한이 있을 때만이라 이번엔 아님.
- `cineforge route` 확인은 이 세션에 셸/실행 도구가 없어 **미실행**입니다(추측으로 대체하지 않음). 실행 환경에서 재확인 필요.

## 0) 입력 — 없으면 후보 시각을 만들 수 없음

| 입력 | 상태 | 이유 |
|---|---|---|
| 단어 타임코드 전사본(화자 구분·발화자 라벨) | **필수, 현재 없음** | 레시피 규칙: 전사 없이 프레임으로 말을 짐작하지 않는다. 후보 시각·훅 인용은 여기서만 나온다 |
| 카메라 2대 원본 + 별도 마이크 오디오 | 필수 | 멀티캠 동기화 기준 |

| 협찬·광고 구간, 사적 인물 언급, 외부 음악 사용 여부 | 미확인 | 후보 위험 표시용, 지어내지 않음 |

## 1) 선행 단계: 멀티캠 동기화 (편집 전)

1. 전사 겹침으로 구조를 먼저 판별: 같은 말이 같은 시각에 있으면 별개 앵글, 공유 발화 없이 시간만 이어지면 재시작 카메라 1대.
2. **동기화 마스터**와 **컷 초안 타임라인**을 분리(중첩 멀티캠 객체 만들지 않음), 카메라별 컬러를 컷 트랙에 표기.
3. 검수: 각 앵글의 시작·중간·끝에서 립싱크 ±1프레임. 신뢰도 낮은 매칭은 숨기지 말고 목록화. 오프셋이 흐르면 클럭 드리프트로 보고(조용한 타임 스트레치 금지).

## 2) 1단계: 쇼츠 후보표 (자르기 전 필수)

**후보표 열** — 전사에서만 채움:

| # | start–end | 훅 줄(전사 그대로 인용) | 단독으로 서는 이유 | 점수 0–100 | 위험 |
|---|---|---|---|---|---|
| S01 | `__:__.__–__:__.__` (전사 후) | | | | |

**점수 구성(합 100, 시작값 — 승인 시 조정)**
- 첫 1–3초 훅 강도 30 · 원본 없이 이해되는 자기완결성 25 · 감정·대비/구체적 예시·숫자 20 · 결말 분명도 15 · 두 화자 상호작용의 재미 10

**위험 플래그(점수와 별도로 반드시 기록)**: 앞 맥락 필요 / 사적 인물 지칭 / 오디오 불명확·겹침 / 협찬·가격·효능 주장(근거 필요) / 외부 음악·타인 발화.

**수량·길이 규칙**
- 후보는 원본 **5–10분당 약 1개** → 60분이면 대략 **6–12개**. 할당량이 아니며, 강한 순간이 적으면 채우지 않고 그렇게 보고.
- 선정 shorts 합계 길이는 원본의 **절반 이하**(≤30분).
- 한 편 길이 **20–75초** 시작값, 요청 없으면 90초 초과 금지.
- 강한 신호: 첫 1–3초 훅, 분명한 결말, 감정·대비, 구체적 예시·숫자. 약한 신호: 목차식 요약, 끊긴 엔딩, 맥락 의존.

**게이트**: 후보표를 사용자가 고른다. 이 선택 없이 편집을 시작하지 않는다.

## 3) 2단계: 선택된 1편의 편집 계획 (9:16)

**구도/재프레이밍**
- 2인 → 기본은 **상하 스택 레이아웃**(위·아래 화자), 얼굴이 실제로 어디 있는지 프레임 확인 후 확정. 얼굴 추적 단일 크롭은 1인 클로즈업 구간에만.
- 금지: 위치 확인 없는 중앙 크롭, 말하는 사람이 잘리는 크롭, 레터박스/찌그러뜨리기 기본값.
- 자막은 하단 1/3, 플랫폼 UI 영역 회피(규격은 목적지별 확인).

**컷 계획(대화 편집)**
- 훅 문장에서 시작. 군말·긴 공백은 걷되 **단어 중간 자르기 금지**, 자연스러운 숨은 남긴다.
- 새 화자가 말 시작한 뒤 **4–8프레임 또는 숨**에서 컷, 최소 샷 길이 **1.5초**(반응 샷만 예외).
- 두 목소리가 **0.8초 이상** 겹치면 와이드로. 반응 샷은 눈에 보이는 반응이 있을 때만 0.5–1초, **분당 2개 이하**. 긴 발언은 20–40초마다 와이드로 끊기.
- 금지: 단어마다 컷, 펀치라인을 가로채는 반응 샷, 하드컷 대신 디졸브로 나쁜 컷 가리기(기본은 하드컷, 전환은 동기 있을 때만).

**자막**
- 단어 타이밍 기반, 음성과 **±2프레임** 일치. 덩어리는 구절 경계에서만 교체.
- 스타일 1종을 파일럿에서 확정(클린형/팝형/마커형 중 택1, 강조색 1개). 얼굴 위 자막 금지.

**오디오/사운드**
- 원본 마이크 트랙 우선. 음악은 "제외/삽입"을 계획에 명시하고, 외부 음원은 **권리 상태(unknown/user_asserted/evidence_recorded/restricted)** 를 큐마다 기록. 음악이 대사를 덮지 않는지 확인.
- 라우드니스·해상도·자막 규격 최종 판정은 실제 파일 측정으로만(현재는 미검증).

**컷 표(09 편집 템플릿 축약 필드)**

| cut_id | source_in_s | source_out_s | playback_rate | final_start_s | final_end_s | 컷 이유·화자/앵글 | transition | sound_id·sync anchor | 검수 상태 |
|---|---|---|---|---|---|---|---|---|---|
| C01 | | | 1.0 | | | | hard_cut | | UNVERIFIED |

- 샷당 배속은 **상수 1개**(가변 램프는 인접 cut으로 분해), 원본 구간과 최종 구간을 별도 숫자 필드로 유지.
- 실제 타임라인·원본 접근 전에는 정밀 in/out을 추정하지 않고, 비어 있으면 비워 둔다.

## 4) 3단계: 파일럿 → 양산

1. 후보 1편만 완성해 **스타일 승인**(레이아웃·자막·컷 리듬·인트로 길이).
2. 승인된 스타일로 나머지를 배치. 승인 전 일괄 제작 금지.

---

## 5) 4단계: 편집 검수 (계획 ≠ 통과)

- 각 숏츠가 **원본 없이 이해되는가**, 첫 줄이 훅인가.
- 화자 교체 컷이 실제 음성을 따르는가, 와이드 사용 이유(겹침·웃음·오프닝·긴 발언 끊기)가 적혔는가.
- 크롭이 말하는 사람을 자르지 않는가, 캡션이 발화와 맞는가(±2프레임).
- 전체를 **소리 포함 1배속 재생**으로 확인. 표본 프레임만 봤으면 리듬·청취는 미검증으로 남긴다.
- 상태 표기 구분: 계획(draft) / 실제 파일 생성(generated) / 재생·측정 검수(verified) / 게시 승인(별개).
