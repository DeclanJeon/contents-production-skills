## 1. 왜 「플랫 비트」인가

| 후보 | 30초 16:9 앱 런칭 적합성 | 판정 |
|---|---|---|
| **플랫 비트** | 음악 비트가 컷 격자를 만들고, 컷마다 단색 배경 + 둥근 굵은 단어 하나 → 30초를 늘려도 지루해지지 않고 카피 교체만으로 수정됨. 끝을 워드마크로 정리 | **채택** |
| 푸시인 타이포 | 앱 런칭에 정확히 맞는 주제지만 설계 의도가 6–15초. 30초로 늘리면 “카메라가 멈추지 않는다”는 규칙이 오히려 부담 | 15초 컷다운용 예비 |
| 매니페스토 팝 | 선언문 톤 + 그라디언트·점 입자 → 앱의 “실제로 하는 일” 증거가 화면에 안 남음 | 제외 |
| 셔터 밴드 | 단어 3–6개 펀치 프로모. 기능 3개 설명에는 부적합 | 제외 |
| 스플릿 슬롯 | 마지막 단어만 교체하는 고정 문구용 → 기능 목록에는 좋지만 30초 전체 구조를 못 만듦 | 부분 차용 안 함(규칙 단순성 유지) |

**한 작품 = 하나의 문법.** 이징 계열 1개, 전환 계열 1개(비트 하드컷), 등장 패턴 3종만 사용한다.

## 2. 캔버스·타이포·팔레트 (시작값, `inferred`)

- 캔버스 **1920×1080 / 30fps / 30.000s = 900프레임**, Rec.709 SDR
- 음악 **120 BPM** → 1비트 = 0.5s = **15프레임**(정수), 1마디 = 2.0s = 60f, 30초 = 15마디 → 프레임 계산이 전부 정수로 떨어짐
- 안전 여백: 액션 세이프 5%(96px), **타입은 좌우상하 10%(192px) 안**. 하단 10%(108px)는 플랫폼 UI·자막 대비 비움(`inferred`: 유튜브/웹 임베드 기준)
- 활자: 둥근 굵은 산세리프. 한 컷 단어 **180–260px**, 두 줄 겹침 필요 시 **100–120px**, 행간 0.95. 대문자 강제 아님(한글 카피는 자간 −1~−2%)
- 팔레트(단색 배경 5): 크림 `#F7F1E8` · 코랄 `#FF5A5F` · 네이비 `#16213E` · 선 `#FFD166` · 청록 `#2EC4B6`
- 허용 조합만 사용(대비 ≥3:1 실측 기준): 크림↔네이비, 선 위 네이비, 코랄 위 네이비, 청록 위 네이비
- 금지: 그라디언트, 사진, 외곽선·그림자, 컷당 단어 3개 초과, 한 배경에 두 색, 폰트 3종

## 3. 화면 구성 규칙

1. **한 컷 = 한 아이디어.** 중앙 정렬, 짧은 줄 3줄 이하, 단어 1–3개. 문장 금지.
2. **시선 경쟁 요소 1개.** 배경은 무지, 소품은 최대 1개(플랫 도형), 움직이는 것은 한 번에 하나.
3. **제품 화면은 “플랫 카드”로만.** 실제 앱 캡처를 단색 배경 위 카드(최대 1200×760, 90% 안전 영역 내, 비율 유지 — 늘이기 금지)로. 캡처가 없으면 그 컷은 카피만으로 대체하고 빈 목업을 그리지 않는다.
4. **읽기 홀드 우선.** 어떤 장식도 0.5초 읽기 창을 침범하지 않는다. 텍스트가 안 읽히면 카피를 줄이거나 컷을 늘린다(폰트 축소 금지).
5. **모티프 1개 반복.** “컷마다 단어가 통째로 안착한다”를 필름 전체의 유일한 반복 장치로 삼는다.

## 5. 움직임 규칙 (한 계열만)

- **이징**: 도착 `cubic-bezier(0.16,1,0.3,1)` / 퇴장 `cubic-bezier(0.4,0,1,1)`. 세 번째 곡선 금지.
- **기본 시간 단위 0.5s(15f)**, 모든 길이는 배수(등장 0.3–0.4s 팝, 0.35s 카드 드롭).
- **등장 패턴 3종만**: ① 스케일 팝 0.94→1.00 (300–400ms) ② 글자 상승 팝(글자당 40ms 스태거, 컷 ≤0.6s) ③ 하드컷(모션 0). 한 컷에 하나만.
- **전환 = 비트 하드컷 단일.** 와이프·페이드·스핀·모션블러 혼용 금지. 빈 프레임 금지(다음 컷은 컷 프레임에 이미 올라와 있음).
- **에너지 지도**: 낮게 시작(A) → 문제 축적(B) → 피크(D) → 기능 구간 유지(E·F) → 정돈된 엔드카드(H). 피크는 하나만.
- **오버슈트**: 최대 2%, 프레임 전체 동시 이동 금지, 이동 중 텍스트 루프 금지.
- **모션 감소 대응**: 워드마크 정지 프레임을 최종 마크로 별도 확보.

**A. 지금(계획) 단계에서 가능한 검수**

| 항목 | 통과 기준 |

| 대비 | 지정 배경/글자 조합만, 대비 ≥3:1 |
| 포인트 억제 | 코랄 배경 컷 간격 ≥5s, 화면당 강조 요소 1개 |
| 안전 영역 | 모든 타입이 90%(1728×972) 안, 하단 108px 비움 |
| 증거 | 카피·기능·수치·날짜는 공급값만. 없는 지표·후기·스크린샷을 만들지 않음 |
| 제품 화면 | 캡처 비율 유지, 실제 화면 내용과 일치 |

**B. 렌더 후에만 가능한 실측(현재 `UNVERIFIED`)**

- 실제 출력 재생: 컷이 비트 ±2프레임인지, 이음매 ±5프레임에 빈/중복 프레임 없는지
- 프레임 정지 비교: 각 단어가 잘리지 않고 읽히는지(특히 한글 받침·영문 descender)
- `ffprobe`: 30.000s / 1920×1080 / 30fps / `color_primaries=bt709`
- 오디오: 계획한 시각(D1·H2)에 액센트가 실제로 나는지, 음악 대비 음성 레벨
- 밴딩·탁한 중간색 없음(그라디언트 없음 → 발생 시 결함)

**C. 즉시 반려(방향 결함)**
