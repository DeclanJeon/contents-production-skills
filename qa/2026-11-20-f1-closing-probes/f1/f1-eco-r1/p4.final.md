## 1. 오퍼 시트 (공급값 + 계산값)

| 항목 | 값 | 출처 |
|---|---|---|
| 정가 | 32,000원 | 공급 |
| 할인가 | 25,600원 | 공급 |
| 할인율 | **20%** | 계산 (6,400 ÷ 32,000) |
| 절약액 | **6,400원** | 계산 (32,000 − 25,600) |
| 행사 기간 | 12월 1일–7일 | 공급 (종료 시각 미지정) |
| 코드 | 없음 | 미공급 → 코드 비트 없음 |
| CTA(행동+목적지) | 없음 | 미공급 → CTA 비트 없음 |

계산 확인: 화면에 나갈 파생 수치는 **20% / 6,400원 / 25,600원** 셋뿐이며 모두 위 두 입력에서만 나옵니다. 할인 입력은 하나(할인가)만 사용했습니다.

## 2. 각도 선택

- A. **가격 직격** — "20% 할인, 12월 1–7일"만 말한다. 제품 주장 입력이 필요 없음 → **채택**
- B. 상황·문제형(겨울 외출 등) — 제품 특장점·사용 장면 주장 입력이 있어야 성립, 현재 미공급
- C. 마감 압박형 — 게시 시점 기준 남은 일수를 계산해야 하고 게시일이 정해져야 참이 됨

A로 갑니다. 한 오퍼에 영상 하나.

## 3. 구성 — 15.0초 / 1080×1920

전제: **제품 사진 1장이 0–15초 내내 같은 세계로 유지**(컷 없음), 움직이는 것은 오버레이·카메라 푸시뿐. 사진은 하단 1/3이 비어 있고 제품 윤곽이 잘리지 않는 컷을 고릅니다.

| 시간 | 비트 | 화면 | 화면 문구 (강조어 1개) | 모션·타이밍 |
|---|---|---|---|---|
| 0.0–2.0 | 훅(행사) | 제품 사진 풀블리드 + 대각 세일 테이프 | `[브랜드명] 텀블러 세일` (강조: **세일**) | 250ms 테이프 슬라이드 인, 카메라 100→104% 느린 푸시 |
| 2.0–5.0 | 할인 | 사진 위 도는 원형 배지 + 테이프 강조 | `20% 할인` (강조: **20%**) | 배지 400ms 회전 안착, 350ms 오버슈트 후 정지 |
| 5.0–9.5 | 가격 | 하단 빈 영역 가격 블록 | `32,000원` → `25,600원` (강조: **25,600원**) | 정가에 300ms 줄 긋기 → 0.4초 뒤 할인가 250ms 안착, 0.5초 정지 |
| 9.5–11.8 | 확인 | 작은 칩 1개 | `6,400원 절약` (강조: **6,400원**) | 300ms 페이드 업, 배지 유지 |
| 11.8–13.6 | 기간(마감) | 점선 테두리 칩, 화면 하단 1/3 위쪽 | `12월 1일–7일` (강조: **12월 7일**) | 250ms 슬라이드 인 후 완전 정지 |
| 13.6–15.0 | 클로징 홀드 | 사진 풀샷 유지(로고 없으면 브랜드명 텍스트) | `[브랜드명] · 12월 1–7일` | 움직임 0, 1.4초 홀드 |

비트 간격은 2–3.5초로 유지(광고 스크립트 시작값 2–5초), 카메라 푸시는 15초 전체에 한 번만 걸어 끊김 없이 이어 붙입니다.

**레이아웃 안전 영역**: 문구는 상단 8%·하단 25%를 비우고, 하단 1/3은 사진 여백으로 남김. 가격·기간은 최소 40px 이상, 배지 안 숫자는 세로 중앙 정렬. 이징 계열은 하나(ease-out)만 사용.

**소리**: 기본 무음. 음악을 얹을 경우 라이선스 확인분만, 2.0초 할인 비트에 강한 타격 1회. 박 정렬은 BPM 실측 후에만 확정(현재 미검증).

**후보 문구 대안** (한 줄에 강조어 하나 원칙 유지): `겨울 세일, 텀블러 20%` / `12월 1–7일, 20% 할인` — 첫 2초 훅은 "왜 봐야 하는지"를 말하는 쪽을 씁니다.

## 4. 검수 항목 (정지 프레임 기준)

1. 0.5/2/5/9.5/12/15초 정지 프레임에서 숫자가 계산값과 일치하는가 (20% / 25,600원 / 6,400원)
2. 정가보다 할인가가 낮은가, 정가 줄긋기가 할인가와 겹치지 않는가
3. 기간 표기가 공급값(12월 1–7일) 그대로인가, 시간대·종료 시각을 임의로 만들지 않았는가
4. 문구가 안전 영역 안에서 잘리지 않고 1배속에서 읽히는가
5. 없는 코드·CTA·제품 주장이 화면에 없는가
6. 마지막 1.4초가 완전 정지 상태인가
