## 1. 작업 순서

**S1 — 인제스트·멀티캠 동기화 (편집보다 먼저)**
1. 캠 A/B + 마스터 오디오를 한 세션으로 묶는다.
2. 두 캠의 관계를 **전사 겹침으로 먼저 판별**한다: 같은 말이 같은 시각에 있으면 별개 앵글, 공유 발화 없이 시간만 이어지면 재시작된 카메라.
3. 오프셋을 짐작하지 않는다. 조용한 타임 스트레치로 맞추지 않고, 흐르면 클럭 드리프트·프레임 드롭으로 보고한다.
4. 동기화된 마스터와 컷 초안을 **별도 타임라인**으로 두고 중첩 멀티캠 객체는 만들지 않는다.
5. 검수: 각 앵글의 시작·중간·끝에서 립싱크 ±1프레임. 낮은 신뢰도 매칭은 숨기지 않고 목록으로 남긴다.

**S2 — 후보표 작성(자르기 전에 표부터)**
- 후보 개수 시작값: 원본 5–10분당 1개 → 1시간이면 대략 6–12개 후보, 그중 실제 제작은 3–5편. **할당량 아님** — 강한 순간이 적으면 채우지 않고 그렇게 보고.
- 숏츠 합계 길이 상한: 원본의 절반 이하.
- 회차 길이 시작값: 20–75초, 요청 없으면 90초 초과 금지.

**S3 — 사용자 선택** (후보는 사용자가 고른다. 에이전트가 임의 확정하지 않음)

**S4 — 파일럿 1편**을 끝까지 설계·완성해 스타일 승인을 받은 뒤, 같은 스타일로 나머지를 배치한다. 승인 전 일괄 제작 금지.

**S5 — 배치 + 검수·납품** (§7, §8)

## 2. 후보표 필드

| 컬럼 | 내용 |
|---|---|
| 후보 ID | C01… |
| 시작–끝 | 원본 타임코드(초 또는 프레임) |
| 훅 줄 | 전사에서 **그대로 인용**한 첫 문장 |
| 단독 성립 이유 | 원본 없이 왜 이해되는가 |
| 점수 | 0–100 (§3) |
| 위험 | 앞 맥락 필요 / 사적 인물 지칭 / 불명확 오디오 / 화자 겹침 심함 |
| 사용 앵글 | A컷 중심·B컷 중심·와이드 혼합 |

## 3. 점수 규칙 (시작값)

- **가점**: 첫 1–3초에 훅이 실제로 있는가, 분명한 결말, 감정·대비, 구체적 예시나 숫자.
- **감점**: 앞 맥락이 없으면 이해 불가, 목차식 요약("첫째… 둘째…"), 끊긴 엔딩, 한 문장이 두 화자에게 걸침.
- 대화 상호작용(받아치기·웃음·반박)은 2인 팟캐스트의 강점이므로 "두 사람이 모두 필요해서 성립"하는 후보를 별도 표시.

## 4. 2인·2캠 컷 설계 (시작값)

- 한 화자 발언은 그 사람 클로즈업, 겹침·웃음·오프닝은 와이드.
- 반응 샷은 듣는 사람 클로즈업 0.5–1초, **보이는 반응이 있을 때만**, 분당 2개 이하.
- 화자 교체 컷은 새 화자가 말하기 시작한 뒤 4–8프레임 또는 숨에서. 최소 샷 1.5초(반응만 예외).
- 두 목소리가 0.8초 넘게 겹치면 와이드로.
- 긴 발언은 20–40초마다 와이드로 끊는다.
- 훅 문장부터 시작하고 군말·긴 공백은 걷되 **단어 중간은 자르지 않고** 자연스러운 숨은 남긴다.
- 배속을 쓰면 한 샷 안에서 상수 `playback_rate` 하나, 원본 구간과 최종 구간을 따로 기록.
- J/L컷은 프레임 수로 적고, 시각 컷과 소리 시작을 따로 기록. 하드컷 기본, 전환은 동기가 있을 때만.

## 5. 9:16 재프레이밍

- 크롭 전에 **얼굴·화면 내용의 실제 위치를 확인**한다. 위치 확인 없는 중앙 크롭 금지.
- 2인 기준 시작값: 위아래로 쌓은 레이아웃(화자 강조 시 해당 칸만 확대). 인물이 프레임 가장자리에 있으면 추적 크롭.
- 말하는 사람이 잘리는 크롭 금지. 확대 시 머리 여백이 카메라별로 달라지므로 앵글 A/B 크롭 값을 각각 잡는다.
- 자막은 단어 시간에 맞춰 하단 1/3, 플랫폼 UI와 겹치지 않게.

## 6. 오디오·자막

- 마스터 오디오 기준, 캠 오디오는 동기 참조용. 발화 구간 편집 후 **소리 포함 / 무음 / 화면 없이 듣기** 3종으로 검수.
- 자동 캡션은 음성 큐 근거가 아니다. 단어 시간 전사를 기준으로 캡션을 맞춘다.
- 음악을 넣을 경우 권리 상태를 `unknown/user_asserted/evidence_recorded/restricted`로 기록하고, 미확인 음원은 게시 가능으로 표시하지 않는다.
- 최종 음량·해상도·여백은 목적지 규격을 확인해 실제 파일에서 측정.

## 7. 검수 체크리스트

1. 각 숏츠가 원본 없이 이해되는가
2. 첫 줄이 실제 훅인가(인용이 전사와 일치하는가)
3. 캡션이 발화 타이밍과 맞는가, 플랫폼 UI와 안 겹치는가
4. 크롭이 말하는 사람을 자르지 않는가
5. 화자 교체 컷이 활성 음성을 따르는가, 반응 샷에 보이는 반응이 있는가
6. 와이드가 적어 둔 목적(겹침·웃음·오프닝·긴 발언 끊기)에 맞는가
7. 계획 컷과 실측 컷 길이 대조, 전환 경계 프레임 확인
8. 전체 실시간 재생(소리 포함) 후 판정 — 표본 프레임만으로 통과 판정하지 않음

## 8. 게이트

- 이 계획서만으로는 렌더·내보내기·게시가 열리지 않습니다. 실제 편집/출력은 편집 실행자·출력 규격 확인과 승인 후 `R31`로, 게시는 별도 승인입니다.
- 게스트 얼굴·목소리 사용 범위와 사적 인물 지칭이 포함된 후보는 그 자체로 게시 승인이 아닙니다.
