# 1. 확정 스타일 — "다크 패널 이중 자막 + 좌하단 로어서드"

비교안을 늘어놓지 않고 한 조합으로 확정한다. 아래 값은 **시작값**이며, 승인된 브랜드 폰트·화면비·안전 영역이 있으면 그쪽이 우선한다.

## 2. 이중 자막 (원문 = 한국어 / 번역 = 영어)

**구조**: 언어당 한 줄, 총 2줄 고정. 3줄 금지.

| 항목 | 규칙 |
|---|---|
| 패널 | `rgba(14,18,16,0.66)`, 반경 16px, 하단 15% 안전 영역 중앙 |
| 원문(한국어) | 굵은 산세리프, `#FFFFFF`, 1080p 기준 약 46–52px 가정값(패널 폭 기준 자동 축소) |
| 원문 강조 | 실제 발화 중인 단어만 `#FFD45C` |
| 번역(영어) | 같은 폰트 패밀리의 가는 이탤릭 세리프 또는 같은 산세리프, 원문의 약 70% 크기, `#D9E6DC` |
| 줄 길이 | 언어당 약 42자 — 넘으면 의미 단위에서 끊고 3줄로 만들지 않는다 |
| 폰트 | 한글+라틴 글리프를 모두 가진 패밀리 하나. 렌더로 글리프 누락 확인 전에는 확정 아님 |
| 대비 목표 | 패널 위 일반 텍스트 4.5:1, 큰 텍스트 3:1 (WCAG 2.2 SC 1.4.3). 실제 프레임에서 측정 |

**타이밍**
- 쌍은 구절 첫 단어에 **컷**으로 등장. 페이드는 150ms 이하.
- 원문 강조는 측정된 단어 타이밍을 따르고 균등 분배하지 않는다(±3프레임 허용).
- 영어 줄은 원문보다 **120–250ms 늦게** 올려 위 줄이 먼저 읽히게 한다.
- 쌍 교체는 구절 경계에서만, 2–3프레임 간격을 두고 넘긴다.
- 1초 넘는 침묵에서는 자막을 비운다.
- 읽기 기준: 1배속에서 각 쌍을 두 번 읽을 수 있어야 한다. 초당 글자수 같은 상수를 발명하지 않고 이 검사로 판정.

**내용 규칙**
- 말한 것보다 번역이 더하지 않는다. 추임새를 의미 있는 문장으로 승격하지 않는다.
- 인명·직함·고유명사는 용어집이 지정한 표기를 유지(번역하지 않음).
- 화자 표기는 색만으로 구분하지 않는다(SC 1.4.1) — 화자가 바뀌는 첫 쌍에만 이름 텍스트를 붙인다.
- `[웃음]`, `[박수]` 같은 비음성 소리 표기는 자막 정본(`15`) 규칙을 따르며, 대사 번역만으로 완전 captions라 주장하지 않는다(SC 1.2.2).
- `caption_mode`: 하드 자막(burned_in)이면 SRT 사이드카를 별도 생성해 검수·재편집 근거로 남긴다.

## 3. 로어서드 (이름·직함)

**내용**
- 철자·구두점·띄어쓰기는 **사용자가 준 그대로**. 대소문자 변환은 스타일로만 처리.
- 직함·소속·성을 지어내지 않는다. 둘째 줄 정보가 없으면 사용자가 준 표현을 쓰거나 아예 뺀다.
- 등장인물이 여러 명이면 카드마다 같은 디자인, 별도 파일.

**룩 (1080p 기준 시작값)**
- 이름 약 50–80px 굵은 산세리프, 흰색. 직함은 이름의 절반 크기, `#D9E6DC`.
- 글자 뒤에 패널·띠 또는 진한 그림자 — 어떤 배경에서도 읽히게. 얇고 연한 글자를 사진에 직접 얹지 않는다.
- 좌하단, 프레임 가장자리에서 5% 이상 안쪽. 얼굴·입·손·제품을 가리지 않는다.
- 화면 중앙은 비워 둔다. 카드가 덮는 면적은 프레임의 몇 퍼센트 수준.
- 숫자가 들어가는 카드(연차, 회차, 성구 등)는 라이닝 숫자 폰트로 바꾸고 스틸로 확인.

**타이밍**
- 약 8초: 진입 1초 미만, 정지 유지 5–6초, 퇴장 0.5초.
- 움직임은 진입·퇴장에만. 유지 구간은 정지(느린 광택 하나까지 허용).
- 첫·마지막 프레임은 비워 편집에서 튀거나 잘리지 않게 한다.
- 재등장 시에는 짧게(3–4초 시작값) — 같은 카드를 매번 8초씩 반복하지 않는다.

**납품 형식**
- 알파 채널 별도 파일. 편집 목적지가 ProRes 4444 / WebM / HEVC / 초록 배경 MP4 중 무엇인지는 **목적지 확인 후** 결정하며, 미지정 상태로 ProRes를 기본 계획하지 않는다.
- 알파 없는 H.264 MP4를 배경색 없이 넘기지 않는다.

## 4. 두 요소가 겹칠 때

인터뷰에서 가장 흔한 사고 지점이므로 규칙을 고정한다.

- **세로 스택**: 로어서드 유지 구간에는 자막 블록을 로어서드 높이만큼 위로 올린다. 두 요소 사이 최소 간격은 1080p에서 24px(화면 높이 약 2%).
- **동시 진입 금지**: 로어서드 진입은 자막 쌍이 없는 프레임에 landing한다(자막 교체 2–3프레임 간격을 피해서 배치).
- 우선순위: 자막 > 로어서드. 자막이 목적지 UI 안전 영역을 침범할 상황이면 로어서드를 먼저 접거나 옮긴다.
- 세로(9:16) 리프레임 시: 자막은 하단 안전 영역, 로어서드는 상단 좌측 또는 얼굴 반대편으로 이동. 같은 좌표를 재사용하지 않는다.

## 5. 하지 말 것

- 얼굴·입 위에 자막 또는 로어서드 배치
- 강조색 2개 이상 동시 사용
- 구절 중간에서 자막 덩어리 교체, 구절보다 오래 남는 번역
- 용어집이 유지하기로 한 이름·용어의 임의 번역
- 폴백 폰트로 렌더된 카드, 넘치거나 잘린 긴 이름, 얇은 글자를 사진에 직접 얹기
- 로어서드에 없는 직함·경력 만들기

## 6. 검수 체크리스트 (실제 출력에서)

1. 모든 쌍을 1배속에서 두 번 읽을 수 있는가
2. 강조가 실제 발화 단어와 ±3프레임 내인가
3. 한글·라틴 글리프 누락이 없는가(렌더 프레임 확인)
4. 패널 위 대비가 4.5:1 / 3:1 목표를 실제 프레임에서 만족하는가
5. 가장 긴 이름을 포함한 모든 로어서드 정지 프레임이 어두운·밝은 배경 양쪽에서 읽히는가
6. 로어서드 알파가 실제로 존재하는가(유지 구간 프레임 디코딩), 진입·퇴장이 프레임별로 깨끗한가
7. 자막·로어서드·목적지 UI가 겹치지 않는가(가로/세로 각각 미리보기)
8. 번역이 원문보다 의미를 더하지 않았는가

## 7. 가정과 미확인

- **가정**: 원문 발화 = 한국어, 번역 = 영어(한→영). 반대(영→한)면 원문/번역 줄의 크기·색 역할만 교체하고 나머지 값은 그대로 쓴다. 원본 발화 언어가 확정 입력은 아니다.
- **가정**: 인터뷰 화면비 16:9, 1080p, 30fps. 세로 납품이면 4절 규칙 적용.
- **미확인(input 필요)**: 실제 폰트 파일과 한글/라틴 커버리지, 브랜드 자막 가이드, 목적지 플랫폼 규격·안전 영역, 등장 인물의 실제 이름·직함 철자, 최종 음성 파일(단어 타이밍 측정 원본), 인터뷰 녹음의 사용 권리(본인 녹음/초상 사용 동의).
- **실행 검사**: 없음. 미디어·폰트·렌더를 열지 않았으므로 글리프 렌더, 대비, 타이밍 동기는 모두 `unverified`다. 위 수치는 승인된 스타일 확정값이 아니라 시작값이다.
