## 1. 결론 — 고른 스타일

**계열: 키네틱 타이포 → 골격: 매니페스토 팝(manifesto pop).**
오프화이트 바탕＋점 입자 장, 웨이트 900 지오메트릭 산세리프, `문제 → 전환 → 제품` 선언 3~5줄, 중괄호 목록, 마지막에 제품명 팝＋링. 앱 런칭 영상에서 "무엇이 달라지는가"를 **문장 논증**으로 세우면서, 요청하신 키네틱 타이포 감각(글자가 곧 화면)을 30초 내내 유지하는 유일한 계열 골격입니다.

**버린 후보와 이유(같은 계열 내)**
| 후보 | 버린 이유 |
|---|---|
| 플랫 비트 | 컷 간격 0.5~0.8초 → 30초면 35~40컷. 과밀·피로, 트랙 BPM 의존도 과다 |
| 푸시인 타이포 | "카메라는 멈추지 않는다"는 규칙상 30초 단일 푸시로 부적합 |
| 셔터 밴드 | 15초당 셔터 4회 제한 → 30초 확장 시 전환 피로 |
| 벨로시티 라인 | 속도·성능 제품 한정 소재라 일반 앱 런칭엔 주장이 과함 |

계열 밖 대안(코랄 타이틀 카드·리퀴드 글라스 로고)은 열지 않았습니다. 계열은 하나만 엽니다.

**주의(정직하게)**: 이 골격의 원형은 10~15초 티저입니다. 30초로 늘릴 때 **늘어난 시간을 새 장식·새 효과로 채우지 않고 목록·증거·읽기 홀드로 채웁니다.** 그러지 않으면 스타일이 곧 붕괴합니다.

## 2. 전제와 시작값

- 사용자 지정: 30초, 16:9(1920×1080, 30fps), 앱 런칭.
- `inferred`: 톤은 "명료·경쾌", 카피는 미제공 → 아래 비트맵은 **문장 길이·역할만** 제안하고 문구는 `[카피]`로 둡니다.
- 브랜드 키트·지정 색·지정 글꼴이 있으면 아래 팔레트·타이포 값보다 **우선**합니다. 아래는 조정 가능한 시작값입니다.
- 팔레트 시작값: 오프화이트 `#F3EFE6`, 점 입자 35% 커버리지, 청록 `#0F6E6E` → 머스터드 `#E9A126`(14px 블러 큰 원, 격자 배치), 강조는 청록/머스터드 2색만. 그라디언트 채움은 **제품명에만**.
- 타이포: 웨이트 900 지오메트릭 산세리프, 행간 0.9, 줄 96~120px, 숫자 1개만 220px, 제품명 160~200px. 장식 글꼴 금지.

## 3. 30초 화면 구성 (비트맵)

16:9 그리드: 12컬럼, 외곽 마진 120px, 타입 블록은 좌측 정렬 10컬럼, 줄 간 여백 ≥60px, 하단 12%는 자막·UI 대비 비움.

| # | 시간(프레임) | 시청자 takeaway | 초점 객체 | 변형 | 카피/오디오 | 퇴장 |
|---|---|---|---|---|---|---|
| B1 | 0.0–2.4 (0–72) | "이건 내 문제다" | 점 입자 → 첫 줄 | 점이 중심에서 퍼져 큰 점 하나로 쏟아지며 첫 줄을 실음(600ms) | 문제 한 줄, ≤6단어 | 다음 줄이 같은 축에서 올라옴 |
| B2 | 2.4–6.4 (72–192) | 문제가 구체화됨 | 둘째 줄 (＋숫자 1개, 출처 있을 때만) | 단어 100~120ms 팝 | 문제 심화 한 줄 | 청록 유지 → 색 전환 준비 |
| B3 | 6.4–10.8 (192–324) | "그래서 바뀐다" | 전환 구절(머스터드) | 줄 조립 1.2s, 단어 팝 | 전환 한 줄 | 점 장이 수축하며 다음 축으로 |
| B4 | 10.8–15.6 (324–468) | "실제로 이렇게 생겼다" | 앱 화면 1회(실제 캡처) | 매치컷으로 단어가 화면이 됨 | 제품 소개 한 줄 | 화면이 축소·정지 후 타입으로 복귀 |
| B5 | 15.6–21.6 (468–648) | "혜택 3개" | 중괄호 목록 3항목 | 중괄호가 목록을 죄고 항목이 하나씩 떨어져 열림 | 항목 각 2~4단어 | 목록이 접히며 피크로 |
| B6 | 21.6–26.4 (648–792) | 핵심 주장 | 가장 큰 한 줄 | 피크: 전체 타입 최대 스케일 | 핵심 한 줄 | 정지 후 링 등장 |
| B7 | 26.4–30.0 (792–900) | 제품명 기억 | 제품명 → 로고/태그라인 | 제품명 팝＋링 그리기, 로고 0.8s 안착 | `[브랜드명]`＋`[태그라인]` | 2.0s 이상 완전 정지 유지 |

규칙: 한 프레임에 시선을 다투는 요소는 **하나**. 화면당 포인트 요소 1개. 숫자는 전체 1개, 없으면 그 비트를 삭제(빈 숫자·가짜 수치 금지). 제품명은 반드시 마지막.

## 4. 움직임 사양 (작품 전체 1세트)

| 항목 | 값 |
|---|---|
| 이징 | 등장 back-out 팝 `cubic-bezier(0.34,1.56,0.64,1)`, 퇴장 `cubic-bezier(0.4,0,1,1)`. **곡선 2개 초과 금지** |
| 시간 단위 | 0.3s(단어 팝) / 0.6s(점 폭발·중괄호) / 1.2s(줄 조립·홀드 기준) |
| 스태거 | 단어 100~120ms, 목록 항목 180ms, 레이어 없음(전면 타입 단일 층) |
| 스케일 | 등장 0.92→1.0. 오버슈트는 제품명만 1.04→1.0(0.15s) |
| 홀드 | 줄 ≥1.2s, 목록 항목 ≥0.8s, 엔드카드 ≥2.0s |
| 전환 | **매치컷 1종만**(단어→화면, 줄→링). 와이프·스핀·페이드 조합 금지 |
| 카메라 | 없음. 회전·기울임·줌 펌프 금지. 깊이는 점 장 패럴랙스 ≤2%까지만 |
| 에너지 | 낮은 시작(B1) → 빌드(B2~B4) → 피크(B6) → 정돈된 엔드카드(B7). 피크는 1회 |
| 입자 | 시드 고정, 반짝임 없음, 동일 시각 2회 렌더 시 동일 픽셀 |
| 금지 | 프레임 전체 동시 이동, 읽는 중 텍스트 루프, 장식용 드리프트·바운스, "와우" 순간 2개 이상 |

※ 오디오: 트랙이 없으면 무음 계획으로 진행하고 "음악 분석"을 주장하지 않습니다. 트랙이 있으면 피크·드롭을 B6·B7 안착 프레임에 맞춥니다.

## 5. 검수 기준 (합격선)

**A. 판독성** — 헤드라인 cap height ≥64px@1080p · 줄 홀드 ≥1.2s, 목록 항목 ≥0.8s · 모든 줄이 세이프 안에서 온전히 읽힘(글자 잘림·끝단 클리핑 0) · 대비: 대형 헤드라인 ≥3:1, 목록·라벨 ≥4.5:1.
**B. 박자·일관성** — 컷·팝이 비트 ±2프레임 · 모든 길이가 0.3/0.6/1.2의 배수 · 같은 종류 동작에 같은 이징 · 전환 계열 1종만 · 묶음 등장 스태거 동일.
**C. 구성** — 프레임당 포인트 요소 1개 · 한 프레임에 경쟁 초점 없음 · 줄 여백 ≥60px · 팔레트 3색(+중립) 유지, 그라디언트는 제품명에만.
**D. 프레임 검사** — 각 홀드의 첫/중간/끝 프레임을 정지해 비트맵과 대조 · 이음매 ±5프레임 훑어 빈/중복 프레임 0 · 점 입자 깜빡임 없음(시드 고정 확인).
**E. 사실성** — 숫자·인용·사양은 공급된 값만, 단위·자릿수·출처 일치 · 출처 없으면 숫자 비트 제거(추정 금지) · 카피가 실제 제품 동작과 일치.
**F. 엔드카드·브랜드** — 로고 무왜곡(스케일·페이드만), 클리어스페이스 비움 · 끝 프레임이 반쯤 그려진 획 없는 진짜 로고 · 움직임 감소 대응 정적 프레임 경로 존재.
**G. 규격** — 1920×1080·30fps·16:9 크롭 없음, 하단 12% 비움 확인.

**판정 형식**: `pass / pass_with_notes / needs_revision` + 검사 범위 명시. 위 A~D는 **실제 렌더 프레임을 봐야** 판정 가능하므로, 지금 단계에서는 전부 `UNVERIFIED(계획만)`입니다. 스펙 대조와 재생 검사는 구분해 보고합니다.

**결함 → 결정**: 슬라이드쇼 같음 → 한 객체를 의미 있는 변형으로 운반 / 모두 경쟁 → 주 동작 1개로 줄이고 보조 삭제 / 무게 없음 → 이동 시간·이징 조정 / 텍스트 안 읽힘 → 홀드·대비 증가(카피 단축은 허용될 때만) / 밋밋함 → 타입 스케일·구도 강화(장식 추가 금지) / 바쁜데 말 없음 → 장식 제거 후 인과 동작 표시.
