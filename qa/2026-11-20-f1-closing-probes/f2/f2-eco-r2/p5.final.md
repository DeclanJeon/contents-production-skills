## 0. 미확정 입력 (아래 값은 조건부 시작값)

| 축 | 현재 상태 | 영향 |
|---|---|---|
| 화면비·해상도 | unverified (16:9 1920×1080 가정) | 세로면 패널 위치·글자수 재산정 |
| 발화 언어 / 번역 방향 | 가정: 한국어 발화 + 영어 번역 | 순서·강조어 위치 |
| 목적지 플랫폼 | 미정 | 하단 UI 가림·안전영역 unverified |
| caption_mode | 미정 (burned_in / sidecar) | 이중 자막을 화면에 굽는지 트랙 2개로 내는지 |
| 이름·직함 원문 | 사용자 제공 필요 | 지어내지 않음(아래 C-1) |

## A. 한영 이중 자막

**A-1. 구조 (고정)**
- 한 쌍 = 2줄. **위 줄 원문(한국어), 아래 줄 번역(영어)**. 3줄 금지, 언어당 1줄.
- 원문/번역은 같은 패널 안, 같은 폭 기준으로 정렬(중앙 또는 좌측 — 영상 전체에서 하나만).
- 강조색은 **원문 활성 단어 1색만**. 번역 줄에는 단어별 강조를 넣지 않는다(강조색 2개 이상 금지).

**A-2. 타이포·색·패널 시작값**

| 항목 | 시작값 | 비고 |
|---|---|---|
| 패널 | `rgba(14,18,16,.66)`, 반경 16px | 밝은 배경에서 대비 부족 시 **.80까지 올리고** 실제 프레임에서 확인 |
| 위치 | 하단 안전영역 15% 안쪽 중앙 | 플랫폼 진행바·아이콘과 겹치면 위로 올림(세로형은 하단 25% 위) |
| 원문 | 굵은 산세리프, `#FFFFFF`, 활성 단어 `#FFD45C` | 1080p 기준 본문 40px 내외 |
| 번역 | 같은 계열 산세리프, 원문의 약 70% 크기·굵기, `#D9E6DC` | **한국어에 이탤릭/가짜 기울임 금지**, 세리프 혼용 금지 |
| 글꼴 | 한글+라틴 모두 포함된 단일 패밀리(Pretendard/Noto Sans KR 등) | 폴백 글꼴 렌더 = 실패 |
| 투명도 | 두 줄 모두 100% 유지 | 미발화 단어 30% 디밍은 대비 미달 위험 → 이중 자막 모드에서는 쓰지 않음 |
| 여백 | 가장자리에서 5% 이상 안쪽 | 패널도 동일 |

**A-3. 줄 길이 (한/영 예산이 다름)**
- 라틴 기준 약 42자/줄이 상한이나, **한글은 글자당 폭이 커서 20–24자/줄**을 실질 상한으로 잡는다. 두 줄의 **픽셀 폭**을 맞추는 것이 기준이고 글자 수를 맞추는 게 아니다.
- 초과 시: 글자 축소·말줄임 금지. 의미 경계(절·구)에서 다시 끊고, 그래도 넘치면 구간을 나눠 두 쌍으로 분리.
- 숫자·단위·고유명사는 한 줄 안에서 쪼개지 않는다. 숫자 카드가 있으면 라이닝 숫자 글꼴 사용.

**A-4. 타이밍**
- 쌍은 구절 첫 단어에 **컷 또는 150ms 이하 페이드**로 등장. 쌍 교체는 구절 경계에서 2–3프레임 간격.
- 번역 줄은 원문보다 **120–250ms 늦게** 올린다(위 줄 먼저 읽히게).
- 원문 활성 단어 강조는 측정된 단어 타이밍을 따르며 **±3프레임** 이내. 균등 분배 금지.
- 1초 넘는 침묵에서는 자막을 비운다. 번역이 원문보다 오래 남지 않는다(최대 +0.3초).

**A-5. 내용 규칙**
- 자막은 말한 것을 그대로. 윤문으로 의미를 바꾸지 않는다.
- 용어집이 유지하기로 한 이름·용어는 번역하지 않는다(예: 브랜드명, 직책 고유명).
- 비언어 소리·웃음·끼어듦은 별도 규칙으로 표기(번역만 있는 자막은 완전 캡션이 아님 — WCAG 1.2.2 범위).
- 화자 구분이 필요한 구간은 색이 아니라 이름 라벨/위치로 구분(색만으로 정보 구별 금지).

**A-6. 피할 것**: 3줄 자막, 얼굴·입 위 자막, 강조색 2개, 구절 중간에 쌍 교체, 번역이 원문보다 정보를 더하는 것, 플랫폼 UI에 가린 하단 배치.

## B. 이름 로어서드 (하단 이름 자막)

**B-1. 텍스트 원칙**
- 이름·직함은 **사용자가 준 철자·구두점 그대로**. 성이나 직함을 추정·창작하지 않는다. 대문자 처리는 스타일로만.
- 2번째 줄은 사용자 제공 또는 실제 발화에 있을 때만. 없으면 **한 줄로 두고 비운다**.
- 최대 2줄: `이름` / `직함(또는 소속·직함)`. 한글 이름 + 로마자 표기가 필요하면 같은 줄에 `한글명 · Romanized`로 붙이고 3번째 줄을 만들지 않는다.

**B-2. 레이아웃·타이포 시작값 (1920×1080 기준)**

| 항목 | 시작값 |
|---|---|
| 위치 | 좌하단, 모든 가장자리에서 5% 이상 안쪽. 화면 중앙은 화자 얼굴용으로 비움 |
| 판 | 자막 패널과 동일 팔레트 `rgba(14,18,16,.66)`, 반경 16px, 또는 띠+진한 그림자 |
| 이름 | 50–80px, 굵기 600–700, `#FFFFFF` |
| 직함 | 이름의 약 50–60% 크기, 굵기 400, `#D9E6DC` |
| 포인트 | 좌측 3px 세로 액센트 바 `#FFD45C` — 영상 전체에서 **유일한 액센트** |
| 자간 | 한글 자간 확장·대문자 변환 금지. 한/영 혼용 줄은 베이스라인 정렬, 한글이 커 보이면 한글만 1–2% 축소 |
| 점유 | 프레임의 몇 %만 덮게. 이름 카드가 화자를 가리면 실패 |

**B-3. 등장·퇴장**
- 총 약 8초: 진입 1초 미만(300–500ms 슬라이드+페이드, 방향 1개), 유지 5–6초 **완전 정지**(느린 광택 1회까지), 퇴장 0.5초(진입의 역방향).
- 바운스·회전·반복 루프 금지. 첫/마지막 프레임은 비워 편집에서 튀지 않게.
- 인물이 여러 명이면 각자 첫 등장에 1회, 재등장 시 화면 전환 후 1회만. **두 이름 카드를 동시에 띄우지 않는다**. 여러 요소를 한 페이지에 둘지 그래픽별 페이지로 둘지 사전에 명시.

**B-4. 알파 납품**
- 편집 프로그램용은 ProRes 4444 `.mov`, 웹/스트림은 WebM(+Safari용 HEVC 사본). 알파 없는 H.264는 바탕색 없이 내보내지 않는다.
- 유지 구간 프레임을 디코딩해 알파가 실제로 있는지, 바둑판+어두운/밝은 배경에서 읽히는지 확인.

## C. 공통 검수 (전부 실제 출력 프레임에서)

1. 1배속에서 모든 이중 자막 쌍을 두 번 읽을 수 있는가.
2. 강조 단어가 발화에 ±3프레임으로 맞는가.
3. 가장 긴 이름·가장 긴 번역 줄의 정지 프레임이 어두운/밝은 배경 양쪽에서 읽히는가(대비·잘림·폴백 글꼴).
4. 얼굴·입·손·제품·플랫폼 UI를 가리는 프레임이 없는가.
5. 두 자막 요소(이중 자막·로어서드)가 동시에 뜰 때 겹치지 않는가 — 로어서드 구간은 이중 자막을 잠시 비우거나 로어서드를 위로 올린다. **겹침 규칙을 한 가지로 고정**.
6. 자막은 최종 음성에 맞춰 측정; 최종 음성이 없으면 타이밍은 provisional, 동기화 unverified로 표기.
7. 대비·읽기 시간·비언어 소리 표기는 납품 검수 항목에 남기고, 미검사 항목은 통과로 보고하지 않는다.
