# 카페 로고 시안 — “모닝 슬로우 (Morning Slow)”

**한 줄 컨셉**
해가 막 떠오르는 시간의 느린 리듬. 커피잔과 해가 하나의 형태로 겹치는 심볼.

## 1. 심볼
- 원형 아이콘 하나. 아래쪽 2/3은 **커피잔 실루엣(측면)**, 컵 안쪽 액체 곡선이 **수평선**이 되고, 그 위로 **반쯤 뜬 해**가 컵 림에 걸쳐 있음.
- 해의 지름 = 컵 입구 폭의 약 0.6배. 해는 선 없이 **면(fill)** 으로만, 컵은 **균일 굵기 선(1.5~2pt)** 으로 마감 → 면과 선의 대비로 형태를 읽힘.
- 김(steam) 표현 없음. 대신 해에서 위로 뻗는 **짧은 광선 3개**가 김처럼 보이도록 길이만 다르게(1:0.7:0.5).
- 외곽 원은 생략. 심볼 자체가 원형 실루엣을 이루게 해서 파비콘·스탬프에 그대로 사용 가능.

## 2. 워드마크
- **MORNING SLOW** — 산세리프 지오메트릭(예: Futura 계열 / Poppins SemiBold), 자간 +40, 전부 대문자.
- **coffee & bake** — 소문자, 자간 +120, 워드마크 아래 1줄. 크기는 워드마크의 35%.
- 두 줄 사이 얇은 헤어라인(0.75pt, 폭은 워드마크의 60%)을 넣어 정렬축을 만든다.

## 3. 컬러 (2색 + 여백)
| 역할 | 색 | HEX |
|---|---|---|
| 심볼·워드마크 | 딥 에스프레소 브라운 | `#3B2A20` |
| 해·포인트 | 번트 오렌지 | `#D9722C` |
| 배경 | 웜 오프화이트 | `#F6F1E7` |

- 단색 인쇄 시: 브라운 단색 100%, 해는 **네거티브(배경색 녹아웃)** 로 전환.
- 컵 어깨에 오렌지 1도만 얹는 “미니멀 버전”도 허용.

## 4. 조합 규칙
- **A형(가로)**: 심볼 좌 + 텍스트 우, 심볼 높이 = 텍스트 블록 높이 × 1.2 → 간판·컵홀더
- **B형(정방)**: 심볼 상단 중앙, 텍스트 하단 2줄 → SNS 프로필·스탬프 카드
- **C형(심볼 단독)**: 앱 아이콘·뚜껑 씰
- 최소 여백 = 심볼 지름의 1/4. 최소 사용 사이즈 **가로 12mm**(그 이하에서는 C형으로 대체).

## 5. 톤 체크
- 차분하지만 따뜻함, “동네 단골집” 쪽으로 기움. 프랜차이즈처럼 반짝이는 광택·그라데이션 금지.
- 오렌지는 해에만. 두 번째 오렌지 요소를 추가하지 않는다(포인트 희소성 유지).

## 대안 방향 (원하면 이걸로 교체)
**“SLOW” 레터마크형** — 이탤릭 산세리프로 SLOW만 쓰고, 두 번째 O를 커피잔 단면(위에서 본 원 + 손잡이)으로 치환. 텍스트 비중 90%라 미니멀 카페에 잘 맞고, 심볼 제작 없이 바로 적용 가능.

원하시면 이 시안을 이미지 생성용 프롬프트로 바꿔드리거나, A/B 중 하나로 좁혀서 다듬겠습니다.
