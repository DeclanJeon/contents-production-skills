## 라우팅 (한 줄)

`deliverable_kind` = 모션 스타일 지시서(단일 제작 자산) / `media_axis` = text_only / `authority_axis` = 없음 → **R13**, 크래프트: 33 모션 스타일 색인 → `kinetic-type` 계열, 08a 모션 아트 디렉션·안무·로고 모션·리뷰. 렌더·유료 생성·파일 쓰기 없음.

이 세션에는 `cineforge` CLI/스킬과 셸 실행 도구가 없어 `cineforge route` 확인은 실행하지 못했다. 아래는 설치된 `creative-production` 패키지 절차로 낸 텍스트 계획이며, 실제 재생 검수는 하지 않았다(아래 모든 수치는 **시작값**, 브랜드 키트·측정 BPM이 우선).

## 1. 스타일 선택

**계열: 키네틱 타이포. 스파인: 푸시인 타이포 하나만.**

- 푸시인은 이 패키지에서 "앱·SaaS 런칭 티저, 짧은 단어 몇 개로 만드는 브랜드 오프너"로 지정된 유일한 조합이고, **카메라가 멈추지 않고 타입 레이어를 뚫고 전진해 로고에 도착**하는 메커니즘이라 30초를 하나의 연속 동작으로 쓸 수 있다.
- 30초에서는 레시피 기본 길이(6–15초)를 그대로 못 쓴다. 그래서 **레이어 성장/통과 리듬만 유지하고 홀드만 늘려** 4막(문제→전환→기능 증거→엔드카드)으로 확장한다. 메커니즘은 하나, 밀도만 낮춘다.
- 대안은 채택하지 않는다(이유 명시): **플랫 비트**는 0.5–0.8초 컷 40여 회가 되어 30초에서 읽기 창이 사라짐 / **에코 스택·자이언트 플립**은 단어·숫자 1개 티저용이라 기능 3개를 못 담음 / **셔터 밴드**는 전환 자체가 주인공이 되어 제품 증거가 밀림 / **벨로시티 라인**은 "속도" 주장에 종속된 스타일(주장이 속도가 아니면 부적합).
- 두 번째 메커니즘 금지: 컷 전환·와이프·스핀·크로스페이드 없음. 유일한 예외는 B5 피크의 **강조색 슬래시 1회**.

## 2. 아트 디렉션 고정값 (작품당 하나)

## 3. 화면 구성 (16:9 / 1920×1080 / 30fps)

- **단일 중앙축**: 모든 레이어는 같은 수직축에 정렬. 레이어당 **2–3단어(한글 6–12자)**, 레이어 최대 3줄. 문장 금지.
- **타입 스케일 3단**: 히어로 180–260px(프레임 폭을 채움) / 서브 라벨 44–64px / 엔드 태그라인 40–56px. 디스플레이 행간 0.95–1.05, 자간은 글리프 충돌 없는 선에서만 조인다.
- **한글 대체 규칙**: 응축 대문자·그로테스크 블랙은 한글에 없으므로 ① 승인 브랜드 폰트 → ② 한글 지원 굵은 고딕 대체 폰트 1개(사전 검증) → 위계는 **무게·크기·줄 수**로 만든다. 글리프 누락(두부) 검사 필수.
- **여백**: 외곽 96px, 하단 160px는 캡션·플랫폼 UI 회피 구역. 텍스트는 이미지에 굽지 않고 라이브 텍스트로 유지.
- **제품 증거**: 실제 앱 화면 캡처만. 늘이지 말고 의도해서 자른다. 화면 카드는 라벨 뒤로 안착 후 고정, 카메라만 지나간다(정지 페이지 위 느린 카메라 이동으로 시연을 대체하지 않는다).
- **로고**: 클리어스페이스 유지, 스케일·페이드만(스큐·스쿼시 금지), 끝 프레임은 반쯤 그려진 획 없는 진짜 로고.

## 4. 30초 비트맵

| # | 구간 | 시청자 takeaway | 초점 객체 | 변형/움직임 | 카피·오디오 | 퇴장 |
|---|---|---|---|---|---|---|
| B1 | 0.0–2.4 | "이거 내 얘기다" | 문제 단어 1개 | L1 성장 60→100% 0.8s, 정지 1.6s | [문제 단어] · 첫 비트 착지 | 다음 레이어가 뒤에서 올라옴 |
| B2 | 2.4–7.2 | 문제가 구체화 | 3개 단어 레이어(각 1.6s) | 성장 0.8s + 정지 0.8s, 겹침 0.2s | [증상/상황 2–3개] | 카메라 가속 시작 |
| B3 | 7.2–10.4 | "이제 바뀐다" | 전환 단어 2개 | 강조색 슬래시 1회, 성장 0.8s | [전환 구절] · 서브 드롭 | 슬래시 방향으로 이탈 |

- 총 타입 레이어 11개 → 평균 2.7초/레이어. 키네틱하면서 읽기 창이 남는 상한.
- 오디오: BPM을 **먼저 측정**한 뒤 모든 정착점을 비트에 스냅. 측정 없이 "비트 ±2프레임" 통과를 주장하지 않는다. 음악은 없으면 무음으로 완성하지 말고 막힘을 보고(의도적 무음은 유효).
- 오디오 반응 펄스 금지(엔벨로프/비트맵 없이 "음악 분석"이라 부르지 않는다).

## 5. 요소별 움직임 스펙

- 레이어 성장 60→100%, 0.8–1.2s, ease-out, 같은 축 유지(회전·기울임 금지).
- 통과 600–900%, 블러 6–12px, 0.4–0.6s, 다음 레이어와 150–250ms 겹침 → **빈 프레임 0**.
- 시선 닻은 프레임당 1개. 히어로가 먼저/가장 두드러지게 들어오고 서포트는 응답만.
- 강조색 요소 화면당 1회, 슬래시는 글자를 가로지르지 않는다.
- 로고 모션은 기법 하나만(워드마크 글자별 스태거 또는 선 그리기). 모션 감소 납품용 **정적 끝 프레임 폴백** 경로 필수.
- 모든 길이는 시간의 함수/탐색 가능한 트랙으로 — 0초부터 재생해야만 맞는 시뮬레이션·시드 없는 난수 금지.

## 6. 검수 기준

**계획 단계에서 지금 판정 가능 (텍스트 대조)**
1. 이징 계열 2개 이하인가 / 길이가 0.2s 배수인가 / 전환은 푸시·매치컷뿐인가.
2. 레이어마다 "정지 상태 0.5초 이상 읽기"가 시간표에 실제로 들어 있는가(공개 타이밍 ≠ 읽기 시간).
3. 프레임당 시선 다툼 요소 1개인가 / 색 3개 이하, 강조 화면당 1회인가.
4. 레이어당 3단어·3줄 이하인가 / 빈 프레임·중복 프레임 0인가(이음매 ±5프레임 훑기).
5. 모든 수치·기능명·후기가 **공급된 값**인가(지어낸 통계·사양·인용 0).
6. 로고 클리어스페이스·무왜곡·끝 프레임 완성도, 정적 폴백 존재.

**렌더 후에만 판정 가능 (지금은 UNVERIFIED)**
7. 1920×1080 실제 크기에서 오프닝·B5 피크·B6 홀드 연속 재생, 한글 글리프 누락·폰트 대체 확인.
8. 컷이 비트 ±2프레임인가(측정 BPM 기준), 사운드 로고 피크 = 로고 안착 프레임.
9. 제품 화면이 실제 동작을 보여 주는가(늘어남·크롭 오류 없음), 색 밴딩·탁한 중간색 없음, 트랙이 실제로 들리는가.

**결함 → 결정 변환 규칙**: 슬라이드쇼 같음 → 한 객체를 의미 있는 변형으로 운반 / 다 같이 경쟁 → 주 동작 정하고 서포트 축소·지연 / 무게 없음 → 이동 시간·가감속 조정 / 텍스트 안 읽힘 → 홀드·대비 강화 / 밋밋함 → 타입·구도·모티프 강화 / 바쁜데 말 없음 → 장식 제거하고 인과 동작 표시. 미감을 숫자 점수로 인증하지 않는다.

## 7. 필요한 입력 (플레이스홀더로 계속, 게이트 아님)

브랜드 키트(색·폰트) / 로고 SVG / 실제 앱 화면 캡처 / 확정 카피(문제·전환·기능 3·약속) / 트랙·BPM / 쓰는 숫자와 출처. 없으면 `[브랜드명]`·`[문제 단어]` 형태로 라벨링해 유지한다. 유료 생성·외부 실행은 이 답변에 포함되지 않는다.
