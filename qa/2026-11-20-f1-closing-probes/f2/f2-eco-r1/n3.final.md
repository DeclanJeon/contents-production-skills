# 커피 추출 온도 실험: 1℃ 차이가 맛을 바꾸는 이유

## 들어가며

같은 원두, 같은 그라인더, 같은 레시피인데 어떤 날은 시고 어떤 날은 쓰다. 많은 사람이 원두나 분쇄도만 의심하지만, 실제로 컵의 인상을 크게 흔드는 변수가 **물의 온도**입니다. 이 글은 "추출 온도만 바꾸면 맛이 어떻게 달라지는가"를 정리한 실험 노트입니다.

## 왜 온도가 중요한가

커피 추출은 물이 원두 입자에서 가용 성분을 녹여내는 과정입니다. 온도가 오르면:

- 물의 용해력과 확산 속도가 증가 → 같은 시간에 더 많은 성분이 빠져나옴
- 산미·단맛·쓴맛 성분의 **추출 속도 차이**가 벌어짐
- 점도와 표면장력이 낮아져 물이 커피 베드에 더 고르게 스며듦

즉 온도는 "추출량"과 "추출 성분의 균형"을 동시에 움직이는 손잡이입니다.

## 실험 설계 (재현 가능한 형태)

공정 비교를 위해 아래 조건만 고정하고 온도만 변수로 둡니다.

| 항목 | 조건 |
|---|---|
| 원두 | 동일 로스팅, 동일 배치 |
| 분쇄도 | 동일 (레시피 기준 고정) |
| 비율 | 1:15 (커피 15g : 물 225g) |
| 총 추출 시간 | 2:30 고정 |
| 물 | 동일 정수 + 동일 미네랄 |
| 온도 | 80℃ / 85℃ / 90℃ / 95℃ |

**핵심 원칙:** 한 번에 한 변수만 바꾼다. 온도를 바꾸면 추출량이 같이 변하기 때문에, 시간을 고정해야 "온도 자체의 효과"가 드러납니다. (반대로 추출 수율을 고정하고 온도만 바꾸는 설계도 가능하며, 이 경우 시간이 달라집니다.)

## 예상되는 결과 패턴

일반적으로 관찰되는 경향은 다음과 같습니다.

- **80~85℃ (저온)**: 추출이 느림 → 산미와 향이 앞서고, 단맛이 얇고 텁텁함이 남기 쉬움. 밝고 시큼한 컵.
- **90~93℃ (중온)**: 산미·단맛·바디의 균형 구간. 대부분의 레시피가 목표로 하는 존.
- **95℃ 이상 (고온)**: 추출 과다 → 쓴맛, 떫은맛, 드라이한 여운. 향은 강하지만 뒷맛이 무거움.

포인트는 **"높을수록 좋다/낮을수록 좋다"가 아니라 최적 구간이 존재한다**는 것입니다.

## 로스팅과 브루어에 따른 조정

- **라이트 로스트**: 세포 구조가 단단해 추출이 더디다 → 92~96℃로 올려 단맛을 끌어올리는 편이 유리
- **다크 로스트**: 이미 가용 성분이 많고 쓴맛 성분이 취약 → 85~90℃로 낮춰 과추출 방지
- **핸드드립(V60 등)**: 드리퍼·필터의 열 손실이 있어 표시 온도보다 베드 온도가 낮음 → 1~2℃ 높게 시작
- **에스프레소**: 88~94℃ 구간에서 1℃ 단위 조정이 산미/쓴맛 밸런스를 크게 바꿈
- **콜드브루**: 온도 개념이 아니라 시간·입자 표면적으로 접근하는 별개 영역

## 실무 체크리스트

1. 온도계는 **실제 물 온도**로 보정한다(주전자 표시 ≠ 베드 온도)
2. 물을 붓기 전 예열로 드리퍼·서버의 열 손실을 줄인다
3. 온도를 올렸을 때 추출 시간이 짧아졌다면, 그건 온도 효과 + 유속 효과가 섞인 결과다
4. 4개 온도를 마시고 **"어디서 텁텁함이 시작되는가"**를 찾으면 그 지점이 내 장비의 상한선이다
5. 좋았던 온도를 기록해 두면 원두가 바뀌어도 시작점으로 쓸 수 있다

## 결론

온도는 "1℃도 의미 없는 디테일"이 아니라, 같은 원두를 완전히 다른 컵으로 바꾸는 **가장 저렴하고 즉각적인 튜닝 변수**입니다. 원두를 바꾸기 전에, 물 온도를 5℃ 올리고 내려보는 것만으로도 절반의 답을 얻을 수 있습니다.
