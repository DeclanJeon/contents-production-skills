**적용 범위:** 단일 산출물(R13, `text_only`) — 자막·로어서드의 **룩과 배치**만 정한다. 내용·타이밍 측정·접근성 판정은 15 납품 규칙이 정본이고, 아래는 렌더 전 **시작값(조정 가능)** 이다. 화면비·플랫폼·브랜드 폰트·실제 발화 타이밍은 아직 **unverified**이므로 값을 확정하지 않았다.

## 1. 공통 팔레트·타이포 (자막과 이름 띠가 같은 계열을 쓴다)

| 항목 | 시작값 |
|---|---|
| 패널 | `rgba(14,18,16,.66)` / 반경 16px / 패딩 24–28px |
| 원문(말한 언어) | 굵은 산세리프 600–700, 44–48px, `#FFFFFF` |
| 번역 | 원문의 약 70% 크기(32–34px), 같은 폭, `#D9E6DC`, 이탤릭 세리프 또는 같은 산세리프 |
| 강조 | `#FFD45C` 하나만. **원문의 실제 발화 단어에만** 적용, 번역 줄은 강조하지 않는다 |
| 폰트 | 한글·라틴 글리프를 모두 덮는 한 패밀리(예: Pretendard / Noto Sans KR 계열). 폴백 렌더 금지, 실제 로드 확인 |

- 강조색 2개 이상 금지. 색만으로 정보를 구분하지 않는다(대비는 렌더 프레임에서 4.5:1 확인, 밝은 배경에서 패널 불투명도를 .78–.85로 올린다).

## 2. 한영 이중 자막 규칙

**배치**
- 하단 15% 안전 영역 중앙, 패널 1장. 얼굴·입·손·제품·플랫폼 UI를 비운다.
- **언어당 한 줄**, 최대 2줄(3줄 금지). 위 줄 = 말한 언어 원문, 아래 줄 = 번역. 줄 순서를 화면마다 바꾸지 않는다.
- 줄 길이는 "글자 수"가 아니라 **패널 폭**이 기준이다. 같은 폭에서 라틴 약 42자 / 한글 약 18–22자(어절 단위, 조사는 앞말에 붙임)를 시작값으로 두고 **렌더로 확인**해 조정한다. 한글 중간 끊기 금지.

**타이밍**
- 쌍은 구절 첫 단어에 컷으로 등장, 페이드 ≤150ms. 원문 강조는 측정된 단어 타이밍을 따르고 균등 분배하지 않는다.
- 번역 줄은 원문보다 **120–250ms 늦게** 올려 위 줄을 먼저 읽게 한다.
- 교체는 구절 경계에서 2–3프레임 간격. 1초 넘는 침묵에는 자막을 비운다. 구절보다 오래 남기지 않는다.

**번역**
- 의미를 지우는 윤문 금지, 말한 것보다 더하지 않는다. 인명·직함·단위·고유명사·화자를 원문과 대조.
- 용어집이 유지하기로 한 이름·용어는 번역하지 않는다. 이름 로마자 표기는 **본인이 쓰는 표기 → 없으면 국어의 로마자 표기법**, 영상 전체·썸네일·설명란에서 동일 철자.
- `caption_mode`: 디자인된 쌍은 burned_in, 접근성용으로 원문 언어 sidecar를 별도 제공. **플랫폼 자동 자막은 끈다**(디자인 자막 위에 겹쳐 쌓지 않는다).

## 3. 하단 이름 자막(로어서드) 규칙

**내용**
- 1줄: 이름(철자·구두점까지 제공된 그대로), 2줄: 직함·소속(제공된 값만). **직함·경력·성을 지어내지 않는다.** 둘째 줄이 없으면 빼거나 사용자 문구를 그대로 쓴다.
- 대문자 처리만 스타일로 허용. 이중 언어가 필요하면 이름 띠는 **주 언어 1개 + 보조 언어 이름만 작게** 붙이고 최대 2줄 — 4줄 이중 이름 띠는 만들지 않는다(번역 이름은 설명란·자막이 담당).

**배치·크기 (1920×1080 기준)**
- 최소 5% 가장자리 안쪽. 프레임 중앙은 화자용으로 비운다.
- 이름 64px(50–80px 범위), 직함은 그 절반(32px). 화면의 몇 퍼센트만 덮는다.
- 위치: **하단 자막 존과 충돌 금지.** 자막 패널 상단보다 최소 8% 위(대략 화면 높이 62–75% 지점)에 두고, 인물이 화면 왼쪽이면 오른쪽으로 미러링한다.
- 글자 뒤 패널·띠·진한 그림자 중 하나로 어두운/밝은 배경 모두에서 읽히게 한다. 얇은 밝은 글자를 사진에 직접 얹지 않는다.

**움직임·타이밍**
- 총 약 8초: 진입 <1초(280–360ms), 정지 유지 5–6초, 퇴장 0.5초. 유지 구간은 정지(느린 광택 1개까지).
- 등장 시점 = 해당 인물이 **화면에서 처음 식별되는 순간**(오프닝 질문 중이 아니라 첫 답변 시작). 같은 인물은 1회만, 20초 이상 공백 뒤 재등장 또는 장면 전환 시에만 다시 띄운다.
- 첫·마지막 프레임은 비워 편집에서 튀지 않게 한다. 무음 그래픽이다.
- 밖으로 넘기는 경우: 편집용 ProRes 4444 `.mov`, 스트리밍용 WebM. 알파 없는 H.264 MP4를 바탕색 없이 넘기지 않는다. 인타임 렌더면 별도 파일 불필요.

## 4. 충돌·중복 금지

1. 자막 존(하단 중앙 15%)은 자막 전용. 이름 띠·코너 버그·구독 알림을 겹치지 않는다.
2. 이름 띠 유지 중에도 자막은 계속 간다 — 자막을 지우거나 이름 띠를 자막 위에 얹지 않는다.
3. 얼굴·입·손·제품 위에 어느 것도 올리지 않는다(프레임별 확인).
4. 숫자 카드·인용 카드가 뜨는 구간에는 이름 띠를 띄우지 않는다(카드 계열 하나만).
5. 세로 9:16으로 리프레임하면 오른쪽 12%·하단 UI 존을 피해 스택 전체를 위로 올린다 — 목적지 규격은 실제 확인 후 확정(unverified).

## 5. 검수 체크리스트 (통과 전 "완료" 아님)

- [ ] 1배속에서 모든 자막 쌍을 **두 번** 읽을 수 있는가
- [ ] 강조가 실제 발화 단어에 ±3프레임으로 맞는가
- [ ] 번역이 원문보다 의미를 더하지 않았는가 / 용어집 이름을 건드리지 않았는가
- [ ] 빠진 글리프(한글·라틴)가 없는가, 폴백 폰트로 그려지지 않았는가
- [ ] 3줄 자막·줄 중간 끊김이 없는가
- [ ] 가장 긴 이름을 포함한 모든 카드가 밝은/어두운 배경에서 읽히는가(정지 프레임)
- [ ] 이름·직함 철자가 제공값과 일치하는가(창작 없음)
- [ ] 진입/퇴장 프레임 시트에서 글자가 패널 밖으로 새지 않는가, 빈 첫/끝 프레임이 있는가
- [ ] 알파 파일은 유지 구간 프레임을 디코딩해 알파 존재를 확인했는가
- [ ] 자막·이름 띠·플랫폼 UI가 어떤 프레임에서도 겹치지 않는가
- [ ] 타이밍은 최종 음성에서 측정했는가(최종 음성 없으면 provisional·unverified로 표기)

**하지 말 것:** 말을 바꿔 쓴 자막, 강조색 2개, 얼굴 위 자막, 지어낸 직함·성, 자동 자막과의 이중 표시, 세리프 구식 숫자가 줄 아래로 내려가는 카드, 검사 없이 "동기화 완료" 선언.
