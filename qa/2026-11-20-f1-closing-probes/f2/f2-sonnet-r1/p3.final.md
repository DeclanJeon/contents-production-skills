**편집 계획: 1시간 팟캐스트 → 유튜브 쇼츠** (텍스트 전용, 파일 생성 없음)

**전제**
- 이 단계는 계획만 다룹니다. 실제 컷 편집과 내보내기는 원본 파일과 편집 승인이 있어야 진행합니다.
- 아직 원본과 전사본을 보지 못했습니다. 아래 후보 개수, 시각, 점수는 모두 방법론이고 실제 값은 전사를 본 뒤 채웁니다.
- 말은 단어 시간이 있는 전사로만 판단하고, 화면을 보고 짐작하지 않습니다.

**0단계. 입력 확인**
- 카메라 A·B 원본 파일 전체와 별도 마이크 오디오(있다면)가 필요합니다.
- 화자 이름, 마이크 소유자, 기준 오디오(어느 녹음이 마스터인지)도 알려 주세요.
- 가로 16:9 촬영인지, 각 카메라가 화자 한 명씩 찍었는지 와이드인지도 확인합니다.

**1단계. 멀티캠 동기화와 마스터 분리**
- 두 카메라가 같은 말을 같은 시각에 담고 있으면 별개 앵글로 보고, 공유하는 말 없이 시간이 이어지면 재시작한 카메라 하나로 봅니다.
- 오프셋은 짐작하지 않고 오디오 파형이나 전사 겹침으로 맞춥니다.
- 각 앵글의 시작·중간·끝에서 립싱크를 ±1프레임으로 확인합니다.
- 신뢰도가 낮은 매칭은 숨기지 않고 목록으로 적습니다.
- 클럭 드리프트나 프레임 드롭이 보이면 조용히 늘리거나 줄이지 말고 보고합니다.
- 동기화 마스터와 쇼츠 컷 초안은 별도 타임라인에 둡니다.

**2단계. 전사와 후보표 (자르기 전에 먼저)**
- 단어 시간이 포함된 전사본을 만들고, 화자 구분을 붙입니다.
- 후보표의 열은 다음과 같습니다.
  - 시작–끝 시각
  - 전사에서 인용한 훅 한 줄
  - 단독으로 이해되는 이유
  - 0–100 점수
  - 위험: 앞 맥락 필요, 사적 인물 지칭, 오디오 불명확, 끊긴 엔딩
- 후보 수는 원본 5–10분당 하나 정도라서 1시간이면 대략 6–12개입니다. 할당량은 아니고, 강한 순간이 적으면 그만큼만 제시합니다.
- 숏츠 합계 길이는 원본의 절반 이하로 잡습니다.
- 강한 신호는 첫 1–3초의 훅, 분명한 결말, 감정이나 의견 대비, 구체적 예시나 숫자입니다.
- 길이는 20–75초를 기본으로 하고, 요청이 없으면 90초를 넘기지 않습니다.
- 사용자가 후보를 고르는 것이 선택 게이트입니다.

**3단계. 파일럿 1편으로 스타일 확정**
- 선택한 후보 중 한 편을 먼저 끝까지 만들고, 스타일 승인을 받은 뒤 나머지를 같은 스타일로 배치합니다.
- 승인 전에는 일괄 제작하지 않습니다.

**4단계. 컷 편집 (후보 1편 기준)**
- 훅 문장에서 시작합니다.
- 군말과 긴 공백은 줄이되 숨과 단어 중간은 자르지 않습니다.
- 화자 추적 규칙(시작값)은 다음과 같습니다.
  - 한 사람이 말하면 그 사람 클로즈업으로 가고, 새 화자가 말을 시작한 뒤 4–8프레임이나 숨에서 자릅니다.
  - 최소 샷 길이는 1.5초입니다.
  - 두 목소리가 0.8초 넘게 겹치거나 웃음이 터지면 와이드로 갑니다.
  - 긴 발언은 20–40초마다 앵글을 바꿔 끊습니다.
  - 듣는 사람의 반응 샷은 0.5–1초이고, 눈에 보이는 반응이 있을 때만 분당 2개 이하로 씁니다.
  - 펀치라인 순간에는 반응 샷을 끼우지 않습니다.
- 전환은 하드컷이 기본입니다. 필요하면 J/L 컷으로 소리를 4–24프레임 먼저 넣거나 늦춰 이음새를 숨깁니다.

**5단계. 9:16 재프레이밍과 캡션**
- 먼저 각 앵글에서 화자 얼굴이 실제로 어디 있는지 확인한 뒤 크롭을 정합니다.
- 레이아웃은 두 가지 중에서 정합니다.
  - 한 명씩 말하는 구간: 얼굴 추적 크롭
  - 대화·티키타카 구간: 위아래로 쌓은 투샷 레이아웃
- 캡션은 단어 시간에 맞추고 하단 3분의 1에 둡니다. 유튜브 쇼츠 UI(제목, 버튼 영역)와 겹치지 않게 합니다.
- 상단에는 훅 제목을 3초 이내로 보여 주는 것을 선택 사항으로 둡니다. 훅은 실제 발화를 인용한 문장만 씁니다.
- 말하는 얼굴과 입 위에는 그래픽을 얹지 않습니다.

**6단계. 오디오와 마무리**
- 라우드니스를 통일하고, 필요하면 노이즈 제거와 화자 간 레벨 균형을 맞춥니다.
- 배경음악은 쓰더라도 음성보다 작게 깔고, 쓰지 않아도 됩니다.
- 끝은 열린 결말로 끊지 않고 문장이 완결된 지점에서 닫습니다.

**7단계. 검수 (실제 재생으로 확인하기 전에는 미검증으로 표기)**
- 원본을 보지 않아도 이해되는가.
- 첫 줄이 훅인가.
- 캡션이 발화와 맞는가.
- 크롭이 말하는 사람을 자르지 않는가.
- 화자 교체 컷이 실제 음성을 따라가는가.
- 컷 경계와 전체 출력을 재생해서 확인했는가.

**8단계. 게시 전 확인**
- 제목, 설명, 태그, 공개 여부는 별도로 승인받습니다. 업로드는 명시적 승인이 있을 때만 합니다.
- 게스트가 나오는 경우 사용 동의를 확인합니다.

**진행 순서 요약**
동기화 → 전사 → 후보표 → 사용자 선택 → 파일럿 1편 → 스타일 승인 → 나머지 배치 → 검수 → 게시 승인
