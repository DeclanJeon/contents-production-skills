**스타일 선택**: 푸시인 타이포 (앱·SaaS 런칭 티저용으로 정리된 키네틱 타이포 스타일).
- **고른 이유**: 카메라가 큰 단어 층을 계속 뚫고 전진합니다. 기능 소개와 로고 엔딩으로 이어지는 앱 런칭 구조에 맞습니다.
- **후보**: 셔터 밴드는 더 펀치 있지만 앱 화면을 넣을 자리가 좁습니다. 플랫 비트는 트랙이 있어야 하고 톤이 가볍습니다.
- **원본 길이**: 원본 스타일은 6–15초용이라 30초에 맞게 층 수와 챕터 구성을 늘렸습니다. 이 확장은 제 설계이며 검증된 값이 아닙니다.

**전제 (확인된 것은 없음)**
- 1920×1080, 30fps로 가정했습니다.
- 앱명, 태그라인, 기능 3개, 실제 앱 화면 캡처는 `[앱명]`, `[기능1~3]` 같은 자리표시자로 두었습니다.
- 수치와 인용은 쓰지 않았습니다. 넣으려면 출처가 있는 값만 쓰세요.

## 1. 화면 구성
- **배경**: 단색 종이색 `#F2EEE6`입니다. 그라디언트, 사진, 장식은 쓰지 않습니다.
- **글자**: 잉크 `#16161A`의 굵은 고딕입니다. 층당 2–3어절, 한 줄 한글 6–8자 이내로 합니다. 한글은 대문자 개념이 없어서 Black 웨이트로 대체했습니다.
- **강조색**: 핵심어 하나에만 주황 `#F0532B`을 씁니다. 층당 한 번입니다.
- **포인트**: 노랑 `#F7C534` 슬래시는 챕터당 한 번만 날아 지나갑니다.
- **위치**: 모든 층을 같은 중앙 축에 둡니다. 안전 여백은 좌우 약 96px, 상하 약 54px입니다.
- **앱 화면**: 기능 챕터에서는 실제 앱 화면을 한 층으로 취급해 같은 푸시인 움직임으로 통과시킵니다. 화면 위 글자는 한 단어만 둡니다.
- **엔드 카드**: 정상 크기의 로고, `[앱명]`, 한 줄 약속입니다. 효과 없이 선명하게 둡니다.

## 2. 30초 타임라인
한 층의 주기는 약 2초입니다. 성장 1.0초, 정지 근처 읽힘 0.5초, 통과 0.5초로 잡았습니다. 다음 층은 0.2초 겹쳐 올라옵니다. 트랙이 있다면 120BPM에 맞추면 한 층이 정확히 한 마디(4박)입니다.

| 시간 | 비트 | 내용 |
|---|---|---|
| 0–2s | 훅 | 문제 단어 1층, 예: `[불편한 상황]` |
| 2–8s | 문제 | 3층. 공감 → 악화 → 한계 |
| 8–10s | 전환 | 1층. 이 층에서 주황 강조를 가장 세게 씁니다 |
| 10–22s | 기능 3챕터 (각 4s) | 키워드 층 2s(동사 중심) + 실제 앱 화면 층 2s |
| 22–26s | 약속 | 2층. 혜택 한 줄을 둘로 나눕니다 |
| 26–30s | 엔드 | 26.8s까지 로고 안착(0.8s 이내), 30초까지 약 3초 정지 |

## 3. 움직임 규칙
- **카메라**: 멈추지 않고 계속 전진합니다. 회전과 기울임은 쓰지 않습니다.
- **입장**: 층이 약 60%에서 100%까지 1.0초에 자랍니다. 이징은 감속입니다.
- **통과**: 이후 0.5초에 600–900%까지 커지며 6–12px 모션 블러를 입고 사라집니다.
- **빈 프레임 금지**: 다음 층이 이전 층 통과 중에 이미 올라와 있어야 합니다.
- **블러 위치**: 읽히는 구간에는 블러를 두지 않습니다. 블러는 통과 구간에만 씁니다.
- **금지**: 튀는 이징, 층당 4어절 이상, 초당 4비트 초과, 푸시 대신 컷, 푸시 안의 작은 본문 글씨.
- **사운드(선택)**: 층마다 짧은 whoosh, 강조어마다 저음 히트 한 번입니다. 음악이나 효과음은 공급 또는 동의 후에만 생성합니다.
- **내레이션**: 있으면 키네틱 글자를 자막 역할로 쓰고, 별도 번인 자막과 같은 문구를 중복하지 않습니다.

## 4. 검수 기준
**스타일 규칙**
- 모든 층이 정지에 가까운 상태에서 0.5초 이상 읽힙니다.
- 빈 프레임이 없습니다.
- 강조색이 층당 한 번뿐입니다.
- 엔드 로고가 선명하고 2초 이상 유지됩니다.
- 비트가 있다면 컷이 ±2프레임 안에 들어옵니다.

**가독성과 안전**
- 글자 대비는 큰 글자 3:1 이상, 작은 글자 4.5:1 이상입니다.
- 글자가 안전 여백을 넘거나 잘리지 않습니다.
- 스트로브나 초당 3회 이상의 깜빡임이 없습니다.
- 휴대폰 크기로 축소해서도 읽힙니다.

**사실성**
- 지어낸 통계, 기능, 성능 주장이 없습니다.
- 모든 문구가 브리프나 사용자가 공급한 말에서 나왔습니다.
- 앱 화면은 실제 캡처이고 권리 문제가 없습니다.

**프레임 확인**
- 각 층의 입장 직후, 정점, 통과 중 프레임, 전환 겹침 프레임, 엔드 카드 첫 프레임과 마지막 프레임을 직접 봅니다.
- 1배속 전체 재생을 한 번 확인합니다.
- 판정은 `pass / pass_with_notes / needs_revision`으로 남깁니다.
