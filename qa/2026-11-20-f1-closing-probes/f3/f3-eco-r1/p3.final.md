## 1. 인제스트·멀티캠 정렬 (편집 전 0단계)

| 항목 | 계획 |
|---|---|
| 필수 입력 | Cam A 1개 파일, Cam B 1개 파일, 별도 오디오(있다면 마스터 오디오), 화자 이름/마이크 소유자(선택) |
| 구조 판별 | 전사 겹침을 **먼저** 확인 — 같은 말이 같은 시각에 있으면 별개 앵글, 공유 발화 없이 시간만 이어지면 재시작된 카메라 1대 |
| 금지 | 오프셋 짐작, 조용한 타임 스트레치. 오프셋이 흘러가면 `나쁜 매칭/클럭 드리프트/프레임 드롭`으로 보고 |
| 타임라인 구조 | ① 동기화 마스터(불변) ② 컷 초안(별도 타임라인). 중첩 멀티캠 객체 생성 안 함 |
| 싱크 검수 | 각 앵글의 시작·중간·끝에서 립싱크 ±1프레임. 신뢰도 낮은 매칭은 숨기지 말고 목록화 |
| 기록 | 원본 ID·버전·시간 basis·FPS/PTS를 컷 행마다 연결 |

2인 2캠이면 보통 Cam A=진행자, Cam B=게스트 고정이므로 **화자 추적 컷 초안**을 여기서 뽑아 두면 이후 숏츠 편집이 그대로 재사용됩니다.

## 2. 후보 발굴 — 단어 시간 전사가 선행 조건

- 단어 타이밍이 있는 전사(호스트/제공자 기능)를 씁니다. **프레임만 보고 말을 짐작하지 않습니다.** 자동 캡션은 발화 시각의 근거로 쓰지 않습니다.
- 후보표를 **먼저** 만들고, 그다음에 자릅니다. 후보표 없이 편집을 시작하지 않습니다.

**후보표 필드 (행 = 후보 1개)**

| 필드 | 내용 |
|---|---|
| 시작–끝 시각 | 전사 기준 소스 타임코드 (측정값) |
| 훅 줄 | 전사에서 **그대로 인용**한 첫 문장 |
| 단독으로 서는 이유 | 원본 없이 이해되는 이유 1문장 |
| 점수 | 0–100 |
| 위험 | 앞 맥락 필요 / 사적 인물 지칭 / 오디오 불명확 / 내부 개그 참조 |

**선별 신호 / 위험 신호 (09a 시작값)**

| 구분 | 기준 |
|---|---|
| 강한 신호 | 첫 1–3초 훅, 분명한 결말, 감정·대비, 구체적 예시나 숫자 |
| 위험 신호 | 앞 맥락 필수, 목차식 요약, 끊긴 엔딩, 다른 화자 질문이 없으면 무의미한 답변 |
| 밀도 | 원본 5–10분당 약 1개 → 60분이면 **대략 6–12개 후보**, 최소 4개 제시. 할당량이 아니므로 강한 순간이 적으면 그렇게 보고 |
| 길이 | 후보당 20–75초, 요청 없이 90초 초과 금지 |
| 총량 상한 | 숏츠 합계 ≤ 원본 길이의 1/2 (상한이지 목표 아님) |

**2인 대화 특유의 선별 규칙**
- 질문-답변 구조로만 성립하는 후보는 훅 3초 안에 질문 한 줄을 넣거나 탈락시킵니다.
- 두 사람이 동시에 웃거나 겹치는 순간은 후보로 좋지만, 첫 컷이 와이드여야 하므로 훅 설계를 따로 적습니다.
- 상대를 특정할 수 있는 사적 언급·실명·민감 주제는 `위험`에 적고, 점수와 별개로 하드 컷 판단 대상으로 둡니다.

## 3. 사용자 선택 게이트

후보표를 제시하고 **사용자가 고릅니다**. 내가 점수로 대신 결정하지 않습니다. 선택 후 편집 순서:

1. 후보 **1편만 먼저 완성** → 스타일(컷 리듬·자막·레이아웃) 승인
2. 승인된 스타일로 나머지를 배치 (승인 전 일괄 제작 금지)

## 4. 숏츠 1편 편집 계획 (선택된 후보마다)

| 단계 | 계획 값 (시작값, 브리프 우선) |
|---|---|
| 오프너 | 실제 발화 인용 훅으로 시작. 첫 줄이 훅인지 검수 |
| 다듬기 | 군말·긴 공백 제거, 자연스러운 숨은 유지. **단어 중간 절단 금지** |
| 멀티캠 컷 초안 (16:9 프로그램) | 한 화자 말할 때 클로즈업 / 겹침·웃음·오프닝은 와이드 / 반응 샷은 듣는 사람 클로즈업 0.5–1.0초, **눈에 보이는 반응이 있을 때만** |
| 컷 타이밍 | 새 화자가 말하기 시작한 뒤 4–8프레임 또는 숨에서 컷. 최소 샷 1.5초(반응 샷만 예외). 두 목소리 0.8초 초과 겹침 → 와이드. 반응 샷 분당 2개 이하. 긴 발언은 20–40초마다 와이드로 끊기 |
| 9:16 재프레이밍 | **얼굴·화면 내용의 실제 위치를 확인한 뒤** 결정. 2인이면 위아래 적층 레이아웃이 시작값, 한 명이 화면을 독점하면 얼굴 추적 크롭. 확인 없는 중앙 크롭 금지 |
| 자막 | 전사 단어 시간에 맞춰 하단 1/3 배치, 플랫폼 UI와 겹치지 않게. 스타일·이중 언어 여부는 선택 사항(별도 craft) |
| 오디오 | 대화 우선. 음악이 대사보다 크게 깔리지 않게. 사용 음원은 권리 상태 기록(`unknown`이면 게시 가능으로 주장 안 함) |
| 속도 | 샷당 `playback_rate` 하나. 한 샷 안 속도 곡선을 계획표 값으로 주장하지 않음 |
| 전환 | 하드컷 기본. J/L을 쓰면 프레임 오프셋 기록(다음 샷 소리 4–12f 선행 등). 나쁜 컷을 디졸브로 가리지 않음 |
| 금지 | 모든 클립 쓰기, 화자 잘리는 크롭, 얼굴 위 스티커, 말하지 않은 말·수치 추가 |

**컷 표 필드 (측정 후 채움)** — 지금은 빈 상태로 유지:

`cut_id | shot_id/asset_id | source_in_s | source_out_s | playback_rate | final_start_s | final_end_s | 컷아웃→컷인 phase·state + cue time + 컷 이유 | transition/duration_s | sound_id·sync anchor | reaction/settle hold final start–end s·연속성/검수 상태`

시퀀스 리듬 곡선은 선언하지 않으므로 리듬 대조표는 `N/A`(단일 정점 강조 브리프가 아니면 불필요).
