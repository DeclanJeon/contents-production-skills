## 1. 스타일 선택: 플랫 비트 (Flat Beat)

| 후보 | 판정 | 이유 |
|---|---|---|
| **플랫 비트** | **채택** | 단색 컷마다 1–3단어, 비트에 하드컷, 워드마크 1.5초 엔드카드 — 앱 런칭 30초의 정보 리듬과 정확히 맞음 |
| 푸시인 타이포 | 기각 | 6–15초 기능 한 줄용. 30초에서는 카메라 전진이 단조로워지고 증거 컷을 넣을 자리가 없음 |
| 셔터 밴드 | 기각 | 전환(띠)이 주인공이 되어 기능 증거 3개를 보여줄 여백이 사라짐 |

**탈출 조건 하나**: 플랫 비트는 그라디언트·사진·그림자를 금지한다. 앱 화면 증거는 **평면·하드엣지 UI 카드**로만 넣는다(그림자·베벨·블러 0, 실제 화면 비율 유지). 이건 스타일 위반이 아니라 규칙 준수 방식이다.

## 2. 모션 언어 상수 (작품당 하나씩, 전 컷 고정)

| 항목 | 값 |
|---|---|
| 이징 | 등장 `cubic-bezier(0.34,1.56,0.64,1)`(백아웃, 오버슈트 ≤6%) / 퇴장 `cubic-bezier(0.4,0,1,1)` — **두 곡선만** |
| 시간 단위 | 0.3s = 8분음표(100BPM). 큰 이동 0.6s(1비트), 미세 0.15s |
| 전환 | **하드컷만**. 크로스페이드·와이프·모션블러 전환 0 |
| 스태거 | 글자 40ms, 줄 120ms, 카드 내부 300ms |
| 강도 | 키네틱 × 날카로움 (회전 0, 블러 0, 오버슈트 ≤6%) |
| 홀드 규율 | 컷 첫 프레임부터 읽힘, 단어 컷 ≥0.5s 완전 정지, 비트 뒤 0.3s 정지 |
| 위계 | 히어로(단어) → 서포트(라벨·숫자) → 텍스처(없음). 히어로가 먼저 움직이고 먼저 멈춤 |
| 반복 모티프 | 앱 아이콘 실루엣 하나 — 워드마크까지 동일 형태로 운반 |
| 금지 | 컷당 4단어 초과, 한 화면 3색 초과, 초당 4비트 초과, "와우" 순간 2개, 그라디언트·사진·그림자·외곽선 |

**화면 구성 규칙(16:9)**: 안전 여백 96px(5%), 하단 120px 텍스트 금지(플랫폼 UI·캡션), 텍스트 블록 상하 ≥160px. 단어 컷 = 중앙 정렬, 단어 폭 40–55%, 180–260px. 겹줄 = 100–120px, 최대 3줄. 증거 컷 = 12열 격자(텍스트 2–6열 / UI 카드 7–11열, 카드 높이 720px=프레임 67%). 팔레트 = 주1+강조2+중립1: 크림 `#F7F1E8` / 네이비 `#16213E` / 코랄 `#FF5A5F` / 민트 `#2EC4B6`, 샌 `#FFD166`은 포인트 1회용. 브랜드 색 공급 시 1:1 치환하고 바탕·잉크 비율은 유지.
