# 커피 추출 온도, 몇 도가 정답일까? — 물 온도 실험으로 알아본 맛의 차이

## 1. 왜 물 온도가 중요한가

커피 추출은 결국 **물이 커피 입자에서 향미 성분을 녹여내는 화학 반응**입니다. 온도가 오르면 추출 속도가 빨라지고, 녹아나오는 성분의 종류와 비율도 달라집니다.

- 온도가 **낮으면**: 산미·단맛 계열이 중심, 바디감은 가볍고 텁텁함이 적음. 대신 과소추출(언더) 위험.
- 온도가 **높으면**: 추출량이 늘어 단맛·바디감이 살아나지만, 과추출(오버)로 쓰고 떫은 맛이 붙기 쉬움.

즉 "정답 온도"는 하나의 숫자가 아니라, **원두·분쇄도·비율과 맞물리는 변수**입니다.

## 2. 실험 설계 (영상 기준)

| 항목 | 조건 |
|---|---|
| 원두 | [원두명 / 로스팅 레벨 / 배전일] |
| 분쇄도 | [분쇄 설정값 — 온도 비교 시 고정] |
| 비율 | [예: 1:15] |
| 물 온도 | [예: 80℃ / 85℃ / 90℃ / 95℃] |
| 총 추출 시간 | [예: 2:30 고정 또는 동일 드로우다운] |
| 컵/필터 | [V60, 칼리타 등] |

**핵심 원칙**: 온도만 변수로 두고 나머지는 전부 고정. 시간까지 함께 늘리면 무엇 때문인지 알 수 없습니다.

## 3. 온도별 컵의 변화

- **80℃대**: 향이 닫혀 있고 산미가 도드라짐. 깔끔하지만 밍밍하다는 느낌, 단맛이 잘 안 올라옴.
- **85℃대**: 밸런스 구간. 산미와 단맛이 함께 서고 잡미가 적음. [영상에서 가장 좋은 평가를 받은 온도]
- **90℃대**: 바디감과 단맛이 확실히 살아남. 대신 쓴맛·떫은 맛이 슬슬 따라붙음.
- **95℃ 근처**: 향은 강렬하지만 과추출 성향. 드로우다운이 느려지고 뒷맛이 무거워짐.

## 4. TDS(농도)와의 관계

맛의 인상은 **추출 수율과 농도**로 설명됩니다. 온도가 올라가면 같은 레시피에서도 TDS와 수율이 함께 상승하는 경향이 있습니다. [영상 측정값: 온도별 TDS ○○% / 수율 ○○%]

여기서 중요한 건 **"높은 수율 = 좋은 커피"가 아니라는 점**입니다. 이상적인 구간을 넘어서면 수율이 높아도 맛은 떨어집니다. 온도는 그 구간 안으로 밀어 넣는 **가속 페달**에 가깝습니다.

## 5. 실전 결론

1. **기준점을 먼저 잡으세요.** 90℃, 1:15, 중간 분쇄로 한 잔을 내려 "내 기준 컵"을 만듭니다.
2. **한 번에 5℃씩만 움직이세요.** 80→95처럼 크게 건너뛰면 원인 파악이 안 됩니다.
3. **증상별 처방**
 - 너무 밍밍하고 산미만 튄다 → 온도 +3~5℃
 - 쓰고 텁텁하고 목이 칼칼하다 → 온도 -3~5℃ 또는 분쇄도 살짝 굵게
4. **로스팅 레벨과 상관관계를 보세요.** 라이트 로스팅은 높은 온도에서, 다크 로스팅은 낮은 온도에서 균형이 잡히는 경향이 있습니다.
5. **드리퍼 예열을 빼먹지 마세요.** 예열을 안 하면 실제 추출 온도가 설정값보다 크게 떨어져 실험이 무의미해집니다.

## 6. 마무리

온도 실험의 진짜 수확은 "몇 도가 맛있다"가 아니라, **내 레시피에서 온도가 어떤 방향으로 맛을 밀어내는지 감각을 얻는 것**입니다. 같은 90℃라도 원두가 바뀌면 결과는 달라집니다. 오늘 내린 한 잔이 밍밍했다면, 그라인더를 만지기 전에 주전자 온도부터 5℃ 올려보세요.
