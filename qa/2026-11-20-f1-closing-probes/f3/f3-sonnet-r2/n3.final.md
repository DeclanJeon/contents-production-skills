# 커피 추출 온도, 정말 맛이 달라질까? 실험 정리

## 1. 들어가며
- 같은 원두인데도 내릴 때마다 맛이 다르게 느껴진 적이 있나요?
- 영상은 물 온도 하나만 바꿔서 맛이 얼마나 달라지는지 확인한 실험입니다.

## 2. 실험 조건
- 원두: (품종/로스팅 정도)
- 분쇄도, 원두량, 물량, 추출 시간: (동일하게 고정)
- 비교한 온도: (예: 80℃ / 90℃ / 96℃)
- 추출 방식: (핸드드립 / 에어로프레스 등)

## 3. 온도별 결과
| 온도 | 맛·향 | 산미 | 쓴맛 | 바디감 |
|---|---|---|---|---|
| 낮음 | | | | |
| 중간 | | | | |
| 높음 | | | | |

## 4. 왜 이런 차이가 나는가
- 온도가 낮을수록 성분이 덜 녹아 나와 **과소추출**이 되기 쉽고, 시고 밋밋한 맛이 날 수 있습니다.
- 온도가 높을수록 쓴맛 성분까지 많이 추출되어 **과다추출** 느낌이 날 수 있습니다.
- 로스팅 정도에 따라 적정 온도 범위가 달라집니다. 일반적으로 라이트 로스트는 높은 온도, 다크 로스트는 낮은 온도가 잘 맞습니다.

## 5. 영상의 결론
- 가장 좋았던 온도: (입력 필요)
- 원두별 추천 온도: (입력 필요)

## 6. 집에서 따라 해보기 팁
1. 온도계로 물 온도를 확인합니다.
2. 한 번에 한 가지 변수만 바꿉니다.
3. 맛 메모를 남겨 내 취향 온도를 찾습니다.

## 7. 마무리
작은 온도 차이도 컵 속 맛을 바꿉니다. 내 원두에 맞는 온도를 찾아보세요.
