## 1. 선택: **셔터 밴드**(키네틱 타이포 계열)

30초 16:9 앱 런칭에 이걸 고르는 이유:
- 장면 유지가 **1.2–1.8초**라 30초 안에 메시지 사다리(문제→전환→혜택→약속→로고)를 읽을 시간이 확보된다. 플랫 비트·에코 스택은 0.5–0.9초 컷 전제라 30초에 30컷 이상이 되어 16:9 히어로 영상에서 싸구려로 떨어진다.
- **띠 자체가 전환이자 반복 모티프**다. 30초물에서 가장 흔한 실패(무관한 타이틀 카드 나열)를 구조적으로 막는다.
- 타이포만으로 성립해서 앱 화면 캡처·촬영본이 없어도 오늘 계획이 완결된다.

러너업(지금은 쓰지 않음): **푸시인 타이포** — 같은 브랜드의 6–15초 티저를 따로 만들 때. **플랫 비트** — 마스터가 15초 세로 소셜일 때. 한 작품에 두 계열 섞지 않는다.

## 2. 화면 구성

- 캔버스 1920×1080, 30fps, 16:9 (브랜드/채널 규격이 있으면 그쪽이 우선).
- **행 시스템**: 화면을 전폭 3행으로 나눈 띠 구조. 어두운 행/밝은 행 교대, 한 화면에 3행 초과 금지. 헤드라인은 2행(중앙) 고정.
- 타이포: 단어는 응축 대문자 **180–220px**, 문장은 굵은 그로테스크 **130–150px**, 행간 0.95. 문장은 5단어·2줄 이내, 응축 단어는 8자 이내.
- 정렬: 문장은 좌측 고정선(x=96) 왼쪽 정렬, 단어 하나는 행 축 중앙. 둘 중 하나만 끝까지 유지.
- 팔레트 시작값: 네이비 `#0E1A2B` / 아이보리 `#F2EEE6` / 포인트 1색(예 `#FF5A1F`). 총 3색, 포인트는 **장면당 요소 1개**만. 브랜드 색이 오면 포인트만 1:1 치환.
- 좌우 5% 안전 여백. 로고는 클리어스페이스 0.5×높이 확보, 띠가 로고를 덮지 않는다.
- 생존 모티프: 얇은 마키 단어 띠 하나(제품 카테고리 단어, 등속 흐름). 3–4막에서만 지속.

## 3. 움직임·타이밍

모션 상수(작품 전체 1개씩): 기본 단위 **450ms**, 이징은 **엑스포 아웃(등장) + 인(퇴장/셔터)** 두 곡선만, 전환은 **셔터 밴드 단독**, 스태거 30–40ms, 오버슈트 0%(기계적 정밀감).

## 4. 검수 기준

- [ ] 유지 첫 프레임부터 단어가 읽히고, 정착 후 정지 ≥0.6초
- [ ] 컷이 비트 ±2프레임, 컷 직전 띠가 프레임을 100% 덮음(부분 노출 ≤1프레임)
- [ ] 15초당 셔터 ≤4회, 장면당 포인트 요소 1개
- [ ] 응축 단어 8자 이내, 장면당 5단어·2줄 이내, 잘린 글자 없음
- [ ] 색 3종 이내, 팔레트 밖 색 없음(브랜드 색 제외), 텍스트 대비 ≥4.5:1
- [ ] 이징 2곡선 이내, 길이가 450ms 배수의 의도된 값인가(떠돌이 linear/ease 없음)
- [ ] 이음매 ±5프레임 훑어 빈·중복 프레임 없음
- [ ] 엔드카드: 로고 무왜곡·클리어스페이스 확보, 태그라인 2초+ 정지, 정지 프레임 폴백 존재
- [ ] 텍스트는 라이브 텍스트(이미지에 굽지 않음), 렌더는 Remotion/FFmpeg 레인
- [ ] 스펙: 정확히 30.0초, 1920×1080, 30fps, Rec.709 태그
- [ ] 모션 감소 버전: 띠 이동·스태거 끄고 장면 컷 + 로고 정지로 별도 납품
- [ ] 9:16 컷다운 시 중앙 60% 안에서 재레이아웃 없이 읽힘

결함→결정: 띠가 산만하면 셔터 회수 감소·마키 제거 / 무게 없음 → 행 진입 450ms와 가감속 조정 / 텍스트 안 읽힘 → 유지 연장·대비 상향(카피 단축은 허용될 때만) / 슬라이드쇼 같음 → 띠로 운반되는 연속 요소 하나 지정.
