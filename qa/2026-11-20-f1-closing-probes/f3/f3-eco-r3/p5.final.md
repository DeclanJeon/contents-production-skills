## 라우팅

- **deliverable_kind**: `one_production_asset` (자막·로어서드 룩 규칙) → **R13**
- **media_axis**: `text_only` (파일 생성 없음, 요청대로 채팅 텍스트만)

- 크래프트: `23a-captions-layout` (자막 스타일·이중 언어 자막·로어서드) / 내용·타이밍·접근성 정본은 `15-delivery`

## A. 한영 이중 자막 규칙

### A-1 구조

- **2줄 고정**: 위 줄 = 실제 발화 언어, 아래 줄 = 번역. `[발화 언어]`는 확정 필요(원본 오디오 확인 전 추정 금지) — 지금은 "위=발화, 아래=번역"의 규칙만 고정.
- 언어당 **한 줄**, 총 2줄. 3줄 금지. 원문이 길면 줄 폭이 아니라 **문구를 구절 단위로 쪼개 이월**한다.
- 이름·고유명사·단위·직함은 용어집이 그대로 두는 것은 번역하지 않는다.
- 번역은 말한 것보다 **더하지 않는다**(추론·보충·윤문 금지). 원문 의미를 지우는 요약 대체 금지.

### A-2 룩 시작값 (1080p 기준)

| 항목 | 값 |
|---|---|
| 배경 패널 | `rgba(14,18,16,.66)`, 반경 16px, 하단 15% 안전 영역 중앙 |
| 원문 | 굵은 산세리프 `#FFFFFF`, 44–54px, 발화 중인 단어만 `#FFD45C` |
| 번역 | 같은 폭·원문 크기의 약 70%(32–38px), `#D9E6DC`, 얇은 이탤릭 세리프 또는 같은 산세리프 |
| 줄 폭 상한 | 화면 폭의 약 62%(1080p ≈ 1200px) |
| 글자 수 | 라틴 약 42자 / **한글 22–26자**(같은 폭에서 환산한 추정값) |
| 글꼴 | 한글·라틴 두 체계를 모두 덮는 조합(예: 라틴 Inter + 한글 Pretendard). 폴백 렌더 확인 필수 |
| 위치 | 얼굴·입·플랫폼 UI 회피. 하단 3분의 1의 가슴 높이 |

2160p는 전 항목 ×2(비례 확대, 파생값).

**대비 주의**: 패널 알파 `.66`은 밝은 배경 위에서 대비가 떨어진다. 실제 프레임에서 일반 텍스트 4.5:1·큰 텍스트 3:1(WCAG 1.4.3) 미달이면 알파를 올리거나 그림자를 더한다 — 색만으로 정보를 구분하지 않는다(1.4.1).

### A-3 타이밍·모션

- 쌍은 **구절 첫 단어에 컷으로 진입**, 페이드는 150ms 이내.
- 원문 강조는 **측정된 단어 타이밍**을 따른다(±3프레임). 균등 분배 금지.
- 번역은 원문보다 **120–250ms 늦게** 올라 위 줄이 먼저 읽히게 한다.
- 쌍 교체는 **구절 경계에서만**, 2–3프레임 간격. 구절 중간 교체 금지.
- 1초 넘는 침묵에서는 자막을 비운다(필요한 소리 표기는 `15` 우선).
- 번역이 원문 구절보다 오래 남지 않는다.
- 타이밍은 **최종 음성에서 실측**한다. 원고 글자수로 역산해 프레임 정확 동기라고 하지 않는다. 최종 음성이 없으면 `provisional`로 표시하고 동기화는 미검증.

### A-4 금지 / 검수

- 금지: 얼굴·입 위 자막, 3줄, 강조색 2개 이상, 말을 바꿔 쓴 자막, 용어집이 지키는 이름의 번역.
- 검수: 1배속에서 모든 쌍을 두 번 읽을 수 있는가 / 번역이 원문보다 더하지 않았는가 / 빠진 글리프가 없는가 / 강조가 발화 단어에 ±3프레임인가 / 밝은·어두운 배경 프레임에서 실제 가독.
- 대사 번역만으로 완전한 captions라고 하지 않는다(1.2.2). 의미 있는 웃음·박수·한숨 등은 표기 대상으로 별도 판단.

## B. 하단 이름 자막(로어서드) 규칙

### B-1 문구 규칙 (가장 중요)

- 철자·구두점까지 **사용자가 준 그대로** 쓴다. 대문자 처리만 스타일로 한다.
- **직함·소속·성을 지어내지 않는다.** 둘째 줄이 없으면 사용자 표현으로 쓰거나 뺀다.
- 이름·직함은 실제 인터뷰 대상에게 확인된 값만. 미확인 상태는 `[직함]` 플레이스홀더로 두고 임의 기입 금지.

### B-2 룩 시작값

| 항목 | 값 |
|---|---|
| 캔버스 | 1920×1080 / 30fps / 알파 포함 별도 파일, **약 8초** |
| 시간 구성 | 진입 1초 이내 → 정지 유지 5–6초 → 퇴장 0.5초 |
| 위치 | 좌하단, 모든 픽셀 **가장자리에서 5% 이상 안쪽** |
| 이름 크기 | 50–80px(1080p), 굵은 산세리프 |
| 직함 크기 | 이름의 약 절반(25–40px), 낮은 대비의 밝은 회색 |
| 패널·띠 | 글자 뒤 불투명 패널 또는 띠 + 진한 그림자. 어떤 배경에서도 읽히게 |
| 점유율 | 프레임의 몇 %만. **중앙·화자 얼굴은 비운다** |
| 오디오 | 무음 |

### B-3 모션

- 움직임은 **진입·퇴장에만**. 유지 구간은 정지(느린 광택 하나까지 허용).
- 진입 300–400ms, 이즈 아웃. 퇴장은 진입만큼 깨끗하게.
- **첫·마지막 프레임은 비워** 편집에서 튀거나 잘리지 않게.
- 소개 시점에 한 번 등장이 기본. 재등장은 화자 전환이 화면에서 불명확할 때만.

### B-4 금지 / 검수

- 금지: 글자 넘침·잘림(긴 이름은 박스에 맞춰 축소, 닦임·클립은 가장 넓은 항목 기준), 폴백 글꼴로 그려짐, 사진 위 얇고 연한 글자 직접 얹기, 내려가는 구식 숫자 세리프(숫자 포함 카드에서는 라이닝 숫자 글꼴).
- 검수: 가장 긴 항목 포함 모든 카드의 **정지 프레임**에서 어두운·밝은 배경 모두 읽히는가 / 간격이 고른가 / 실제 글꼴이 로드됐는가 / 진입·퇴장 프레임 시트에서 글자가 패널 밖으로 먼저 나오지 않는가 / 퇴장이 깨끗한가.

### B-5 알파 납품(참고)

편집 도구 미정이므로 형식은 미확정으로 둔다. Premiere·Resolve·FCP → ProRes 4444 `.mov`, OBS·웹 → WebM(+Safari HEVC 사본), 알파 미지원 폰 편집기 → 초록 바탕 MP4. 알파 없는 H.264를 배경색 없이 내보내지 않는다. 실제 규격은 목적지 확인 시 확정(`15`).

## C. 두 요소의 관계

- **동시 노출 금지.** 로어서드 유지 구간에는 이중 자막의 패널을 비우거나 자막을 로어서드 위 라인으로 올린다(겹침 시 로어서드가 아래).
- 로어서드는 **얼굴 반대편**, 이중 자막 패널은 하단 중앙. 두 요소가 같은 하단 띠를 나눠 쓰지 않는다.
- 카드 계열은 영상 전체에서 **하나만** 쓴다(숫자 카드·인용 카드·로어서드 중 계열 통일).

## D. 정본 위임 · 열린 사실

- 자막 내용·타이밍·`caption_mode`(none/sidecar/burned_in)·접근성은 `15-delivery`가 정본. 이 문서는 룩·배치만 정한다.
- **placeholder(진행 비차단)**: `[화면비/플랫폼]` — 플랫폼 규격·읽기 속도 상수는 목적지 확인 전 `unverified`, 숫자 발명 금지. `[브랜드 글꼴·색]` — 승인된 브랜드가 있으면 위 값보다 우선. `[발화 언어]` — 원본 오디오로 확인. `[이름·직함]` — 대상자 확인 필요.
- **게이트 아님, 사실 확인**: 인터뷰 대상이 제3자면 그 발화·이름·직함의 사용(초상·음성·실명) 동의 상태는 별도 확인 항목이다. 이 턴은 텍스트 규칙만 반환하며 동의를 추정하지 않는다.

파일은 만들지 않았다.
