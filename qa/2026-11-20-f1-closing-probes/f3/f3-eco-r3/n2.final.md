# 로고 시안 01 — 가칭 「온기 (ONGI)」

## 컨셉
"따뜻함이 머무는 온도" — 커피잔의 김(steam)과 건물의 아치창(카페 파사드)을 하나의 형태로 겹친 심볼. 김은 위로 흐르는 두 줄기, 아치는 반원. 결과적으로 **잔 + 문 + 온도계 눈금**이 동시에 읽히는 이중 은유.

## 심볼 구조
- 반원 아치(지름 : 높이 = 2 : 1) 하나
- 아치 내부에서 위로 솟는 곡선 2줄 — 좌측은 짧고 굵게, 우측은 길고 가늘게(비대칭으로 온도 상승감)
- 아치 하단 중앙에 짧은 수평선 1개 → 받침/눈금 역할
- 선 두께는 아치 8pt, 김 5pt, 받침 3pt로 3단 위계

## 타입
- 워드마크: 세리프 계열 라이트(예: Noto Serif KR Light / Playfair Display Light), 자간 +8%
- 아치 곡률을 워드마크 베이스라인에 미세하게 반영(가운데 글자가 1px 정도 올라간 형태)
- 서브라인 "COFFEE & SLOW MORNING" — 산세리프, 자간 +20%, 8pt

## 컬러
| 역할 | 색 | HEX |
|---|---|---|
| 메인 | 딥 브라운 | `#3E2A21` |
| 서브 | 크림 배경 | `#F4EDE3` |
| 포인트 | 번트 오렌지 (김 끝단만) | `#C56A3A` |

## 레이아웃
- **A형(주 사용)**: 심볼 상단 + 워드마크 하단, 세로 정렬
- **B형(간판/컵)**: 심볼 좌 + 워드마크 우, 가로 정렬
- **C형(파비콘/스탬프)**: 아치만 남긴 단색 1도 버전

## 적용 메모
- 최소 사이즈: 심볼 8mm / 디지털 24px까지 판독 가능하도록 선 두께 유지
- 컵 슬리브·명함은 크림 배경 + 브라운 1도, 야간 간판은 브라운 배경 + 크림 역상
- 김 곡선은 로고 모션(인스타 스토리 오프닝)에서 0.6초 상승 애니메이션으로 확장 가능

## 리스크 체크
- 아치+김 조합은 카페 업계에서 흔한 축 → 차별점은 **김 2줄의 비대칭 리듬**과 세리프 워드마크의 곡률에 둠
- 상표 검색 시 "아치형 창 + 김" 유사도 상위에 몰릴 가능성 있음, 등록 전 유사상표 조회 권장
