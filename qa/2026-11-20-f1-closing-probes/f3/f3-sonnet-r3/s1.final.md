# 《첫 잔의 온도》 — 30초 카페 브랜드 영상

**로그라인:** 아무도 오기 전 이른 아침, 한 바리스타가 정성껏 내린 첫 잔이 누군가의 하루를 데운다.

| 항목 | 내용 |
|---|---|
| 포맷 | 9:16 세로, 30초, 5씬 / 11컷 |
| 스타일 | 따뜻한 실사 시네마틱, 아침 햇살, 얕은 심도 |
| 구조 | 하루의 의식형: 준비 → 추출 → 건넴 → 여운 → 로고 |

| 평가 | hook 70 / 실현성 85 / 감정 80 / 독창성 60 / 일관성 85 / 플랫폼 적합 90 → **go** |

*추정값(inferred):* 톤, 길이 배분, 무대사 구성은 제가 정한 제안입니다. 바꾸고 싶으면 알려주세요.

## 1. 시놉시스
새벽빛이 드는 카페에서 바리스타가 문을 열고 앞치마를 맨다. 원두를 갈고 에스프레소를 내려 라떼를 만든다. 완성된 잔이 손님의 손으로 건너가고, 김이 오르는 컵을 감싸 쥔 손에서 하루가 따뜻해진다. 마지막에 브랜드 로고가 뜬다.

## 2. 후킹 (0:00–0:03)
- 첫 이미지: 햇빛 속에 먼지가 떠다니는 창가, 손이 `CLOSED` 팻말을 `OPEN`으로 뒤집는다.
- 자막: 없음. 소리로 시작한다(문 종소리, 원두 소리).
- 시청자가 품을 질문: ① 누구의 아침일까? ② 이 잔은 누구에게 갈까? ③ 어떤 맛일까?

| 5–13 | S2 추출 | 그라인더, 에스프레소, 증기 너머 미소 |
| 13–21 | S3 라떼 | 스팀 우유, 라떼아트, 건넴 |

| 27–30 | S5 로고 | 브랜드 로고와 슬로건 |
