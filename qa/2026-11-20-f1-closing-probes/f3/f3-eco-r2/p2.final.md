# 30초 16:9 앱 런칭 — 모션 스타일 확정안

## 1. 선택: 키네틱 타이포 › **셔터 밴드**

키네틱 타이포 계열 14종 중 **셔터 밴드** 하나로 갑니다.

- 요구(30초·16:9·런칭·키네틱)를 동시에 만족하는 유일한 조합: 강한 단어 3–6개 + 약속 + 로고로 구성되고, **전환과 타이포가 한 계열**이라 "전환 계열 하나" 규칙을 스스로 지킴.
- 30초를 감당함: 장면당 행 3개 → 문구 유지 → 밴드 셔터로 교체. 비트 수(7비트)와 타이포 밀도가 서로를 잡아먹지 않음.
- 실패 조건이 숫자로 측정됨: 밴드가 프레임을 **완전히 덮은 뒤** 교체, 장면당 포인트 요소 1개, 색 3개 이하. 검수 기준을 문장이 아니라 프레임으로 쓸 수 있음.

건너뛴 계열(이름만): **플랫 비트**(비트마다 하드컷 — 30초 내내 컷이 필요해 앱 메시지 7개엔 과밀), **푸시인 타이포**(6–15초 티저용, 30초에서 "카메라는 멈추지 않는다"가 단조로워짐), **매니페스토 팝**(제품 공개 중심이라 출시 메시지 구조가 좁음).

**이 선택의 대가(명시):** 셔터 밴드는 **타입 전용 문법**이라 실제 앱 UI 화면을 화면에 넣지 않습니다. 앱 실화면이 반드시 보여야 하면 이 계열이 아니라 제품·커머스 계열로 바꿔야 하고, 그건 스타일 재선택입니다.

## 2. 모션 시스템 (작품 전체에서 하나씩만)

| 축 | 값 (시작값) | 규칙 |
|---|---|---|
| 이징 | 등장 `expo-out` 450ms / 퇴장·셔터 `expo-in` 300–350ms | 곡선은 이 둘만. 세 번째 곡선 금지 |
| 기본 시간 단위 | 0.35초 | 모든 길이는 이 단위의 배수 |
| 전환 계열 | **가로 밴드 셔터 하나만** | 와이프·스핀·페이드 추가 금지 |
| 스태거 | 밴드 30–40ms / 행 450ms | 두 스태거 외 새 리듬 금지 |
| 모션 강도 | 키네틱 × 날카로움 (오버슈트 0%) | 행은 튕기지 않고 안착. 로고만 스케일 1.04→1.00 허용 |
| 홀드 규율 | 문구 유지 1.8초 + 완전 정지 0.35초 | 읽는 중 텍스트는 절대 움직이지 않음 |
| 타이밍 기준 | **장면 로컬 프레임** 하나 (30fps = 900프레임) | 음악을 쓰면 BPM 실측 후 셔터 피크 8개를 비트에 재배치. 두 기준 혼용 금지 |

## 3. 화면 구성 (룩 바이블)

- **캔버스**: 1920×1080, 30fps, 30.00초(900f).
- **팔레트 3색 고정**: 배경 다크 `#0E1A2B`, 라이트 `#F2EEE6`, 포인트 1색 `#FF5A1F`(브랜드 색이 있으면 이 3개만 1:1 교체). 그라디언트·그림자·사진·글로우 없음.
- **행 구조**: 프레임을 가로 전폭 행 3개로 쌓음 — 히어로 행 30%(324px) / 서포트 행 22%(238px) / 라벨 행 12%(130px). 행은 좌우 끝까지 블리드, **글자만** 타이틀 세이프 96px 안쪽.
- **명암 교차**: 다크 행(네이비 바탕+아이보리 글자) ↔ 라이트 행(아이보리 바탕+네이비 글자)을 장면마다 번갈아. 한 장면에 한쪽만 씀.
- **타입**: 히어로 = 응축 굵은 대문자 180–220px, **행당 8자 이하**; 서포트 = 굵은 그로테스크 130–150px; 라벨 = 42–56px, 자간 −1~−2%, 행간 0.9.
- **시선 닻 1개**: 히어로 행만 "움직이는 것"이고 서포트·라벨은 안착 후 완전 정지.
- **포인트 요소**: 장면당 정확히 1개(포인트 색 단어 하나, 또는 포인트 색 사각 표식 하나).
- **마키**: 히어로 행 안에서 단어 하나가 좌→우 등속으로 흐르는 변주(장면 2개까지만, 등속은 이 요소에만 허용).

## 5. 움직임 상세

**셔터 밴드 (전환 전담)**
- 6장, 각 180px, 30–40ms 간격으로 순차 진입 → 300–350ms에 화면 도달. **0.30초 시점에 프레임 100% 피복** 후 반대편으로 퇴장하며 다음 장면 노출.
- 진입은 `expo-in`(가속), 퇴장은 `expo-out`. 셔터에 회전·블러 추가 금지.
- 셔터 피크는 장면 로컬 0.30초 = 계획된 비트 위치. 8개 모두 같은 방식.

**행 등장**
- 읽는 순서(바탕 → 히어로 → 서포트 → 라벨)대로 450ms 간격, 각 행 `expo-out` 450ms, 이동 24px 이하(세로), 스케일 0.96→1.0.
- 3행이 동시에 뜨지 않음. 안착 후 완전 정지.

**히어로 마키 / 포인트 요소**
- 마키는 등속(등속 허용 예외), 포인트 표식은 히어로 안착 200ms 뒤 한 번만 등장.

**엔드카드 (로고 모션)**
- 기법은 **하나만**: 워드마크 글자별 스태거(80ms, 0.5초, 스케일 0.85→1). 아이콘은 왜곡 없이 등장(스케일·페이드만). 스큐·스쿼시 금지.
- 0.8초 안착, 2.25초 정지, 마지막 프레임이 진짜 완성 로고(반쯤 그려진 획 없음). 클리어스페이스 안에 모션 잔해 금지.
- 모션 감소 대응 납품용으로 "정지 로고만" 경로를 별도로 둠.

**금지 목록**
프레임 전체 동시 이동 / 와이프+스핀+페이드 겹치기 / 읽는 중 텍스트 루프 / 행 오버슈트 / 회전·기울임 / 장면당 포인트 2개 / 색 4개 이상 / 8자 초과 응축 단어 / 지어낸 수치·후기 / 장면 사이 빈 프레임 / 공간 이동에 linear(마키 제외) / 15초당 셔터 4회 초과.
