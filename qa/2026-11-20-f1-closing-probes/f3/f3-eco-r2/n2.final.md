**컨셉: "MORNING SLOW" — 필기체 워드마크 + 단순 아이콘**

| 항목 | 내용 |
|---|---|
| 네임 | SLOW MORNING (가칭, 한글 병기: 슬로우 모닝) |
| 심볼 | 커피잔 손잡이를 반원으로 말아 올린 형태 + 그 위로 김 대신 해가 떠오르는 반원 1개. 선 두께 균일(2.5pt), 선 끝 라운드 |
| 조판 | 심볼 좌측, 워드마크 우측 가로 조합. 워드마크는 세리프 계열 소문자(slow morning) 자간 +40 |
| 컬러 | 메인 다크브라운 #3E2A1E / 포인트 테라코타 #C8794F / 배경 크림 #F5EEE4 (2색 사용, 심볼은 단색) |
| 형태 원칙 | 24px에서도 읽히도록 곡률 최소화, 그라데이션·그림자 없음 |
| 응용 | ① 원형 엠블럼(잔+해를 원 안에) ② 워드마크 단독(컵 리드·영수증용) ③ 반전 흰색 버전(유리문 사인) |
| 금지 | 사진 질감, 커피콩 여러 개 흩뿌리기, 얇은 헤어라인 |

원하시면 이 브리프를 이미지 생성용 프롬프트로 바꿔드리거나, 네임·컬러 방향을 다른 안(모던 미니멀 / 빈티지 스탬프 / 손그림 라인)으로 2~3개 더 뽑아드릴 수 있습니다.
