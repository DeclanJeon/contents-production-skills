## 실제 참조 도달 확인

각 loaded child의 보존된 session.jsonl에서 read/grep 도구 인수를 직접 확인했다. 답안의 ‘참조를 읽었다’는 자기 주장만 센 것이 아니다.

|case|실제 조회|
|---|---|
|A|공통 참조→performance-and-style의 heading 검색 및1–38행 부분 읽기|
|B|performance-and-style 전체 read|
|C|공통→world-rules-and-information 전체 read|
|D|공통→world-rules-and-information 전체 read|
|E|공통 read,두 상세 참조 read 없음|

따라서 새로운 상세 참조가 실제 네 적용 과제에서 도달 가능했고 비적용E에서 상세 읽기/기법 강제가 없었다. 조회 자체가 실제 화면 성공/품질 상승의 증거는 아니다. 문구 강제/금지 microtest는 새 강제 행동을 도입하지 않아 별도 실행하지 않았다.
