# 조건부 후보의 별도 텍스트 적용

부모가 원작과 다른 브리프에 작성한 짧은 설계 사례다. fresh control/loaded5쌍과는 다른 자료이며, 독립 최종검토자가 결과와 근거 한계를 대조한다. 실제 이미지/재생은 없다.

## V1 — 분실물 보관표의 기억/복귀

가상 브리프: 현재 역무원이 왼쪽 모서리가 찢어진 보관표를 쥐고 있고, 물건을 맡던 이전 순간을 떠올린다.
- 현재: 손이 보관함 잠금 앞에서 멈추고 표의 찢긴 모서리와 현재 함 위치가 보인다.
- 과거: 같은 표가 온전한 채 다른 손에서 넘어오고, 당시 보관함에 물건을 넣는 행동과 필요한 언어적 기억 단서로 이전 상황임을 제안한다. 색만으로 분류하지 않는다.
- 복귀: 찢긴 표와 잠금 앞의 멈춘 손으로 돌아와 현재 선택을 잇는다. 과거의 온전한 표가 현재의 수리/새 표 생성이 되지 않는다. 실제 연대·기억의 진위는 브리프 밖이면 확정하지 않는다.
검수: 현재 행동의 중단/재개와 각 시간선 물체 상태를 연결할 수 있는지. 실제 이미지의 판독·초수는 미검증.

## V2 — 가림을 이용한 허용된 로봇 형상 변화

가상 브리프: 작은 우편 로봇이 사각 몸에서 원통 몸으로 바뀌며, 녹색 세로선과 식별 번호·운반 중 봉투는 유지된다. 변형 중간의 생략은 허용된다.
- 가림 전: 사각 몸·선/번호·봉투 소유와 이동 방향을 세운다.
- 경계: 로봇이 기둥 뒤로 진입하고 일부가 가려지는 상태를 둔다. 변형 자체가 보였다고 서술하지 않는다.
- 재등장: 원통 몸이 같은 이동 목적을 이어받고 선/번호·봉투가 보존된다. 주변 인물은 새로운 개체가 아니라 수행을 이어가는 로봇에게 다음 일을 건넨다.
검수: 몸 형태는 승인 델타,나머지 앵커/소유는 유지 속성이다. 이3상태는 연속 morph의 증명이 아니다. 실제 중간 접힘 시연을 요구하는 다른 브리프에는 이 생략안을 통과로 쓰지 않는다.

## V3 — 기록 보존의 분업

가상 브리프: 두 인물이 접힌 큰 기록지를 손상시키지 않고 읽어 필요한 내용을 옮긴다.
- A가 접힌 부분을 허용 범위에서 펼쳐 지지하는 동안 B는 드러난 구역을 읽고 별도 종이에 기록한다. 구역이 가려져 있을 때부터 기록이 완성되어 있지는 않다.
- B가 읽기 위치를 옮기면 A도 지지 구역을 조절한다. 기존 찢김을 수리한 것으로 만들지 않으며 두 인물의 손/대상을 구별한다.
- 필요한 기록이 끝난 뒤 A가 접고 B가 새 기록을 챙긴다. 원본과 새 기록의 소유/상태를 각각 잇는다. 전체 목표 성공은 요청 범위의 기록 완료까지만 제안한다.
검수: 서로 다른 수행·도움을 받는 단계·지속 의존·해제 시점이 읽히는지. 단순히 둘이 동시에 몸을 움직이는 것과 구별하며 실제 손/종이 접촉 성립은 미검증.
