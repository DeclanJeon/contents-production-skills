# 12초 단일 정적 교육 화면 — 배치·검수 지시

## 기본 룩
- 0–12초 동안 같은 화면을 유지한다. 왼쪽에 승인된 유입량 도표, 오른쪽에 승인된 유출량 도표를 둔다. 두 도표는 동시에 보이며 위치·강조가 바뀌지 않는다.
- 두 영역의 상단과 바깥 여백을 정렬하고 중앙에 간격을 둔다. 도표는 원래 비율을 유지하며 축·범례·단위·수치가 잘리거나 가려지지 않게 배치한다. 균형을 맞추려 내부 축척이나 도형 크기 관계를 바꾸지 않는다.
- 배경은 도표와 경쟁하지 않는 단순한 면으로 한다. 승인된 색·선·기호는 보존하고, 좌우 구별을 새 색상에만 의존시키지 않는다. 수치의 대소·증감·인과는 추가로 해석하지 않는다.

## 주요 대비 축: 위치와 언어 역할
- **화면:** 왼쪽/오른쪽의 위치와 분리된 영역으로 두 도표를 구별한다. 각 도표 안에서는 승인된 데이터의 관계를 보여준다.
- **문자:** 기존 제목·범례·축·단위·수치는 정확한 명칭과 값을 맡는다. 기존 제목으로 식별이 어렵다면 도표 밖 영역 표제로만 ‘유입량’/‘유출량’을 제안한다. 원문을 덮거나 도표 내용을 고치지 않는다.
- **내레이션:** 「왼쪽은 유입량, 오른쪽은 유출량입니다.」를 그대로 유지한다. 말은 공간과 개념의 대응을 명시한다. 화면만 보는 검수는 시각적 구별을 점검하는 방법이지 내레이션 삭제 지시가 아니다.

## 지금 확인 가능한 것
- 문안상 좌=유입량·우=유출량의 대응, 12초 단일 정적 화면이라는 조건, 승인 내용·내레이션 불변 원칙을 대조할 수 있다.
- 인물·갈등·코미디·마법·카메라 이동·추가 컷·새 제작 단계는 넣지 않는다.
- 혼동 시 먼저 좌우 배치·간격·표제의 대응을 바로잡는다. 설명문이나 장식을 늘려 덮지 않는다.

## 미확인 사항: 실제 자료가 필요한 검수
- **승인 원본 이미지:** 승인본과 수치·축·단위·범례가 일치하는지, 최종 표시 크기에서 작은 글자와 기호가 읽히는지, 잘림·왜곡·가림이 없는지 확인한다. 제목과 색상 상태는 현재 추정하지 않는다.
- **실제 녹음과 12초 표시 재생:** 발화가 정확하고 잘리지 않는지, 지칭하는 좌우와 화면이 맞는지, 듣는 동안 두 도표를 찾아 읽을 여유가 있는지 확인한다.
- 원본 이미지·녹음이 없으므로 실제 가독성·발화 길이·시청 시 이해도는 미검증이다. 문제가 있으면 먼저 외부 여백·배치·허용 범위의 표시 크기를 조정하며, 승인 내용 변경이 필요한 문제는 임의 수정하지 않고 남긴다.
