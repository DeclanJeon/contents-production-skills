# 2D 러프 콘티 — 4패널

**공통 연출 제안**: 막대 자체를 효과 도구로 정한다. 방에서 들판으로 화면 왼쪽→오른쪽 통과. 같은 옆시점과 화면 크기를 유지한다. 원형 경계 바깥 왼쪽은 붉은 벽 방, 원 안쪽 오른편은 푸른 하늘 아래 들판이다. 방의 문틀·노란 표지는 왼쪽 위, 들판의 세 갈래 표지목은 원 안 오른쪽 위에 고정한다. 초록 리본 인물은 한 명, 같은 막대를 계속 오른손에 든다. 들판의 금속컵과 옆 천은 떨어뜨려 놓되 효과 범위에는 함께 들어오게 한다. 대사·자막·음향 지시 없음.

### P1 — 통과 전 / 비교 기준
- **그림·프롬프트**: 2D 선 러프, 공유 와이드. 두 공간과 양쪽 앵커가 보인다. 초록 리본 인물은 전신이 방 쪽에 있고, 오른손의 막대 끝을 원 쪽으로 향한다. 들판의 금속컵 표면에는 흰 선이 없고 옆 천의 주름도 또렷하다. 효과는 없다.
- **읽힐 것**: 출발지·도착지와 변화 전 상태. 시선은 인물→원→컵으로 잇는다.

### P2 — 부분 통과 / 경계의 가림
- **그림·프롬프트**: P1과 같은 구도·앵커. 초록 리본 인물의 머리·상체·오른손과 막대 앞부분은 들판 쪽, 뒷다리와 막대 뒤끝은 방 쪽에 남는다. 원의 가까운 테두리가 허리와 막대 중간의 짧은 부분만 가린다. 리본·손의 쥠·막대 굵기는 그대로. 컵과 천은 아직 무변화.
- **전환**: 몸의 위치 변화로 왼쪽→오른쪽 통과를 보인다. 가려진 부분을 복제 인물이나 끊어진 막대로 그리지 않는다.

### P3 — 발원과 선택 대상
- **그림·프롬프트**: 같은 앵커와 부분 통과 자세를 유지. 오른손 막대 끝에서 나온 옅은 효과 띠가 금속컵과 옆 천 위에 함께 겹친다. 컵 표면에만 흰 선 하나가 보이고 천은 기존 주름·색 그대로다. 막대 끝→효과 범위→컵의 흰 선을 한 화면에서 연결한다.
- **주의 초점**: 컵의 흰 선을 가장 선명하게, 효과 띠는 약하게 그려 표면 변화와 발광을 구별한다.

### P4 — 효과 종료 / 잔류 상태
- **그림·프롬프트**: 같은 구도·양쪽 앵커·초록 리본 인물·오른손 막대·부분 가림 유지. 효과 띠와 막대 끝 발광은 사라지고, 금속컵의 같은 위치에 같은 흰 선이 남는다. 옆 천은 P1과 같은 색과 주름이다.
- **이후 상태**: 완전 통과나 복귀는 추가하지 않는다. 이번 시연의 잔류만 보이며 모든 천의 영구 면역으로 확대하지 않는다.

**읽힘 보완**: 경계가 평면 그림처럼 보이면 몸·막대의 가림 접점을 먼저 다듬고, 흰 선이 반사광처럼 보이면 P1·P4의 동일 구도 대비를 강화한다. 텍스트 연출 제안이며 실제 그림의 가독성·3D 성립·시간 재생은 검증하지 않았다.
