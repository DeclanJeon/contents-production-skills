# 앱 런칭 영상 30초 16:9 — 키네틱 타이포 모션 스타일 제안

## 선택: 푸시인 타이포를 기본으로, 셔터 밴드를 섹션 전환에 보조로 사용

- **푸시인 타이포**: 카메라가 큰 단어 층을 계속 뚫고 전진해서 로고에 도착하는 방식입니다. 이 스타일 자료는 앱·SaaS 런칭 티저를 쓰는 곳으로 명시합니다. 멈추지 않는 전진감이 "런칭"과 잘 맞고, 16:9 가로 화면에서 큰 글자 층이 깊이감을 만듭니다.
- **셔터 밴드**: 가로 색 띠가 지나가며 장면을 바꿉니다. 30초 안에서 호흡을 끊어 주는 용도로만 1~2번 씁니다.
- **대안**
  - 플랫 비트: 경쾌한 트랙에 컷을 맞추는 방식입니다.
  - 벨로시티 라인: 속도·성능이 핵심 메시지일 때 씁니다.

이 문서의 시작값은 모두 `inferred`(제안)이며 승인된 것이 아닙니다. 브랜드 키트가 있으면 색과 글꼴은 키트를 우선합니다.

## 1. 화면 구성

| 항목 | 시작값 |
|---|---|
| 해상도·프레임 | 1920×1080, 30fps (`inferred`) |
| 바탕 | 종이색 `#F2EEE6` 단색 |
| 글자 | 굵은 그로테스크 대문자(한글은 굵은 고딕), 잉크 `#16161A`, 층당 2~3단어 |
| 포인트 | 핵심어에만 `#F0532B`, 지나가는 노랑 `#F7C534` 슬래시 |
| 정렬 | 모든 층을 같은 축 중앙에 둡니다. 푸시인이 "뚫고 지나가는" 느낌을 내려면 축이 일정해야 합니다. |
| 셔터 띠 | 네이비 `#0E1A2B`와 같은 포인트색 계열 |
| 엔드 카드 | 정상 크기의 로고, 제품명, 한 줄 약속 |

- 한 화면에 포인트색은 하나만 씁니다.
- 앱 화면(UI) 컷이 필요하면 푸시인 끝에 실제 스크린샷 한 장을 안착시키는 정도로 제한합니다.
- UI는 공급된 실제 화면만 씁니다. 지어낸 화면은 쓰지 않습니다.

## 2. 30초 구성안 (타임라인은 제안)

| 구간 | 시간 | 내용 | 모션 |
|---|---|---|---|
| ① 문제 | 0–6s | 문제 단어 2~3개 (예: 사용자가 겪는 불편) | 층 푸시인 2~3개. 각 층이 1.0초에 60%→100%로 자랍니다. |
| ② 전환 | 6–8s | 셔터 밴드로 어두운 장면 → 밝은 장면 | 띠가 300–350ms 동안 들어옵니다. |
| ③ 해결 | 8–16s | 앱이 해결하는 핵심 동사·혜택 3개 | 푸시인 3층. 마지막 층 뒤에 포인트색 단어가 등장합니다. |
| ④ 증명 | 16–23s | 실제 앱 화면 1~2컷 + 짧은 캡션 | 마지막 푸시인 층이 화면 카드로 안착한 뒤 1.5초 이상 유지합니다. 수치는 공급된 값만 씁니다. |
| ⑤ 약속 | 23–27s | 한 줄 약속 문장 (3단어 이하 층으로 분할) | 푸시인 2층 |
| ⑥ 엔드 | 27–30s | 로고, 제품명, 한 줄 약속, 필요하면 출시일·스토어 안내 | 0.8초에 안착한 뒤 2초 이상 유지합니다. |

- 카피(단어)는 사용자가 줘야 합니다. 이 구간표는 틀일 뿐이고, 문구·수치·출시일·스토어 정보는 지어내지 않습니다.
- 원 스타일은 6~15초 티저용입니다. 30초로 늘리면서 층 개수와 증명 구간을 추가한 부분은 제 확장 제안입니다.

## 3. 움직임 규칙

- **카메라**
  - 멈추지 않고 계속 전진합니다.
  - 회전·기울임은 쓰지 않습니다.
- **층 입장**
  - 0.8–1.2초 동안 약 60%→100%로 커집니다.
  - 읽히는 정지 구간은 0.5초 이상입니다.
- **층 퇴장**
  - 0.4–0.6초 동안 600–900%로 커지며 6–12px 모션 블러를 입고 사라집니다.
- **겹침**
  - 다음 층이 150–250ms 일찍 올라와 빈 프레임이 없게 합니다.
- **슬래시**
  - 노랑 슬래시는 날아 지나가는 장식으로만 씁니다.
- **셔터**
  - 30초 안에 2회 이하로 씁니다.
  - 띠 간격은 30–40ms입니다.
  - 교체 전에 프레임을 완전히 덮어야 합니다.
- **음악·사운드**
  - 컷과 층 교체를 박자에 맞춥니다.
  - 트랙이 없으면 생성하지 않고, 있으면 BPM을 먼저 잰 뒤 맞춥니다.

## 4. 피할 것

- 초당 4비트를 넘기는 과속

## 5. 검수 기준

**프레임 단위 확인** (정지 프레임을 직접 보고 판단합니다)
- [ ] 각 층이 정지 상태에서 0.5초 이상 읽히는가
- [ ] 영상 어느 프레임에도 빈 화면이 없는가
- [ ] 셔터 교체 직전에 띠가 프레임을 완전히 덮는가
- [ ] 엔드 카드의 로고가 선명하고 2초 이상 유지되는가
- [ ] 글자가 프레임 가장자리에서 잘리지 않는가 (16:9 안전 여백 포함)

**내용**
- [ ] 모든 수치·사양·날짜가 사용자가 준 값과 같은가
- [ ] 화면에 보이는 앱 UI가 실제 앱 화면인가
- [ ] 장면당 포인트 요소가 하나인가
- [ ] 문제 → 해결 → 증명 → 약속의 흐름이 소리 없이도 읽히는가

**타이밍·시청 환경**
- [ ] 컷과 층 교체가 박자와 ±2프레임 안에 있는가 (음악이 있을 때)
- [ ] 글자와 바탕 대비가 충분한가 (최소 3:1 이상)
- [ ] 무음으로도 메시지가 전달되는가
- [ ] 블러나 플래시가 반복·점멸처럼 느껴지지 않는가

## 6. 진행 전에 필요한 것

1. 브랜드 키트: 색·글꼴·로고. 있으면 위 팔레트를 포인트색 일대일 교체로 대체합니다.
2. 앱 이름, 핵심 혜택 3개, 한 줄 약속, 출시일·스토어 정보
