Using creative-production, 모션 스타일 선택 경로(키네틱 타이포 계열)로 정리했습니다. 파일은 만들지 않았고 실행·생성·지출은 하지 않았습니다.

## 1. 선택: 푸시인 타이포 (주력)

**이유:** 앱 런칭 티저에 맞는 스타일이고, 카메라가 큰 단어 층을 계속 뚫고 전진하다 로고에 도착하는 구조입니다. 키네틱 타이포의 "글자 자체가 움직임"이라는 요구를 가장 직접 충족합니다.

**주의:** 원 스타일은 6–15초 기준입니다. 30초는 아래처럼 **4막으로 나누고, 중간에 실제 앱 화면을 같은 푸시 축 위의 층으로 끼우는 확장**을 제안합니다. 이 확장은 제 설계이고, 스타일 원본에 있는 값이 아닙니다.

**대안:**
- 음악 비트가 확정되어 있으면 **플랫 비트**(경쾌한 소비자 앱, 비트에 하드컷)가 낫습니다.
- 성능·속도가 핵심이면 **벨로시티 라인**이 낫습니다.

**추정으로 채운 값:** 해상도 1920×1080, 30fps, 카피는 자리표시자입니다. 브랜드 키트가 있으면 아래 색·글꼴보다 **항상 우선**합니다.

## 2. 화면 구성

| 항목 | 시작값 |
|---|---|
| 바탕 | 종이색 `#F2EEE6` 단색 |
| 글자 | 굵은 그로테스크 대문자, 잉크 `#16161A`, 레이어당 **2–3단어**, 중앙 동일 축 |
| 강조 | 핵심어만 `#F0532B`, 날아 지나가는 노랑 `#F7C534` 슬래시 (화면당 강조 하나) |
| 글자 크기 | 층 정지 시 프레임 폭의 60–80%. 앱 화면 층의 보조 라벨은 1080p 기준 36px 이상 |
| 여백 | 타이틀 안전영역(가장자리 약 5–10%) 안에 핵심어 배치 |
| 앱 화면 층 | 실제 앱 화면을 16:9 프레임 안에 정면 배치. 목업 로렘 입숨 금지 |
| 엔드 카드 | 정상 크기 로고 + 앱 이름 + 한 줄 약속 |

## 3. 움직임과 타임라인 (30초)

**공통 규칙**
- 카메라는 멈추지 않습니다. 회전·기울임은 쓰지 않고, 푸시 대신 컷을 쓰지 않습니다.
- 각 층은 0.8–1.2초에 약 60%→100%로 자랍니다. 정지 상태에서 **0.5초 이상** 읽혀야 합니다.
- 이후 0.4–0.6초에 600–900% 크기로 6–12px 블러를 입고 지나가며 사라집니다.
- 다음 층은 150–250ms 겹쳐 올라와 **빈 프레임이 없게** 합니다.

| 구간 | 내용 | 비고 |
|---|---|---|
| 0:00–0:05 | **훅.** 문제 단어 층 3개 | 첫 층은 시작 직후 읽혀야 함 |
| 0:05–0:11 | **전환.** 핵심 동사 층 2–3개 | 여기서 주황 강조 처음 사용, 노랑 슬래시 1회 |
| 0:11–0:23 | **기능 3개.** 각 약 4초: 단어 층 1–2개 → 실제 화면 층 | 화면 층은 정지 후 0.5초 이상 유지, 탭·상태 변화 1회까지만 |
| 0:23–0:27 | **약속.** 층 2개 | 마지막 층이 로고로 이어지는 연결점 |
| 0:27–0:30 | **엔드 카드** | 0.8초에 안착, **2초 이상 유지**, 마지막 프레임은 정지 |

**음향:** 층 교체와 비트를 맞춥니다(층 전환 ±2프레임). 음악이나 SFX를 새로 생성하려면 별도 동의가 필요합니다.

## 4. 피할 것
- 레이어당 3단어 초과, 푸시 안의 작은 본문
- 정지 없이 계속 지나가기만 하는 구간(읽을 시간 부족)
- 강조색 둘 이상
- 지어낸 수치·평점·순위
- 입점하지 않은 스토어 배지
- 일반 페이드 전환

## 5. 검수 기준
1. **가독성:** 모든 층이 정지 상태에서 0.5초 이상 읽히는가. 빈 프레임이 없는가.
2. **간격:** 층 겹침이 150–250ms인가.
3. **비트:** 전환이 음악 비트 ±2프레임인가.
4. **엔드 카드:** 로고가 선명하고 2초 이상 정지하는가.
5. **사실:** 화면이 실제 앱과 같은가. 숫자·문구가 공급된 값과 같은가.
6. **안전영역:** 핵심어와 로고가 잘리지 않는가.
7. **축소 확인:** 모바일 크기로 줄여도 읽히는가.
8. **프레임 단위:** 키 프레임(첫 층, 전환점, 화면 층 도착, 엔드 카드)을 프레임 단위로 확인했는가.
9. **길이:** 총 길이가 30.0초 ±0.5초인가.

## 6. 확정에 필요한 입력
- 앱 이름과 로고
- 실제 앱 화면 3장
- 카피 비트(사용자가 쓴 말로 10–12개 내외)
- 브랜드 색과 글꼴
- 음악 유무와 BPM
- 스토어 입점 여부

이 입력이 오면 층별 대본(단어, 길이, 프레임 번호)과 Remotion/FFmpeg용 제작 명세까지 이어서 만들 수 있습니다.
