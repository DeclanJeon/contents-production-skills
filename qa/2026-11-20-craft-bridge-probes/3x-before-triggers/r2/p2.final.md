**선택: 푸시인 타이포를 기본으로 하고, 기능 소개 구간에만 셔터 밴드식 전환을 보조로 씁니다.**

- 푸시인 타이포는 앱·SaaS 런칭 티저용 스타일이고, 카메라가 큰 단어 층을 뚫고 전진해 로고에 도착합니다. 원래 6~15초용이라 30초에 맞게 구간을 나눴습니다.
- 셔터 밴드는 가로 색 띠가 전환과 타이포를 겸합니다. 푸시인만 30초 동안 이어 가면 단조로워서 중반 기능 구간에서만 씁니다.
- 아래 수치와 색은 스타일 라이브러리의 시작값입니다. 브랜드 색과 글꼴이 있으면 그것이 우선합니다.

## 1. 화면 구성 (1920×1080, 16:9, 30fps)
- **바탕:** 종이색 `#F2EEE6` 단색, 잉크 `#16161A`.
- **강조색:** 핵심어에만 주황 `#F0532B`을 씁니다. 노랑 `#F7C534` 슬래시는 날아 지나가는 장식으로만 씁니다. 한 장면에 강조는 하나입니다.
- **글자:** 굵은 그로테스크 대문자(한글은 같은 굵기의 고딕)로 레이어당 2~3단어를 씁니다. 모든 레이어는 같은 중심축에 둡니다.
- **안전 여백:** 좌우 약 10%, 상하 약 8%를 둡니다. 큰 단어는 프레임을 가득 채우되 글자가 잘리면 안 됩니다.
- **앱 화면:** 실제 UI 캡처를 한 장의 "레이어"로 취급해 같은 푸시인으로 통과시킵니다. 이 화면은 사용자가 제공해야 합니다.

## 2. 타임라인 (30초)
| 구간 | 내용 | 움직임 |
|---|---|---|
| 0–3초 | 훅: 문제 단어 1~2개 | 60%에서 100%로 자라며 등장 |
| 3–9초 | 문제와 전환: 단어 레이어 2~3장 | 푸시인으로 연속 통과 |
| 9–12초 | 제품 공개: 앱 이름과 앱 화면 첫 등장 | 단어 레이어에서 UI 레이어로 푸시인 |
| 12–24초 | 핵심 기능 3개, 각 약 4초 | 기능마다 "단어 한 개와 UI 한 컷", 기능 사이는 셔터 밴드 전환 |
| 24–30초 | 엔드 카드: 로고, 제품명, 한 줄 약속 | 0.8초에 안착해 2초 이상 정지 |

카피는 아직 없으므로 단어는 모두 자리표시입니다. 사용자가 준 문구만 씁니다.

## 3. 움직임 규칙
- **푸시인:** 레이어가 0.8~1.2초에 약 60%에서 100%로 자랍니다. 이어서 0.4~0.6초에 600~900%로 6~12px 블러를 입고 지나가며 사라집니다.
- **겹침:** 다음 레이어는 150~250ms 겹쳐 올라와 빈 프레임이 없게 합니다.
- **카메라:** 멈추지 않고, 회전·기울임은 쓰지 않습니다.
- **셔터 전환(기능 구간만):** 띠가 300~350ms 동안 30~40ms 간격으로 들어와 장면을 덮고 반대쪽으로 나갑니다. 30초에 3~4회를 넘기지 않습니다.
- **이징:** 튀는 이징은 쓰지 않습니다. 감속 위주(ease-out)로 갑니다.
- **음악:** 컷은 비트에 둡니다. 음악이 없으면 먼저 사용자 동의를 받아야 하며, 합의 전에 생성하지 않습니다.

## 4. 하지 말 것
- 레이어당 3단어 초과, 푸시인 안의 작은 본문
- 푸시 대신 컷으로 넘기기
- 강조색 2개 이상
- 지어낸 수치·성능·수상 같은 문구. 숫자는 출처가 있는 값만 씁니다.

## 5. 검수 기준
1. 모든 단어와 UI가 정지 상태로 0.5초 이상 읽히는가 (훅은 0.7초 이상 권장).
2. 빈 프레임이나 검은 프레임이 없는가.
3. 컷과 전환이 비트 ±2프레임 안에 들어가는가.
4. 글자가 잘리지 않고 안전 여백을 지키는가.
5. 셔터 띠가 교체 전에 프레임을 완전히 덮는가.
6. 엔드 카드의 로고가 선명하고 2초 이상 정지하는가.
7. 총 길이가 30.0초(±0.5초)인가.
8. 장면당 강조색이 하나인가. 글자와 바탕 대비는 3:1 이상인가.
9. 키 프레임을 프레임 단위로 직접 확인했고, 확인하지 못한 부분을 기록했는가.
10. 모든 문구와 수치가 사용자가 제공한 근거와 일치하는가.

## 6. 진행에 필요한 입력
- 앱 이름과 로고
- 3~5개 카피 비트
- 핵심 기능 3개
- 앱 화면 캡처
- 브랜드 색·글꼴
- 음악 유무

이 입력이 오면 장면별 카피와 타임코드를 확정한 스토리보드로 이어 갈 수 있습니다. 제작 실행(렌더링)과 음악 생성은 별도 승인이 필요합니다.
