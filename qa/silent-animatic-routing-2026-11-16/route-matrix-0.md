# 현행 라우팅 적용 결과

요청은 **라우팅 시험**이다. 아래는 실제 전문 작업자에게 전달할 수 있는 배정안이며, 이야기 집필·제작 실행 결과가 아니다. 네 사례 모두 영상 기획이므로 `creative-production`의 범위·승인 해석은 활성화하되, 프로젝트 초기화나 실제 작업자 호출은 하지 않는다. 실제 승인자는 미지정이다. A2의 v17 승인은 제공된 조건으로 보존하며 재승인하지 않는다. 단계 ORDER는 별도로 요청되지 않았으므로 전체 제작 순서를 추가하지 않는다.

## A1 — 새 무대사 서정 드라마, 6비트

- **요청 산출물 / 현재 단계:** 각본·보드 이전의 새 시각 서사 6비트 텍스트 계획.
- **PRIMARY:** `silent-visual-storytelling`. 일반 개념·비트 맵보다 무대사 시각 서사 요청에 해당하는 좁은 배정을 적용한다.
- **의존성:** 비트 구성의 기존 깊은 소유자는 `developing-video-synopses`/02이다. 필요한 이야기 설계에 한정하며 각본 03, 연기 04, 보드 06을 별도 산출물로 자동 확장하지 않는다. `animatic-direction`과 로컬 풍자 포맷은 불필요하다. 단일 산출물이므로 `orchestrating-video-preproduction`의 다중 패키지 경로도 불필요하다.
- **입력 패킷:** “6비트, 서정적 드라마, 새 이야기, 대사 없음, 보드·각본 없음, 텍스트만.” 길이·인물·구체 소재는 미정/제안으로 표시한다. 대사 금지를 완전 무음·내레이션 금지·비언어 발성 금지·화면 글자 금지와 동일시하지 않는다. 미정 요소에 설명 기능을 몰래 맡기지 않는다.
- **출력 패킷:** B1–B6별 시작 상태, 목표/장애, 보이는 자극→선택→결과, 관객 공개/유보, 감정 변화, 구체적인 시선·동작·구도·환경 단서, 다음 비트에 남는 상태, 대안 해석/읽힘 위험. 시간표나 완성 각본은 추가하지 않는다.
- **정지선:** 6비트 계획 제안에서 종료. 실제 이미지 가독성·감정 전달·재생 리듬은 `UNVERIFIED`.

## A2 — 승인 v17의 45초/24FPS 시간표만 수정

- **요청 산출물 / 현재 단계:** 승인 이야기·각본/콘티 v17의 컷·hold·반응 시간화.
- **PRIMARY:** `animatic-direction`.
- **의존성:** 기존 06 샷 큐, 08 포즈/접촉/스페이싱, 09 편집 시간 필드를 소비·갱신 제안한다. 수치표 작성 시 해당 전문의 `timing-and-review.md`가 적용된다. 새 무성 이야기·시놉시스·인물 설계는 의존성이 아니다. 별도 다중 텍스트 패키지도 아니다.
- **입력 패킷:** v17의 실제 beat/shot/panel ID와 승인 참조, 고정 이야기·인물·공개 순서, 필수 행동/결과/잔류 상태, 45초 고정, 24FPS 고정. 오디오 의도·실제 미디어 유무·전환/크레딧의 45초 포함 여부는 제공값 또는 미정으로 전달한다. 이 시험에서는 v17 본문을 읽지 않았으므로 존재만으로 내용을 확인했다고 하지 않는다.
- **출력 패킷:** 원본 ID별 컷 경계, hold 목적, 반응/정착 구간, 컷 이유, 연속 상태와 시간 충돌. **09 최종 시간표 합계는 45초=1080프레임**, 같은 구간을 06/08의 shot-local 값으로 연결한다. 고정 내용을 지킬 수 없으면 충돌 위치와 필요한 승인만 반환한다. 실제 ID가 없어 구체 컷 배분은 만들지 않는다.
- **정지선:** 시간 재배분 제안·재생검수 계획까지. 스토리 재작성·새 카메라 해법·렌더 금지. 실제 재생 리듬은 `UNVERIFIED`.

## A3 — 기존 그림 12장과 확정 이야기를 보존하는 완전 무음 편집

- **요청 산출물 / 현재 단계:** 기존 정지이미지만 사용하는 영상 편집 계획.
- **PRIMARY:** `storytelling-with-still-images`.
- **의존성:** 승인 이야기와 기존 12장 자산 매핑만 필요하다. 새 이야기 작업이 없으므로 `silent-visual-storytelling`을 붙이지 않는다. 무음이라는 이유만으로 `animatic-direction`도 붙이지 않는다. 새 그림·각본·보드나 영상 생성 모델이 필요하지 않다.
- **입력 패킷:** 12장 원본 ID, 확정 이야기 및 승인 순서가 있으면 그 순서, 기존 내용 보존, 새 사건/장면 금지, 인간 발화·음악·효과음·비언어음까지 오디오 없음. 화면 글자/자막은 무음과 별도 조건이며 새 설명을 추가하지 않는다. 길이·FPS·화면비는 미정으로 유지한다.
- **출력 패킷:** 각 hold별 시작–끝(제안), still ID, 기존 이야기 내 기능, hold 근거, 허용 가능한 crop/reframe·cut/dissolve 제안, speech=`없음`, sound=`없음`, 끝맺음. 12장을 빠짐없이 추적하되 한 장당 동일 초수나 정확히 12컷을 강제하지 않는다. 그림은 읽지 않았으므로 내용은 묘사하지 않고 `proposed—not inspected`로 표시한다.
- **정지선:** 편집 큐 계획만. 새 이미지·오디오·MP4 조립 없음. 실제 크롭 가독성·이미지 연결·완전 무음 파일 검증은 `UNVERIFIED`.

## A4 — 90초 직장인 풍자, 로컬 반복개그 포맷

- **요청 산출물 / 현재 단계:** 반복 강화·펀치라인 중심의 로컬 무성 풍자 기획/비트 예산 텍스트.
- **PRIMARY:** `silent-satire-animatic`. 일반 무성 드라마나 승인 보드 시간화로 대체하지 않는다.
- **의존성:** 현재 기획에는 로컬 무성 원칙·풍자 구조·비트 예산 계약이 적용된다. 이 포맷이 요구하는 인기 원천의 실측 조회수·길이 근거는 미제공이다. 원천 발견/선정/수요 검증을 별도로 수행한다면 `topic-demand-selection`, 공개 영상 검색이면 `searching-social-media`가 조건부 의존성이다. 직장인 풍자라는 잠긴 방향은 바꾸지 않으며 이번에는 검색하지 않는다. 캐릭터 팩은 후속 캐릭터 배정/타임라인의 미해결 입력으로 남기고 도형으로 대체하지 않는다.
- **입력 패킷:** 90초 고정, 직장인 행동/현상 풍자, 로컬 반복개그, 텍스트만. 원천 근거·팩·FPS는 미제공. 무성은 인간 발화 부재이며 완전 무음으로 바꾸지 않는다. 로컬 계약상 대사·TTS·내레이션·자막·말풍선 금지, BGM 안내는 계획 요건이다.
- **출력 패킷:** setup/escalate/punchline/resolve 배치안, 동일 동작 3회 이상과 증가하는 변주 축, 첫 `notice` ≤3초, 마지막 `land`, 90초 합계와 22–32비트의 양립 검토. 예컨대 22비트면 평균 약 4.09초이며 개별 2–8초 제약을 별도 확인한다. FPS 미정이므로 프레임 정렬은 미검증으로 남긴다. 실측 원천 없이 ‘인기 검증 완료’ 또는 원천 기반 제작 가능으로 판정하지 않는다.
- **정지선:** 조건부 기획 패킷·누락 입력까지. 원천 근거 부재는 해당 로컬 제작 진행의 차단점이며 새 대본이나 원천을 날조하지 않는다. BGM 합성·캐릭터 생성·타임라인 실행·렌더·썸네일·배포는 하지 않는다.

## 확인 범위

읽은 문서: 현행 `creative-production/SKILL.md`, 정본 `creative-production/references/production-routing.md`, `orchestrating-video-preproduction/SKILL.md`, 위 네 PRIMARY의 `SKILL.md`만. 원본/코퍼스 이미지, 전송 영수증, 테스트, 다른 매트릭스 답안, 리뷰 기대치는 읽지 않았다. 저장한 것은 이 시험 보고서뿐이며 제작 프로젝트·미디어·원장은 생성하지 않았다. 실행 품질·사용자 승인·최종 납품은 검증하지 않았다. `complete`는 네 사례의 라우팅 응답 완료만 뜻한다.
