# 현재 저장소 라우팅 적용 답변

실제 제작이 아닌 요청별 라우팅 모의 적용이다. 아래 배정·입출력은 **제안 패킷**이며 워커를 호출하거나 산출물을 제작했다는 뜻이 아니다. 총괄 활성화도 가상 요청의 판정이다. 이번 실행에서는 이 QA 보고서만 저장한다. 승인자는 별도 지정이 없어 `unassigned`; B4의 기존 승인만 주어진 전제로 보존한다. 실제 프로젝트·아티팩트 ID/버전은 제공되지 않았으므로 발명하지 않는다.

## B1 — 내레이션 설명 영상 각본만

- **산출물/현재 단계:** 확정 주제·사실을 사용하는 내레이션 포함 영상 각본. 일반 글쓰기가 아니라 명시적인 영상 제작용 단일 각본 단계다.
- **총괄:** `creative-production` 활성화, 범위 확인·단일 배정만. 다중 텍스트 레인 `orchestrating-video-preproduction`은 불필요.
- **PRIMARY:** `video-production-assets` **03-screenplay**.
- **의존성:** 제공된 주제·사실·근거 위치와 해당 주장 연결이 필요하다. 사실 주장에는 필요한 범위의 10-evidence를 지원으로 적용하되 새 사실 조사·주제 선정·가상 등장인물은 추가하지 않는다. 주제가 고정되어 `topic-demand-selection`도 불필요하다.
- **입력 → 출력 패킷:** `{확정 주제/사실/출처, 대상·길이·언어의 제공값/미정, 내레이션 유지, 각본만, 콘티·애니매틱 제외}` → `{씬별 장소·시간·목적/화면 행동, 정확한 내레이션, 화면–소리 대응, 주장–근거 연결, 예상 발화시간과 미정 입력}`. 이 테스트에는 실제 주제·사실 본문이 없으므로 내용·근거는 미확인으로 남긴다.
- **정지:** 각본 텍스트에서 끝낸다. `silent-visual-storytelling`과 `animatic-direction`은 배정하지 않는다. 내레이션을 무성 행동으로 대체하지 않는다. 녹음·재생·실측 러닝타임은 `UNVERIFIED`.

## B2 — 대사 있는 일반 드라마 제작용 콘티

- **산출물/현재 단계:** 전체 기술 슬롯을 갖춘 제작용 콘티 설계. 러프 패널이나 애니매틱 단계가 아니다.
- **총괄:** `creative-production` 활성화. 단일 보드이므로 다중 패키지 레인은 불필요.
- **PRIMARY:** `storyboarding-video`, 정본 `storyboard-contract.md` 적용.
- **의존성:** 기존 각본·비트·캐릭터/룩 입력을 소비한다. 03/04/22의 대사·연기·립싱크, 06의 샷/블로킹, 09의 기본 시간·음향, 적용되는 VFX 명세를 보드에 통합한다. 수치 카메라가 필요하면 `camera-spatial-design`; 실제 씬별 3D 배치 검증에 의존할 때만 `blender-previsualization` 검증 요구를 연결한다. 모든 기술 슬롯이 모든 전문가 실행을 뜻하지는 않는다.
- **입력 → 출력 패킷:** `{원문/버전, 대사·화자, 비트/캐릭터/룩, 제작용 목적, 애니매틱·재생시험 제외}` → `{입력·잠금, 전체 beat→scene→shot→panel 커버리지와 씬별 카메라 의도, 전체 샷 기술표, 전체 패널표, 이미지/시트 수 계획과 인계표, KEEP/FIX/미검증표}`. 샷마다 시간·카메라·공간·VFX·발화/립싱크·음향·참조·시작끝 상태를 채우거나 사유 있는 N/A를 쓴다. 모든 발화를 실제 화자·화면 안/밖·구간에 연결하고 중요한 청자 반응을 설계하되 발화마다 별도 두 샷을 강제하지 않는다.
- **정지:** 일반 보드의 시간 필드는 유지하지만 별도 애니매틱 시간화·재생시험 계획은 추가하지 않는다. 무성 서사/애니매틱 전문가는 비활성. 없는 각본·기술 입력은 씬/샷/비트별 단일 요구 패킷으로 반환하며 완성 보드라 주장하지 않는다. 이미지·음성·립싱크·3D·재생 검증은 미실행/미검증.

## B3 — 8분 비풍자 무성 애니메이션 텍스트 패키지

- **산출물/현재 단계:** 새 이야기에서 각본·캐릭터·제작 콘티·애니매틱 시간 설계까지의 다중 텍스트 프리프로덕션. 현재 착수점은 새 무성 이야기 설계다.
- **총괄:** `creative-production` 활성화·단일 총괄 유지.
- **PRIMARY:** 패키지 담당 `orchestrating-video-preproduction`. 무성 이야기의 조건부 전문 오너는 `silent-visual-storytelling`; 각본·캐릭터·완전한 보드의 기존 소유권을 빼앗지 않는다.
- **요청 범위의 의존 순서:** 공유 브리프/무성 제약 → `silent-visual-storytelling` 지원 아래 `developing-video-synopses`의 새 이야기·안정 비트 → `designing-video-character-sheets`와 필수 `designing-character-personas`의 통합 캐릭터 → `video-production-assets` 03 각본 → `storyboarding-video`의 전체 기술 콘티 → `animatic-direction`의 해당 이야기/보드 버전 시간화 → 총괄의 커버리지·인과·연속성·480초 합계 대조. 창작안은 명확한 제안 버전으로 넘기며 사용자 승인으로 둔갑시키지 않는다. 필요한 캐릭터/각본 정합 수정은 해당 의존분만 반영한다.
- **입력 → 출력 패킷:** 공통 `{8분=480초 고정, 새 창작 위임, 비풍자, 무성, 이미지 금지, 요청 단계}`. 무성 전문가는 `{비트별 정보·감정 변화/고정 조건}` → `{보이는 원인→선택→결과, 연기·구도·환경 단서, 공개/유보, 다음 비트 잔류 상태, 대안 해석·미검증}`. 캐릭터는 행동 규칙·표현 브리지를 단일 SSOT에 통합하고 비발화 역할의 보이스는 사유 있는 N/A로 둔다. 보드는 B2의 완전한 계약을 유지한다.
- **시간화 패킷:** `{제안/승인 상태가 명시된 이야기·보드 버전과 beat/scene/shot/panel 연결, 필수 행동·공개·상태 순서, 480초, FPS 미정, 실제 미디어 없음, 오디오 의도}` → `{06 샷 로컬 cue, 08 포즈·접촉·스페이싱, 09 최종 컷/hold/반응·정착 시간, 길이 충돌·연속성·재생검사 상태}`. 최종 시간 정본은 09이며 FPS가 없으면 초 단위로 제안한다.
- **정지:** ‘무성’을 전체 오디오 금지와 혼동하지 않는다. 인간 발화 없는 방향을 보존하고 내레이션·비언어 발성·음악/SFX·자막 허용은 독립 미정값으로 명시한다. 내레이터를 임의로 넣지 않는다. `silent-satire-animatic`의 85–120초/반복개그 규칙은 적용하지 않는다. 이미지·렌더·움직이는 애니매틱은 만들지 않는다. 시간은 제안이며 실제 읽힘·재생 리듬은 `UNVERIFIED`. 실행 시 요구되는 다단계 조정 보조 계약의 가용성도 이번 테스트에서 확인하지 않았다.

## B4 — 승인 광고의 전체 오디오 제거 계획만

- **산출물/현재 단계:** 기존 승인 영상의 제한된 후편집 계획. 화면·이야기 구조는 고정이다.
- **총괄:** `creative-production` 활성화, 기존 승인 범위와 편집 범위만 관리.
- **PRIMARY:** `video-production-assets` **09-edit**.
- **의존성:** 승인본 버전·원본 영상/타임라인·오디오 트랙/스트림 목록. 정지 이미지 전용 편집이라는 근거가 없으므로 `storytelling-with-still-images`로 보내지 않는다.
- **입력 → 출력 패킷:** `{승인본/버전, 화면·컷·구조 잠금, 모든 오디오 제거, 새 각본·콘티 금지}` → `{내레이션·대사·음악·SFX·환경음 및 잔존 트랙 제거 범위, 영상 구간·순서·속도·프레이밍 보존 조건, 원본 보존/별도 출력 방침, 출력 오디오 스트림 부재 및 화면 동일성의 추후 검사 항목}`. 필요한 원본 정보는 미확인으로 적고 실제 구간을 발명하지 않는다.
- **정지:** 무음 편집은 새 무성 서사 의뢰가 아니다. `silent-visual-storytelling`, `animatic-direction`, 새 각본·콘티를 추가하지 않는다. 설명 손실 가능성은 위험으로만 보고하고 화면/이야기를 보완 개작하지 않는다. 실제 제거·인코딩·출력검사 모두 미실행이다.

## 근거와 실행 한계

현재 저장소의 `creative-production/SKILL.md`, `creative-production/references/production-routing.md`, `orchestrating-video-preproduction/SKILL.md` 및 위 배정에 필요한 전문 진입점, 03/09와 보드 계약의 관련 절을 읽었다. 전송 영수증·테스트·다른 매트릭스 답안·리뷰 기대값·원본/코퍼스 이미지는 읽지 않았다. 제작 워커, 미디어 생성, 프로젝트 초기화, 설치, 커밋, 푸시는 수행하지 않았다. 이 답변의 완료는 라우팅 응답 완료이며 품질 승인·제작 완료가 아니다.
