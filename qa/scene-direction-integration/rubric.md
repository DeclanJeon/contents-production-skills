# 씬·컷 통합 제작 V1 — 내용 판정 기준

## 사용법
평가자는 protocol.md와 고정 cases.json을 읽고 실제 입력/원시 출력의 위치를 대조한다. 생성 에이전트에는 이 문서, required_observations, locks, forbidden_expansions, coverage와 검토 카드를 주지 않는다. user_request와 supplied_context만 사용자 입력이다.

모든 required_observations는 해당 과제에 적용되는 필수 관찰이다. R01–R06은 공통 분류이고, 실제 판정 단위는 SD01-O1 등의 개별 관찰이다. case의 rubric_ids에 없는 축은 점수화하지 않는다. 입력 locator의 세미콜론 뒤 축약 이름은 같은 case.supplied_context의 필드다. user_request는 case의 최상위 필드다.

| ID | 대조 대상 | PASS에 필요한 관찰 | FAIL 예 |
|---|---|---|---|
| R01 원문/정본 | 공급 원문·화자·ID/version·순서·잠금과 실제 출력 | 모든 관련 잠금이 일관되고 inherited 사실/새 연출/입력 미확정을 구별 | 원문 변조, 화자/손 바뀜, stale 핀을 현재판으로 취급 |
| R02 인과/인물 | 세계 법칙/상황·목표/관계→선택→행동/대가·후속 | 규칙/지식/성향이 실제 장면의 관찰 가능한 선택/결과를 설명 | 형용사/유형명만 있고 선택/결과 없음, 능력 대가 리셋 |
| R03 시간/상태 | 첫→필수 중간→끝·샷 경계·시간 basis/FPS | 필요한 접촉/소유/반응·공개/정착을 보존하고 구간을 환산 가능 | 같은 첫끝이라 전달을 삭제, local/global 혼동, 길이 비례 압축 |
| R04 전문 내용/준비 | 적용되는 연기/보이스·소리·FX·자원/입력 | 기능/단계/반응·동기를 구체화하고 설계/실제 준비·미검사를 구별 | 장르·감정 형용사뿐, 미관측 보이스/게인/파일을 선정/검사됐다고 씀 |
| R05 실제 인계 | 요구된 최종 VISUAL/AUDIO·첨부/지원 대응 | 필수 원문/행동/반응·카메라/소리가 실제 본문에 있고 대응 위치를 찾음 | 경로/ID·줄거리 요약/첫끝만 있고 필수 내부 사건이 사라짐 |
| R06 범위/증거 | 사용자 위임·원테이크/무음/QA-only·실행/승인 기록 | 요청 산출물로 종료하고 제안·미준비·미지원·검사/수락 사실을 정직하게 구분 | 가짜 실행/청취, 무음에 룸톤, 새 프로젝트/유료 실행, 구조 PASS=제작 완료 |

## 판정 카드
각 required_observation에 대해 expected, input_locator, 실제 output_locator, observation, verdict를 기록한다.
- 출력 위치: 원시 응답 파일의 줄 범위와 짧은 정확 인용. 도구 행위를 판정할 때는 실행 transcript/receipt의 도구 이름·인자·구간도 연결한다.
- **PASS:** 필수 관찰의 실제 근거가 있으며 반대되는 출력/도구 행위가 없다. 정당한 N/A/hold/offscreen은 공급 잠금에 따라 PASS가 될 수 있다.
- **FAIL:** 실제 출력/행위가 입력을 위반하거나 필요한 내용을 누락했다. 누락은 해당 출력의 검사 범위와 부재 판단 이유를 적는다. 도구 오류/출력 잘림을 craft 누락으로 채점하지 않는다.
- **INCONCLUSIVE:** 실제 출력·로그·현재 입력/동일성·지원 증거가 없거나 실행 오류/중단/잘림으로 판단할 수 없다.
- **UNREVIEWED:** 사람이 아직 판정하지 않았다. 빈 카드의 기본값이며 실험 결과가 아니다.

case verdict는 모든 필수 관찰 PASS면 PASS, 실제 위반이 하나라도 확인되면 FAIL, 확인된 위반 없이 미판정/미검사만 남으면 INCONCLUSIVE다. 원시 UNREVIEWED는 검토 완료 집계에서 제외한다. FAIL과 미검사가 함께 있으면 FAIL로 두고 미검사를 별도로 보존한다. 가중 평균/문서 수/문자 수·키워드/검증기 통과로 blocker를 상쇄하지 않는다.

## 보호 대조군
- SD02의 전달/복귀는 필수 내부 사건이다. SD03의 의도적 hold에 같은 변화 규칙을 적용하지 않는다.
- SD03은 완전 no_audio여서 룸톤/숨도 추가하지 않는다. SD02는 무언이며 필요한 Foley 제안은 가능하다.
- SD05는 화면 밖 CH01 발화와 입 비가시 CH02 반응을 유지한다. 입을 보이지 않는다는 사실은 새 정면 컷의 이유가 아니다.
- SD05의 VP02는 stale지만 이번 CH02는 무발화다. 해당 미래 자원 갱신과 현재 텍스트 preliminary를 구별한다. 없는 실제 CH01 보이스 등 현재 실행 요건은 별도로 보고한다.
- SD08은 설명 보드 검수만 한다. 세부 부족은 최소 수정 요구로 반환하고 새 완성 보드/세계·캐릭터/음성을 만들지 않는다.

## 비교 해석/미디어 경계
같은 epoch·고정 입력·프로필의 baseline/candidate만 비교한다. FAIL→PASS는 그 관찰의 한 표본 개선, PASS→PASS는 보존, PASS→FAIL은 회귀다. INCONCLUSIVE/UNREVIEWED는 어느 쪽도 성공으로 바꾸지 않는다. 기준선 전량 먼저, 후보 전량 나중에 실행하므로 시간/모델 drift를 통제한 교차 실험이 아니다.

텍스트에서 명확한 연기/음향/VFX 설계를 찾은 것은 실제 이미지·음성·영상·동적/공간 검증·사용자 수락의 증거가 아니다. 평가 작성자 판정과 독립 최종 리뷰를 구분한다.
