# C2 추가 수락 — 승인 B의 샷별 통합 조회 인터페이스

기존 E1/E2 사용자 입력과 43개 원래 관찰은 바꾸지 않는다. 이 문서는 원래 승인 spec §9와 독립 리뷰의 미구현 지적을 직접 검사하는 **별도 인터페이스 수락**이며, C2 편집·생성 전에 고정한다. 생성자에게 이 기준/기존 결과를 주지 않는다.

## 단위와 조건

각 최종 사례에 아래 한 관찰을 덧붙인다. 기존 43개 관찰의 점수·의미를 바꾸거나 합산해 원래 실패를 숨기지 않는다.

| 관찰 | 적용 | PASS에 필요한 실제 내용 |
|---|---|---|
| SD09-X1 | 전체 제작용 보드 | 모든 샷에서 아래 통합 조회 내용을 실제로 읽을 수 있고, 소품의 손/점유·받침/수용 위치가 첫/중간/끝·패널 이미지 지시·실제 요청문과 일치한다 |
| SD10-X1 | 전체 제작용 보드 | 모든 샷의 통합 조회에 능력 조건/지지·접촉/진행/대가와 잔류·환경/효과/소리·자원/검수가 같은 시간 기준으로 연결된다. 무발화에는 사유 있는 N/A |
| SD11-X1 | 전체 제작용 보드 | 한 고정 샷의 통합 조회 안에서 관계/공개 근거·발화/반응·고정 음성/이번 연기·공간 밖 화자/시각 립싱크 N/A·소리/자원·검수를 읽을 수 있다. 컷/얼굴 공개 추가 없음 |
| SD12-X1 | 전체 제작용 보드 | 모든 샷에서 소리의 원인/인지→반응→얼굴 공개의 상태·큐/시간·자원/검수를 통합 조회할 수 있다. 발화/보이스를 만들지 않는다 |
| SD14-X1 | 전체 제작용 보드 | 모든 샷에서 세계 규칙/인물 선택과 비용·기억/통과 효과·발화/반응·소리·잔류/자원/검수가 실제 내용으로 연결된다 |
| SD03-X1 | 좁은 텍스트 샷 명세 | 원래의 정적/무음/원테이크·미배정 ID/무실행을 보존한다. 확대 보기 때문에 전체 세계·캐릭터·패널·요청문 패키지로 확장하지 않는다 |
| SD08-X1 | QA-only | 통합 명세/상태 역대조 기준을 점검·최소 수정 요구로만 쓰고 새 완성 보드/대본·발화/파일/실행을 만들지 않는다 |
| SD13-X1 | 잠긴 기존 보드 인계만 | 기존 표와 PERF_PACKET을 소비하며 새 확대 보드·인물/관계/외형·샷·자원 원장을 작성하거나 기존 입력을 재작성하지 않는다 |

## 통합 조회의 의미

필요한 내용을 기존 보드의 전체 샷 명세 안에서 **해당 샷 확대 보기 + 실제 내용을 담아 적용을 명시한 공통 블록**으로 조회한다. 열 구획은 입력과 목적 / 첫 프레임 / 내부 사건 / 마지막 프레임과 연결 / 화면·카메라·공간 / 발화·연기 / 사운드 / VFX·조명 / 필요한 자원 / 프롬프트·검수다.

- 해당 샷에 작용하는 실제 세계 규칙·인물의 목표/판단과 원문/오너 version·locator를 소비한다. 링크/ID 목록만으로 대체하지 않는다.
- 첫→필수 중간→끝/다음 연결의 점유·손·받침/수용 위치, 자극/인지·선택·반응·접촉/공개·정착이 구간과 함께 구체적이다. 의도적 hold와 미사용 전문 항목은 사유 있는 N/A로 유효하다.
- 필요한 카메라/정체성/말투/발화 연기·소리/효과의 실제 내용과 자원 상태·실제 제출문/검수 위치를 찾을 수 있다. 공통 블록 재사용은 내용과 적용 샷/요청에 포함됨이 명시돼야 한다.
- 세계/캐릭터·목소리·룩 등의 정본을 보드에서 독립 변경하지 않는다. 새 제작 JSON key/enum/전역 원장·실행·파일을 요구하지 않는다.
- 표현 형식은 표/짧은 항목 블록 모두 가능하다. 제목 열 개 존재, 문서 길이, 키워드 개수는 PASS 근거가 아니다. 실질 내용이 여러 전역 표에 흩어져 실행자가 다시 합쳐야 하면 이 인터페이스는 미충족이다.

## 기준판과 정직성

C1의 43개 작성자/독립 판정과 원시 응답은 그대로다. 추가 X1은 원래 spec의 미구현 인터페이스를 확인하는 후속 수락이며 **사후 추가된 기존 창작 품질 점수**로 사용하지 않는다. C1 전체 보드 다섯 응답에는 여러 전역 표/캐릭터·연기 표와 별도 전체 요청문이 있으나, 해당 샷과 실제 공통 내용으로 묶은 확대 보기는 없었다. 독립 리뷰도 06 템플릿의 부재를 확인했다. 이 인터페이스 RED와 SD09의 실제 위치 불일치를 C2의 수정 근거로 보존한다.

C2에서는 동일한 최종 8입력/프로필을 새 소스에서 각 한 번 실행하고 원래 43개 기준과 X1 여덟 개를 **별도** 판정한다. 실패 원문/오류를 덮거나 재추출하지 않는다. 새 이야기는 허용되며 옛 이야기의 실패가 소급해서 수정된 것은 아니다. 실제 미디어/청취/물리·공급자 지원/권리·사용자 수락은 이 텍스트 수락으로 인증하지 않는다.
