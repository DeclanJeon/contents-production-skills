# 풍자 서사 구조

풍자는 조롱이 아니라 **구조**다. 같은 상황이 심해지다가 터지는 문법이 있어야 웃기고, 그 문법이 무성에서도 읽힌다.

## 소재 → 풍자 대상 변환

### 원칙

원본을 **재현하지 않는다**. 추출하는 것은 장면이 아니라 **행동 패턴**이다.

| 원본 | 재현 (금지) | 추출 (허용) |
|---|---|---|
| "자판기를 속이는 법" | 자판기 튜토리얼을 다시 그림 | "돈만 삼키는 기계"라는 행동 |
| "1가지 방법으로 모든 문제 해결" | 그 방법을 설명 | "만능인 척하는 한 단계 해법" |
| "추격전" | 추격 장면 복사 | "목표에 절대 닿지 않는 끝없는 추격" |

### 저작권 경계

- 원본 미디어 **다운로드 금지**
- 사용 가능: 제목, 조회수, 길이, 게시일
- 사용 금지: 영상 프레임, 오디오, 캐릭터 디자인
- 풍자 대상은 **행동 한 줄**로 환원한다 (예: "코인을 전부 삼키는 기계")

### 규모 기준

| 지표 | 최소 | 의미 |
|---|---|---|
| 조회수 | 1,000,000 | 이미 대중이 아는 소재 |
| 원본 길이 | ≤ 300초 | 숏폼 문법이 검증된 소재 |

기준 미달 소재로는 제작하지 않는다. 후보 0건이면 `NO_SOURCE`로 종료하는 것이 정상 동작이다.

## 4막 구조

```
setup → escalate → punchline → resolve
```

### setup (약 40~50%)

목표: **상황과 규칙을 3초 안에 세운다.**

- `notice`: 문제 오브젝트 발견, 경악
- `run`: 목표를 향해 출발
- `trip`: 첫 실패 (규칙 학습)

첫 실패에서 관객은 "이 세계에서는 이게 문제다"를 배운다. 이 학습이 없으면 이후 반복이 무의미하다.

### escalate (약 35~40%)

목표: **같은 시도를 더 크게 반복한다.**

- `run`/`trip` 반복
- 매 회차 변주 축 1개 이상 증가
- 실패의 **원인이 다양해져야** 한다 (속도 문제 → 장애물 문제 → 크기 문제)

변주 축 순환 순서:

```
speed → obstacles → scale → direction → (speed 심화) → ...
```

같은 축을 심화할 때는 이전 값보다 반드시 커야 한다. 축이 다시 돌아올 때 값이 초기화되면 관객은 "되감기"로 읽는다.

### punchline (약 15~20%)

목표: **최대 시도 → 최대 실패.**

- `dive`: 최후의 시도 (전력)
- `trip`: 절정의 실패
- 카메라를 좁힌다 (`close`/`whip`) — 시선 집중

펀치라인은 **한 번**이다. 여러 번 터뜨리면 펀치라인이 아니라 소음이 된다.

### resolve (약 5~10%)

목표: **해소.**

- `land`: 착지/정지
- 카메라를 넓힌다 (`wide`)
- 원래 상태로 돌아감

## 무성에서의 서사 전달

대사가 없으므로 다음 세 가지가 서사를 대신한다:

| 수단 | 역할 | 예 |
|---|---|---|
| **동작** | 의도 | 달린다 = 목표가 있다 |
| **표정/포즈** | 감정 | 경악 포즈 = 문제 인식 |
| **반복 강도** | 긴장 | 장애물 3개 → 5개 |

### 읽히지 않는 서사

- 두 인물이 서로 대화하는 장면 (대사 없이는 관계를 알 수 없음)
- 과거 회상 (전환이 무성에서 모호함)
- 아이러니한 해설 (설명자가 없음)

무성 풍자는 **1인칭 단일 목표**가 가장 안전하다. 인물이 하나이고 목표가 하나이면 대사 없이도 서사가 성립한다.

## 서사 밀도 계산

10분 무성물에서 "늘어짐"은 서사의 문제가 아니라 **밀도**의 문제다.

```
비트 수 = 총 길이 ÷ 평균 비트 길이

늘어짐 지표: 같은 (동작, 변주) 조합이 3회 이상 연속
```

### 예시 배분 (390초 기준)

| 막 | 비트 수 | 예상 시간 |
|---|---|---|
| setup | 50 | ~180초 |
| escalate | 31 | ~130초 |
| punchline | 8 | ~60초 |
| resolve | 1 | ~5초 |

setup이 절반을 차지하는 이유: 규칙을 세우는 데 시간이 걸리고, escalate는 이미 세운 규칙을 가속하므로 짧아도 된다.

## 안티패턴

| 안티패턴 | 왜 문제인가 |
|---|---|
| 클라이맥스 여러 번 | 펀치라인 희석 |
| 변주 없이 동작만 반복 | "고장난 영상" |
| 3막(해소 없음) | P6 위반, 완시청 방해 |
| 여러 인물의 관계극 | 무성에서 전달 불가 |
| 소재를 조롱하는 텍스트 | P2 위반 (자막 금지) |
| 원본 장면 재현 | 저작권 위험 |

## 검증

```
1. satire_target 이 "행동" 문장인가 (장면 설명이 아닌가)
2. 4막이 모두 존재하는가
3. 첫 비트 notice, 마지막 비트 land
4. 반복 동작 3회 이상 + 변주 단조 증가
5. 펀치라인이 한 곳에 집중되는가
6. 원본 미디어 다운로드가 없었는가
```
