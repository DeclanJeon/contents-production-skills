# 무성 애니메이션 원칙 (P1~P6)

이 문서는 `silent-satire-animatic`의 로컬 반복 개그 계약이다. 아래 무자막·BGM·`notice`→`land`·시간 제약은 이 레시피에만 적용하며 일반 무성 서사의 정의나 관객 반응 보장이 아니다. 일반 작업의 대사·오디오·자막 조건은 독립이다.

## 정의

**무성 = 인간 발화의 부재.** 소리의 부재가 아니다.

| 허용 | 금지 |
|---|---|
| 배경 음악 (BGM) | TTS, 보이스 클론 |
| Foley / 효과음 (SFX) | 내레이션, 대사 |
| 캐릭터 비언어 음 (합성) | 화면 자막, 말풍선 텍스트 |

### 왜 완전 무음이 아닌가

유튜브는 무음 자동재생 환경에서 소비된다. 이 사실은 두 가지 상반된 결론을 만든다:

1. **소리에 의존하면 안 된다** → 대사·내레이션은 이탈을 부른다
2. **완전 무음도 안 된다** → 오디오 스트림이 없거나 정적이면 "고장난 영상"으로 판정될 수 있다

따라서 해법은 **저음량 지속 BGM + 짧은 SFX**다. 정보를 소리가 아니라 화면이 전달하고, 소리는 리듬만 만든다.

### 자막 금지의 이유

대사가 없으면 자막으로 설명하려는 유혹이 생긴다. 그러나:

- 자막은 "무성" 분류를 깨뜨린다 (화면에 언어 정보가 있음)
- 무성 콘텐츠는 언어권을 넘어 소비된다. 자막은 그 장점을 버린다
- 자막은 시선을 화면 하단에 고정시켜 동작 읽기를 방해한다

**예외는 썸네일의 제목 텍스트뿐이다.** 본편 프레임에는 어떤 글자도 그리지 않는다.

## P1. 첫 3초에 상황이 읽힌다

알고리즘은 초기 이탈률로 품질을 판정한다. 무성 콘텐츠는 설명이 없으므로 첫 컷만으로 "무엇이 문제인지"가 보여야 한다.

**강제**
- 첫 비트 동작은 `notice` (발견/경악)
- 첫 비트 길이 ≤ 3.0초
- 첫 비트에 등장인물 1명 + 문제 오브젝트 1개가 **동시에** 프레임 안에 있음
- 로고/타이틀/블랙 컷으로 시작 금지

**검증 방법**
```
timeline.cuts[0].action == "notice"
timeline.cuts[0].end_s <= 3.0
```

**흔한 실패**: 오프닝에 풍경이나 로고를 넣어 분위기를 잡으려는 시도. 무성에서는 그 3초에 아무 정보가 없어 이탈한다.

## P2. 무성은 대사의 부재다

위 "정의" 절이 정본이다. 구조적으로 강제하는 방법:

```json
{
  "silent": true,
  "dialogue": [],
  "captions": []
}
```

세 필드를 **계약**으로 두고 검증 함수가 위반 시 예외를 던진다. 문서 규칙이 아니라 코드 규칙이어야 지켜진다.

**흔한 실패**: "설명이 필요할 것 같아서" 자막을 한 줄 넣는 것. 그 한 줄이 분류를 바꾼다.

---

## P3. 반복 강화 → 펀치라인

풍자는 "같은 상황이 점점 심해지다가 터진다"는 구조에서 나온다.

**강제**
- 동일 동작이 **3회 이상** 반복됨
- 매 회차 변주 축 중 **최소 1개 증가**
- 반복 구간 뒤에 펀치라인 비트(`trip` 또는 `dive` + 클라이맥스) 필수
- 변주 없는 동일 비트 **2회 연속 금지**

**변주 축 단조성**

| 축 | 단조 증가? | 비고 |
|---|---|---|
| `speed` | 예 | 1.0 → 3.0 |
| `obstacles` | 예 | 0 → 5 |
| `scale` | 예 | 0.6 → 1.6 |
| `direction` | **아니오** | ±1 토글. 단조성 검사 제외 |

`direction` 을 단조성 검사에 넣으면 좌우 반전이 "후퇴"로 판정되어 오탐이 난다.

**검증 방법**
```
동일 action 반복 시 (speed + obstacles + scale) 합이 이전보다 작으면 위반
repeats >= 3
```

## P4. 비트 길이는 8초를 넘지 않는다

무성 콘텐츠는 시선을 붙잡을 대사가 없다. 8초를 넘기면 "아직 같은 장면인가?"가 된다.

**강제**
- 단일 비트 ≤ 8.0초
- 권장 평균 4~6초

**현재 로컬 비트 예산**

```
비트 수 = 총 길이 ÷ 평균 비트 길이
총 길이 85~120초, 비트 수 22~32
```

과거 600초·90~120비트 설계는 현행 권장이 아니다. 현재 예산은 `03-beat-budget.md`를 따른다.

## P5. 썸네일은 영상의 가장 강한 프레임이다

무성 영상의 썸네일은 유일한 언어-free 훅이다.

**강제**
- 0초 프레임 캡처 금지 (오프닝 포즈는 가장 약하다)
- 펀치라인 비트에서 캡처
- **wide 또는 medium 샷**에서 캡처 (클로즈업 금지)
- 본편과 동일 종횡비 (9:16이면 1080×1920)
- 캡처 실패 시 **릴리스 생성 중단**

### 클로즈업 금지의 이유

샷 배율과 변주 배율이 곱해진다:

```
close (2.2) × variation.scale (1.6) = 3.52배
```

3.5배 확대에서는 인물의 머리와 어깨만 남아 "무엇을 하는지"가 사라진다. 썸네일의 목적은 미적 클로즈업이 아니라 **상황 전달**이다.

**결합 배율 상한**: 샷×변주 곱을 2.0으로 클램프한다. 그래야 wide/medium 에서도 인물이 프레임을 벗어나지 않는다.

**검증 방법**
```
ffprobe 썸네일 → width x height == 배포 규격
캡처 시점의 활성 컷 camera.shot ∈ {wide, medium}
```

## P6. 로컬 85~120초 + 완결 구조

**이 파이프라인의 강제**
- 총 길이 85~120초
- 마지막 비트는 `land` (해소)

**왜 완결이어야 하나**

미해결 종료는 "다음 편 보기"를 유도하는 기법이지만 무성 풍자에는 부적합하다:

- 무성에서는 미해결 상태를 해석할 단서가 없다
- 알고리즘은 완시청률을 본다. 미해결은 완시청을 방해한다
- 풍자는 "터지고 정리된다"가 완성형이다

## 통합 검증 순서

렌더 전에 이 순서로 검사한다. 위에서 실패하면 아래는 의미가 없다.

```
1. silent == true, dialogue == [], captions == []
2. 첫 비트 notice, ≤3.0초
3. 마지막 비트 land
4. 총 길이 85~120초
5. 비트 수 22~32 (각 비트 최소 2초)
6. 단일 비트 ≤ 8.0초
7. 반복 3회 이상 + 변주 단조 증가
8. articulation 4 hinge 중 2개 이상 > 0.2 rad
9. 썸네일 규격 + 가독 샷
10. BGM 폴백 사유 기록
```
