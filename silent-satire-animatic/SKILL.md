# Silent Satire Animatic

무성(無聲) 풍자 애니메틱의 제작 계약. "무성"은 **인간 발화의 부재**를 뜻하며 소리의 부재가 아니다.

## 경계

| 다룸 | 다루지 않음 |
|---|---|
| 무성 원칙과 판정 | 실제 렌더 실행 |
| 풍자 서사 구조 | 유튜브 게시 |
| 소재 선별 기준 | LLM 이미지/영상 프롬프트 생성 |
| 비트 예산 계산 | 음성/TTS 생성 |
| 썸네일 프레임 선택 | 저작권 법률 판단 |

## 언제 쓰는가

- "무성 애니메이션 만들어줘" / "대사 없는 애니메틱"
- 인기 소재를 풍자하는 콘텐츠 기획
- 기존 무성 편집물이 시선을 붙잡을지 검토
- 2분 이내 무성 애니메틱의 비트/컷 배분

## 무성 원칙 (P1~P6)

정본은 `references/01-silent-principles.md`다. 요약:

| # | 원칙 | 강제 |
|---|---|---|
| P1 | 첫 3초에 상황이 읽힌다 | 첫 비트는 `notice`, ≤3.0초, 인물+문제 오브젝트 동시 등장, 로고/타이틀 컷으로 시작 금지 |
| P2 | 무성은 대사의 부재 | BGM/SFX/비언어 음 허용. TTS·내레이션·대사·자막·말풍선 금지 |
| P3 | 반복 강화 → 펀치라인 | 동일 동작 3회 이상 반복, 매 회차 변주 축 1개 이상 증가, 이후 펀치라인 필수 |
| P4 | 비트는 8초를 넘지 않는다 | 단일 비트 ≤8.0초, 평균 4~6초 |
| P5 | 썸네일은 가장 강한 프레임 | 0초 캡처 금지, 펀치라인의 가독 샷(wide/medium), 본편과 동일 종횡비, 실패 시 릴리스 중단 |
| P6 | 2분 이내 + 완결 | 총 85~120초, 마지막 비트는 `land`(해소). 무성은 롱폼에 부적합 |
| P7 | 캐릭터 시트를 실제로 쓴다 | 공급된 캐릭터 팩을 로드해 팔레트·실루엣·파츠를 적용. 팩 누락 시 기본 도형 폴백 금지, 중단 |
| P8 | 이미지 자산은 이미지 생성 스킬 | 시트·썸네일은 `codex-imagen`. SVG/도형 대체 금지. 단 프레임 관절 렌더는 코드 허용 |

## 제작 순서 (7단계)

```
소재 선택 → 대본 → 씬/컷 → 캐릭터 배정 → 타임라인 → 렌더 → 게이트/배포
```

**캐릭터 배정**은 타임라인 앞에 온다. 팔레트·실루엣이 렌더에 영향을 주므로, 그 뒤에 바꾸면 전체 재렌더가 필요하다. 정본은 `references/05-character-assets.md`다.

각 단계는 검증 가능한 산출물을 남긴다. 상위 단계 실패 시 하위로 진행하지 않는다.

### 1. 소재 선택

인기 규모를 실제 지표로 확인한 소재만 쓴다. 원칙:

- 조회수와 길이를 **실측 지표**로 검증 (추정·추측 금지)
- 원본 미디어는 다운로드하지 않는다. 제목·지표·길이만 사용
- 풍자 대상은 **행동/현상**을 추출한다. 원본 재현이 아니다
- 후보 0건이면 제작하지 않고 `NO_SOURCE`로 종료

### 2. 대본

4막 구조 (`setup → escalate → punchline → resolve`). 정본은 `references/02-satire-structure.md`.

- `silent: true`, `dialogue: []`, `captions: []` 를 구조적으로 강제
- 첫 비트 `notice`, 마지막 비트 `land`
- 결정적(deterministic) 조립을 우선한다. 같은 소재 → 같은 대본
- LLM 대본을 쓸 경우 재현 불가를 명시하고 시드를 고정한다

### 3. 씬/컷

- 컷 1개 = 동작 1개 = 연속 구간
- 같은 동작이 반복되면 변주 축(`speed`/`obstacles`/`scale`/`direction`) 중 하나 이상이 증가
- `direction` 은 증가 축이 아니라 **토글 축**이다. 단조성 검사에서 제외한다
- 카메라 샷은 `wide`/`medium`/`close`/`whip`, 팔로우는 `static`/`track`/`whip`

### 4. 타임라인

정본은 `references/03-beat-budget.md`.

- 총 길이 **85~120초** (P6: 무성은 롱폼 부적합)
- 비트 경계는 프레임에 정렬
- 비트 수 **22~32**
- 비트 하나는 최소 2초 — 그보다 짧으면 동작으로 인지되지 않는다

### 5. 렌더

이 스킬의 범위 밖이다. 호출자는 다음을 요구받는다:

- 관절 articulation 증거 (영수증)
- 썸네일 해상도·샷 검증
- 중간 산출물 정리 정책

### 6. 게이트/배포

- 자동 공개 금지. `publication_ready=false` 로 렌더하고 검수 후 전환
- 중간 산출물은 게시 + 드라이브 저장 확인 **후** 삭제

## 비트 예산 계산

```
비트 수 = 총 길이 ÷ 평균 비트 길이
제약: 평균 비트 길이 ≤ 8초 (P4)
      비트 수 22~32
      총 길이 85~120초

120초 ÷ 4초 = 30비트   (상한 근처)
85초 ÷ 3.9초 = 22비트   (실측 기본값)
```

비트 수를 먼저 정하고 길이를 맞추지 말 것. **길이가 먼저, 비트 수가 결과**다.

**롱폼 이력**: 90~120비트는 10분을 채우기 위한 값이었고, 그 설계로 만든 6분 29초 버전은 집중이 유지되지 않았다. 문서 기록은 `references/03-beat-budget.md` 참조.

## 변주 축

5개 기본 동작(`notice`/`run`/`trip`/`dive`/`land`)만으로 120초를 채우면 같은 장면이 20회 이상 반복된다. 변주 축이 이를 막는다.

| 축 | 범위 | 시각 효과 |
|---|---|---|
| `speed` | 1.0~3.0 | 위상 압축, 빠른 동작 |
| `obstacles` | 0~5 | 장애물 개수 증가 |
| `scale` | 0.6~1.6 | 인물 크기 |
| `direction` | ±1 | 진행 방향 반전 (토글) |

**잘림 방지**: 배율 상한만으로는 부족하다. 샷 배율 × 변주 배율이 곱해지고 확대는 캔버스 중앙 기준으로 일어나므로, 원래 중앙에서 벗어난 포즈(`land` 등)는 상한을 걸어도 프레임 밖으로 밀려난다.

필수 보정:
```
1. 결합 배율을 2.0으로 상한
2. 확대 후 실제 조인트 경계 계산
3. 스트로크 폭 보정 (머리 반지름 + 손 반지름) × 배율
4. 24px 마진 밖으로 나가면 dx 재정렬
```

**조인트 중심만 검사하면 안 된다.** 머리 원이 조인트 밖으로 뻗으므로 마진을 지켰는데도 그려진 픽셀이 8px까지 나가는 경우가 있다. 검증은 렌더된 픽셀 스캔으로 한다.

## 스테이징 (2.36 연동)

상위 `video-production-assets` 2.36 계약의 스테이징 규칙을 무성 애니메틱에 맞게 적용한다.

| 2.36 필드 | 무성 애니메틱 적용 |
|---|---|
| `focal_hierarchy` (3단 깊이) | ① 전경 장애물(가깝고 큼) ② 인물 행동면 ③ 배경 맥락(지면 흔적·잔류 상태) |
| `kinetic_cues` | 액션 피크에 수직 기립 정지자세 금지. 무게중심 이탈·동세선 유지 |
| `expression_pose` | 얼굴이 단순화된 스틱맨은 눈·입 상태(정지/놀람/충돌)로 대체하고 라벨만 쓰지 않는다 |
| `image_prompt` (KO/EN) | 해당 없음 (이미지 생성 단계가 아니라 결정론적 래스터 렌더) |

**깊이 3단 구현 요점**: 장애물을 하나의 평면에 나열하면 평면적으로 읽힌다. 인덱스를 깊이 밴드로 나누어 가까운 것일수록 크고 낮게, 먼 것일수록 작고 높게 배치하고 채도를 낮춘다.

**주의**: 이 스테이징을 레거시 짧은 포맷에 적용하면 기존 출력이 바뀐다. 스테이징은 해당 프레임이 카메라/변주 축을 가질 때만 적용하고, 없을 때는 원본과 바이트 동일해야 한다.

## 썸네일

정본은 `references/04-thumbnail-selection.md`.

- 펀치라인 비트의 **wide 또는 medium** 샷에서 캡처 (클로즈업 금지 — 상황이 안 읽힘)
- 본편과 동일 종횡비, 배포 해상도
- 캡처 실패는 **치명적**. 무시하고 진행하지 않는다
- 대상 0초 프레임(오프닝 포즈)은 가장 약한 프레임이다

## BGM

무성이므로 BGM이 유일한 청각 안내다.

- 라이선스 검증된 풀에서 선택하되, 부재/부적합 시 **합성 폴백**
- 저작자 표시 필요 곡은 쓰지 않는다 (설명란에 표기할 자리가 없다)
- 폴백 사유를 기록한다. 조용히 넘어가지 않는다
- 폴백 판정은 기계적이어야 한다: 풀 없음 / 적격 없음 / 파일 불가 / 길이 판독 실패 / 30초 미만

## 안티패턴

| 안티패턴 | 문제 |
|---|---|
| 자막으로 상황 설명 | 무성 원칙 위반. P2 |
| 클로즈업 썸네일 | 상황이 안 읽혀 CTR 하락. P5 |
| 롱폼(6~10분) 무성 | 대사가 없어 집중 유지 불가. 6.5분 실측으로 확인됨 |
| 초당 1.3컷 (120초에 90비트) | 동작이 인지되지 않음. 깜빡임으로 읽힘 |
| 변주 없는 반복 | "고장난 영상"으로 보임. P3 |
| 원본 영상 재촬영 | 저작권 위험. 풍자 대상은 행동이지 장면이 아니다 |
| BGM 크롤링 자동화 | Content ID 청구 위험. 로컬 검증 풀을 쓴다 |
| 썸네일 실패 무시 | 배포 불가 산출물이 통과됨 |

## 검증 체크리스트

- [ ] `silent: true`, `dialogue == []`, `captions == []`
- [ ] 첫 비트 `notice` ≤3초
- [ ] 마지막 비트 `land`
- [ ] 총 길이 85~120초
- [ ] 비트 수 22~32
- [ ] 비트 최소 길이 ≥2초
- [ ] 단일 비트 ≤8초
- [ ] 동일 동작 3회 이상 + 변주 증가
- [ ] 관절 articulation 증거 통과
- [ ] 썸네일 펀치라인 프레임, 정확한 종횡비
- [ ] BGM 폴백 사유 기록 (폴백 시)
- [ ] 캐릭터 팩을 실제로 로드했고 팩 폴백이 아님
- [ ] 렌더 프레임의 인물 색·실루엣이 팩 정의와 일치
- [ ] 제목이 팩 `title_template` 을 사용
